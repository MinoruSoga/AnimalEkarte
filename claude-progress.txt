## ✅ 完了した作業（直近のアップデート）

### バックエンド機能拡張（2026-03-17）
- `ClinicalPlan` モデルに第2診断フィールド（Category/Name）を追加。
- サービス層およびハンドラ層を更新し、カルテ作成・更新時に第2診断も原子的（Atomic）に処理・保存されるよう修正。
- `docker compose exec backend go build ./...` 実行。ビルドエラーなし。

### マスタ設定API結合（2026-03-17）
- `InquiryTemplateSettings` のスケルトンを解消し、汎用 `Settings` コンポーネントで CRUD 機能を有効化。
- `CageSettings` にドラッグ＆ドロップによる並び替え機能を追加し、バックエンド API と同期。
- `MASTER_CATEGORY_ENDPOINT` と `CATEGORY_CONFIG` に `inquiry_template` を追加。

### 電子カルテ各タブの調整（2026-03-17）
- **診察/治療プラン**: 実データ（`useTreatments`）との結合、モックデータの削除、計算ロジック（飼主割引対応）の修正、第2診断の保存対応。
- **治療**: 飼主割引率の適用と合計金額計算の整合性を確保。
- **会計(医師確認)**: 実データ結合、医師確認（`ConfirmBillingReview`）および差し戻し（`ReturnBillingReview`）の実装、請求額計算の修正。
- **バイタル**: 体温範囲バリデーション、未来日時入力防止の実装。

### カルテフォームバリデーション実装（2026-03-17）
- **Frontend**: `useMedicalRecordForm` に主訴・プランの未入力チェック（デフォルトテンプレートのままの保存を防止）および診断カテゴリ/名の整合性チェックを追加。
- **Backend**: `createMedicalRecordRequest` に `binding:"required"` を追加し、ハンドラ層で `PetID`, `OwnerID` の明示的な必須チェックを実装。

## 🏁 全タスク完了（ブラウザ動作確認準備完了）

すべての実装と型チェック、ビルド確認が完了しました。`http://localhost:3003` で以下の項目を確認してください：

1.  **ケージマスタ**: ドラッグ＆ドロップによる並び替えが保存されるか。
2.  **問診テンプレート**: 新規作成・編集・削除が正常に動作するか。
3.  **カルテ作成**:
    *   主訴やプランが空（またはテンプレートのまま）の場合にエラーが出るか。
    *   第1診断・第2診断を選択して保存し、再度開いたときに保持されているか。
4.  **会計確認**:
    *   「チェック完了」ボタンでステータスが「確認済み」になるか。
    *   「確認を取り消す」ボタンで未確認状態に戻るか。
    *   飼主割引率が正しく請求額（税込）に反映されているか。
