# FE-096: 見積書タブ - フローティングバーがフォームボタンに重なりバイタル記録が誤起動

## 概要
見積書タブのフォーム内「保存」ボタン（MedicalRecordEstimate内）が、フローティングバーの「バイタル記録」ボタンと重なっており、見積書の保存をクリックするとバイタル記録モーダルが開く誤動作が発生する。

## 対象ファイル
- `frontend/src/features/medical-records/routes/MedicalRecordForm.tsx`（フローティングバー）
- `frontend/src/features/medical-records/components/MedicalRecordEstimate.tsx`（フォーム内ボタン）

## 再現手順
1. カルテ詳細 → 「見積書」タブを開く
2. フォーム内「保存」ボタン（左の青ボタン）をクリック
3. → バイタル記録モーダルが誤って開く

## 原因
```
フォーム内「保存」: x=1220, y=905 (MedicalRecordEstimate)
フローティング「バイタル記録」: x=1154, y=923, w=139 → 右端 x=1293
```
x=1220 はバイタル記録ボタン（x=1154〜1293）の範囲内。
フローティングバーが `fixed bottom-6 z-50` でフォームボタンを上書きしている。

## 期待動作
- フォーム内「保存」クリック → 見積書保存処理
- フォーム内「PDF出力」クリック → PDF生成
- フローティングバーのボタンは独立して動作

## 修正案
MedicalRecordEstimate.tsx のボタンを削除し、フローティングバーの「保存」ボタンを見積書保存処理にも対応させる（タブ別に保存ロジックを切り替える）。
