# プロジェクト・アーカイブ (Project Archive)

本ディレクトリには、Animal Ekarte の開発過程で作成された過去の設計資料、刷新前の古いドキュメント、および完了したタスクの記録が保存されています。

> **注意**: これらのドキュメントは歴史的経緯を参照するためのものであり、最新の仕様や規約については `docs/` ルート配下のファイルを参照してください。

---

### 1. タスク・イシュー記録
- **[AGENT_COORDINATION_TRACKER.md](./AGENT_COORDINATION_TRACKER.md)**: 開発初期の AI エージェント間の連携・進捗管理記録。

### 2. 品質・監査記録
- **[FE_CODE_QUALITY_AUDIT_2026-04-23.md](./FE_CODE_QUALITY_AUDIT_2026-04-23.md)**: React 19 移行期におけるフロントエンド品質監査の最終報告。

### 3. 設計・計画（刷新前）
- **[backend-refactor-checklist.md](./backend-refactor-checklist.md)**: バックエンドのクリーンアーキテクチャ導入時の計画書。

## 管理方針
- **不変性**: アーカイブ内のファイルは、原則として内容の更新を行わず、作成時点の情報を維持します。
- **移動**: 最新の仕様から外れたドキュメントは、混乱を避けるため速やかに本ディレクトリへ移動されます。
