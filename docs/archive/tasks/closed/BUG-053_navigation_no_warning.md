# BUG-053: 設定変更中にナビゲーションすると警告なく遷移する

## 概要
病院設定等のフォームで入力中にサイドバーのリンクをクリックすると、
「変更が保存されていません」などの警告なく即座に遷移してしまう（NavigationBlocker未実装）。

## 再現手順
1. 病院設定ページで院長名等を変更
2. サイドバーの「飼主・ペット」等をクリック
3. → 警告なく即座に遷移（変更が破棄される）

## 期待する動作
- 未保存の変更がある場合、ナビゲーション時に確認ダイアログを表示
- 「保存せずに移動」または「キャンセル」の選択肢を提供

## 実装場所
- `frontend/src/features/` の各フォームコンポーネント
- React Router の `useBlocker` を使用した NavigationBlocker を実装
