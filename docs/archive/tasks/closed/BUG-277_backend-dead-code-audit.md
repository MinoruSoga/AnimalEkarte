# BUG-277: バックエンド デッドコード監査

## 概要

backend/ 全ドメインのデッドコード（未使用の関数・型・定数・ファイル）を洗い出した。
発見は3カテゴリに分類される:
1. **実装漏れ**: 基盤は作ったが呼び出し側の組み込みが漏れたもの
2. **デッドコード**: 設計変更やリファクタリングで不要になったもの
3. **スキャフォールド**: 将来の機能拡張用に先行実装されたもの
