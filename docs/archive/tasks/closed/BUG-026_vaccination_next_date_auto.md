# BUG-026: ワクチン次回予定日の自動計算なし

## 概要
ワクチン接種登録フォームで接種日・ワクチン種別を入力しても、
「次回の予定」日付が自動計算されない。手動入力が必要。

## 再現手順
1. `/vaccinations/new?petId=1` にアクセス
2. ワクチン: 混合ワクチン を選択
3. 接種日: 2026-03-30 を入力
4. → 「次回の予定」日付フィールドが空のまま（自動計算されない）

## 期待する動作
- ワクチン種別を選択すると、該当ワクチンの接種間隔（マスタデータ）に基づいて次回予定日が自動計算される
  - 例: 混合ワクチン（年1回）→ 接種日 + 1年 = 2027-03-30 が自動入力
  - 例: 狂犬病ワクチン（年1回）→ 接種日 + 1年 が自動入力

## 実装場所
- `frontend/src/features/vaccinations/` のフォームコンポーネント
- ワクチン種別選択または接種日変更時に次回予定日を自動計算するロジック追加
- ワクチンマスタの接種間隔データを利用
