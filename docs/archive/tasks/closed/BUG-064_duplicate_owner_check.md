# BUG-064: 重複オーナー登録チェック（部分修正済み・残存NG）

## 概要
オーナー新規登録時の重複チェックが不完全。

## 修正済み（2026-03-30確認）
- **メールアドレス重複**: バックエンドが 409 Conflict を返す ✅
  - エラーメッセージ: "このメールアドレスはすでに登録されています"

## 残存NG

### 1. 電話番号の重複チェックなし
- 同一電話番号で別メールアドレスを使えば登録成功（HTTP 201）
- バックエンドに電話番号 UNIQUE 制約なし

### 2. フロントエンドのエラー表示がそのまま
- 409 Conflict 時に生エラーメッセージが Toast に表示される
  ```
  "owner 'このメールアドレスはすでに登録されています' already exists"
  ```
- ユーザーフレンドリーなエラー表示にすべき
- 重複候補（既存オーナー）へのリンクも表示すべき

### 3. 重複候補UI未実装
- 重複オーナーが存在する場合に「既存オーナーへ移動する」リンクを表示する UI なし

## 再現手順（電話番号重複）
1. `吉田 誠 / 080-7788-9900` が登録済みであることを確認
2. `/owners/new` で 異なるメールアドレス、同一電話番号 `080-7788-9900` で登録
3. → HTTP 201 で登録成功（重複が検出されない）

## 期待する動作
- 電話番号・メールアドレスのいずれかが一致する場合に 409 または警告
- フロントエンドで「この電話番号/メールで既に〇〇さんが登録されています」メッセージを表示
- 既存オーナーページへのリンクを提示

## 実装場所
- Backend: `internal/repository/owner_repository.go` - Create 時に phone unique チェック追加
- Frontend: `features/owners/` - 409 エラー時のハンドリングを `handleApiError` 経由で改善
