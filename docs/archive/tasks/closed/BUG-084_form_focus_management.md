# BUG-084: フォームエラー時の自動フォーカス未実装・モーダル閉じ後のフォーカス戻り未実装

## 概要
以下のフォーカス管理の問題がある:
1. **バリデーションエラー時のフォーカス**: 必須未入力で登録ボタンをクリックしても最初のエラーフィールドへの自動フォーカスなし
2. **モーダル閉じ後のフォーカス戻り**: モーダル close 後 activeElement=BODY（トリガーボタンに戻らない）
3. **サイドパネルのフォーカス**: パネル open 後 activeElement=BODY（先頭フィールドへ移動しない）
4. **DatePicker のキーボード**: Enter/Space で日付確定できない（クリックのみ）

## 期待する動作
- バリデーションエラー時: 最初のエラーフィールドに自動スクロール・フォーカス
- モーダル閉じ後: トリガーボタンにフォーカスを戻す
- パネル open 後: 先頭フィールドにフォーカス
- DatePicker: Enter/Space で日付確定

## 実装場所
- WCAG 2.1 フォーカス管理ガイドラインに準拠
- `frontend/src/components/shared/` のモーダル・サイドパネルコンポーネント
- フォームバリデーション後の `focus()` 呼び出し追加
