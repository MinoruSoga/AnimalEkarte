# BUG-038: カルテ診断タブのドロップダウンがz-index不足で他要素の背面に表示される

## 概要
カルテ編集画面の「診察・治療プラン」タブで、診断カテゴリ・病名のドロップダウンを開くと、
他のUI要素の背面に描画されて操作できない。

## 再現手順
1. カルテ編集画面を開く
2. 「診察・治療プラン」タブをクリック
3. 診断カテゴリドロップダウンをクリックして開く
4. → ドロップダウンが他の要素の背面に表示される

## 期待する動作
- ドロップダウンが最前面に表示され、選択できる

## 実装場所
- `frontend/src/features/medical-records/` の診断セクションコンポーネント
- `z-index` または `position: relative/absolute` の修正
