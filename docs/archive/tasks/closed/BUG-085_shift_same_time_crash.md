# BUG-085: シフト 開始時刻=終了時刻でアプリクラッシュ

## 概要
シフト編集フォームで開始時刻と終了時刻を同じ値（例: 09:00=09:00）に設定して保存すると、
React Error Boundary が発動してアプリがクラッシュする。

## 再現手順
1. シフト管理画面でシフト編集ダイアログを開く
2. 開始時刻 = 09:00、終了時刻 = 09:00 に設定
3. 「保存」をクリック
4. → 「エラーが発生しました / アプリケーションで予期しないエラーが発生しました」画面が表示される（React Error Boundary）

## 期待する動作
- 「開始時刻と終了時刻は異なる値を設定してください」バリデーションエラー表示
- クラッシュしない

## 実装場所
- `frontend/src/features/` のシフト編集フォームコンポーネント
- 保存前に `startTime === endTime` のバリデーションチェックを追加

## 優先度
High（クラッシュのため）
