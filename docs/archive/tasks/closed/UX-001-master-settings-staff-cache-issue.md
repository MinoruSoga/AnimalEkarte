## 問題点と対応策

### 1. スタッフマスタの初回表示キャッシュ問題 ⚠️（要調査）

**現象**: 初回訪問時は 0 件と表示されるが、ページリロード後は正常に 10 件を表示

**確認事項**:
- API `/v1/masters/staffs` は正常に 10 件を返す（ネットワークで確認済み）
- ページリロード後は UI に 10 件が表示される
- React Query hook `useGetStaffs()` の動作は正常

**根本原因の推測**:
1. React Query の初期キャッシュ状態が空である
2. `MasterCRUDPage` マウント時に `data` が `undefined` → 空配列に初期化される可能性
3. その後、React Query が非同期フェッチを開始し、リロード時に UI が更新される

**対応すべき箇所**:
- [ ] `frontend/src/features/master/routes/StaffSettings.tsx:223` の `useGetStaffs()` 戻り値確認
- [ ] `frontend/src/features/master/components/MasterCRUDPage.tsx` の `data` 依存性確認
- [ ] React Query の `initialData` または `placeholderData` の設定検討
- [ ] `useGetStaffs` の `staleTime` / `gcTime` 設定確認（他のマスタと一貫性があるか）

**ビジネス影響**: 中程度（UI が不完全に見えるが、リロードで回復）
