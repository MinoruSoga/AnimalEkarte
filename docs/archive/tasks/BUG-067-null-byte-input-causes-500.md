# BUG-067: NULL バイト・制御文字入力でバックエンドが 500 エラー

## 種類
バグ（バックエンド入力サニタイズ欠如）

## 重要度
中

## 発見日
2026-03-29

## 再現手順

1. 飼主登録フォームで名前フィールドに `テスト\u0000ヌル`（NULL バイト含む文字列）を入力する
2. 「登録」ボタンをクリックする

## 期待動作

- フロントエンドで NULL バイトをサニタイズするか、または
- バックエンドが HTTP 400 Bad Request で `{"error": "名前に無効な文字が含まれています"}` を返す

## 実際の動作

- `POST /api/v1/owners` が HTTP 500 Internal Server Error を返す
- フロントエンドはサニタイズなし
- バックエンドの入力バリデーションが制御文字を処理できていない

## 影響範囲

- 飼主登録・編集フォーム（`/owners/new`, `/owners/:id/edit`）
- NULL バイトを受け入れる任意のテキストフィールド

## 修正方針

### バックエンド
- `owner_service.go` の `Validate()` メソッドで、NULL バイト（`\u0000`）・制御文字を拒否するチェックを追加
- `fmt.Errorf("invalid characters in name: %w", ErrInvalidInput)` で 400 を返す

### フロントエンド（任意・多層防衛）
- `useOwnerForm.ts` の submit 前に制御文字を除去するサニタイズ処理を追加

## 優先度
中（意図的な入力ミスよりも悪意ある入力のリスク）
