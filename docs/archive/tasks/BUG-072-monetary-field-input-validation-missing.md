# BUG-072: 金額・割引率フィールドに入力値制約なし（負の金額・100%超の割引率が入力可能）

## 種類
バグ（フロントエンド + バックエンド — 入力バリデーション欠如）

## 重要度
中

## 発見日
2026-03-29

## 再現手順

### 金額フィールド（負の値）
1. 処置または会計の金額フィールドに `-1000` を入力する
2. 保存ボタンをクリックする

### 割引率フィールド（100%超）
1. 割引率フィールドに `150` （150%）を入力する
2. 保存ボタンをクリックする

## 期待動作

- 金額フィールドに負の値を入力 → フロントエンドでバリデーションエラー（`min=0` 制約）
- 割引率に 100 超の値 → フロントエンドでバリデーションエラー（`max=100` 制約）
- バックエンドでも同様のバリデーションを実施し、違反時は HTTP 400 を返す

## 実際の動作

- 処置・会計の金額フィールドに `min` 属性なし → `-1000` 等の負の値が入力・送信可能
- 割引率フィールドに `max` 属性なし → 100% 超の値が入力可能
- 負の金額・異常な割引率のデータが DB に保存される

## 影響範囲

- 処置タブの金額フィールド
- 会計の金額・割引率フィールド
- 不正データが会計計算・レポートに影響する

## 修正方針

### フロントエンド
- 金額 input に `min={0}` を追加
- 割引率 input に `min={0}` `max={100}` を追加
- バリデーションメッセージを表示する

### バックエンド
- 金額・割引率のバリデーションで `< 0` または `> 100` の場合に `ErrInvalidInput` を返す

## 優先度
中（UI 操作で不正データを保存できる）

## 派生イシュー

| イシュー | 領域 | 内容 |
|---------|------|------|
| BUG-072（FE） | Frontend | 金額フィールド min=0、割引率フィールド max=100 バリデーション追加 |
| BUG-072（BE） | Backend | 金額・割引率の範囲バリデーション追加（負の金額・100%超割引率 → 400） |
