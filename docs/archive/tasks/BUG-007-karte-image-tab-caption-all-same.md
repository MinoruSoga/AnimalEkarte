# BUG-007: カルテ画像タブ - 全画像のキャプションが「画像名」と表示される

## 発見日
2026-03-24

## 発見方法
ブラウザテスト（Chrome DevTools MCP）

## 症状
カルテ詳細画面の「画像」タブを開くと、登録されている全ての画像のキャプション（画像名）が一律「画像名」というプレースホルダー文字列で表示される。実際の画像名が表示されない。

## 再現手順
1. カルテ一覧 (`/medical-records`) を開く
2. 画像が登録されているカルテ詳細を開く
3. 「画像」タブをクリック
4. 全画像のキャプションが「画像名」と表示されることを確認

## 原因の仮説
以下のいずれか：
1. **シードデータの問題**: `001_init.sql` の画像レコードで `caption` または `name` フィールドが全て「画像名」というダミー値になっている
2. **表示ロジックの問題**: フロントエンドで正しいフィールドを参照していない（例: `image.name` の代わりに固定文字列を表示）
3. **API レスポンスの問題**: バックエンドが caption フィールドを返していない

## 影響範囲
- カルテ詳細 > 画像タブ

## 優先度
Low（画像の閲覧自体は可能で、キャプション表示のみの問題）

## 修正方針
1. DB のシードデータを確認し、実際の画像名が正しく格納されているか確認
2. バックエンド API のレスポンスに caption/name フィールドが含まれているか確認
3. フロントエンドの画像キャプション表示コンポーネントが正しいフィールドを参照しているか確認
