# BUG-017: 定期健診ページが「ページが見つかりません」と表示される

## 種類
バグ（ルーティング不具合）

## 発見日
2026-03-24

## 再現手順
1. サイドバーの「定期健診」をクリック、または `/checkups` に直接遷移
2. メインコンテンツエリアを確認

## 期待動作
定期健診の管理画面（一覧または登録画面）が表示される。

## 実際の動作
「ページが見つかりません」と表示され、コンテンツが一切表示されない。
サイドバーでは「定期健診」が選択状態（ハイライト）になっているが、ページ本体は空白のエラー表示のみ。

## 原因調査
`/checkups` ルートがフロントエンドのルーター（`frontend/src/app/router.tsx`）に定義されていないか、対応するページコンポーネントが実装されていない可能性が高い。

## 影響
- 定期健診機能が完全に利用不可（クリティカル）
- サイドバーリンクが存在するにもかかわらずページが表示されない UX 不整合

## 調査対象ファイル
- `frontend/src/app/router.tsx`：`/checkups` ルート定義の有無
- `frontend/src/features/checkups/`：feature ディレクトリの存在確認
