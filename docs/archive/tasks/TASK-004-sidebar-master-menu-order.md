# TASK-004: サイドナビバーのマスタ設定メニュー順序を /settings ページに合わせる

**作成日**: 2026-03-17
**ステータス**: Open
**依頼元**: ユーザー

---

## 概要

サイドバーの「マスタ設定」ドロップダウンメニューの項目順序・グループ構成を、`/settings` ページ（MasterSettingsIndex）のセクション構成に合わせる。

## 依頼内容（原文）

> サイドナビバーの設定マスタの表示を、/settingsページと同じような順序にして。

## 現状の差分

| /settings ページ（目標） | Sidebar（現在） |
|-------------------------|----------------|
| **基本設定**: 医院マスタ, 動物種類マスタ | ❌ 含まれていない |
| **カルテ**: 診療項目 → 診断 → 問診 → 薬剤 | 治療プラン → 薬剤 → 診断 → 問診（順序違い） |
| **診療関連**: 予約区分マスタ | 先頭に配置（順序違い） |
| **入院・ケージ**: 入院 → ケージ | 入院 → ケージ（同じ） |
| **トリミング**: トリミングマスタ | トリミングマスタ（同じ） |
| **スタッフ・保険**: スタッフ → 職種 → 保険 | スタッフ → 保険（職種なし） |
