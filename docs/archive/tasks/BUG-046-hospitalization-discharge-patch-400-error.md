# BUG-046: 退院処理ボタン実行時に PATCH が 400 エラーを返す

## 概要
入院詳細ページ（`/hospitalization/:id`）の「退院処理」ボタンから退院処理を実行すると、
`PATCH /api/v1/hospitalizations/:id` が HTTP 400 を返し「入力値が不正です」トーストが表示される。

## 再現手順
1. `/hospitalization/1` を開く
2. 右上「退院処理」ボタンをクリック
3. 確認ダイアログ「退院処理を行いますか？」が表示される
4. 「退院処理を実行」ボタンをクリック

## 期待動作
- `PATCH /api/v1/hospitalizations/1` → HTTP 200
- ステータスが「退院済」に変更
- 一覧「退院済」タブに移動

## 実際の動作
- `PATCH /api/v1/hospitalizations/1` → **HTTP 400**
- トースト「入力値が不正です」が表示される
- ステータスは変更されない

## 補足
API に直接 PATCH リクエストを送ると 200 成功する：
```json
PATCH /api/v1/hospitalizations/1
{ "status": "discharged", "end_date": "2026-03-28T00:00:00Z" }
→ 200 OK
```
フロントエンドが送信するリクエストボディに問題がある（必須フィールドの欠落またはバリデーション不通過）。

## 影響範囲
- 入院詳細ページの退院処理機能全体
- 退院処理がUIから実行できないため業務フローが完全に阻害される

## 優先度
高（退院処理がUIから実行不可）
