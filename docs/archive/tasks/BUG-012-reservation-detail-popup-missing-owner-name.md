# BUG-012: 予約詳細ポップアップで飼い主名が空欄表示

## 種類
バグ

## 発見日
2026-03-24

## 再現手順
1. `/reservations` に遷移
2. カレンダー上の任意の予約ブロックをクリック
3. 予約詳細ポップアップを確認

## 期待動作
「患者情報」セクションの「飼い主名」フィールドに飼い主名（例: 林 文明）が表示されるべき。

## 実際の動作
「飼い主名」ラベルは表示されるが、値が空欄（空文字）になっている。
a11yツリー上も対応するStaticTextノードが存在しない。

## 原因調査
APIレスポンス（`GET /api/v1/reservations`）には `pet.owner.owner_name` フィールドが含まれている（例: "林 文明"）。
フロントエンドの予約詳細ポップアップコンポーネントが owner_name を正しくマッピング・表示していない可能性が高い。

## 影響
- 予約詳細を確認する際に飼い主が誰か分からない
- 同名ペットが複数いる場合の識別が困難

## 調査対象ファイル
- `frontend/src/features/reservations/` 配下の詳細ポップアップコンポーネント
- 予約データのtransform関数（`transforms.ts`）
