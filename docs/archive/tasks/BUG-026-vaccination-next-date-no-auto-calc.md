# BUG-026: 予防接種フォームの次回予定日自動計算が機能しない

## 種類
バグ（フロントエンド — 次回予定日自動計算未実装）

## 重要度
中

## 発見日
2026-03-28

## 再現手順
1. `/vaccinations/select-pet` でペットを選択して新規登録フォームへ遷移
2. 接種日に任意の日付を入力（例: 2026年3月28日）
3. 「次回予定」のラジオボタン（「4週間後」「3週間後」等）を選択
4. 次回予定日フィールドを確認する

## 期待動作
- ラジオボタンを選択すると、接種日から指定週数後の日付が次回予定日フィールドに自動入力される
- 例: 接種日 2026-03-28 + 4週間後 → 次回予定日 2026-04-25

## 実際の動作
- 接種日入力後にラジオボタンを選択しても次回予定日フィールドが空のまま変化しない
- ラジオボタン選択は表示上は機能している（選択状態が変わる）
- 次回予定日フィールドへの自動入力が行われない

## 影響
- ユーザーが次回予定日を手動計算して入力する必要があり、入力ミスのリスクがある
- UX の悪化（フォーム設計上、自動計算が期待される）

## 修正方針
### フロントエンド
- `features/vaccinations/hooks/` のフォームフックでラジオボタン変更時のハンドラを実装
- 接種日 (`date`) と選択された間隔（週数）から次回予定日を計算
- `date-fns` の `addWeeks()` または `addDays()` を使用して計算
- 計算結果を次回予定日フィールド (`next_date`) に自動反映
- 接種日が変更された場合も再計算する（接種日変更時のハンドラにも計算ロジックを追加）
