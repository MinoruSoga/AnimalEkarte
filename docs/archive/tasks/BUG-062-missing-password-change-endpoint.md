# BUG-062: パスワード変更エンドポイントが未実装

**作成日**: 2026-03-29
**ステータス**: Open
**優先度**: High
**領域**: Backend
**関連**: BUG-060（パスワードリセット）, BUG-055

---

## 背景・問題

ログイン中のユーザーが自分のパスワードを変更するエンドポイントが存在しない。

- `PUT /v1/users/:id` にはパスワードフィールドが含まれていない
- 初期パスワードを使い続けるリスクがある
- 変更手段がなく `clinic_admin` が手動対応するしかない

---

## 修正方針

`PUT /v1/users/me/password` を新設。`current_password` 必須で他ユーザーのパスワードを変更できない設計にする。

BUG-055（Dual-Token）完了後は、パスワード変更後に全 `refresh_tokens` を revoke して全端末ログアウトを行う。
