# BUG-065: 飼主登録完了後に一覧ページにリダイレクト（詳細ページへ遷移するべき）

## 種類
バグ（フロントエンドナビゲーション）

## 重要度
低

## 発見日
2026-03-29

## 再現手順

1. `/owners/new` で新規飼主を登録して「保存」をクリック
2. HTTP 201 で登録成功する

## 期待動作

- 登録完了後に作成された飼主の詳細ページ（`/owners/:id`）にリダイレクトされる
- 飼主詳細でペット追加などのフォローアップ操作に即座に移れる

## 実際の動作

- 登録後に `/owners`（飼主一覧ページ）にリダイレクトされる
- 作成した飼主の詳細ページに遷移しない

## 原因

`OwnerForm.tsx` の保存後ナビゲーションが `navigate(paths.owners.getHref())` で
一覧ページに遷移するよう実装されている。
登録成功時のレスポンスに含まれる新規飼主 ID を使って詳細ページに遷移すべき。

## 修正方針

`useOwnerForm.ts` の保存成功後ナビゲーションを以下のように変更：

```typescript
// 変更前
navigate(paths.owners.getHref());

// 変更後
navigate(paths.owners.detail.getHref(createdOwner.id));
```

## 優先度
低（機能は正常に動作するが UX が若干不便）
