# BUG-053: マスタ設定サイドパネルの未保存変更時にナビゲーションブロックなし

## 概要
マスタ設定（`/settings/clinic` 等）のサイドパネルでフィールドを変更した後、サイドバーのナビゲーションリンクをクリックすると、警告ダイアログなしに別ページへ遷移し、未保存の変更が失われる。

## 再現手順
1. `/settings/clinic` を開く
2. 「八王子院」行をクリックしてサイドパネルを開く
3. 「院長名」フィールドの値を変更する（例: 「変更テスト」）
4. サイドバーの「飼主・ペット」リンクをクリックする

## 期待動作
- 「変更が保存されていません。ページを離れますか？」等の警告ダイアログが表示される
- ユーザーが確認後に遷移する

## 実際の動作
- 警告ダイアログが表示されず、即座に `/owners` ページに遷移する
- 変更した内容は失われる

## 原因（推測）
設定サイドパネルコンポーネントが React Router の `useBlocker` を使用していない。
飼主登録フォーム等（`/owners/new`）では `useBlocker` による NavigationBlocker が実装されているが、
マスタ設定のサイドパネルには同様の保護が実装されていない。

## 影響範囲
- 全マスタ設定サイドパネル（`/settings/clinic`, `/settings/animal-species`, etc.）
- 意図せず変更が失われる UX 問題

## 優先度
低（意図的にサイドパネルには NavigationBlocker を実装しない設計の可能性もあるが、UX 観点で要検討）
