# BUG-071: カルテ作成・編集フォームで visit_type が「再診」にハードコード

## 種類
バグ（フロントエンド — フォーム値のハードコード）

## 重要度
高

## 発見日
2026-03-28

## 再現手順

1. カルテ新規作成画面（`/medical-records/new`）を開く
2. 来院種別（visit_type）フィールドを確認する

## 期待動作

- 来院種別（初診/再診/緊急/往診）を選択できる UI が表示される
- 選択した値が `visit_type` として PATCH/POST される

## 実際の動作

- `visit_type` が `"再診"` にハードコードされており、UI に選択フィールドが存在しない
- 全カルテが「再診」固定で登録される
- 初診フラグを持つ予約から作成した場合も「再診」になる

## 影響範囲

- カルテ新規作成・編集の来院種別フィールド全体
- 初診/再診の区別が必要な診療報酬計算・レポート機能

## 修正方針

カルテ作成フォームに `visit_type` の選択 UI（Select / RadioGroup）を追加する。
初診/再診/緊急/往診 の選択肢を提供し、デフォルト値は「再診」のまま維持可。
予約から遷移した場合は予約の来院種別を初期値として引き継ぐことを検討する。

## 優先度
高（初診・再診の区別はカルテの基本情報として必須）
