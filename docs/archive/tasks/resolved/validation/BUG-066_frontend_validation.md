# BUG-066: フロントエンドバリデーション未実装（電話番号・メール・値引率）

## 概要
オーナー編集フォームにおいて、以下のフィールドのバリデーションが未実装。
不正な値のまま保存できてしまう。

## 再現手順

1. `/owners` → 任意のオーナーの編集画面を開く
2. 以下の入力を試みる
   - 電話番号: `abc123`（数字以外を入力）
   - メールアドレス: `invalid-email`（HTMLブラウザバリデーションはあるが、カスタムエラー表示なし）
   - 値引率: `-10`（負の値）

## 期待する動作

| フィールド | バリデーション | エラーメッセージ例 |
|-----------|--------------|-----------------|
| 電話番号 | 数字・ハイフンのみ許容（例: `090-1234-5678`） | 「電話番号の形式が正しくありません」 |
| メールアドレス | メール形式チェック + UIエラー表示 | 「メールアドレスの形式が正しくありません」 |
| 値引率 | 0〜100の範囲 | 「値引率は0〜100の範囲で入力してください」 |

## 実際の動作

- 電話番号: `abc123` を入力してもフォーム送信できてしまう（バリデーションなし）
- メールアドレス: HTML5 の `type="email"` による標準バリデーションのみ。カスタムUIエラー表示なし
- 値引率: `-10` など負の値でも保存できてしまう

## 実装場所

- `frontend/src/features/owners/` 配下のオーナーフォーム
- バリデーションルールは `frontend/src/utils/validation/` に追加推奨
