# BUG-056: 一般ユーザー（staff）でもマスタ設定メニューが表示される

## 概要
`can_view=false` の権限を持つ一般グループ（医師・看護師等）のユーザーでもサイドバーに
「マスタ設定」メニューが表示される。UIのサイドバー制御が漏れている。

## 再現手順
1. 山田花子（vet@example.com）でログイン
2. サイドバーを確認
3. → 「マスタ設定」メニューが表示される（本来は非表示であるべき）

## 期待する動作
- `master:can_view=false` のユーザーにはサイドバーの「マスタ設定」メニューを非表示にする

## 実装場所
- `frontend/src/` のサイドバーコンポーネント（権限チェックのロジック）
- マスタ設定メニューの表示条件に権限チェックを追加
