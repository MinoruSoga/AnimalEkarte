# BUG-MEDI-004: カルテ所見のオートセーブ機能がない

## 概要
カルテ詳細の所見テキストにオートセーブ機能がない。
明示的な保存ボタン押下のみで保存され、入力中の内容はページ離脱で失われる。

## 期待する動作
- 入力停止後 3〜5秒でオートセーブ（debounce）
- 保存中インジケーター表示（「保存中...」「保存済み」）

## 実装場所
- `frontend/src/features/medical-records/` のフォームコンポーネント
- `useDebounce` フックを利用した自動保存ロジック追加

Low
