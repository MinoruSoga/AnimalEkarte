# BUG-083: 必須フィールド未入力時に POST はブロックされるがエラーメッセージが表示されない

## 種類
バグ（フロントエンド — バリデーションフィードバック欠如）

## 重要度
低

## 発見日
2026-03-29

## 再現手順

### パターン A: マスタ設定サイドパネル
1. `/settings/animal-species` を開く
2. 「+ 新規登録」をクリック → サイドパネルが開く
3. 名称フィールドを空のまま「保存」ボタンをクリックする

### パターン B: 権限グループ作成
1. `/settings/permission-groups` を開く
2. 新規グループ作成フォームを開く
3. グループ名フィールドを空のまま「保存」ボタンをクリックする

## 期待動作

- 必須フィールドが空の場合、「名称を入力してください」等のインラインエラーメッセージを表示する
- ボタンを赤くハイライトするか、フィールド下にエラーテキストを表示する

## 実際の動作

- POST リクエストが送信されない（バリデーションは機能している）
- ただし、エラーメッセージ・インラインエラー・トーストが**一切表示されない**
- ユーザーには「保存ボタンを押したが何も起きない」という不明な体験となる

## 影響範囲

- マスタ設定の全サイドパネル（動物種類・薬品・病名・処置名マスタ等）
- 権限グループ作成フォーム
- ケージマスタ・病院設定フォーム（空欄保存時サイレントブロック）
- マスタ API 取得失敗時の空プルダウン（`PetEditModal.tsx` — エラーメッセージなしで選択肢が空になる）

## 修正方針

各フォームの `handleSave` / `handleSubmit` で必須フィールドが空の場合に `setErrors` または `toast.error()` でユーザーに通知する。

```typescript
// ✅ 修正後
const handleSave = () => {
  if (!formData.name.trim()) {
    setErrors({ name: "名称を入力してください" });
    return;
  }
  startSaveTransition(async () => { ... });
};
```

## 優先度
低（データ保存は正しくブロックされているが、ユーザー体験が悪い）
