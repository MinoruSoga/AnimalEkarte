# BUG-014: ペット選択画面の「前回来院」日付フォーマット不統一

## 種類
バグ（表示不具合）

## 発見日
2026-03-24

## 再現手順
1. 以下のいずれかのペット選択画面に遷移
   - `/accounting/select-pet`
   - `/examinations/select-pet`
   - その他ペット選択画面
2. 検索結果テーブルの「前回来院」列を確認

## 期待動作
「前回来院」の日付が「生年月日」と同じ `YYYY-MM-DD`（ハイフン区切り）形式で統一されて表示される。

## 実際の動作
一部のペットで「前回来院」が `YYYY/MM/DD`（スラッシュ区切り）で表示される：

| ペット | 前回来院（実際） | 期待 |
|--------|----------------|------|
| Iris(イリス) 林文明 | 2015/08/28 | 2015-08-28 |
| Max(マックス) 林文明 | 2024/11/15 | 2024-11-15 |
| ミケ 田中花子 | 2024/11/18 | 2024-11-18 |
| その他ペット | - | - |

「生年月日」列は全て `YYYY-MM-DD` で統一されているが、「前回来院」列だけが混在している。

## 原因調査
APIレスポンスの `last_visit_date` フィールドのフォーマットが、バックエンドから `YYYY/MM/DD` 形式で返却されているか、フロントエンドの transforms 関数でフォーマット変換が不統一の可能性が高い。

## 影響
- UIの一貫性が損なわれる
- 医療システムとして日付表示の不統一は信頼性低下につながる

## 調査対象ファイル
- `frontend/src/components/shared/PetSelection/` 配下のコンポーネント
- `frontend/src/hooks/use-pet-selection.ts`
- 各 feature の `api/transforms.ts`（前回来院のフォーマット変換箇所）
- `frontend/src/utils/format/date.ts`（日付フォーマット関数）
