# BUG-016: 予防接種編集画面の「予防接種履歴」パネルでペット未選択状態になる

## 種類
バグ（表示不具合）

## 発見日
2026-03-24

## 再現手順
1. `/vaccinations` に遷移（予防接種管理一覧）
2. 任意のレコードの編集ボタン（鉛筆アイコン）をクリック
3. `/vaccinations/:id` の編集画面が開く
4. 右パネルの「予防接種履歴」セクションを確認

## 期待動作
右パネルの「予防接種履歴」にそのレコードに紐づいたペットの全予防接種履歴が一覧表示される。

## 実際の動作
右パネルに「ペットを選択してください」と表示され、履歴が一切表示されない。

## 原因調査
編集ページ（`/vaccinations/:id`）がロードされた際、既存レコードに紐づくペットID（`pet_id`）を右パネルの予防接種履歴コンポーネントに渡していないと考えられる。

APIレスポンスから `pet_id` を取得して右パネルに渡す必要がある。

## 影響
- 編集時に同一ペットの過去接種履歴が確認できないため、重複接種・過多接種のリスクがある
- 予防接種記録の整合性確認が困難

## 調査対象ファイル
- `frontend/src/features/vaccinations/` 配下の詳細・編集コンポーネント
- ペットIDを右パネル（履歴コンポーネント）へ渡す箇所
