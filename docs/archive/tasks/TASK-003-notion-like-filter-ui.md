# TASK-003: 全一覧ページの検索フィルタを Notion ライクUIに統一

**作成日**: 2026-03-17
**ステータス**: Open
**依頼元**: ユーザー

---

## 概要

全一覧ページで使用している SearchFilterBar + 個別フィルタUI を、Notion のフィルタUIパターンに統一する。「フィルタ追加」ボタン → Popover でプロパティ・条件・値を選択し、アクティブなフィルタがピル（タグ）として表示されるUIに置き換える。

## 依頼内容（原文）

> 検索フィルタですが、NotionライクなUIにしてください。
> （対象: 一覧ページのすべての検索フィルタ）
