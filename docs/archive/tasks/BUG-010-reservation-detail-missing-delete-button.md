# BUG-010: 予約詳細ダイアログに削除ボタンがない

## 種類
バグ（UI機能不備）

## 発見日
2026-03-23

## 再現手順
1. `/reservations` (予約カレンダー) を開く
2. 予約カードをクリックして詳細ダイアログを開く

## 期待動作
詳細ダイアログに「削除」ボタンが表示される

## 実際の動作
詳細ダイアログに表示されるボタンは以下のみ：
- 「仮予約」（ステータス変更）
- 「編集」（編集モーダルへ）
- 「カルテ作成」
- 「Close」

削除ボタンが存在しない。

## 解決結果

**誤検知 (False Positive)** — 削除ボタンは `ReservationDetailModal.tsx` L238-247 に実装済み。
`Trash2` アイコンのみの ghost ボタン（テキストなし）のため、Playwright の
`allTextContents()` で検出されなかった。

`onDelete={handleDelete}` は `ReservationManagement.tsx:258` で正しく渡されており機能している。
