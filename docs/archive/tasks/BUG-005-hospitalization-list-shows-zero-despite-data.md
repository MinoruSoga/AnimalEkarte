# BUG-005: 入院一覧が0件表示（APIは7件返却）

## 種類
バグ

## 発見日
2026-03-20

## 再現手順
1. `/hospitalization` で入院一覧を表示
2. 「入院中」「すべて」タブいずれも0件と表示

## 期待動作
- 「入院中」: admitted 2件（id=1, id=6）
- 「予約」: reserved 2件（id=4, id=5）
- 「退院済」: discharged 3件（id=2, id=3, id=7）
- 「すべて」: 7件

## 実際の動作
全タブで0件。ケージボードは全て「空き」表示。

## 調査結果
- APIレスポンス: `GET /api/v1/hospitalizations` → 200 OK、7件のデータが返却されている
- admitted のレコード id=1 は cage_id=5（犬用ケージ大）、id=6 は cage_id=3（犬用ケージ小）

## 修正方針
フロントエンドの入院管理コンポーネント（HospitalizationList等）でAPIレスポンスデータの変換・マッピングロジックを確認。データが正しく受け取れているのに表示されていない。
