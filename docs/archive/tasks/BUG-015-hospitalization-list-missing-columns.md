# BUG-015: 入院・ホテル管理のリストビューで「入院No」「種」カラムが空表示

## 種類
バグ（表示不具合）

## 発見日
2026-03-24

## 再現手順
1. `/hospitalization` に遷移
2. 右上の「リストビュー」に切り替え（Board View → List View）
3. 「すべて」タブを選択して全件を表示
4. テーブルの「入院No」「種」カラムを確認

## 期待動作
- 「入院No」カラムに各入院レコードのIDまたは番号が表示される
- 「種」カラムにペットの種別（犬/猫/etc）が表示される

## 実際の動作
全8件に対して「入院No」「種」カラムが全て空白で表示される。

## 影響
- 入院番号が確認できないため、カルテや会計との突合が困難
- 種別が確認できないため、ケージ割り当て確認に支障

## 調査対象ファイル
- `frontend/src/features/hospitalization/` 配下のリストビューコンポーネント
- 入院データの transform 関数（hospitalization_no や species のマッピング確認）
