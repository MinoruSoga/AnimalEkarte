# BUG-052: ペット追加モーダルがキャンセル後に状態をリセットしない

## 概要
飼主登録フォーム（`/owners/new`）の「ペット追加」モーダルで入力後にキャンセルし、再度「ペット追加」を開くと、前回入力した値が残留している。

## 再現手順
1. `/owners/new` を開く
2. 「ペット追加」ボタンをクリックしてモーダルを開く
3. ペット名フィールドに「テストペット」と入力する
4. 「キャンセル」ボタンをクリックしてモーダルを閉じる
5. 再度「ペット追加」ボタンをクリックする

## 期待動作
- モーダルが空の状態で開く（全フィールドがデフォルト値にリセットされている）

## 実際の動作
- ペット名フィールドに「テストペット」が残っている
- キャンセル前に入力した値がそのまま残留する

## 原因（推測）
ペット追加モーダルのフォーム状態（useState）がモーダルのclose/openではリセットされていない。
キャンセル時に明示的なフォームリセット処理が呼ばれていないか、モーダルがアンマウントではなく非表示（`hidden`/`display:none`）制御になっているため、状態が保持される。

`frontend/src/features/owners/components/` 内のペット追加モーダルコンポーネントで、
キャンセルハンドラ内で `resetForm()` または `setFormData(initialValues)` を呼び出す必要がある。

## 影響範囲
- 飼主登録フォームのペット追加モーダル（`/owners/new`）
- 飼主編集フォームのペット追加モーダル（`/owners/:id`）も同様の可能性あり
