# BUG-069: 予約詳細ポップアップの編集モーダルで予約区分・担当者フィールドが空欄

## 種類
バグ（フロントエンド — 編集フォームの初期値未設定）

## 重要度
中

## 発見日
2026-03-28

## 再現手順

1. 予約カレンダー（`/reservations`）で既存の予約カードをクリックして詳細ポップアップを表示
2. 鉛筆（編集）アイコンボタンをクリックして編集モーダルを開く

## 期待動作

- 編集モーダルに既存の予約区分（サービス種別）と担当者が初期値として表示される
- ユーザーは変更したいフィールドだけ修正して「更新する」をクリックできる

## 実際の動作

- 編集モーダルが開くが、予約区分・担当者フィールドが空欄
- 既存値が初期表示されないため、変更しない場合でもフィールドを再入力する必要がある
- 空欄のまま「更新する」をクリックすると、これらのフィールドが上書きされる可能性がある

## 原因

予約詳細ポップアップの編集ボタン押下時、既存の予約データを編集モーダルのフォーム初期値として渡すロジックが未実装。
予約の `service_type_id` / `staff_id` 等が編集モーダルコンポーネントに渡されていない。

## 影響範囲

- 予約カレンダーの全編集フロー（月表示・週表示のポップアップから）

## 修正方針

予約詳細ポップアップの編集ボタン押下時、対象予約の `service_type_id` / `staff_id` / `appointment_type` 等を
編集モーダルコンポーネントの `defaultValues`（または `initialValues`）として渡す。

## 優先度
中（既存値が消える可能性があり、意図しない上書きのリスクがある）
