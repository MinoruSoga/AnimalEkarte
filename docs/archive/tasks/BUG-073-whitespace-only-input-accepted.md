# BUG-073: スペースのみの入力が有効値として登録される

## 種類
バグ（フロントエンド + バックエンド — 空白バリデーション欠如）

## 重要度
中

## 発見日
2026-03-29

## 再現手順

1. 飼主登録フォームの「飼主名」フィールドに半角スペース 3 文字（`   `）を入力する
2. 「登録する」をクリックする
3. HTTP 201 で登録成功する

## 期待動作

- スペースのみの入力を空欄と同等に扱い、バリデーションエラーを表示する
- 全角スペースのみの入力も同様に拒否する
- バックエンドでも `.trim()` 後の空文字チェックを実施する

## 実際の動作

- 半角スペース 3 文字の飼主名が HTTP 201 で登録成功する
- 全角スペースのみも API 直接送信で 201 成功する
- 空白のみの値がそのまま DB に保存される

## 影響範囲

- 飼主名・ペット名など必須テキストフィールド全般
- 空白のみのレコードが一覧に表示され検索・表示が乱れる

## 修正方針

### フロントエンド
- `required` フィールドのバリデーションで `.trim().length === 0` をチェック
- エラーメッセージ：「スペースのみは入力できません」

### バックエンド
- service 層の `Validate()` で `.TrimSpace()` 後の空文字チェックを追加
- 空文字の場合は `ErrInvalidInput` を返す

## 優先度
中（不正データが蓄積されデータ品質に影響）

| イシュー | 領域 | 内容 |

| BUG-073（BE） | Backend | service Validate() で strings.TrimSpace 後の空文字チェック追加 |
