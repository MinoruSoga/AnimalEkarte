# フォーム・バリデーション共通仕様書

本ドキュメントは、システム全体のフォーム実装における共通のバリデーションルール、入力制約、および高度な計算ロジックを定義します。

各画面固有のフィールド詳細は、**[画面定義書 (docs/screens/)](./SCREENS.md)** を参照してください。

---

## 1. 共通バリデーションルール

### 1.1 必須入力
- **マーク**: 必須フィールドには項目名の横に `*`（赤色）を表示。
- **エラー**: 未入力のまま保存を試みた場合、フィールド直下に赤文字でメッセージを表示し、保存をブロックする。

### 1.2 数値入力制約
- **金額・数量**: 原則として 0 以上の整数。
- **体重**: 小数点第2位まで（例: `5.25`）。`step="0.01"` で制御。
- **体温**: 小数点第1位まで（例: `38.5`）。`step="0.1"` で制御。
- **負数**: 割引額や保険負担額など、特定の控除項目のみマイナス値を許容（内部ロジックで自動反転）。

### 1.3 日付入力制約
- **生年月日・実施日**: 未来日の選択を禁止。
- **予約日・有効期限**: 過去日の選択を禁止（一部例外あり）。
- **日付範囲**: 「開始日 ≦ 終了日」の相関チェックを実施。

## 2. 高度な計算ロジック

### 2.1 診療費・会計計算 (`useMedicalRecordCalculation` / `useAccountingDetail`)
システム全体で一貫した金額計算を行います。

- **税抜小計**: 各明細の `税込単価 / 1.1`（内税10%の場合）の合計。
- **消費税額**: 各明細ごとに消費税を算出し、端数は**切り捨て**。
- **保険負担額**: `保険対象項目の合計(税込) × 負担割合`。
- **最終請求額**: `合計(税込) - 保険負担額 - 値引額`。

### 2.2 在庫アラートロジック
在庫一覧およびカルテ保存時に判定されます。
- **在庫切れ**: `現在庫 = 0`
- **残少**: `0 < 現在庫 ≦ 最低在庫（発注点）`
- **十分**: `現在庫 > 最低在庫`

## 3. ユーザー体験（UX）仕様

### 3.1 フォーム離脱保護 (`NavigationBlocker`)
- フォームに入力変更（`isDirty`）がある状態で、保存せずに画面を戻る・閉じる操作をした場合、確認ダイアログを表示して入力を保護する。

### 3.2 リアルタイム集計
- 数量や単価、値引率を変更した際、保存ボタンを押さずとも集計サマリーが即座に更新される。

### 3.3 マスター連携の自動反映
- 予防接種マスタを選択すると、標準接種間隔に基づいた「次回予定日」が自動入力される。
- トリミングコースを選択すると、標準単価が自動セットされる。

---

## 4. アクセシビリティ仕様

- **エラー通知**: スクリーンリーダー利用者のために、`aria-invalid="true"` および `aria-describedby` を用いてエラーメッセージと入力欄を適切に紐付ける。
- **フォーカス管理**: バリデーションエラー発生時、最初の違反フィールドに自動的にフォーカスを移動させる。
- **キーボード操作**: 全ての `Select` や `Dialog` は、Tab キーおよび矢印キーでの操作をサポートする（`radix-ui` 準拠）。
