# BE: 受付済みステータスにした時にカルテを自動作成する

## 背景
予約の受付処理（受付済みステータスへの変更）が行われた時点で、
対応するカルテ（medical_records）レコードを自動的に作成する必要がある。

これにより、受付後すぐにカルテ画面を開くと既にカルテIDが確定しており、
スムーズに診察記録を入力開始できる。

## 必要な変更

### 受付済み処理のエンドポイント
予約を受付済みにする際（PATCH /v1/reservations/:id など）、以下を実行:
1. 予約ステータスを「受付済み」に更新
2. 対応するカルテを作成:
   - `pet_id`: 予約の pet_id
   - `owner_id`: 予約の owner_id
   - `visit_date`: 予約日（today）
   - `visit_type`: 予約区分に対応する値
   - `status`: "draft"
   - サブテーブル（inquiries, treatment_plans, clinical_plans）も空レコードで作成

### 考慮事項
- 既に同日のカルテが存在する場合の扱いを検討（重複作成しない等）
- トランザクション内で予約更新とカルテ作成を原子的に処理する

## 優先度
Medium（受付フローの UX 改善）
