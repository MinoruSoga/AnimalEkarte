# S33: 明細兼領収書 — プレビュー → 印刷 → PDF 保存

> **目的**: 確定会計の「明細兼領収書」（A4 統合帳票）がプレビューで正しく表示され、ブラウザ印刷（`window.print()`）→「PDF として保存」まで崩れず出力できることを納品前に証明する。
> **所要目安**: 10分 / **深度**: 中
> **仕様正本**: [screens/11-accounting-detail.md](../../../spec/screens/11-accounting-detail.md)。関連 tracker: `SLACK-BILLING-UAT`（工程 3。物理プリンタ実印刷・実締め・運用承認は外部レーン）・`BUG-367`（A4 統合帳票）。

## 前提条件

- ローカルの使い捨て clinic、または承認済みの専用 UAT tenant。実請求・実患者データは使わない。
- 確定済み会計の fixture を 1 件以上（明細・税区分・飼主名付き）。登録番号を設定した医院と、**登録番号未設定の医院**の 2 パターンが望ましい。
- actor は会計の参照権限を持つ attached account。
- ブラウザの印刷プレビュー →「PDF として保存」が使える対象ブラウザ。物理プリンタは不要（実印刷は外部レーン）。
- 依存シナリオ: S08（訂正・未収残）・S21（確定の競合）・S20（明細経路）。

## 手順と期待結果

| # | 操作 | 期待結果 |
|:--|:--|:--|
| 1 | 確定会計の詳細を開き「明細兼領収書」を開く | 「明細兼領収書プレビュー」ダイアログが開き、A4 帳票の印刷イメージが表示される（`AccountingDocument`・BUG-367） |
| 2 | 帳票の内容を確認する | 医院ヘッダー（名称・住所・TEL・登録番号）・飼主名「◯◯様」・明細・税区分・合計が、会計データと一致して表示される。セクションは `effectiveOrder` 順で、非表示設定のセクションは出ない |
| 3 | 登録番号未設定の医院で同じ操作をする | 「登録番号が未設定です…適格請求書として無効となります」の警告バナーが画面に出る（`print:hidden` で印刷物には出ない）。登録番号欄は「未設定」表示 |
| 4 | 飼主名が空の会計で開く | 「様」のみの空欄にならず「（飼主名未取得）」のフォールバック表示になる（BUG-374 TC-367-03） |
| 5 | 「印刷する」を押してブラウザ印刷 →「PDF として保存」する | `window.print()` が起動し、印刷プレビューで A4 全幅に崩れずレイアウトされる（`print:max-w-none print:w-full print:border-none print:p-0`）。ヘッダー/フッターのページ分割で明細が不自然に切断されない |
| 6 | 保存した PDF を開く | 画面上の帳票内容が PDF に再現される。文字化け・欠落・レイアウト崩壊がない。印刷専用でない警告バナーは PDF に出ない |

## 確認観点

- プレビューは `AccountingDetailPanels` の「明細兼領収書プレビュー」ダイアログ、印刷は `window.print()`。帳票本体は `AccountingDocument`（BUG-367・A4 統合帳票）で `print:` クラスにより印刷時レイアウトを切り替える。
- 登録番号警告は**画面のみ** `print:hidden` で出る設計（適格請求書として無効の注意）。「画面に警告が出るが PDF には出ない」という挙動を確認し、PDF に残るのは異常、画面に出ないのも異常。
- セクションは `effectiveOrder`/`sectionVisible` で順序・表示を制御する（#190）。既定の並びと設定で変わる並びの両方を確認できればよい。
- 工程 3 の受入は「プレビュー → `window.print()` → PDF 保存」まで。**物理プリンタ実印刷・実締め・医院運用承認は外部レーン**で、本シナリオの PASS 範囲に含めない。
- 複数ページにまたがる長い明細での改ページ・合計行の切断は境界ケースとして確認する（明細多数の fixture があれば）。

## 実装突合

- 変更サマリ:
  - `AccountingDetailPanels` の「明細兼領収書プレビュー」ダイアログと `window.print()` ボタン、`AccountingDocument` の `print:` レイアウト・`effectiveOrder`/`sectionVisible`・登録番号警告（`print:hidden`）・飼主名フォールバック（BUG-374）を現行コードと突合
  - `SLACK-BILLING-UAT` 工程 3（プレビュー→印刷→PDF 保存）を手順 1–6 に対応づけ、物理印刷・実締めは外部レーンと明記
