# S32: 飼主検索モーダル — 多数候補の可視範囲と操作到達

> **目的**: 飼主検索モーダル（`OwnerSearchModal`）が、候補多数・0 件の両方で検索欄・結果一覧・末尾行の「選択」・閉じる操作が画面内に収まり、キーボード選択とフォーカス復帰が機能することを、対象 viewport で納品前に証明する。
> **所要目安**: 10分 / **深度**: 薄い
> **仕様正本**: [screens/03-owners-list.md](../../../spec/screens/03-owners-list.md)。検証キュー: `SLACK-OWNER-HEIGHT`（[todo-verification.md](../../../../todo-verification.md)）。

## 前提条件

- 対象 viewport は **1366×625 CSS px** から開始する（医院回答の Windows 8 / Chrome / 15.6 インチ想定）。実機の CSS 表示領域・ブラウザ版・100%/既報 125% ズームを run 記録に別記し、最新 Chromium の合格を旧 Chrome 対応済みとしない。
- 検索で多数の候補（一覧が明確にあふれる件数）と 0 件になる語の両方を用意した飼主 fixture。固定 ID は仮定しない。
- actor はモーダルを起動できる画面（予約作成・受付・カルテ作成等の飼主選択）を開ける権限を持つ attached account。
- 依存シナリオ: S18（TreatmentSearchDialog 相当の一覧高さ）・S19（viewport 適合）と同じ fixture/run を使ってよい。

## 手順と期待結果

| # | 操作 | 期待結果 |
|:--|:--|:--|
| 1 | 飼主選択を要する画面から `OwnerSearchModal` を開く | モーダル全体が `max-h-[80vh]` 内に収まり、検索欄・結果領域・閉じる操作がはみ出さず到達できる |
| 2 | 多数候補になる検索語で一覧を出す | 結果一覧だけがコンテナ内でスクロールし（`flex-1 min-h-0 max-h-[calc(80vh-12rem)] overflow-y-auto`）、**末尾行の「選択」ボタンまで到達できる**。ページ全体をスクロールさせずに最下行へ届く |
| 3 | 0 件になる検索語を入れる | エラー・固まりではなく 0 件の空状態が表示され、検索欄・閉じる操作は画面内に残る |
| 4 | キーボード（矢印・Enter・Escape）だけで候補選択とキャンセルを行う | マウスなしで候補を選び確定/閉じるができる。フォーカスが一覧内で迷子にならない |
| 5 | 候補を選択して確定する | 選択した飼主が呼び出し元のフォームへ反映され、モーダルが閉じる。フォーカスが呼び出し元（起動ボタン等）へ戻る |
| 6 | Escape または閉じるボタンで閉じる | 選択せず閉じる。フォーカスが呼び出し元へ戻る（focus restoration） |

**モーダルの構造（結果一覧だけが内側スクロール）:**

```text
OwnerSearchModal（モーダル全体は高さ上限 max-h-[80vh] 内に収まる）
┌───────────────────────────────────────────┐
│ 検索欄                         …固定・常時到達 │
│ ┌───────────────────────────────────────┐ │
│ │ 結果一覧                                │ │
│ │   この領域だけが内側スクロール            │ │
│ │   (flex-1 min-h-0 / overflow-y-auto)    │ │
│ │   候補 … 末尾行の「選択」まで到達できる   │ │
│ └───────────────────────────────────────┘ │
│ 閉じる                         …固定・常時到達│
└───────────────────────────────────────────┘
0 件時 → 空状態表示（エラー・固まりではない。外側の操作は画面内に残る）
選択確定 / Escape / 閉じる → フォーカスは呼び出し元へ復帰
```

## 確認観点

- 結果一覧は `OwnerSearchModal`（`frontend/src/components/shared/OwnerSearchModal/`）の結果領域が `flex-1 min-h-0 max-h-[calc(80vh-12rem)] overflow-y-auto` で内側スクロールする。`isFiltering` 中は `opacity-60` で絞り込み中が分かる。
- 「一覧の中だけスクロール・外側の操作は固定」「末尾行の選択ボタンへ到達」は `SLACK-OWNER-HEIGHT` の受入条件。末尾行へ届かない・画面下の操作が隠れるのは FAIL。
- ズーム 125%（既報の発生条件）は必ず別 run で確認する。100% で収まることをもって 125% 合格としない。
- 元報告が飼主/ペット一覧の画面本体だった場合は、その surface（一覧のスクロール・ページング）も別途確認し、モーダルの合格だけで元症状の解消としない。
- 結果は viewport・ブラウザ版・ズーム・表示領域を紐づけて `reports/uat-YYYY-MM-DD/` に記録する。scenario 本文へ実行結果を書かない。
