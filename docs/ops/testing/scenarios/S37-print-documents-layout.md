# S37: 印刷帳票のレイアウト — 領収書以外の印刷面

> **目的**: 領収書（S33）以外の印刷可能面 — カルテ印刷・検査結果・日次会計・月次レポート・締め明細 — が印刷メディアで帳票のみを残し、見切れ・ページ分割・余白が破綻しないことを納品前に証明する。
> **所要目安**: 15分 / **深度**: 中
> **仕様正本**: [screens/32-accounting-reports.md](../../../spec/screens/32-accounting-reports.md)・各帳票の screens 正本。領収書の印刷チェーンは [S33](S33-receipt-print-pdf.md) を参照。

## 前提条件

- 印刷可能な fixture: 明細・診断・バイタルを持つ確定カルテ、確定済み検査、当日会計を含む日次会計、月次集計データ、実行済みの締め。
- Playwright/ブラウザの `print` メディアエミュレーションまたは `window.print()` 計測が使える環境。
- 対象プリンタ用紙は A4 縦を基準とする。

## 手順と期待結果

| # | 操作 | 期待結果 |
|:--|:--|:--|
| 1 | カルテ印刷ビュー（`MedicalRecordPrintView`）を開き print メディアで確認 | 画面用 UI（ナビ・ボタン・サイドバー）が `print:hidden` で消え、帳票のみ残る |
| 2 | 検査結果の印刷（`ExaminationPrintArea`）を確認 | 項目表がページ内に収まり、基準値・異常フラグが印刷でも判読可能。ヘッダー/列がページ境界で切断されない |
| 3 | 日次会計の印刷（`DailyAccountingPrintArea`）を確認 | 会計一覧が帳票レイアウトで出力され、合計行がページをまたいで分断されない |
| 4 | 月次レポート印刷（`MonthlyReportPrintArea`）を確認 | 集計表・サマリカードが印刷面に収まり、表の最右列が見切れない |
| 5 | 締め明細印刷（`ClosePrintArea`）を確認 | 締めサマリが帳票として出力され、金額列の桁が揃う |
| 6 | 各印刷で長文・多数行 fixture（S35 と共通）を通す | 行がページをまたぐ場合にヘッダー行が繰り返されるか、または分断位置が読める |

## 確認観点

- `PrintPortal`/`print:hidden` の配線が各帳票で一貫していること。画面用コンポーネント（トースト・モーダル・サイドバー）の混入は FAIL。
- `page-break`/`break-inside` により行の途中切断・合計行の孤立がないこと。帳票の単位（円・税込/税別・医院名・出力日）が揃うこと。
- 印刷プレビューで白紙ページ・無限ページが出ないこと（高さ固定要素の残存）。
- 実プリンタ/PDF 保存は実機 lane で別 run。本シナリオは print メディアエミュレーションでの構造確認を PASS とする。
