# S02: 検査異常値ハイライトと確定ロック

> **目的**: 基準値範囲外の検査値が自動でハイライトされ重要値の見落としを防ぐこと、および確定した検査記録が編集不可となり臨床データの真正性が守られることを納品前に証明する。
> **所要目安**: 20分 / **深度**: 深い
> **仕様正本**: [specification.md §2.1](../../../spec/specification.md)・[screens/12-examinations-list.md](../../../spec/screens/12-examinations-list.md)・[screens/13-examinations-form.md](../../../spec/screens/13-examinations-form.md)

## 前提条件

- 環境: ローカル（seed 003_demo）。ログイン: vet ロール（examinations の create/edit 権限あり）。
- 対象ペット: ペット検索で「ステータス=生存」の犬を 1 頭選ぶ。
- 検査種別: 検査種別マスタのうち、基準値（Min〜Max）が定義された測定項目テンプレを持つ種別（例: 名称に「血液」を含む種別。WBC/RBC 等に基準値あり）。
- 手順 8 の権限変更用に admin ロールで権限グループ設定を編集できること。
- 依存シナリオ: なし。

## 手順と期待結果

| # | 操作 | 期待結果 |
|:--|:--|:--|
| 1 | 検査一覧から「新規検査登録」→ ペット選択 → 検査フォームで前提の検査種別を選択 | 選択した種別に基づき測定項目テーブルが動的生成され、項目名・単位・その動物種の基準値が表示される（[13 §1.2](../../../spec/screens/13-examinations-form.md)） |
| 2 | ある項目に基準値上限を超える測定値を入力して保存し、画面を再読込 | 当該項目が高値（H）として赤でハイライトされる。判定はバックエンドが導出し保存・再読込後に反映される（[13 §1.2/§2.2](../../../spec/screens/13-examinations-form.md)） |
| 3 | 別の項目に基準値下限未満の値を入力して保存・再読込 | 低値（L）としてブランドカラー（teal）でハイライトされる（[13 §1.2](../../../spec/screens/13-examinations-form.md)） |
| 4 | 基準値ちょうど（Min または Max と同値）を入力して保存・再読込 | 【要実測】境界値の判定（正常扱いか H/L 扱いか）。仕様文書に明記なし |
| 5 | 基準値範囲内の値を入力して保存・再読込 | ハイライトなし（判定なしの通常表示） |
| 6 | 検査を「確定 (finalized)」ステータスへ移行する | 【要実測】確定操作の UI 経路。確定後は当該検査記録の一切の編集がロックされる（[13 §2.1](../../../spec/screens/13-examinations-form.md)） |
| 7 | 確定済み検査を開き、測定値の変更・保存を試行する | 編集がロックされ変更を保存できない（[13 §2.1](../../../spec/screens/13-examinations-form.md)）。【要実測】ロックの具体形（入力無効化かエラー表示か） |
| 8 | examinations の edit 権限を持たないロールでログインし、確定操作・結果入力を試行する | 操作不可（操作権限は権限制御による — [13 概要](../../../spec/screens/13-examinations-form.md)）。【要実測】seed 003_demo の標準ロールは全て edit を保有するため、権限グループ設定で examinations の edit を外した検証用ロールを用意する |

## 確認観点

- 異常値判定はバックエンド service 層（`backend/internal/service/examination_service.go` の `computeExamResultStatus`）に集約されており、フロントは表示専任であること（DB と画面の判定乖離を防ぐ設計）。
- 確定ロックはフロントの保存スキップ + バックエンド拒否の二重ガードであること。
- カルテ詳細の「検査」タブと検査一覧の結果がリアルタイムに同期すること（[12 §2](../../../spec/screens/12-examinations-list.md)）。
- 検査一覧の進捗フィルタ（依頼中/検査中/完了）で対象検査が正しく抽出できること（[12 §1.1](../../../spec/screens/12-examinations-list.md)）。
- 【要実測】基準値の犬猫別切替（犬と猫で同じ項目の基準値表示が変わるか。[13 §1.2](../../../spec/screens/13-examinations-form.md) は動物種別表示を記述するが、基準値マスタの実データ次元は要確認）。
