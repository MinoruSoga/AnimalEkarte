# ペット選択 仕様書

![ペット検索画面イメージ](./images/03-owners-list-v2.png)

## 概要
- **画面の目的**: 診療記録、入院、トリミング、会計等の各機能において、新規データ作成の対象となるペットを検索・特定するための中間ページ。
- **URLパターン**: `/:feature/select-pet`
  - 例: `/medical-records/select-pet`, `/hospitalization/select-pet` 等
- **アクセス権限**: 遷移元機能の `<Resource>:create` 権限（`RequirePermission` によるルートガード）。例: `/medical-records/select-pet` は `ResourceMedicalRecords` の `create` アクションを要求。

---

## 画面構成

### 1. 検索条件パネル (`PetSelectionSearchForm`)
Notionスタイルのプロパティ編集UIを採用し、入力と同時に結果が絞り込まれるリアクティブな検索体験を提供します。

| フィールド名 | 項目ID | 備考 |
|:---|:---|:---|
| **飼主No** | `ownerId` | `owners.id` による部分一致 |
| **飼主名** | `ownerName` | 漢字氏名による部分一致 |
| **飼主名よみ** | `ownerNameKana` | よみによる部分一致（ひらがな・カタカナを区別しない） |
| **電話番号** | `phone` | 電話番号文字列による部分一致 |
| **ペット名** | `petName` | ペット名による部分一致 |
| **ペット名よみ** | `petNameKana` | よみによる部分一致（ひらがな・カタカナを区別しない） |
| **種別** | `species` | 種別名のテキスト入力による部分一致 |
| **住所** | `address` | 住所文字列による部分一致 |

### 2. 検索結果一覧 (`PetSelectionResultsTable`)
絞り込まれたペット情報を表形式で表示します。

| カラム | 説明 |
|:---|:---|
| **飼主No / 飼主名** | 飼い主の基本情報（別カラム）。 |
| **ペット番号** | クリニック独自の患者番号。 |
| **ペット名** | ペットの名称。 |
| **生死** | 生存/死亡ステータスをバッジで表示（死亡時は行がグレーアウト）。 |
| **種** | 動物種別。 |
| **生年月日** | 基本属性。 |
| **体重** | ペット基本情報に登録された体重。 |
| **環境** | 室内/室外等の飼育環境。 |
| **前回来院** | 最終診療日。 |
| **操作** | 選択ボタン（死亡ペットは「選択不可」表示で無効化）。 |

## ユーザーアクションとガード

### ペットの特定と遷移
- **選択実行**: 該当する行をクリック、または右側の「選択」ボタンを押下。
- **パラメータ連携**: 選択された `petId` をクエリパラメータとして保持し、遷移先の新規作成フォーム (`/:feature/new?petId=xxx`) へ引き渡します。

### 臨床安全ガード（死亡ペットの保護）
- **誤入力防止**: ステータスが「死亡 (deceased)」となっているペットは、ボタンが「選択不可」に切り替わり、クリックイベントが物理的に無効化されます。これにより、既に死亡した個体に対して誤ってカルテや入院記録を作成することを未然に防ぎます。

## 技術仕様

### 使用コンポーネント
- 機能ごとの合成用コンテナ（例: `MedicalRecordPetSelection`, `HospitalizationPetSelection`, `AccountingPetSelection` 等、7 機能に個別実装）が以下を組み合わせる。
- **`PetSelectionSearchForm`**: 検索条件パネル。
- **`usePetSelectionPage`**: 検索フィルタリングとナビゲーションのコアロジック（`frontend/src/hooks/use-pet-selection-page.ts`）。
- **`PetSelectionResultsTable`**: `memo` 化された高速な一覧表示部品。

### API連携
| メソッド | エンドポイント | 用途 | 必須権限 | 必須アクション |
|:---|:---|:---|:---|:---|
| GET | `/api/v1/pets` | テナント内全ペット情報の取得（初期ロード時に実行） | `owners` | `view` |
