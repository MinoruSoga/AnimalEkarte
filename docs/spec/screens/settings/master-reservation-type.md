## 1. 画面構成

### 1.1 予約区分一覧
- **区分グループ**: [所属と色の継承](#requirement-fr-reservation-types-group-inheritance)を採用。区分の所属は0または1グループ、グループの入れ子はなし。業務分類は各区分に別途設定し、[13:14の担当者・記録接続](#requirement-fr-reservation-types-business-routing)へ使う。予約区分自体の親子分類は未決。既存モデルのgeneral／trimmingだけで新合意の分類・対応を実装済みと扱わない。
- **表示項目**: 名称、備考、ステータス（有効/無効）。グループ見出し行にグループ色のドットを表示。行はドラッグ&ドロップで並び替え可能。

### 1.2 詳細編集サイドパネル (`SidePeekPanel`)
- **基本属性**: 名称、ステータス（有効/無効）、グループ、備考。略称・標準所要時間は下記「LINE予約設定」セクション内にある（所要時間は `<input type="number">` min=5 / max=480 分。15 分刻みへの制約はない）。
- **カレンダー色**: 色は[グループ側のみ](#requirement-fr-reservation-types-group-inheritance)で設定し、区分が継承する。未所属は共通標準色。現実装の固定グレーやseed色値を新しい標準色の確定値にしない。
以下のLINE公開・曜日・枠などの詳細は既存実装／既存仕様の参照。2026-10-13の院内予約見直しでLIFFの規制を解除せず、LINE条件は[現在の正本](../../line/reservation-spec.md#line-scheduled-slot-basis)へ従い、残す項目や配置の具体化は設計へ分ける。

- **LINE 予約連携**:
    - **予約ページに表示**: 有効かつオンの区分を飼主向け LIFF アプリの選択肢に出す。「内部サービス」がオン、または無効の区分は公開しない。無効化済み区分の新規予約もサーバ側で拒否する（#238）。
    - **所要時間**: [院内／LINE共通・保存済予約不変](#requirement-fr-reservation-types-shared-duration)が合意仕様。LINE予約設定内に置かれている現画面の配置と、業務上の共通責務は分ける。
- **予約可能枠**: [追加合意1](../../line/reservation-spec.md#requirement-fr-line-reservations-business-start-times)では、通常診療は営業時間から生成、トリミングは医院が担当者別に登録した開始時刻だけを候補とし、時刻を変更できる。以下の追加・削除リストは現行UI参照で、担当者別編集の実装適合は未確認。予約可能な開始時刻（毎週／特定日）をリスト形式で追加・削除。「カレンダーで編集」リンクから [LINE予約枠カレンダーページ](../28-line-reservation.md)（`/line-reservation/slots?typeId=:id`）へ遷移し、週カレンダーで日別に編集できる。子予約区分を持つ親区分では非表示（「子予約区分ごとに予約枠を設定してください」の案内のみ表示）。
- **予約不可時間**: 予約を受け付けない時間帯（毎週／特定日）を時間範囲で登録。予約可能枠と同様、子予約区分を持つ親区分では非表示。

## 主要な機能

### 1. カレンダー・スケジューリング
ここで設定された標準所要時間は、[最新8点](../../domains/reservations/pages/reservation-management.md#booking-course-option-duration-20261017)のコース未選択時の基礎時間として院内／LINEで共通に用いる。コース選択時はコース時間を基礎にし、選択追加オプション時間を加算する。

### 2. カラーコーディング
区分グループ単位の色分け（例：診察系グループは赤、トリミング系グループは緑）により、カレンダーを俯瞰した際の院内の忙しさやリソース配置を一目で把握可能にします（色は区分グループに設定するもので、予約区分単体には設定できません）。
