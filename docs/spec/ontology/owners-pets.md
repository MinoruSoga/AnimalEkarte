# 飼主・ペットの用語と関係

文書確認日2026-10-15。既存台帳仕様の語彙整理であり、関係の新しい承認や実装済み宣言ではない。[業務正本](../domains/owners-pets/lifecycle.md)・[技術契約](../../design/domains/owners-pets/technical-spec.md)。

| 概念 | 意味・識別 | 関係・境界 |
|:---|:---|:---|
| 飼主 | 医院の顧客台帳。owner ID、飼主Noはその表示別名 | 一人に複数pet。identity groupはD19の既存scope内で別リンク |
| ペット／患者 | 診療・施術等を受ける個体の台帳。pet IDとpet_numberを区別 | 現在主飼主一人、他の副飼主リンクは複数可。臨床記録IDとは別 |
| 主飼主 | pet.owner_idの現在の帰属 | 台帳変更は過去請求・預り金の譲渡を意味しない |
| 副飼主／共同飼育 | pet-ownerの追加リンクと続柄 | 主飼主との重複・同一owner重複なし。会計／LINE／割引の主飼主は変えない |
| identity group | 既存scope内の同一人物／個体の手動連携。医院間利用を本整理で拡大しない | 台帳移管・予約移管・自動名寄せとは別、D19正本 |
| 生死状態 | alive／deceased、死亡日・理由 | 専用死亡／復活writer。削除や過去記録の消去ではない |
| 飼主特記 | owners.is_dangerous、人への対応上の注意 | ペットの特記レベルとは別概念 |
| ペット特記 | danger_levelとdanger_reason、取扱い上の注意 | 高／中／低・未設定。スタッフ専用、限定DTO除外を維持 |
| 動物種 | 全医院共有の分類master | ワクチン／投薬量の固定enumとは別。名称犬／猫のサジェストとの現行関係を保持 |
| 体重 | pet.weightは台帳値 | 個々の診察／施術時バイタルから自動引用する保証なし |
| サイグラム | 飼主生年月日からの派生表示 | 独立永続事実ではない、未設定／不正時分類なし |
| 未保存pet | temp-*等の画面draft | 永続IDでも深いリンク対象でもない |

参照・多重度は業務正本のprimary-secondary／primary-transferへ。医院横断readは他医院writeの許可ではない。メール／電話／氏名の一致は同一IDの証明や保存receiptの代わりにならない。
