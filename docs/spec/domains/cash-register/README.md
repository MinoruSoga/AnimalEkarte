## 区分保護と差額メモの追加合意

締め済み保護は実際に締めた区分だけに適用し、午前締めだけで未締めの午後・夜間を保護対象にしない。確定済み会計の訂正条件は維持する。現金差額が残っていても締められるが、非0差額ではメモ必須とし「原因不明・確認中」も許容する。差額合わせの架空入出金は作らない。 [根拠・受入条件](business-rules.md#closing-segment-difference-agreement-20261015)。FR6件を維持し、AC22件へ6件を追加した計28件。実装適合は別工程。
