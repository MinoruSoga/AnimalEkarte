# templates — フォルダの説明


## このフォルダの役割と使い方

仕様本文を書くための既存形式の入口。

[画面形式](page-spec.md)と[フロー／保存契約形式](workflow-spec.md)を置く。確定業務仕様、受入済み証跡、概念定義の本文を置かない。

子フォルダ：現在、子フォルダはありません。

主要文書：[page-spec.md](page-spec.md)、[workflow-spec.md](workflow-spec.md)

読む順：[記述規約](../authoring-guide.md) → 必要なテンプレート → 対象正本。テンプレートを埋めるためだけの空仕様・重複本文は作らない。

正本・状態：[決定状態と検証状態の規約](../authoring-guide.md#status)に従い、各節・FRの承認根拠と実装／実機状態を別に読む。READMEへの掲載・フォルダ配置は承認や実装済みを表さず、対象外の既存仕様を新たに確定しない。既存の別名入口・索引の責務は維持し、本書は案内を補う。
