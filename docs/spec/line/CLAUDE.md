## 💡 開発・運用の留意点

1.  **UX の一貫性**: LINE アプリ内でも、電子カルテ本体と同じ「Notion ライトモード」のトーン＆マナーを維持する。
2.  **安全な配信**: 誤送信（特に死亡ペット向けのリマインド）は、ブランドイメージに致命的な影響を与えるため、カルテ側の状態を 100% 優先して判定する。
3.  **トークンの保護**: Messaging API の長期トークンは暗号化して保存し、定期的に有効性をテストする。
