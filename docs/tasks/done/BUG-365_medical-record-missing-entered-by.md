# BUG-365: medical_records テーブルにカルテ入力者（entered_by）が記録されない

## 優先度: LOW

## 概要

`medical_records` テーブルに `doctor_id`（担当医）はあるが、
実際にカルテを入力したスタッフ（entered_by）の記録がない。

## 背景

動物病院の運用では、看護師やスタッフが医師の指示のもとカルテを代行入力することがある。
この場合 doctor_id は担当医だが、入力者は別のスタッフとなる。
現状では「誰が入力したか」が追跡できない。

## 修正判断

実装前に運用実態を確認：
1. 実際にスタッフが医師の代わりにカルテ入力する運用があるか
2. 監査上、入力者と担当医の分離が必要か

必要な場合のみ実装する。

## 修正内容（実装する場合）

### DB スキーマ
```sql
entered_by bigint REFERENCES staffs(id)  -- nullable
```

### 全レイヤー
