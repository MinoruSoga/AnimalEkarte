# BUG-091: 検索「×」クリアボタンが未実装

## 概要
検索フィールドに「×」（クリア）ボタンがなく、検索ボタン再クリックで入力欄を閉じても
検索テキストが残り絞り込みが継続する。全件表示に戻れない。

## 再現手順
1. 任意の一覧画面で検索キーワードを入力・実行
2. 検索ボタンを再クリック（入力欄を閉じる）
3. → 検索テキストが残り、絞り込みが継続する

## 期待する動作
- 検索フィールドに「×」ボタンを追加
- クリックで検索テキストをクリア → 全件表示に戻る
