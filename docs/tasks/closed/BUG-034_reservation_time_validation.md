# BUG-034: 予約 開始時刻 > 終了時刻でのバリデーションなし

## 概要
予約作成フォームで開始時刻 > 終了時刻の矛盾した値を入力してもフロントエンドでエラーが表示されない。
バックエンドが 500 を返す。

## 再現手順
1. `/reservations/new` にアクセス
2. 開始時刻: 18:00、終了時刻: 09:00 など逆順で入力
3. 保存をクリック
4. → フロントエンドエラーなし・バックエンド 500

## 期待する動作
- 開始時刻 > 終了時刻の場合「開始時刻は終了時刻より前に設定してください」エラーを表示
- APIリクエストは送信しない
- バックエンドも400を返す

## 実装場所
- `frontend/src/features/reservations/` のフォームコンポーネント
- 保存前の時刻バリデーションロジックを追加
- バックエンド `internal/handler/reservation_handler.go` または service のバリデーション追加
