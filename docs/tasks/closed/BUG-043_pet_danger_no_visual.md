# BUG-043: 危険度「高」ペットの視覚的強調表示なし

## 概要
ペットの危険度を「高」に設定しても、飼主一覧や患者一覧の行に視覚的強調（バッジ・行色変化等）が表示されない。

## 再現手順
1. ペット編集で危険度を「高」に設定・保存
2. 飼主一覧または患者一覧に戻る
3. → 該当行にバッジ・警告色などの視覚的変化なし

## 期待する動作
- 危険度「高」のペットがいる飼主行に警告バッジ（例: 赤い「危険」ラベル）を表示
- または、ペット名横に危険度アイコンを表示

## 実装場所
- `frontend/src/features/owners/` の一覧コンポーネント
- `frontend/src/features/pets/` の表示コンポーネント
