# BUG-043: 危険度「高」ペットの視覚的強調表示が飼主一覧に反映されない

## 概要
飼主一覧（`/owners`）において、危険度「高」に設定されたペットを持つ飼主行に
視覚的な強調表示（バッジ・行色変化・アイコン等）が一切表示されない。

## 再現手順
1. ペット編集モーダルで `danger_level` を「高」に設定・保存
2. `/owners` 一覧ページを確認
3. 対象飼主の行を他の行と比較

## 期待動作
危険度「高」のペットを持つ飼主行に、以下いずれかの視覚的強調が表示される
- 例: 赤いバッジ「⚠ 危険」、行背景色の変化（薄赤）、アイコン表示

## 実際の動作
危険度「高」ペットを持つ飼主行と通常の行を区別する視覚的差異が皆無。
A11y ツリー上も role/aria 属性差異なし。

## 影響範囲
- 飼主一覧 `/owners` の全行表示
- 診察スタッフが危険なペットを持つ飼主を事前に識別できないリスク（安全上の問題）

## 優先度
中（診療安全に関わるが、ペット詳細で確認は可能）
