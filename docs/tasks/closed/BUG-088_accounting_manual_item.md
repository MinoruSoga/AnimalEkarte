# BUG-088: 会計明細への手動入力追加が未実装

## 概要
会計ダイアログで「手動入力で追加」ボタンがない。
物販・処置はマスタ選択のみで、任意の名称・金額を手動で追加できない。
また、会計済みデータの明細行数量が StaticText で編集不可。

## 期待する動作
- 「手動入力で追加」ボタンから名称・単価・数量を自由入力で追加できる
- 手動追加行の区分表示（「その他」等）
- 会計前の明細行数量を編集可能にする

## 実装場所
- `frontend/src/features/accounting/` の会計ダイアログコンポーネント

Low
