## よくある質問 (FAQ)

### Q1: どのドキュメントから読み始めるべき？
**A**: SECTION14-TEST-SUMMARY.md から開始。全体像を 5 分で把握できます。

### Q2: ブラウザUI テストは必須？
**A**: API テストは完了していますが、UI/UX の確認として推奨。本番デプロイ前に実施推奨。

### Q3: テストで HTTP 409 エラーが出た
**A**: FK 依存関係により削除できない正常な動作です。エラーメッセージを確認し、関連データを削除後に再試行。

### Q4: PostgreSQL クエリの実行方法は？
**A**: `docker compose exec -T db psql -U ekarte_user -d ekarte_db -c "SELECT ..."`

### Q5: NG 項目を見つけた場合は？
**A**: スクリーンショット取得後、バグ形式（BUG-XXX）で docs/tasks/open/crash/ に起票。
