# BUG-045: 会計明細に物販追加後、既存明細がUIから消え合計が不正になる

## 概要
会計精算ページ（`/accounting/:id`）の「物販・その他追加」から品目を選択すると、
既存の明細行（カルテ連携アイテム）がUI上から全て消え、選択した物販アイテムのみが表示される。
また、バックエンドへのPOSTリクエストが発生せず、リロードすると元の状態に戻る。

## 再現手順
1. `/accounting/1` を開く（再診料¥800 + アモキシシリン¥3,850 = ¥4,730 の明細）
2. 「物販・その他追加」ボタンをクリック
3. ダイアログから「ノミ・ダニ予防首輪（¥1,500）」を選択
4. 明細一覧を確認

## 期待動作
- 既存明細（再診料、アモキシシリン）はそのまま表示される
- ノミ・ダニ予防首輪が3行目として追加される
- 合計: ¥4,730 + ¥1,650 = ¥6,380 に更新される
- POST `/api/v1/accountings/1/items` 等でバックエンドに保存される

## 実際の動作
- 既存の明細行（再診料・アモキシシリン）がUI上から消える
- ノミ・ダニ予防首輪 ¥1,650 のみ表示（税抜¥1,500 + 消費税¥150）
- 「今回の請求金額」が ¥1,650 のみ表示（¥4,730 を含まない）
- ネットワークリクエスト確認: POSTリクエスト発生なし（GETのみ）
- ページリロードで元の ¥4,730（2アイテム）に戻る

## 影響範囲
- 会計精算ページ全体の物販追加機能
- 物販を追加しても保存されない → 会計明細の追加が全て無効

## 優先度
高（会計明細への追加が機能しないため、会計業務に直接影響）
