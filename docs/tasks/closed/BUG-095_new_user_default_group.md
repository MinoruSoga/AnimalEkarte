# BUG-095: 新規ユーザー作成時のデフォルトグループ未付与

## 概要
スタッフ新規作成後にパーミッショングループが未付与。手動でグループを設定する必要がある。
権限設定漏れのリスクがある。

## 期待する動作
- 新規ユーザー作成フォームに「グループ」選択フィールドを追加
- または作成後に自動でデフォルトグループ（例: 一般スタッフ）を付与

## 実装場所
- `frontend/src/features/users/` または `settings/` の新規作成フォーム
- バックエンドで作成時にデフォルトグループを付与するロジック追加
