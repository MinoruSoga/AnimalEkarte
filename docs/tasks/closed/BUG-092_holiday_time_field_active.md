# BUG-092: 休日選択時の時刻フィールドが非活性化されない

## 概要
シフト設定で「休日」を選択しても開始時刻・終了時刻フィールドが常時活性のまま。
休日の場合、時刻入力は不要なため非活性（disabled）または非表示にすべき。

## 期待する動作
- 「休日」選択時に開始時刻・終了時刻フィールドを非活性（disabled）または非表示にする

## 実装場所
- `frontend/src/features/` のシフト設定フォームコンポーネント
