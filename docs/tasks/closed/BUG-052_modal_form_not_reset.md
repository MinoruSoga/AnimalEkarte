# BUG-052: モーダル・サイドパネルのキャンセル後に入力値が残留する

## 概要
ペット追加モーダルでキャンセル（または×）して再度開くと、前回入力した値が残留している。
ペット編集モーダルも同様。入力値がリセットされていない。

## 再現手順
1. 飼主詳細ページで「ペットを追加」モーダルを開く
2. ペット名などを入力
3. 「キャンセル」または「×」で閉じる
4. 再度「ペットを追加」をクリック
5. → 前回の入力値が残留している

## 期待する動作
- モーダル・サイドパネルを閉じると、未保存の入力値はリセットされる

## 実装場所
- `frontend/src/features/owners/` または `features/pets/` のペット追加・編集モーダル
- モーダルを閉じる際にフォームをリセットするロジックを追加
