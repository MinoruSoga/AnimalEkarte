# BUG-037: ダッシュボード PatientInfoCard に担当医フィールドが表示されない

## 概要
ダッシュボードの予約カードをクリックして表示される PatientInfoCard（詳細ポップアップ）に、
担当医（スタッフ）フィールドが存在しない。仕様上は表示が期待される。

## 再現手順
1. ダッシュボード（`/`）を開く
2. カンバンボードの予約カード（例: 3/28 Iris(イリス)）をクリック
3. 詳細ポップアップが表示される

## 期待動作
PatientInfoCard に「担当医」または「担当スタッフ」フィールドが表示される

## 実際の動作
- ペット名（Iris）、動物種（犬）は表示される
- 担当医フィールドがカード UI に存在しない
- 予約作成時に担当者（スタッフ）を設定していない場合、データ自体が NULL の可能性あり

## 影響範囲
- ダッシュボード / 予約詳細ポップアップ

## 優先度
低〜中（情報表示欠落。担当医フィールド自体が予約データに含まれているか要確認）

## 調査ポイント
- 予約（reservation）テーブルに staff_id / assigned_doctor_id カラムがあるか確認
- PatientInfoCard コンポーネントに担当医フィールドの実装漏れか、データ欠落か切り分け
