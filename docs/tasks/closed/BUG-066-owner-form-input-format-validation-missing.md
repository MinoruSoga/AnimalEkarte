# BUG-066: 飼主登録フォームの入力形式バリデーション未実装（電話・メール・値引率）

## 種類
バグ（フロントエンドバリデーション欠落）

## 重要度
低

## 発見日
2026-03-29

## 再現手順

1. `/owners/new` を開く
2. 電話番号フィールドに「abc」を入力する
3. メールアドレスフィールドに「invalid-email@」を入力する
4. 値引率フィールドに「-10」を入力する
5. 「登録」ボタンをクリックする

## 期待動作

- 電話番号の形式不正（数字以外）でインラインエラーを表示する
- メールアドレスの形式不正でインラインエラーを表示する
- 値引率の負値入力をフロントエンドで弾く（min=0 の実効バリデーション）

## 実際の動作

- 「abc」の電話番号でエラーメッセージ未表示（バックエンドにも通過する）
- 「invalid-email@」でエラーメッセージ未表示
- `min=0` 属性があるが「-10」入力可能でエラー未表示

## 影響範囲

- 飼主登録フォーム（`/owners/new`）
- 飼主編集フォーム（`/owners/:id/edit`）

## 修正方針

`useOwnerForm.ts` のバリデーションロジックに以下を追加：
1. 電話番号: 正規表現でフォーマットチェック（例: `/^[0-9\-+()]{7,20}$/`）
2. メールアドレス: `type="email"` の HTML5 バリデーションを有効化、または正規表現チェック
3. 値引率: `value < 0` 時にエラーを表示（min=0 は入力阻止ではないため明示的チェックが必要）

## 優先度
低（バックエンドでも受け入れるため即時の機能障害はないが、データ品質への影響あり）
