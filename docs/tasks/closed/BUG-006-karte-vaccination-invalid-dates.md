# BUG-006: カルテ予防接種タブ - シードデータに無効な日付が含まれる

## 発見日
2026-03-24

## 発見方法
ブラウザテスト（Chrome DevTools MCP）

## 症状
カルテ詳細画面の「予防接種」タブを開くと、一部の接種記録に無効な日付が表示される。

例：
- `25/1/35`（1月35日は存在しない）
- `25/1/40`（1月40日は存在しない）
- `25/1/45`（1月45日は存在しない）

## 再現手順
1. カルテ一覧 (`/medical-records`) を開く
2. 任意のカルテ詳細を開く
3. 「予防接種」タブをクリック
4. 日付列に無効な値が表示されることを確認

## 原因の仮説
- `backend/migrations/002_seed_master.sql` または `001_init.sql` のシードデータに不正な日付が含まれている
- または、フロントエンドの日付フォーマット処理でゼロ埋めや範囲チェックが行われていない

## 影響範囲
- カルテ詳細 > 予防接種タブ
- 予防接種管理一覧 (`/vaccinations`) では正常な日付が表示されているため、表示ロジックの差異も疑われる

## 優先度
Medium（シードデータの問題であれば修正は容易）

## 修正方針
1. シードデータの日付値を正しい値に修正する
2. フロントエンドの日付表示ロジックで無効日付をフォールバック表示する（防御的実装）
