# BUG-MEDI-005: タブ切替後にスクロール位置がリセットされない

## 概要
カルテ詳細画面で長いコンテンツのタブ切替後、スクロール位置が保持される。
共有スクロールコンテナのため、別タブに切り替えると前のタブのスクロール位置が引き継がれる。

## 期待する動作
- タブ切替時にスクロール位置をトップにリセット
- または各タブが独立したスクロールコンテナを持つ

## 実装場所
- `frontend/src/features/medical-records/` のタブコンポーネント
- `handleTabChange` にスクロールリセット処理（`container.scrollTop = 0`）を追加
