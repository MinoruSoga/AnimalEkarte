# BUG-039: カルテ診断タブのプレースホルダーに内部フィールド名が表示される

## 概要
カルテ編集画面の診断カテゴリ・病名フィールドのプレースホルダーに
「診断カテゴリID」「診断病名ID」という開発用ダミーテキストが表示されている。

## 再現手順
1. カルテ編集画面の「診察・治療プラン」タブを開く
2. 診断カテゴリ・病名フィールドを確認
3. → プレースホルダーに「診断カテゴリID」「診断病名ID」が表示される

## 期待する動作
- プレースホルダーを適切な説明文に変更（例: 「診断カテゴリを選択」「病名を入力」）

## 実装場所
- `frontend/src/features/medical-records/` の診断セクションコンポーネント

## 優先度
Medium
