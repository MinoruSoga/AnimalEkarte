# BUG-073: 空白のみ入力がバリデーションされず登録成功する / FE・BE必須フィールド定義の乖離

## 概要
以下の問題が存在する:
1. **空白のみ入力が通過**: 飼主名に「   」（半角・全角スペースのみ）でPOST → 201で登録成功（trim後の空チェックなし）
2. **FE/BE必須フィールド定義の乖離**: フロントエンドはphone必須として扱うが、バックエンドはphone=""で201成功

## 再現手順
1. 飼主名に「   」（スペース3文字）を入力して飼主登録
2. → HTTP 201 で飼主No=XXX として登録成功

## 期待する動作
- バックエンド: 全文字列フィールドで `strings.TrimSpace()` 後に空チェック
- 空白のみの場合は 400 Bad Request + バリデーションエラー
- FE/BE の必須フィールド定義を統一する

## 実装場所
- `backend/internal/service/owner_service.go` 等の各サービスのバリデーション
- または `backend/internal/handler/` のリクエストバリデーション
