# BUG-086: シフト 開始時刻>終了時刻（逆転）でバックエンド500

## 概要
シフト編集フォームで開始時刻 > 終了時刻（逆転）で保存するとバックエンドが500を返す可能性がある。
フロントエンドのバリデーションが未実装。

## 期待する動作
- 「開始時刻は終了時刻より前に設定してください」エラーをフロントエンドで表示
- バックエンドも400バリデーションエラーを返す（500ではなく）

## 実装場所
- `frontend/src/features/` のシフト編集フォーム（フロントバリデーション追加）
- `backend/internal/handler/` または service でのバリデーション追加
