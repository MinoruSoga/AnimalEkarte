- BUG-387: 2回目以降のLINE予約でお客様情報が自動復元されない

## 事前条件

- LINE予約設定が `running` である
- 対象医院で LIFF 予約画面にアクセスできる
- 管理画面で受付一覧を確認できる権限がある
- `owner` / `pet` 自動紐付け確認用に、既存の飼い主データを1件以上用意する

---

## ケース1: 新規 LINE予約の受付詳細表示

### 手順

1. LIFF 予約画面を開く
2. STEP1 で以下を入力する
   - お名前
   - 電話番号
   - 飼い主名
   - ペット名
   - 犬種
3. 予約を確定する
4. 管理画面の受付一覧で該当予約の詳細を開く

### 期待結果

- [ ] 飼い主名が空欄でない
- [ ] ペット名が空欄でない
- [ ] 犬種が空欄でない
- [ ] relation 未紐付けでも `customer_fields` 由来の値が表示される

## ケース2: 受付済み変更時のカルテ自動作成

### 手順

1. ケース1で作成した予約を開く
2. ステータスを `受付済` に変更する
3. カルテ一覧または予約詳細から、対象カルテの作成有無を確認する

### 期待結果

- [ ] ステータス変更が正常終了する
- [ ] カルテが自動作成される
- [ ] 作成カルテが該当予約に紐付く
- [ ] owner / pet 自動紐付け済みのケースでは `owner_id` / `pet_id` が反映されている
