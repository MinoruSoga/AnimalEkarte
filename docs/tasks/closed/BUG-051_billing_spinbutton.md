# BUG-051: 会計の割引率・治療プラン明細の単価・数量フィールドが機能しない

## 概要
会計画面のグローバル割引率（%）・割引額（円）フィールドが spinbutton の valuemax=0 制約により機能しない。
値を入力しても割引後金額が更新されない。
また、治療プラン明細の単価・数量が StaticText（編集不可）となっている。

## 再現手順
1. 会計管理で請求書を開く
2. グローバル割引率フィールドに「10」を入力
3. → 割引後金額が更新されない

## 期待する動作
- グローバル割引率・割引額フィールドが正常に入力・計算できる
- 治療プラン明細の単価・数量が編集可能になる

## 実装場所
- `frontend/src/features/accounting/` の請求書フォームコンポーネント
- spinbutton の valuemax 制約を修正、handleUpdateItem で discountRate を正しく反映

## 優先度
High（コア機能が動作しない）
