# BUG-040: 診断カテゴリ変更後に病名が自動クリアされない

## 概要
カルテの診断セクションで診断カテゴリを変更・クリアしても、選択済みの病名が残存する。
また、カテゴリ未選択状態でも全カテゴリの病名コンボボックスが活性のまま表示される。

## 再現手順
1. カルテ詳細画面の診断セクションにアクセス
2. 診断カテゴリ「皮膚科」を選択 → 病名「膿皮症」を選択
3. 診断カテゴリをクリア（または別カテゴリに変更）
4. → 病名「膿皮症」がそのまま残る（自動クリアなし）
5. カテゴリ未選択で病名コンボボックスをクリック → 全病名が表示される

## 期待する動作
- カテゴリ変更/クリア時に病名フィールドも自動クリア
- カテゴリ未選択時は病名コンボボックスを非活性（disabled）にする

## 実装場所
- `frontend/src/features/medical-records/` の診断セクションコンポーネント
