# BUG-099: 同時編集時の楽観的ロックが未実装

## 概要
2ユーザーが同一レコードを同時編集した場合、バックエンドに楽観的ロック（version / ETag / If-Match）がない。
後で保存したユーザーの変更が先の変更を上書きする（後勝ち）。

## 期待する動作
- 編集時に `version` または `updated_at` を送信
- バックエンドで競合を検出し 409 Conflict を返す
- フロントエンドで「他のユーザーが変更しました。再読み込みしてください」メッセージ表示

## 実装場所
- バックエンドモデルに `version` フィールド追加
- PATCH API で `If-Match` ヘッダーまたは `version` フィールドを検証
- フロントエンドで 409 エラーハンドリング追加
