# BUG-096: 過去日付入力時の汎用エラーメッセージ

## 概要
ワクチン有効期限などに過去日付を入力した際、「入力値が不正です」という汎用メッセージが表示される。
過去日付専用のエラー文言が表示されない。

## 期待する動作
- 「有効期限は本日以降の日付を入力してください」など具体的なエラーメッセージ

## 実装場所
- `frontend/src/features/vaccinations/` のフォームバリデーション
- 日付バリデーション時の過去日付専用エラー文言を追加
