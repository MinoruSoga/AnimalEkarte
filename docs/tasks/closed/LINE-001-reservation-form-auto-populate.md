# INVESTIGATION: LINE予約 - 予約フォーム入力値がカルテ予約詳細に反映されない

## 事象
LINE予約フォームで入力した飼い主名・ペット名・犬種が、カルテ側の予約詳細画面に反映されない。

## 機能定義
「予約フォームからの電子カルテへの自動入力」

LINE予約フォームで収集した情報（飼い主名・ペット名・犬種）を、カルテ側の予約詳細に自動連携する仕様。

## 調査事項

1. **データ保存フロー確認**
   - LINE予約フォームのサブミット時に飼い主名・ペット名・犬種が API に送信されているか
   - `line_customers` テーブルと `appointments` テーブルへの保存が正しく行われているか

2. **カルテ側の表示フロー確認**
   - 予約詳細 API（`GET /api/v1/appointments/:id`）のレスポンスに飼い主名・ペット名・犬種が含まれているか
   - フロントエンドの予約詳細コンポーネントで該当フィールドを表示しているか

3. **自動入力の実装状況確認**
   - `line_customers` → `owners` / `pets` への自動紐付けロジックが実装されているか（新規飼い主の場合）
   - 既存飼い主の場合のマッチングロジック

## 関連ファイル（調査候補）
- `backend/internal/handler/` - LINE予約ハンドラ
- `backend/internal/service/` - 予約登録サービス
- `frontend/src/features/reservations/` - 予約詳細表示
- `docs/line/reservation-spec.md` - 機能仕様書
