# BUG-044: バイタル記録の新規登録で POST API が 500 エラーを返す

## 概要
カルテ詳細ページの「バイタル記録」モーダルから記録を追加しようとすると、
`POST /api/v1/medical-records/:id/vitals` が HTTP 500 を返してエラートーストが表示される。

## 再現手順
1. `/medical-records/21` を開く
2. 右下の「バイタル記録」ボタンをクリック
3. モーダルで「記録を追加」をクリック
4. 記録日時（例: `2026-03-28T10:00`）と体温（例: `38.5`）を入力
5. 「追加」ボタンをクリック

## 期待動作
- HTTP 201 が返り、バイタル記録が一覧に追加される
- トースト「バイタル記録を追加しました」が表示される

## 実際の動作
- `POST http://localhost:8080/api/v1/medical-records/21/vitals` → **HTTP 500**
- トースト「サーバーエラーが発生しました。しばらく経ってから再度お試しください。」が表示される

## 影響範囲
- カルテ詳細ページのバイタル記録新規登録（全カルテ共通）
- バイタル記録が一切保存できない

## 優先度
高（バイタル記録が保存できないため診療記録の完全性に影響）
