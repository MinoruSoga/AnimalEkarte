# BUG-TRT-001: 治療明細の数量に0が入力できない

## 概要
治療タブの明細行において、数量フィールドに0を入力すると強制的に1に戻される。
`min=0.1`（実際は `0.10000000149011612`）制約により0が拒否される。
エラーメッセージも表示されない。

## 再現手順
1. カルテ編集 → 「治療」タブ → 「明細を追加」で行を追加
2. 数量フィールド（初期値=1）をクリックして編集モードに入る
3. `0` を入力して Tab/Enter で確定
4. → 値が `1` に強制リセットされる（エラーメッセージなし）

## 現在の制約値
```
valuemin="0.10000000149011612"  ← float32精度起因の不正確な値
```

## 期待する動作
- 数量0は医療上意味がない場合は、バリデーションエラーを表示する（「数量は1以上を入力してください」）
- または、0を許容して「キャンセル済み」扱いにするユースケースを設計して実装する

## 実装場所
- `frontend/src/features/medical-records/components/` 治療タブコンポーネント
- spinbutton の `min` 属性が `0.1` になっている箇所を確認・修正
