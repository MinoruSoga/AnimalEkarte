# BUG-027: トリミング登録フォームのバリデーションエラー表示なし

## 概要
トリミング登録フォームでコース未選択のまま「保存」を押しても、バリデーションエラーが表示されない。
API リクエストも送信されずサイレント失敗する（BUG-024ワクチンと同様の問題）。

## 再現手順
1. `/trimming/new?petId=1` にアクセス
2. 何も選択せず「保存」をクリック
3. → エラーメッセージなし、リクエストなし、ページ遷移なし

## 期待する動作
- コースが未選択の場合: 「コースを選択してください」エラーを表示
- 保存前にバリデーションを実行しエラーがある場合は送信しない

## 実装場所
- `frontend/src/features/trimming/` のフォームコンポーネント
- 保存ボタン押下時のバリデーションロジックを追加
