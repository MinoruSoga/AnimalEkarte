# BUG-029: シフト編集ダイアログで既存時刻が空欄になり、保存すると NULL になる

## 概要
シフト編集ダイアログで既存の開始・終了時刻が表示されない（空欄）。
そのまま保存すると `start_time`/`end_time` が NULL になる。

## 再現手順
1. `/shifts` でシフトが登録されているスタッフのエントリをクリック
2. 「編集」ダイアログを開く
3. 開始時刻・終了時刻フィールドを確認
4. → 既存の時刻が表示されず空欄
5. 空欄のまま保存
6. → PATCH リクエストで `start_time: null`, `end_time: null` が送信・保存される

## 期待する動作
- 編集ダイアログを開くと既存の start_time/end_time が初期値として表示される

## 実装場所
- `frontend/src/features/shifts/` の編集ダイアログコンポーネント
- フォームの初期値設定で既存の時刻データを正しくバインドする
