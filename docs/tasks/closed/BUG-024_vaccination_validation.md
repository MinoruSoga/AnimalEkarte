# BUG-024: ワクチン新規登録の必須バリデーションなし

## 概要
ワクチン接種登録フォームで「保存」ボタンを押しても、必須フィールド（接種日・ワクチン種別）が未入力の場合に
バリデーションエラーが表示されない。API リクエストも送信されずサイレント失敗する。

## 再現手順
1. `/vaccinations/new?petId=1` にアクセス
2. 何も入力せず「保存」をクリック
3. → エラーメッセージなし、リクエストなし、ページ遷移なし（完全にサイレント）

## 期待する動作
- 接種日が空の場合: 「接種日は必須です」エラーを表示
- ワクチン種別が未選択の場合: 「ワクチンを選択してください」エラーを表示
- バリデーションエラーがある場合はフォームを送信しない

## 実装場所
- `frontend/src/features/vaccinations/` の新規登録フォームコンポーネント
- 保存ボタン押下時のバリデーションロジックを追加
