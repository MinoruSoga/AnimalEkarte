# BUG-048: マスタ設定サイドパネルの名称フィールドでEnterキーが保存トリガーにならない

## 概要
マスタ設定の各サイドパネル（動物種類・薬品等）の名称入力フィールドで
Enterキーを押しても保存が実行されない。

## 期待する動作
- テキストフィールドでEnterキー押下時に「保存」ボタンと同じ動作をする

## 実装場所
- `frontend/src/features/` の各マスタ設定サイドパネルコンポーネント
- `onKeyDown` ハンドラでEnterキーを検知して保存処理を呼び出す
