# BUG-045: 会計明細書に既存カルテ連携行が表示されない

## 概要
物販を追加した後の明細書に、ローカルで追加したアイテムのみ表示される。
既存カルテから連携された治療明細行が明細書に含まれない。

## 再現手順
1. カルテに治療項目を入力・保存
2. 会計ページで当該カルテに紐付く請求書を開く
3. 物販アイテムを追加
4. 「明細書」ボタンで印刷プレビューを確認
5. → ローカル追加の物販アイテムのみ表示（カルテ連携行なし）

## 期待する動作
- カルテの治療項目と、手動追加した物販アイテムの両方が明細書に表示される

## 実装場所
- `frontend/src/features/accounting/` の明細書プレビューコンポーネント
- カルテ連携データと手動追加データをマージして表示するロジック
