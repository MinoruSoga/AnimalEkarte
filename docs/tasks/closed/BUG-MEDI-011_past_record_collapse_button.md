# BUG-MEDI-011: 過去カルテパネルの「折りたたむ」ボタンが未実装

## 概要
カルテ詳細の過去カルテパネルで、展開した過去カルテカードを折りたたむボタンが未実装。
現在は「引用」ボタンのみ存在し、展開後に閉じる手段がない。

## 再現手順
1. カルテ詳細画面にアクセス
2. 過去カルテ一覧の行をクリック → カード展開
3. → 「折りたたむ」ボタンがない（「引用」ボタンのみ）

## 期待する動作
- 展開した過去カルテカードに「折りたたむ」（または「閉じる」）ボタンを追加
- クリックでカードが折りたたまれる

## 実装場所
- `frontend/src/features/medical-records/` の過去カルテパネルコンポーネント
- 展開状態管理の toggle ロジックと折りたたみボタン追加
