# BUG-042: 問診テンプレートマスタのカテゴリ列に英語コードが表示される

## 概要
マスタ設定の「問診テンプレートマスタ」（`/settings/inquiry-templates`）で、
カテゴリ列に日本語ラベルではなく内部コード名（英語snake_case）がそのまま表示されている。

## 再現手順
1. `/settings/inquiry-templates` を開く
2. 一覧のカテゴリ列を確認

## 期待動作
カテゴリ列に日本語ラベルが表示される
- `chief_complaint` → 「主訴」
- `history` → 「既往歴」
- `current_medications` → 「現在の投薬」
- `notes` → 「メモ/備考」

## 実際の動作
カテゴリ列に内部コード名が表示される:
- `chief_complaint`
- `history`
- `current_medications`
- `notes`

## 影響範囲
- マスタ設定 > 問診テンプレートマスタ一覧のカテゴリ列

## 優先度
中（機能に支障はないがUX品質の問題。管理者向け画面のため影響範囲は限定的）
