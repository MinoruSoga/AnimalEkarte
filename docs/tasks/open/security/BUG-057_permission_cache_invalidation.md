# BUG-057: 権限変更後にページリロードが必要（即時反映なし）

## 概要
権限グループのリソース権限を変更しても、割当済みユーザーの現セッションに即時反映されない。
ページリロードが必要で、リロードするまで古い権限でアクセス可能。

## 再現手順
1. ユーザーAがログイン中
2. 管理者がユーザーAの権限グループを変更
3. ユーザーAのページを確認
4. → 権限変更がリアルタイムに反映されない（ページリロードまで古い権限が有効）

## 期待する動作
- 権限変更後、次のAPIリクエスト時に最新権限を参照する
- または定期的な権限再取得（数十秒ごと）を実装

## 実装場所
- フロントエンド: 権限情報のキャッシュ戦略（React Query の staleTime）を短縮
- バックエンド: JWTに権限情報を含めず、毎リクエストでDB参照する設計へ
