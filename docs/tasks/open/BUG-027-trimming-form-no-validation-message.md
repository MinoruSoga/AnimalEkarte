# BUG-027: トリミング登録フォームの必須バリデーションエラーが表示されない

## 種類
バグ（フロントエンドバリデーション — エラーメッセージ未表示）

## 重要度
高

## 発見日
2026-03-28

## 再現手順
1. `/trimming/select-pet` でペットを選択して新規登録フォームへ遷移
2. コース・担当者を未選択のまま「保存」ボタンをクリック

## 期待動作
- 「コースを選択してください」等のバリデーションエラーがコースフィールド下に表示される
- POST リクエストが送信されない

## 実際の動作
- 「保存」ボタンをクリックしても画面に何も変化しない
- バリデーションエラーメッセージが表示されない（フィールドに赤枠も出ない）
- POST リクエストは送信されない（フロントエンドで止まっている）
- ユーザーは何が問題なのか判断できない

## 影響
- ユーザーが保存できない理由を把握できない
- 操作が詰まっているように見え、UX が著しく悪化

## 修正方針
### フロントエンド
- `features/trimming/hooks/` のフォームフックでバリデーション実行時にエラーメッセージを `formErrors` ステートにセット
- コース未選択時: コースフィールド下に「コースを選択してください」を表示（`FormFieldError` コンポーネントを使用）
- `components/shared/FormFieldError/` を使用して一貫した UI で表示
- `useTrimmingForm` フック内の `validate()` 関数を修正してエラーを状態として保持
