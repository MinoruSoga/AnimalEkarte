# BUG-001: ペットなし飼主が飼主一覧に表示されない

## 種類
バグ

## 発見日
2026-03-20

## 再現手順
1. `/owners/new` で飼主のみ登録（ペット追加なし）
2. `/owners` 一覧に戻る
3. 登録した飼主が一覧に表示されない

## 期待動作
ペットが0件の飼主も一覧に表示されるべき。ペットカラムは空欄で表示。

## 実際の動作
一覧がペット行ベースで表示されるため、ペットなし飼主は一切表示されない。

## 影響
新規登録した飼主が一覧で見つからず、編集もできない（直接URL `/owners/:id` でのみアクセス可能）。

## 修正方針
フロントエンドの一覧クエリまたは表示ロジックを修正し、ペットなし飼主もペットカラム空欄で1行表示するようにする。
