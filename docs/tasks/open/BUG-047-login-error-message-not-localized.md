# BUG-047: ログイン失敗時のエラーメッセージが英語の生HTTPエラーになる

## 概要
ログイン画面でメールアドレスまたはパスワードを誤って入力してログインを試みると、
「Request failed with status code 401」という英語の生HTTPエラーメッセージが表示される。

## 再現手順
1. `/login` を開く
2. 間違ったメールアドレス（例: wrong@example.com）と間違ったパスワードを入力
3. 「ログイン」ボタンをクリック（またはEnterキー）

## 期待動作
- 「メールアドレスまたはパスワードが違います」等の日本語のユーザーフレンドリーなエラーメッセージが表示される
- フォームの下部またはトースト通知として表示される

## 実際の動作
- 「Request failed with status code 401」という英語の生HTTPエラーが赤字でフォーム内に表示される
- ユーザーにとって意味不明なエラーメッセージ

## 影響範囲
- ログイン画面のエラーハンドリング
- ユーザーエクスペリエンスの低下（日本語システムで英語エラーが表示される）

## 優先度
低（機能的には動作しており、エラーは表示される）
