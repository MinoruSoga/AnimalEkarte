# BUG-041: カルテ Tab4 予防接種名ドロップダウンにワクチンマスタではなく診断カテゴリが表示される

## 概要
カルテ詳細ページ Tab4（予防接種）の「予防接種名」ドロップダウンに、
ワクチン名（混合ワクチン5種、狂犬病ワクチン等）ではなく
診断カテゴリ（食欲不振、嘔吐・下痢、皮膚・被毛異常、呼吸困難、排尿・排泄異常、外傷・骨折）
が表示される。

## 再現手順
1. カルテ詳細ページ（例: `/medical-records/21`）を開く
2. Tab4「予防接種」を選択
3. 「予防接種名」ドロップダウンをクリックして開く

## 期待動作
ワクチンマスタから正しいワクチン種別が表示される
- 例: 混合ワクチン5種（犬）、混合ワクチン3種（猫）、狂犬病ワクチン、フィラリア予防薬 等

## 実際の動作
診断カテゴリの選択肢が表示される:
- 食欲不振
- 嘔吐・下痢
- 皮膚・被毛異常
- 呼吸困難
- 排尿・排泄異常
- 外傷・骨折

デフォルト選択値も「食道炎」（疾患名）が表示されている。

## 原因推定
フロントエンドで予防接種名ドロップダウンに渡しているAPIエンドポイントまたはデータが誤っている。
- 正しい API: `GET /masters/vaccine-types` または `GET /masters/vaccines`
- 誤った API: `GET /masters/diagnosis-categories` を呼び出している可能性

## 影響範囲
- カルテ詳細ページ Tab4「予防接種名」選択フィールド
- 誤ったワクチン名（診断カテゴリ名）が接種記録に保存されるリスク

## 優先度
高（予防接種記録の正確性に直結。ワクチン接種記録に診断カテゴリ名が入力・保存される可能性）
