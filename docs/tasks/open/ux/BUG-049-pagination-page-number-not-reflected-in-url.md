# BUG-049: ページネーションのページ番号がURLに反映されない

## 概要
飼主一覧（`/owners`）等の一覧ページでページネーションの2ページ目以降をクリックしても、URLに `?page=2` 等のクエリパラメータが付かない。
そのため、ブラウザリロード・URL共有・ブラウザバック後でページ状態が失われる。

## 再現手順
1. `/owners` を開く（28件・2ページ）
2. ページネーションの「2」をクリックしてページ2に移動（21-28件表示）
3. URLバーを確認する
4. ブラウザをリロード（F5）する

## 期待動作
- ページ2クリック後: URL が `/owners?page=2` になる
- リロード後: `/owners?page=2` として2ページ目が表示される

## 実際の動作
- ページ2クリック後: URL は `/owners` のまま（クエリパラメータなし）
- リロード後: ページ1（1-20件）に戻る

## 影響範囲
- 飼主一覧・カルテ一覧・その他ページネーション付き全一覧ページ
- URLのコピー・共有でページ状態が失われる
- ブラウザバック後に一覧に戻るとページ1に戻される

## 優先度
低（機能は動作するが、UXの観点でページ状態が非永続）
