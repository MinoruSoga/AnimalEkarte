# BUG-002: ペット登録モーダルのラベル「CFBE」「BREED」が英語のまま

## 種類
バグ（UI国際化不備）

## 発見日
2026-03-20

## 再現手順
1. `/owners/:id` で飼主編集画面を開く
2. 「ペット追加」ボタンをクリック
3. モーダル内のラベルを確認

## 期待動作
- 「CFBE」→「種別」または「動物種」
- 「BREED」→「品種」

## 実際の動作
英語ラベル「CFBE」「BREED」がそのまま表示されている。

## 影響
ユーザーが入力項目を理解しにくい。

## 修正方針
フロントエンドのペット登録モーダルコンポーネントでラベルを日本語に修正。
