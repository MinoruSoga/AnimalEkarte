# BUG-025: 予防接種編集フォームの削除ボタンが無反応

## 種類
バグ（フロントエンド — 削除ボタン非動作）

## 重要度
高

## 発見日
2026-03-28

## 再現手順
1. `/vaccinations` で任意の行をクリックして編集フォームへ遷移
2. フォーム右下の「削除」ボタンをクリック

## 期待動作
- 確認ダイアログが表示される（「本当に削除しますか？」等）
- 「確認」を押すと `DELETE /v1/vaccinations/:id` が送信され、一覧にリダイレクト

## 実際の動作
- 「削除」ボタンをクリックしても何も起きない
- ダイアログが表示されない
- ネットワークリクエストも送信されない
- コンソールエラーなし（イベントハンドラが未接続または空の状態）

## 影響
- 予防接種記録を削除できない
- ユーザーは削除操作が可能かどうか判断できない

## 修正方針
### フロントエンド
- `features/vaccinations/routes/` の編集フォームで削除ボタンのクリックハンドラを確認・実装
- `useVaccinationForm` フックまたは同等のフックで `handleDelete` を実装
- 削除確認ダイアログ（`AlertDialog` または `ConfirmDialog`）を表示
- 確認後に `DELETE /v1/vaccinations/:id` を呼び出す API 関数を作成・呼び出し
- 削除成功後に `/vaccinations` へリダイレクト
