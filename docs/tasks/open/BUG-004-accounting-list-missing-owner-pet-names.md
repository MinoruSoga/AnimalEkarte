# BUG-004: 会計一覧で飼主名・ペット名が表示されない

## 種類
バグ

## 発見日
2026-03-20

## 再現手順
1. `/accounting` で会計一覧を表示
2. 飼主名・ペット名カラムを確認

## 期待動作
各行に飼主名とペット名が表示される。

## 実際の動作
カラムヘッダに「飼主名」「ペット名」のソートボタンは存在するが、データ行には飼主名・ペット名が表示されていない（空欄）。

## 影響
どの飼主・ペットの会計か一覧から判別できない。

## 修正方針
バックエンドのaccounting APIレスポンスで飼主・ペット情報がPreloadされているか、フロントエンドの表示ロジックを確認。
