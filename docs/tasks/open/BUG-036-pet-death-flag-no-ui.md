# BUG-036: ペットの死亡フラグをUIから変更できない（死亡登録機能未実装）

## 種類
バグ（フロントエンド — 機能未実装）

## 重要度
中

## 発見日
2026-03-28

## 再現手順
1. `/owners/:id/edit` でペット編集の「...」ボタンをクリック
2. ペット編集モーダルを確認

## 期待動作
- ペット編集モーダルまたはペット詳細に「死亡登録」ボタンまたは「生死ステータス」切替UIが存在する
- 死亡フラグを ON にすると `status: "dead"` が API に送信される
- 一覧の生死ステータスバッジが「死亡」表示に変わる

## 実際の動作
- ペット編集モーダルに死亡フラグを変更するUIが存在しない
- バックエンドの `status` フィールド（"alive"/"dead"）はAPIレベルでは存在するがUIから変更不可

## 影響
- 死亡したペットを「死亡」ステータスにできない
- 一覧で全ペットが「生存」表示になり、死亡済みペットの識別ができない
- カルテ作成時に死亡ペットを選択できてしまう（期待動作では警告または非表示）

## 修正方針
### フロントエンド
- ペット編集モーダルに「生死ステータス」選択UI（ラジオボタンまたはトグル）を追加
- `status: "alive" | "dead"` を PATCH リクエストで送信する

## 対象ファイル（推定）
- フロントエンドのペット編集モーダルコンポーネント（`features/owners/` 配下）
