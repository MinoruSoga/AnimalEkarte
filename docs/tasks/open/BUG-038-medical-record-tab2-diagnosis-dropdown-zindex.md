# BUG-038: カルテ Tab2 診断カテゴリドロップダウンが左サイドバーに重なって表示される

## 概要
カルテ詳細ページ（`/medical-records/:id`）の Tab2（診察/治療プラン）で、
診断カテゴリの Select コンボボックスを開くと、ドロップダウンリストが
左サイドバー（ナビゲーション）領域に重なって表示される。

## 再現手順
1. カルテ詳細ページ（例: `/medical-records/21`）を開く
2. Tab2「診察/治療プラン」を選択
3. 「診断1カテゴリ」の Select ボックスをクリックしてドロップダウンを開く

## 期待動作
ドロップダウンリストがカルテ編集フォーム内（コンテンツエリア）に表示される

## 実際の動作
ドロップダウンリストが左サイドバー（ナビゲーションメニュー）の上に重なって表示される
→ コンテンツエリアより左側（左サイドバー領域）にポップアップが出現する

## 原因分析（推定）
- Select/Popover コンポーネントの `position: absolute` または Portal の基準点が誤っている
- 親コンテナに `overflow: hidden` が設定されており、Portal が body 直下ではなく
  親要素内に appendされている
- `z-index` の問題ではなく、座標計算バグ（`getBoundingClientRect` の参照ズレ）

## 影響範囲
- カルテ詳細ページ Tab2 の診断カテゴリ選択 UI
- 診断1カテゴリ・診断2カテゴリ・診断3カテゴリすべて影響の可能性

## 優先度
高（診断カテゴリが選択できないため、カルテ入力の主要フローがブロックされる）
