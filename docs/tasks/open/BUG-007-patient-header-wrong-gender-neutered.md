# BUG-007: 患者情報ヘッダで性別・避妊/去勢状態が誤表示

## 種類
バグ

## 発見日
2026-03-20

## 再現手順
1. `/trimming/new?petId=1&ownerId=1` でトリミング登録画面を開く
2. 患者情報ヘッダを確認

## 期待動作
Iris(イリス) のDB値: gender=male, neutered_date=null
→ 「オス」と表示、避妊/去勢の記載なし

## 実際の動作
「9才5ヶ月 / メス / 避妊済」と表示（性別が逆、避妊済は不正）

## 影響
獣医師やトリマーが誤った性別情報で施術する危険性がある。臨床上のリスクが高い。

## 修正方針
患者情報ヘッダコンポーネント（PatientInfoCard等）でペットの gender/neutered_date の変換ロジックを確認。male→「オス」、female→「メス」のマッピングが逆になっているか、別のペットのデータが表示されている可能性がある。
