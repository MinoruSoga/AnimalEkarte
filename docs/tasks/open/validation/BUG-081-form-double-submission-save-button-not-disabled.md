# BUG-081: 保存ボタンが送信中に disabled にならず連打で二重登録が発生する

## 種類
バグ（フロントエンド — 二重送信防止未実装）

## 重要度
高

## 発見日
2026-03-29

## 再現手順

1. 飼主登録フォームを開く
2. 必須フィールドを入力する
3. 「登録する」ボタンを素早く 3 回連続クリックする

## 期待動作

- 1 回目のクリックで送信が開始され、ボタンが `disabled` になる
- 送信完了まで追加クリックが無効化される
- 1 件のみ登録される

## 実際の動作

- 3 回クリックすると 3 件（No.44, 45, 46）が重複登録される
- `useTransition` の `isPending` 中でもボタンに `disabled` 制御がない
- ネットワーク遅延中でも同様に連打で複数登録が発生する

## 影響範囲

- 飼主登録フォーム（確認済み）
- その他全フォーム（同一パターンで実装されているため影響を受ける可能性が高い）

## 修正方針

各フォームの保存ボタンに `disabled={isPending}` を追加する。
`useTransition` の `isSavePending` が `true` の間はボタンを無効化する。

```typescript
// ✅ 修正後
<Button
  onClick={handleSave}
  disabled={isSavePending}
>
  {isSavePending ? "保存中..." : "登録する"}
</Button>
```

## 優先度
高（重複データが DB に保存される）

## 派生イシュー

| イシュー | 領域 | 内容 |
|---------|------|------|
| BUG-081（FE） | Frontend | 全フォームの保存ボタンに `disabled={isPending}` を追加（二重送信防止） |
