# BUG-072: 金額・数量フィールドの負値・上限バリデーション欠如

## 概要
治療タブ・会計タブの金額・数量・割引率フィールドで以下のバリデーションが欠如している:
- 単価フィールド: min属性なし → 負の値（-1000等）が入力・送信可能
- 数量フィールド: min制約なし → 0件の請求書作成可能
- 割引率フィールド: max属性なし → 100%超の値が入力可能
- 体重フィールド: step属性なし → 0.001等の細かい小数も入力可能
- 金額上限: max属性なし → 理論上Go int64の上限まで入力可能

## 再現手順（例）
1. 治療タブの単価フィールドに `-1000` を入力
2. → ¥-1,000 として表示・合計に加算（エラーなし）

## 期待する動作
- 単価: min=0（負の値不可）
- 数量: min=1（0以下不可）
- 割引率: min=0, max=100
- 金額: 上限値を設定（例: max=999999999）

## 実装場所
- フロントエンド: `frontend/src/features/medical-records/` の TreatmentRow・会計フォームコンポーネント
- バックエンド: 各サービスのバリデーション
