# BUG-084: アクセシビリティ違反（WCAG AA コントラスト・フォーム構造・フォーカス管理）

## 種類
バグ（フロントエンド — アクセシビリティ違反）

## 重要度
低

## 発見日
2026-03-30

## 違反内容

### 1. エラーメッセージのコントラスト比不足（WCAG 1.4.3）
- エラーテキスト色 `rgb(235, 87, 87)` on white = **3.48:1**（WCAG AA 要件 4.5:1 未満）
- `/owners/new` バリデーションエラーで確認
- 視力の弱いユーザーがエラーメッセージを読めない可能性

### 2. フォームが `<form>` 要素でラップされていない（WCAG 1.3.1）
- `/owners/new`・`/settings/clinic` のフォームがすべて `<div>` ベース実装
- スクリーンリーダーがフォーム境界を認識できない
- `form` 要素カウント = 0

### 3. バリデーションエラー時のフォーカス管理なし（WCAG 2.4.3）
- 必須未入力で登録ボタンをクリック後、フォーカスがボタンに残留
- 最初のエラーフィールドへの自動フォーカス移動なし
- キーボードユーザーがどこにエラーがあるか探さなければならない
- 確認行: `/owners/new`（L11056）・飼主登録フォーム（L11136）

### 4. フォーカス管理不備（モーダル・サイドパネル）
- モーダル閉じた後 `activeElement = BODY`（トリガーボタンに戻らない）
- サイドパネル open 後 `activeElement = BODY`（先頭フィールドへ移動しない）

## 修正方針

1. **コントラスト**: エラーテキスト色を `#dc2626`（on white = 5.74:1）以上に変更
2. **フォーム要素**: `<div>` を `<form onSubmit={...}>` に変更し、`<button type="submit">` を設定
3. **フォーカス移動**: `handleSave` でバリデーションエラー検出後、最初のエラーフィールドに `ref.focus()` を呼ぶ
4. **モーダルフォーカス**: モーダル open 時に先頭フィールドへ、close 時にトリガーボタンへ `focus()` を戻す

## 優先度
低（直接的な機能障害はないが、障害のあるユーザーへの影響大）
