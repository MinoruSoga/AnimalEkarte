# BUG-040: カルテ Tab2 診断カテゴリ選択後に病名リストが絞り込まれない

## 概要
カルテ詳細ページ Tab2（診察/治療プラン）の診断セクションで、
診断カテゴリを選択しても病名ドロップダウンが対応カテゴリの病名に絞り込まれない。
全カテゴリの病名が常に表示される。

## 再現手順
1. カルテ詳細ページ（例: `/medical-records/21`）を開く
2. Tab2「診察/治療プラン」を選択
3. 「診断1カテゴリ」で「皮膚・被毛」を選択
4. 「診断1病名」のドロップダウンを開く

## 期待動作
病名ドロップダウンが「皮膚・被毛」カテゴリに属する病名のみ表示
（例: アトピー性皮膚炎、膿皮症、真菌症 等）

## 実際の動作
全カテゴリの病名20件が混在して表示される
- てんかん（神経系）
- アトピー性皮膚炎（皮膚系）
- パルボウイルス感染症（感染症）
- 気管支炎（呼吸器）
- 胃腸炎（消化器）
- 骨折（外傷）
- 等

## 影響範囲
- カルテ詳細ページ Tab2「診断1」「診断2」の病名選択コンボボックス
- カテゴリ絞り込みなしでは誤った診断名を選択するリスクあり（医療情報の正確性に関わる）

## 優先度
高（診断精度に直結するUX問題。カテゴリと無関係な病名を誤選択するリスクがある）

## 原因推定
フロントエンドで `diagnosis_category_id` に基づいて病名リストをフィルタリングする処理が未実装。
API `GET /masters/diagnosis-names?category_id=X` へのパラメータ付き呼び出しが行われていない可能性。
