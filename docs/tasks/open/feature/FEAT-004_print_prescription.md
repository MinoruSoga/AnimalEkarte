# FEAT-004: カルテ・処方箋の印刷機能未実装

## 概要
カルテページおよび処方箋の印刷機能が未実装。
`@media print` スタイルがカルテページに存在しない（会計ページのみ実装済み）。

## 期待する動作
- カルテ印刷: A4サイズで適切なマージン・フォントサイズ
- 病院ロゴ・住所が印刷ヘッダーに表示
- 処方箋印刷:
  - 動物病院情報・獣医師名
  - 処方薬名・用量・用法・日数
  - ペット情報（名前・種別）
- 治療計画の飼主向け説明書出力

## 必要な実装
1. `@media print` CSS をカルテページコンポーネントに追加
2. 処方箋専用印刷レイアウトコンポーネント
3. 印刷ボタンの追加（TreatmentsTab / ClinicalPlanSection）
