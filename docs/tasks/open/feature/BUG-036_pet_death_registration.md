# BUG-036: ペット死亡登録 UI がない

## 概要
ペット編集モーダルに死亡フラグ設定 UI が存在しない。
ペットを「死亡」状態に変更できず、一覧での生死ステータス表示が機能しない。

## 再現手順
1. ペット詳細ページにアクセス
2. 編集モーダルを開く
3. → 生死フラグ・死亡日などの入力フィールドがない

## 期待する動作
- 編集モーダルに「死亡登録」フィールド（死亡日・原因など）を追加
- 死亡フラグ ON → ペット一覧で「死亡」ステータスバッジ表示

## 実装場所
- `frontend/src/features/pets/` のペット編集フォームコンポーネント
- バックエンドモデルに `died_at` / `is_deceased` フィールドが必要な場合はマイグレーション追加
