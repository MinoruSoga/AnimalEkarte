# BUG-048: マスタ設定サイドパネルの名称フィールドで Enter キーを押しても保存されない

## 概要
マスタ設定ページ（`/settings/medicine` 等）の SidePeek パネルにある名称テキストフィールドで Enter キーを押下しても、フォームが保存されない。

## 再現手順
1. `/settings/medicine` を開く
2. 薬品リストの操作メニュー（⋮）から「編集」をクリック
3. SidePeek パネルが開き、薬品名フィールドが表示される
4. 薬品名フィールドをクリックしてフォーカスを当てる
5. Enter キーを押す

## 期待動作
- フォームが送信され、変更が保存される
- 「保存しました」等のトーストが表示される

## 実際の動作
- SidePeek パネルが開いたまま
- 保存トリガーなし（トースト表示なし）
- フォームは変更されない

## 影響範囲
- マスタ設定の全SidePeekパネル（薬品・病名・処置名・その他マスタ）

## 優先度
低（マウスで「保存」ボタンをクリックすれば保存できる。キーボードUXの改善）
