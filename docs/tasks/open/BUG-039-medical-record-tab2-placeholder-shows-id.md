# BUG-039: カルテ Tab2 プレースホルダーに「診断カテゴリID」「診断病名ID」と表示される

## 概要
カルテ詳細ページ Tab2（診察/治療プラン）の「診察所見・診断・治療方針」セクションで、
フォームフィールドのプレースホルダーテキストに内部 ID 名（「診断カテゴリID」「診断病名ID」）が
そのまま表示されている。開発時のダミーテキストが残存している。

## 再現手順
1. カルテ詳細ページ（例: `/medical-records/21`）を開く
2. Tab2「診察/治療プラン」を選択
3. 「診察所見・診断・治療方針」セクションを確認

## 期待動作
プレースホルダーは日本語の入力ガイドテキスト（例:「カテゴリを選択」「病名を入力」）を表示

## 実際の動作
- 「診断カテゴリID」というテキストがプレースホルダーとして表示される
- 「診断病名ID」というテキストがプレースホルダーとして表示される
→ 開発者向けフィールド名がそのままユーザーに見えている状態

## 影響範囲
- カルテ詳細ページ Tab2「診察所見・診断・治療方針」セクション

## 優先度
中（機能に支障はないが、ユーザーに開発内部情報が露出しており UI 品質として問題）
