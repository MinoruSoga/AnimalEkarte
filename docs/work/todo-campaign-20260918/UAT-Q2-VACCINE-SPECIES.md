## 集計母集団と医院境界

対象医院と時刻窓が承認された後、読取権限内の未削除 `vaccinations` を、**当該医院の接種 1 行を 1 件**として抽出する。日付に用いる列と境界時刻・タイムゾーンは実行前に固定する。pet と vaccine はそれぞれ参照 ID だけで結合せず、`vaccinations.clinic_id = pets.clinic_id = vaccines.clinic_id = 対象医院` を検査する。pet・vaccine の不在、削除済み、他医院参照を通常集計から分離し、参照異常として数える。同じ ID が他医院に存在しても結合しない。通常集計へ進めるのは、接種・pet・vaccine が同じ医院の有効な参照として確認できた行だけとする。無効なワクチンマスタは参照異常と混同せず、現行の新規候補からは除外し、既存履歴の照合対象には残す。

出力案の列は **医院の匿名ラベル、ペット種、マスタ種（`cat` / `dog` / `both` / `UNSET`）、医院が承認したマスタ識別子、件数、参照不一致件数** に限定する。通常件数と参照不一致件数は別集計として提示し、参照不在・削除済み・他医院の内訳は院内の権限付き照合で保持する。内訳を共有列として追加するには医院の承認を要する。参照不整合行のマスタ種・識別子は推測せず `UNRESOLVED` とする。集計時の内部分類は「マスタ種品質」と「旧記録照合結果」の二軸で保持し、匿名分類表を共有する際の追加列・粒度は医院承認後に確定する。個体名、実 pet ID、飼主情報、接種履歴本文、自由記述、実データ行は出さない。少数セルの共有可否も医院側で決める。

## 二軸の分類規則

| 軸 | 値 | 判定根拠 |
|---|---|---|
| マスタ種品質 | A（種欠損）/ 設定あり / 参照不能 | 同一医院のワクチンマスタの種。NULL は A。参照不能を A と決めつけない。 |
| 旧記録照合 | B（参照違い）/ C（旧記録と一致）/ UNKNOWN | 承認された旧記録の識別子と参照関係を照合した結果。名称やペット種だけで B/C を付けない。 |

A と C は同時に成立する。旧記録未入手・未照合なら A の有無にかかわらず B/C は **UNKNOWN**。B と確定した場合も訂正対象・方法・監査・復旧は別承認とする。C の履歴は犬用に見える名称でも自動非表示・削除しない。
