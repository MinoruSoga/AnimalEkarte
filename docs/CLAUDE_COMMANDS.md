# Claude Code カスタムコマンド・マニュアル

このドキュメントでは、本プロジェクトの Claude Code で利用可能なカスタムコマンド（スラッシュコマンド）について解説します。これらのコマンドを使用することで、プロジェクトの規約に則った開発、レビュー、テストを効率的に行うことができます。

## 🚀 基本的な使い方

Claude Code のチャット入力欄で、`/` に続けてコマンド名を入力してください。
例: `/status` (現在の進捗を確認)

---

## 🛠 開発ワークフロー

日常的な開発サイクルを支えるコマンド群です。

| コマンド | 説明 | 主な用途 |
|:---:|:---|:---|
| **`/tdd-workflow`** | Red-Green-Refactor サイクルをガイド | 新機能実装時のテスト駆動開発 |
| **`/status`** | 現在の進捗状況（Progress）を確認 | 作業再開時や区切りでの状況把握 |
| **`/next`** | 次に実装すべき機能を特定し着手 | 開発の優先順位に基づいた自動遷移 |
| **`/save`** | 現在の作業状態をコミットし進捗を保存 | 作業の区切りでのチェックポイント作成 |

---

## 🔍 品質管理・レビュー

シニアエンジニアの視点でコードや設計を検証するコマンド群です。

| コマンド | 説明 | 主な用途 |
|:---:|:---|:---|
| **`/review`** | ステージングされた変更のコードレビュー | PR作成前やセルフチェック |
| **`/go-review`** | Go 言語に特化した詳細なコードレビュー | バックエンドの実装品質向上 |
| **`/db-schema-review`** | DBスキーマ設計の正規化・Index・性能レビュー | テーブル設計変更時の妥当性確認 |
| **`/refactor`** | コードの可読性・保守性を向上させる提案 | 既存コードのクリーンアップ |

---

## 🛡 セキュリティ・検証

安全性とパフォーマンスを担保するためのコマンド群です。

| コマンド | 説明 | 主な用途 |
|:---:|:---|:---|
| **`/security-audit`** | 脆弱性スキャン (gosec, npm audit) の実行 | リリース前のセキュリティチェック |
| **`/test-gen`** | 実装コードに基づいたテストコードの自動生成 | テストカバレッジの向上 |
| **`/perf-profile`** | パフォーマンスのボトルネックを分析 | 画面の重さやAPIの遅延調査 |

---

## 📦 インフラ・運用

Docker環境やデプロイに関連するコマンド群です。

| コマンド | 説明 | 主な用途 |
|:---:|:---|:---|
| **`/docker-optimize`** | Dockerfile や Compose 設定の最適化 | ビルド速度やイメージサイズの改善 |
| **`/deploy`** | デプロイフローの実行（Vercel, Cloud Run等） | 本番/ステージング環境への反映 |
| **`/ci-trigger`** | GitHub Actions などの CI を手動でキック | パイプラインの動作確認 |
