# LINE予約システム 機能仕様書 (LINE Reservation)

> **目的**: 飼い主向けLINE予約システムの機能・計算エンジンを定義する。
> **読者**: 実装者・運用者。
> **タイミング**: LIFF予約機能の仕様確認時。

> **Animal Ekarte**: LIFF アプリによる快適な予約体験
> **最新更新**: 2026-06-12 | **ステータス**: 統合完了・運用中

---

## 1. システム概要

本システムは、飼い主が LINE アプリから直接病院の空き枠を確認し、診察予約を完結させるためのプラットフォームです。

### 特徴
- **シームレスな体験**: LINE ログインにより、二回目以降の入力（名前・電話番号等）を自動補完。
- **高精度な空き枠計算**: スタッフの勤務シフト、休憩時間、既存の院内予約をリアルタイムに集計。
- **カルテ統合**: LINE 経由の予約は、院内の受付カンバンボードへ「source=line」として自動反映。

---

## 2. 飼い主側の予約フロー (LIFF App)

1.  **コース選択**: 診察、ワクチン、トリミング等（マスタで公開設定されたもののみ表示）。
2.  **スタッフ選択**: 担当医の指名、または「指名なし」の選択。
3.  **日時選択**: カレンダー形式。15分/30分単位の空きスロットを表示。
4.  **ペット選択**: 飼い主に紐付くペットをリストから選択。
5.  **予約確定**: Messaging API により、予約完了通知が飼い主の LINE へ即時送信。

---

## 3. 病院側の管理機能 (Integrated Admin)

LINE 予約の管理機能は、電子カルテの各標準メニューに完全に統合されています。

| 管理項目 | 設定場所 | 備考 |
|:---|:---|:---|
| **予約種別の公開** | `/settings/reservation-type` | LINE上での表示名、所要時間、アイコンの設定。 |
| **スタッフの公開** | `/settings/staff` | LINE予約を受け付けるスタッフの選択と紹介文。 |
| **空き枠の基礎** | `/shifts` | 勤務時間と休憩時間。複数の休憩時間登録に対応。 |
| **予約の俯瞰** | `/reservations` | ソースフィルタで「LINE予約のみ」の抽出が可能。 |

---

## 4. 時間枠計算ロジック (Timeslot Engine)

システムは以下の 3 つの要素を動的に合算して空き枠を算出します。

1.  **Positive (加点要素)**: 指定されたスタッフの「勤務時間」。
2.  **Negative (減点要素)**: スタッフの「休憩時間」、医院の「休診日」。
3.  **Conflict (除外要素)**: 既に入っている「診察予約」「トリミング予約」「手術枠」。

---

## 5. 通知のライフサイクル

- **予約完了時**: 病院への受付通知 ＋ 飼い主への完了メッセージ。
- **変更/キャンセル時**: 双方への即時ステータス通知。
- **前日リマインド**: 予約日の前日に、忘れ防止の自動メッセージを配信。
