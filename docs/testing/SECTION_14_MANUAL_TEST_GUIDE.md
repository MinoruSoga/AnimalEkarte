# セクション14：シナリオテスト（ブラウザテスト）実行ガイド

## 1. 概要
本ドキュメントは、動物病院向け電子カルテシステム「アニマルエカルテ」の主要ドメインにおける、ブラウザを通じた詳細なCRUD操作の検証手順を定義したものである。

詳細な検証項目と過去の全テスト結果については、[機能テストレポート (FUNCTIONAL_TEST_REPORT.md)](./FUNCTIONAL_TEST_REPORT.md) を参照すること。

## 2. テスト実行の準備
- **環境**: ローカル開発環境（localhost:3003）またはステージング環境
- **アカウント**:
  - 管理者: `admin@example.com`
  - 一般スタッフ: `staff@example.com`
- **ツール**: ブラウザ（Chrome推奨）、または Playwright

## 3. 基本操作シナリオ（主要ドメイン）

### 3.1 診察記録 (Examinations)
1. **作成**: 受付一覧からペットを選択し「診察開始」をクリック。主訴・体重・体温を入力して保存。
2. **閲覧**: 診察一覧またはカルテ詳細から、保存した内容が正しく表示されるか確認。
3. **更新**: 既存の記録を編集し、内容が正しく上書きされるか確認。
4. **削除**: 削除ボタンをクリックし、一覧から消えることを確認。

### 3.2 会計 (Accounting)
1. **精算**: 診察完了後の項目が会計一覧に出現することを確認。
2. **項目操作**: 薬剤や処置の追加、個数変更、値引きの適用が計算に反映されるか確認。
3. **完了**: 支払方法（現金・カード等）を選択し、精算完了後に領収書が発行可能か確認。

### 3.3 マスタ設定 (Settings)
1. **スタッフ管理**: 新規スタッフ作成、権限グループの割り当て、ログイン可否の確認。
2. **病院設定**: 休診日や診療時間の設定が予約カレンダーに反映されるか確認。
