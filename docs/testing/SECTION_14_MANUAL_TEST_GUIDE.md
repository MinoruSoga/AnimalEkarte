# Section 14 (マスタ設定) — Manual Browser Testing Guide

**目的**: Chrome DevTools MCP 不在時の代替手段として、手動でセクション 14 の未確認テスト項目を検証するためのガイド

**テスト環境**:
- URL: `http://localhost:3003`
- ログインアカウント: `admin@example.com` / `password`
- テスト日時: 記入例：2026-04-12
- テスター: 記入欄を用意

---

## ステップ 0: テスト前準備

### 0.1 ブラウザDevToolsの準備
```
1. Chrome DevTools を開く (F12 または Cmd+Option+I)
2. "Network" タブを開く
3. "Console" タブも別タブで開いて、エラーが出ないか監視
```

### 0.2 ログイン
```
1. http://localhost:3003 にアクセス
2. ログイン画面が表示されたら:
   - Email: admin@example.com
   - Password: password
   - 「ログイン」ボタンをクリック
3. ダッシュボード(/dashboard) が表示されるまで待機
```

### 0.3 設定ページへのナビゲーション
```
1. 左サイドバーから「マスタ設定」をクリック
2. または直接 http://localhost:3003/settings にアクセス
3. マスタ設定トップページ（各マスタカードが表示）が出現を確認
```

## テストセット 1: 削除確認ダイアログの「キャンセル」動作

**テスト項目**: 14.3 マスタ共通ボタン動作 — 削除確認「キャンセル」ボタン

### テスト手順

```
【前提】 マスタ設定 / 役職マスタ (/settings/job-title) にいる状態

Step 1: リストで任意の役職を選択（例：「獣医師」）
  - 行をクリック → 右サイドパネルに「獣医師」の編集フォーム表示

Step 2: サイドパネル下部の赤い「🗑 削除」アイコンボタンをクリック
  - 期待: 「この役職を削除してもよろしいですか？」確認ダイアログ表示

Step 3: ダイアログ内「キャンセル」ボタンをクリック
  - 期待:
    ✅ ダイアログが閉じる
    ✅ サイドパネルは開いたままで、「獣医師」の内容が変わらない
    ✅ リスト側の件数に変化なし（削除されていない）
    ✅ トースト通知が出現しない

Step 4: DevTools Network タブ確認
  - 期待: DELETE リクエストが送信されていない
```

## テストセット 2: 病院設定（クリニックマスタ）- 基本情報編集

**テスト項目**: 14.4 病院設定 — 病院名/電話番号/住所フィールド編集

### テスト手順

```

    ✅ 「保存しました」トースト表示
    ✅ フィールドが新しい値で更新される

Step 4: ページをリロード (F5)
  - 期待: 病院名が変更後の値で表示

---------- テスト 2.2: 電話番号編集 ----------
Step 1: 「電話番号」フィールドを特定してクリア

Step 3: 下部「保存」ボタンをクリック

    ✅ PATCH リクエスト送信 (HTTP 200)
    ✅ トースト成功表示

---------- テスト 2.3: 住所フィールド編集 ----------

Step 2: 下部「保存」ボタンをクリック
  - 期待:
    ✅ PATCH リクエスト (HTTP 200)
```

## テストセット 5: スタッフマスタ — 有効/無効切替

**テスト項目**: 14.6 スタッフマスタ管理テスト — スタッフ有効/無効切替

### テスト手順

```
【前提】 マスタ設定 > スタッフ (/settings/staff) にいる状態

Step 1: 任意のスタッフ行をクリック（例: テストスタッフ太郎）
  - 右サイドパネルに編集フォーム表示

Step 2: パネル内で「ステータス」フィールドを特定
  - 形式: トグルスイッチ または ドロップダウン
  - 現在値確認: "有効" → "無効" に変更

Step 3: 「保存」ボタンをクリック
  - 期待:
    ✅ PATCH リクエスト送信 (HTTP 200)
    ✅ トースト成功表示
    ✅ リスト側でステータスバッジが更新される
      例: 🟢 有効 → ⚫ 無効 (色/アイコン変更)

Step 4: ページリロード (F5)
  - 期待: ステータスが無効のままで表示

Step 5: 逆方向テスト（無効 → 有効）
  - 同様にステータスを有効に戻す
  - PATCH 200 確認
```

**記録欄**:

**テスト項目**: 14.10 処置マスタ管理テスト — 処置カテゴリ別フィルタリング + パネル自動クローズ

### テスト手順

```
【前提】 マスタ設定 > 処置マスタ (/settings/treatment-items) にいる状態

Step 1: タブ構成を確認
  - 期待: 上部に5つのタブが表示
    - 診察 (5件)
    - 検査 (N件)

    - 予防接種 (L件)

Step 5: 処置タブ内で任意の処置行をクリック

Step 6: 「予防接種」タブをクリック
```

## テストセット 8: 処置マスタ — 単価変更の即時反映

**テスト項目**: 14.10 処置マスタ管理テスト — 単価変更後に新規カルテで変更後単価が表示

### テスト手順

```
【前提】 マスタ設定 > 処置マスタ (/settings/treatment-items) で診察タブ表示

Step 1: リスト内の既存処置（例：診察）を選択
  - 行をクリック → サイドパネル表示
  - 現在の単価を記録: 例 "1,000円"

Step 2: 単価フィールドをクリア → 新しい単価を入力
  - 例: "1,000" → "2,500"

Step 3: 「保存」ボタンをクリック
  - 期待: PATCH 200 + トースト成功 + リスト側で単価が更新

Step 4: 別タブで医療記録フォームを開く（新規作成）
  - http://localhost:3003/medical-records/new

Step 5: フォーム Tab 3「処置」セクションで、変更した処置を追加
  - 処置検索 → 「診察」を選択

Step 6: 追加後、自動入力された単価を確認
  - 期待: 新しい単価 "2,500" が表示される
  - 古い単価 "1,000" ではなく、最新値が反映
```
