## 2. 共通テスト・ポリシー

全てのハンドラーテストは以下の 4 つの観点を必須項目として検証しています。

1.  **認可 (RBAC)**: 無権限ユーザーによる 403 エラーの発生。
2.  **テナント隔離**: 他院の ID 指定に対する 404/403 反応。
3.  **入力不備**: 不正な JSON 構造に対する `apperrors.WrapInvalidInput` の返却。
4.  **正常系リダイレクト**: 新規作成時の `Location` ヘッダーまたは ID 返却の正確性。
