# Testing & Quality Assurance Directory

## Purpose
テスト計画、テストケース、自動テストのガイド、および品質検証の結果報告を格納します。

## Contents
- `E2E_TESTING_GUIDE.md`: Playwrightなどを用いたエンドツーエンドテストの手順。
- `INTEGRATION_TEST_PLAN.md`: 結合テストの実施計画。
- `FUNCTIONAL_TEST_REPORT.md`: 機能テストのパス/フェイル状況の記録。
- `PERFORMANCE_PROFILING.md`: 性能測定とボトルネック分析の結果。
- `FE_CODE_QUALITY_VERIFICATION_xxx.md`: フロントエンドのコード品質監査結果。
