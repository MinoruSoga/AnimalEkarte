# LINE/Lステップ連携 — 費用・実装方針分析

**作成日**: 2026年4月26日  
**対象**: 3 LINE アカウント運用

---

## 🎯 背景・問題設定

### 要件
- 八王子病院（clinic_id=1）を含む **3 つのクリニック** で LINE 連携実装
- オーナー対応機能：タグ管理、シナリオ配信、セグメント配信

### 選択肢
1. **パターンA**: Lステップ API を使用（Lステップ側でタグ・シナリオ・配信を管理）
2. **パターンB**: LINE API のみで実装（AnimalEkarte 側で機能を自主実装）

---

## 📊 料金詳細

### Lステップの料金構成

| 項目 | 金額 | 備考 |
|------|------|------|
| **プロプラン基本料** | ¥32,780/月 | 月 50,000 通まで配信可能 |
| **API 連携オプション** | ¥11,000/月 | webhook 未使用時 |
| **API 連携オプション** | ¥5,500/月 | webhook 既使用時（軽減） |
| **API 呼び出し制限** | 50,000 回/月 | プロプラン時 |

**参考**: Lステップ API は 2026 年 4 月 1 日よりプロプラン以上で提供開始。申請にはセミナー参加が条件。

| 項目 | 料金 | メッセージ無料枠 | 超過時 |
|------|------|---|---|
| **LINE Messaging API 本体** | **¥0**（無料） | — | — |
| **LINE 公式アカウント** | | | |
| 　- Communication Plan | ¥0/月 | 200 件/月 | 追加配信不可 |

## 💰 費用比較

### パターンA：Lステップ API 使用（3 アカウント）

| 項目 | 単価 | × 3 アカウント | 月額 |
|------|------|---|------|
| Lステップ プロプラン | ¥32,780 | × 3 | **¥98,340** |
| Lステップ API 連携 | ¥11,000 | × 3 | **¥33,000** |
| LINE 公式アカウント（Light Plan） | ¥5,000 | × 3 | **¥15,000** |
| | | **月額合計** | **¥146,340** |
| | | **年額合計** | **¥1,756,080** |

**特徴**:
- ✅ Lステップ UI で簡単にタグ・シナリオを管理可能
- ❌ 月額固定費が高い（¥1,756,080/年）
- ❌ Lステップの仕様変更・価格改定の影響を受ける

---

### パターンB：LINE API のみ（AnimalEkarte 自主実装、3 アカウント）

| 項目 | コスト | 備考 |
|------|--------|------|
| Lステップ | **¥0** | 不採用 |
| LINE Messaging API | **¥0** | API 使用料無料 |
| LINE 公式アカウント × 3 | **¥0 ～ ¥15,000/月** | 配信量による（詳細後述） |
| | **月額合計** | **¥0 ～ ¥15,000** |
| | **年額合計** | **¥0 ～ ¥180,000** |

**配信シナリオ別の LINE 公式アカウント料金**:

```
【シナリオ1】月 100 オーナー × 週 1 回配信
  = 100 × 4 週 = 400 メッセージ/月
  → Communication Plan（¥0/月）で収まる ✅

【シナリオ2】月 500 オーナー × 週 1 回配信
  = 500 × 4 週 = 2,000 メッセージ/月
  → Communication Plan では不足（超過停止）
  → Light Plan（¥5,000 × 3 = ¥15,000/月）必要

【シナリオ3】月 1,000 オーナー × 週 2 回配信
  = 1,000 × 2 × 4 週 = 8,000 メッセージ/月
  → Light Plan（¥15,000/月）で収まる
```

**特徴**:
- ✅ 月額固定費が圧倒的に低い
- ✅ 配信機能を自社で完全制御可能
- ✅ 長期運用で莫大な費用削減（初年度 ¥150 万以上）
- ❌ 初期開発が必要
- ❌ 運用・保守は自社責任

---

### コスト削減効果（3 アカウント）

```
パターンA - パターンB（Light Plan）
= ¥146,340/月 - ¥15,000/月
= ¥131,340/月 削減

初年度：¥1,576,080 削減
3 年間：¥4,728,240 削減
```

**損益分岐点**:
```
初期開発コスト ÷ 月額差 で投資回収期間を算出
```

## 🎯 推奨判断

### パターンB（LINE API のみ、自主実装）を推奨する理由

1. **圧倒的な費用削減**
   - 初年度：¥1,576,080 削減
   - 3 年間：¥4,728,240 削減

2. **データ完全所有**
   - 配信履歴・タグ情報が自社データベース内
   - 分析・カスタマイズが自由

3. **長期運用に適合**
   - 3 クリニック運用で月額 ¥146,340 vs ¥15,000 の差は甚大
   - 診療所の成長に応じて配信機能を拡張可能

4. **依存度低減**
   - Lステップの価格改定・仕様変更の影響を受けない
   - 自社で全機能をコントロール

### ただし、以下の場合はパターンA も検討

- 迅速な導入スケジュールが必須
- 開発リソースが限定的
- セキュリティ・法令対応の自主実装が困難
