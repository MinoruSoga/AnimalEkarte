# システム全体概要 (SPECIFICATION)

本ドキュメントは、動物病院電子カルテシステム「Animal Ekarte」の全体コンセプト、業務ドキュメントの構成、および主要なビジネスフローを定義します。

詳細な技術仕様や各画面の項目定義については、各専門ドキュメントを参照してください。

---

## 1. プロジェクト概要

「Animal Ekarte」は、予約管理から受付、診療、入院管理、会計までの一連の動物病院業務をシームレスにデジタル化し、スタッフの業務効率化とインフォームド・コンセントの質を向上させるための統合プラットフォームです。

### 主要なコンセプト
- **Notionライクな操作性**: 直感的なプロパティ編集とクリーンなUI。
- **データ駆動型ワークフロー**: カンバンボードによるリアルタイムな院内状況の可視化。
- **柔軟なマスタ管理**: 診療項目、薬剤、スタッフ権限などを病院ごとに最適化可能。

## 3. 主要なビジネスフロー

### 3.1 外来フロー
1. **予約**: 予約管理画面 (`/reservations`) で枠を確保。
2. **受付**: 当日、ダッシュボード (`/`) で「受付予約」から「受付済」へ移動。
3. **診療**: カルテ入力画面 (`/medical-records/:id`) で診療内容を記録。
4. **会計**: 会計精算画面 (`/accounting/:id`) で支払い完了、領収書発行。

### 3.2 入院フロー
1. **登録**: 入院登録フォーム (`/hospitalization/new`) から開始。
2. **管理**: 入院詳細 (`/hospitalization/:id`) で日次のバイタル・ケアを記録。
3. **退院**: ステータスを「退院済」に変更し、蓄積された明細を会計へ連携。
