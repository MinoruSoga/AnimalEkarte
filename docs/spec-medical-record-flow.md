# カルテ登録・編集フロー仕様

## カルテID確定タイミング
- カルテ新規作成ページ（/medical-records/new?petId=X）が表示された時点で即座にカルテレコードを作成する
- 作成後、編集URL（/medical-records/:id）に replace ナビゲーションする
- 受付済みステータスにした時点でもカルテレコードを自動作成する

## タブ別保存仕様
フローティング保存ボタンはアクティブなタブのデータのみを保存する。

| タブ | 保存対象 | 備考 |
|------|---------|------|
| 問診 | inquiries テーブル（主訴・治療方針） | |
| 診察/治療プラン | treatment_plans + clinical_plans テーブル | clinical_plans は ClinicalPlanSection 経由 |
| 治療 | treatment_items テーブル | 行単位でインライン保存（フローティングボタン不使用） |
| 予防接種 | vaccinations テーブル | 行単位でインライン保存 |
| 定期健診 | checkups テーブル | 行単位でインライン保存 |
| 検査 | examinations テーブル | 行単位でインライン保存 |
| 画像 | medical_images テーブル | アップロード単位で保存 |
| 見積書 | estimates テーブル | |
| 会計(医師確認) | 保存ボタン非表示 | |

## 保存後の挙動
- 保存成功後はページ・タブに留まる（リスト画面には遷移しない）
- 成功時は「保存しました」トースト表示

## サブテーブルの upsert
各タブのデータはカルテ作成時に空レコードで一括作成される。
以降の保存は常に UPDATE（レコードが存在しない場合は INSERT）。
