# 会計一覧 仕様書

## 概要
- **画面の目的**: 会計待ち・保留・回収済のペットの会計一覧を管理する
- **URLパターン**: `/accounting`
- **アクセス権限**: 認証済ユーザー全員

## 画面レイアウト
```
┌──────────────────────────────────────────────────────┐
│ 会計管理  [新規会計ボタン]                            │
├──────────────────────────────────────────────────────┤
│ タブ: [未収] [保留] [回収済] [すべて]                │
├──────────────────────────────────────────────────────┤
│ 🔍 [飼主名 / ペット名 / カルテNo 検索]               │
├──────────────────────────────────────────────────────┤
│ テーブル                                             │
│ 会計ID | 日付 | 飼主名 | ペット名 | 合計金額 |        │
│ 支払方法 | ステータス | 操作                          │
└──────────────────────────────────────────────────────┘
```

## 表示項目

| フィールド名 | 型 | 説明 | 備考 |
|------------|-----|------|------|
| 会計ID | string | 会計識別子 | `accountings.id` |
| 会計予定日 | date | 会計予定日 | `accountings.scheduled_date` |
| 飼主名 | string | 飼い主氏名 | `owners.name` |
| ペット名 | string | ペット名 | `pets.name` |
| 合計金額 | decimal | 税込合計 | `accountings.total_amount` |
| 請求金額 | decimal | 保険・値引後の実請求額 | `accountings.billing_amount` |
| 支払方法 | enum | 現金/クレジットカード/電子マネー | `accountings.payment_method` |
| ステータス | enum | 未収/保留/回収済/キャンセル | `accountings.status` |

## フィルタータブ

| タブ名 | フィルター条件 |
|--------|--------------|
| 未収 | status = `未収` |
| 保留 | status = `保留` |
| 回収済 | status = `回収済` |
| すべて | フィルターなし |

## ステータスバッジ色定義

| ステータス | 色 |
|-----------|-----|
| 未収 | 赤（red） |
| 保留 | 黄（amber） |
| 回収済 | 緑（green） |
| キャンセル | グレー |

## UI コンポーネント
- **PageLayout**: ページコンテナ
- **Tabs**: ステータスフィルタータブ
- **SearchFilterBar**: フリーワード検索
- **DataTable**: テーブルコンテナ
- **DataTableRow**: クリックで詳細へ
- **StatusBadge**: ステータスバッジ
- **PrimaryButton**: 「新規会計」ボタン

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 新規会計 | 「新規会計」ボタン | ペット選択画面へ | `/accounting/select-pet` |
| 詳細/精算 | 行クリック or 操作ボタン | 会計精算画面へ | `/accounting/:id` |
| タブ切替 | タブクリック | ステータスフィルター変更 | 同画面 |
| 検索 | テキスト入力 | 一覧フィルタリング | 同画面 |

## 画面遷移

| 遷移元 | 遷移先 | 条件 |
|--------|--------|------|
| サイドバー | `/accounting` | 常時 |
| 「新規会計」ボタン | `/accounting/select-pet` | ボタンクリック |
| ペット選択完了 | `/accounting/new?petId=xxx` | ペット選択後 |
| 行クリック | `/accounting/:id` | クリック |
| カルテ見積「会計作成」 | `/accounting/new?petId=xxx` | 会計作成ボタン |
