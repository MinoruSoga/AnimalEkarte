# 会計一覧 仕様書

## 概要
- **画面の目的**: 会計レコードの一覧管理。
- **URLパターン**: `/accounting`
- **アクセス権限**: 認証済ユーザー全員

## 画面構成
- **ヘッダー**: タイトル、新規会計登録ボタン
- **検索・フィルタ**: `NotionFilter`（ステータスフィルタ、飼主名・ペット名での検索、ソート機能）
- **データテーブル**: `DataTable` による一覧表示
- **ページネーション**: 20件/ページ

## 表示項目（テーブル）

| フィールド名 | 型 | 説明 | 備考 |
|------------|-----|------|------|
| 日時 | date | 会計予定日（等幅フォント） | `scheduledDate` |
| 飼主名 | string | 飼い主氏名 | |
| ペット名 | string | ペット名 | |
| 請求金額 | decimal | 税込請求金額（右寄せ） | `totalAmount` |
| 支払方法 | enum | 現金 / カード / 電子マネー | |
| ステータス | enum | 会計待ち / 会計済 / キャンセル | |
| 返金 | icon | 返金処理済の場合に `RotateCcw` アイコン＋「返金あり」バッジを表示 | `hasRefund` |
| カルテ | link | 関連カルテへのリンクアイコン | `medicalRecordId` がある場合に表示 |
| 操作 | - | 詳細ボタン | |

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 新規登録 | 「新規会計登録」ボタン | ペット選択画面へ | `/accounting/select-pet` |
| 詳細・精算 | 行クリック or 「編集」 | 会計精算画面へ | `/accounting/:id` |
| カルテ参照 | カルテ列のアイコンクリック | 関連カルテ詳細へ | `/medical-records/:id` |

## API連携
| メソッド | エンドポイント | 用途 |
|---------|--------------|------|
| GET | `/api/v1/accountings` | 会計一覧取得 |
| DELETE | `/api/v1/accountings/:id` | 会計データ削除 |
