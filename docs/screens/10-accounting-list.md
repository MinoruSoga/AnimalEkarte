# 会計一覧 仕様書

## 概要
- **画面の目的**: 会計レコードの一覧管理。
- **URLパターン**: `/accounting`
- **アクセス権限**: 認証済ユーザー全員

## 画面構成
- **ヘッダー**: タイトル、新規会計登録ボタン
## 検索・フィルタ
- **NotionFilter**:
  - 日付範囲 (`date`): 会計予定日での絞り込み（サーバーサイド）。
  - ステータス (`status`): 会計待ち / 会計済 / キャンセル（クライアントサイド）。
  - 支払方法 (`paymentMethod`): 現金 / クレジットカード / 電子マネー。未会計（空値）の絞り込みも可能。
  - キーワード検索: 飼主名、ペット名。
- **FilteringIndicator**: 検索・フィルタ計算中に透過度を下げて視覚的にフィードバック。

## 表示項目（テーブル）

| フィールド名 | 型 | 説明 | 備考 |
|------------|-----|------|------|
| 日時 | date | 会計予定日（等幅フォント） | `scheduledDate` |
| 飼主名 | string | 飼い主氏名 | |
| ペット名 | string | ペット名 | |
| 請求金額 | decimal | 税込請求金額（右寄せ） | `totalAmount` |
| 支払方法 | enum | 現金 / カード / 電子マネー | 完了時のみ表示 |
| ステータス | enum | 会計待ち / 会計済 / キャンセル | `StatusBadge` |
| 返金 | badge | `totalRefundedAmount > 0` の場合に「返金あり」バッジを表示 | |
| カルテ | button | 関連カルテへの遷移ボタン | `medicalRecordId` がある場合に表示 |
| 操作 | - | 詳細ボタン | `RowActionButton` |

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 新規登録 | 「新規会計登録」ボタン | ペット選択画面へ | `/accounting/select-pet` |
| 詳細・精算 | 行クリック or 操作ボタン | 会計精算画面へ | `/accounting/:id` |
| カルテ参照 | カルテ列のアイコンクリック | 関連カルテ詳細へ | `/medical-records/:id` |
| ページネーション | 下部ナビゲーション | 20件/ページ。URLパラメータ `?page=N` と同期。 | - |

## API連携
| メソッド | エンドポイント | 用途 |
|---------|--------------|------|
| GET | `/api/v1/accountings` | 会計一覧取得 |
| DELETE | `/api/v1/accountings/:id` | 会計データ削除 |
