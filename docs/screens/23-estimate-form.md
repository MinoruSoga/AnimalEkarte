# 見積書作成・編集 仕様書

## 概要
- **画面の目的**: 見積書の作成、項目の編集、金額の算出を行う。
- **URLパターン**: `/estimates/new` / `/estimates/:id/edit`
- **アクセス権限**: 認証済ユーザー全員

## 画面構成
- ヘッダー: タイトル + 戻るボタン + 保存ボタン
- メインコンテンツ: 2カラム
  - 左: フォーム情報（タイトル、有効期限、ステータス、コメント、備考）
  - 右: 金額サマリ（小計、税、保険、割引、合計）
- 下部: 見積明細（`TreatmentTable`）

## フォーム項目
| フィールド | 入力部品 | 必須 | 備考 |
|-----------|----------|------|------|
| タイトル | `Input` | ✅ | 見積書の名称 |
| ステータス | `Select` | ✅ | 下書き / 送付済み / 承認済み / 却下 |
| 有効期限 | `NotionDatePicker` | | |
| コメント | `Textarea` | | 飼主向けのメッセージ |
| 備考 | `Textarea` | | 社内用のメモ（見積書には印字されない） |

## 金額セクション（自動計算）
| 項目 | 説明 |
|------|------|
| 小計（税抜） | 明細の税抜合計 |
| 消費税 | 消費税合計（内税/外税混在対応） |
| 保険適用額 | 保険適用による減額分 |
| 割引額 | 全体割引による減額分 |
| 合計金額 | 税込請求予定額 |

## 明細セクション
- **コンポーネント**: `TreatmentTable`
- **機能**: 
  - 診療項目の検索・追加（`TreatmentSearchDialog`）
  - 単価、数量、割引率、保険適用の個別設定
  - 行の削除

## UI コンポーネント
| コンポーネント | 種別 | 説明 |
|---|---|---|
| `EstimateForm` | `[R]` | メインページ |
| `TreatmentTable` | `[C]` | 診療明細テーブル |
| `TreatmentSearchDialog` | `[C][M]` | 診療項目検索ダイアログ |
| `NotionDatePicker` | `[S]` | 日付ピッカー |
| `PageLayout` | `[S]` | ページレイアウト |

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/estimates/:id` | 見積詳細取得 | 実装済 |
| POST | `/api/v1/estimates` | 見積作成 | 実装済 |
| PATCH | `/api/v1/estimates/:id` | 見積更新 | 実装済 |
