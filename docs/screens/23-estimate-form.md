# 見積書作成・編集 仕様書 (Estimate Form)

## 概要
- **画面 of Purpose**: 診療や処置に先立ち、飼い主へ提示する概算費用の算出、および明細の構成管理。
- **URLパターン**: 
  - 新規作成: `/estimates/new?petId=xxx`
  - 編集: `/estimates/:id/edit`
- **アクセス権限**: 認証済ユーザー全員（操作権限は `usePermission` で制御）

---

## 1. 画面構成

### 1.1 基本情報セクション
- **件名**: 見積の目的（例：右膝蓋骨脱臼 整復手術）。
- **有効期限**: 単価を保証する期限。
- **ステータス**: 下書き、送付済み、承認済み、却下の管理。

### 1.2 明細構成セクション
診療項目マスタから複数の項目を選択・追加し、概算を組み立てます。
- **項目追加**: 診察、検査、手術、入院、処方等のカテゴリからの高速検索。
- **自由入力**: マスタにない特殊な項目や備考のインライン追加。
- **数量・単価**: 項目の個数や、必要に応じた単価の微調整。

### 1.3 テキスト・メッセージ設定
- **飼主向けメッセージ**: 帳票の下部に印字される、処置の前提条件や補足説明。
- **内部メモ**: スタッフ間での算出根拠等の共有。

---

## 2. 主要な運営機能

### 2.1 自動計算ロジック (`calculations.ts`)
- **税率別集計**: 10%（技術料等）と 8%（処方食等）を自動で判別し、消費税を正確に算出。
- **保険シミュレーション**: 窓口精算保険が設定されている場合、保険負担額と飼主負担額を事前にシミュレーション表示。

### 2.2 臨床連携
診察室（カルテ）から直接見積タブを開き、明細を共有することが可能です。これにより、インフォームド・コンセントの質を向上させます。

---

## 3. 技術仕様

### 3.1 ハイパフォーマンス・フォーム
- **再描画の抑制**: 大量の明細項目を扱う場合でも、セクション単位の `memo()` 化により、快適な入力レスポンスを維持します。
- **保存アクション**: React 19 の `useActionState` を活用し、保存中の二重送信を防止。

### API連携
| メソッド | エンドポイント | 用途 |
|:---|:---|:---|
| GET | `/api/v1/estimates/:id` | 明細を含む見積情報の取得。 |
| POST | `/api/v1/estimates` | 新規保存。 |
| PATCH | `/api/v1/estimates/:id` | 内容およびステータスの更新。 |
| GET | `/api/v1/masters/consultations` | 診療項目（診察）マスタの検索・引用。 |
| GET | `/api/v1/masters/examination-types` | 検査項目マスタの検索・引用。 |
| GET | `/api/v1/masters/procedures` | 処置項目マスタの検索・引用。 |
| GET | `/api/v1/masters/vaccines` | 予防接種項目マスタの検索・引用。 |
| GET | `/api/v1/masters/checkup-types` | 定期健診項目マスタの検索・引用。 |
