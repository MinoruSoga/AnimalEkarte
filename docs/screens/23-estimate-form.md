# 見積書作成・編集 仕様書

## 概要
- **画面の目的**: 概算見積の算出、明細の追加・編集、ステータス管理。
- **URLパターン**:
  - 新規: `/estimates/new?petId=xxx`
  - 編集: `/estimates/:id/edit`
- **アクセス権限**: 認証済ユーザー全員（操作権限は `usePermission` で制御）

## 画面構成
- **ヘッダー**: タイトル、保存ボタン、キャンセルボタン。
- **メインフォーム**: パフォーマンス最適化のため、以下のメモ化された独立セクションで構成。
  - **基本情報 (`BasicInfoSection`)**: タイトル（必須）、ステータス、有効期限（`NotionDatePicker`）。
  - **金額サマリ (`AmountSection`)**: 
    - 小計（税抜）、消費税、保険適用額、割引額、合計金額。
    - 各項目は `NumberInput` による直接数値入力。
  - **テキスト情報 (`TextSection`)**: 飼主向けコメント、社内用備考（`Textarea`）。

## 主要機能
- **セクション別メモ化**: 複雑な入力フォームにおいて、各セクションを `memo` 化。他のセクションの変更による不要な再レンダーを抑制。
- **React 19 アクション**: `useActionState` フック経由での非同期保存処理。
- **権限ベースのUI**: 更新権限がないユーザーに対しては、保存ボタンの非表示化。
- **離脱保護**: `NavigationBlocker` により、未保存の変更がある状態での離脱時に確認ダイアログを表示。

## UI コンポーネント
| コンポーネント | 種別 | 説明 |
|---|---|---|
| `EstimateForm` | `[R]` | メインページ。Action と状態管理を統括。 |
| `BasicInfoSection` | `[C]` | 基本属性入力セクション。 |
| `AmountSection` | `[C]` | 明細・金額計算セクション。 |
| `TextSection` | `[C]` | フリーテキスト入力セクション。 |
| `TreatmentSearchDialog` | `[S][M]` | 診療項目マスタからの検索・追加モーダル。 |

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/estimates/:id` | 見積詳細取得 | 実装済 |
| POST | `/api/v1/estimates` | 見積新規作成 | 実装済 |
| PATCH | `/api/v1/estimates/:id` | 見積更新 | 実装済 |
