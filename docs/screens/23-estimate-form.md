# 見積書作成・編集 仕様書

## 概要
- **画面の目的**: 見積書の作成、項目の編集、金額の算出を行う。
- **URLパターン**: `/estimates/new` / `/estimates/:id/edit`

## 機能詳細

### 1. 金額計算エンジン
- **リアルタイム計算**: 明細項目の単価・数量変更、値引率の適用、保険適用の有無を即座に計算し、合計金額を算出する。
- **消費税計算**: 項目ごとの税率（8%/10%）を自動判別して内訳を表示する。

### 2. ドキュメント発行
- **PDFプレビュー**: 保存済みの見積書を、診療明細書と同様の A4 レイアウトでプレビュー・PDF 出力できる。
