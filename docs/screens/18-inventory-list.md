# 在庫管理 仕様書

## 概要
- **画面の目的**: 在庫品目の一覧表示・検索・フィルタリング、および登録・編集。
- **URLパターン**: `/inventory`
- **アクセス権限**: 認証済ユーザー全員

## 画面構成
- **ヘッダー**: タイトル（Package アイコン）、データ取込ボタン、新規登録ボタン
- **アラートサマリー**: 在庫切れ・残少品目数の強調表示
- **検索・フィルタ**: `NotionFilter`（カテゴリ、ステータス、キーワード検索、ソート機能）
- **データテーブル**: `DataTable` による一覧表示
- **ページネーション**: 標準ページネーション

## 表示項目（テーブル）

| フィールド名 | 型 | 説明 | ソート | 備考 |
|------------|-----|------|--------|------|
| 品名 | string | 商品・薬品名 | ○ | |
| カテゴリ | enum | 医薬品 / 消耗品 / フード / その他 | ○ | |
| 在庫数 | number | 現在の在庫（単位付） | ○ | |
| 最低在庫 | number | 発注点（単位付） | - | |
| 保管場所 | string | 収納場所 | ○ | |
| 有効期限 | date | 期限（等幅フォント） | ○ | |
| ステータス | enum | 十分 / 残少 / 在庫切れ | ○ | `StatusBadge` |
| 操作 | - | 編集・削除 | - | `RowActionButton` |

## 主な機能
- **在庫アラート**: 在庫数が最低在庫を下回った場合に「残少」、0になった場合に「在庫切れ」と自動判定。
- **検索フィルタ**: カテゴリ別の絞り込みや、保管場所・仕入先を対象としたフリーワード検索が可能。

## API連携
| メソッド | エンドポイント | 用途 |
|---------|--------------|------|
| GET | `/api/v1/inventories` | 在庫一覧取得 |
| POST | `/api/v1/inventories` | 在庫品目登録 |
| PATCH | `/api/v1/inventories/:id` | 在庫品目更新 |
| DELETE | `/api/v1/inventories/:id` | 在庫品目削除 |
