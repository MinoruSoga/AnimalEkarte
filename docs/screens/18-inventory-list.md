# 在庫管理 仕様書

## 概要
- **画面の目的**: 在庫品目（医薬品、消耗品等）の一覧表示、検索、フィルタリング。
- **URLパターン**: `/inventory`
- **アクセス権限**: 認証済ユーザー全員

## 画面構成
- **ヘッダー**: タイトル（Package アイコン）、新規登録ボタン
- **アラートサマリー**: 在庫切れ・残少品目数の強調表示（条件表示）
- **検索・フィルタ**: 
  - `NotionFilter`: カテゴリ、ステータス、キーワード検索、ソート機能
  - `FilteringIndicator`: 計算中の視覚的フィードバック
- **データテーブル**: `DataTable` による一覧表示
- **ページネーション**: 20件/ページ。URLパラメータ `?page=N` と同期。

## 表示項目（テーブル）

| フィールド名 | 型 | 説明 | ソート | 備考 |
|------------|-----|------|--------|------|
| 品名 | string | 商品・薬品名 | ○ | |
| カテゴリ | enum | 医薬品 / 消耗品 / フード / その他 | ○ | |
| 在庫数 | number | 現在の在庫（単位付） | ○ | `item.quantity` `item.unit` |
| 最低在庫 | number | 発注点（単位付） | - | `item.minStockLevel` |
| 保管場所 | string | 収納場所 | - | |
| 有効期限 | date | 使用期限（等幅フォント） | - | |
| ステータス | enum | 十分 (sufficient) / 残少 (low) / 在庫切れ (out_of_stock) | ○ | `StatusBadge` |
| 操作 | - | 編集ボタン | - | `RowActionButton` |

## ユーザーアクション
- **新規登録**: `/inventory/new` へ遷移。
- **編集**: 行クリックまたは操作ボタンから `/inventory/:id` 編集フォームへ遷移。
- **データ取込**: （現状プレースホルダ）

## API連携
| メソッド | エンドポイント | 用途 |
|---------|--------------|------|
| GET | `/api/v1/inventory` | 在庫一覧取得 |
| DELETE | `/api/v1/inventory/:id` | 在庫削除 |
