# 在庫管理 仕様書

## 概要
- **画面の目的**: 医薬品・フード・消耗品の在庫数管理とマスタ連動
- **URLパターン**: `/inventory`
- **アクセス権限**: 認証済ユーザー全員

## 画面レイアウト
```
┌──────────────────────────────────────────────────────┐
│ 在庫管理  [新規登録ボタン]                            │
├──────────────────────────────────────────────────────┤
│ タブ: [すべて] [在庫不足] [在庫切れ]                 │
├──────────────────────────────────────────────────────┤
│ 🔍 [品名 / カテゴリ 検索]   カテゴリフィルター        │
├──────────────────────────────────────────────────────┤
│ テーブル                                             │
│ 品名 | カテゴリ | 在庫数 | 単位 | 最低在庫数 |        │
│ 保管場所 | 有効期限 | ステータス | 操作              │
└──────────────────────────────────────────────────────┘
```

## 表示項目

| フィールド名 | 型 | 説明 | 備考 |
|------------|-----|------|------|
| 品名 | string | 在庫品目の名前 | `inventory_items.name` |
| カテゴリ | enum | medicine/consumable/food/other | `inventory_items.category` |
| 在庫数 | int | 現在の在庫数量 | `inventory_items.quantity` |
| 単位 | string | 錠/ml/個等 | `inventory_items.unit` |
| 最低在庫数 | int | アラート発生の閾値 | `inventory_items.min_stock_level` |
| 保管場所 | string | 保管場所の説明 | `inventory_items.location` |
| 有効期限 | date | 在庫の有効期限 | `inventory_items.expiry_date` |
| 仕入先 | string | 仕入先業者名 | `inventory_items.supplier` |
| 最終入荷日 | date | 最後に入荷した日付 | `inventory_items.last_restocked` |
| ステータス | enum | sufficient/low/out_of_stock | `inventory_items.status` |

## カテゴリ一覧

| 値 | 表示名 |
|----|--------|
| `medicine` | 医薬品 |
| `consumable` | 消耗品 |
| `food` | フード |
| `other` | その他 |

## ステータスバッジ色

| ステータス | 表示名 | 色 |
|-----------|--------|-----|
| `sufficient` | 十分 | 緑（green） |
| `low` | 残少 | 黄（amber） |
| `out_of_stock` | 在庫切れ | 赤（red） |

## フィルタータブ

| タブ名 | フィルター条件 |
|--------|--------------|
| すべて | フィルターなし |
| 在庫不足 | status = `low` |
| 在庫切れ | status = `out_of_stock` |

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 新規登録 | 「新規登録」ボタン | 在庫品目登録フォームへ | インラインまたは詳細画面 |
| 編集 | 行クリックまたは操作ボタン | 在庫品目編集フォームへ | 同画面（インライン）or 詳細 |
| 入荷処理 | 「入荷」ボタン | 在庫数加算処理 | ダイアログ |
| タブ切替 | タブクリック | ステータスフィルター変更 | 同画面 |
| 在庫不足アラート確認 | ステータスバッジ | 在庫不足一覧フィルター | 同画面 |
