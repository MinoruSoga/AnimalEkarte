# 在庫管理 仕様書

## 概要
- **画面の目的**: 在庫品目（医薬品、消耗品等）の一覧表示、検索、フィルタリング。
- **URLパターン**: `/inventory`
- **アクセス権限**: 認証済ユーザー全員

## 画面構成
- **ヘッダー**: タイトル「在庫管理」（Package アイコン）、新規登録ボタン
- **アラートサマリー**: 在庫切れ・残少品目がある場合、`AlertTriangle` アイコンと共に件数を強調表示するパネルが出現。
- **検索・フィルタ**: 
  - `NotionFilter`: カテゴリ、ステータス、キーワード検索（品名・保管場所・仕入先）、ソート機能。
  - フィルタリング挙動: カテゴリとステータスの "is" 条件はサーバーサイド、それ以外はクライアントサイドで処理。
- **データテーブル**: `DataTable` による一覧表示。
- **ページネーション**: 20件/ページ。URLパラメータ `?page=N` と同期。

## 表示項目（テーブル）

| フィールド名 | 型 | 説明 | ソート | 備考 |
|------------|-----|------|--------|------|
| 品名 | string | 商品・薬品名 | ○ | `item.name` |
| カテゴリ | enum | 医薬品 / 消耗品 / フード / その他 | ○ | `item.category` |
| 在庫数 | number | 現在の在庫（単位付） | ○ | `item.quantity` `item.unit` (等幅) |
| 最低在庫 | number | 発注点（単位付） | - | `item.minStockLevel` (等幅) |
| 保管場所 | string | 収納場所 | - | `item.location` |
| 有効期限 | string | 使用期限 | - | `item.expiryDate` (YYYY-MM-DD) |
| ステータス | enum | 十分 / 残少 / 在庫切れ | ○ | `getInventoryStatusColor` で配色 |
| 操作 | - | 編集ボタン | - | `RowActionButton` |

## ユーザーアクション
- **新規登録**: `/inventory/new` へ遷移。
- **編集**: 行クリックまたは操作ボタンから `/inventory/:id` 編集フォームへ遷移。
- **データ取込**: （現状プレースホルダ）

## API連携
| メソッド | エンドポイント | 用途 |
|---------|--------------|------|
| GET | `/api/v1/inventory` | 在庫一覧取得 |
| DELETE | `/api/v1/inventory/:id` | 在庫削除 |
