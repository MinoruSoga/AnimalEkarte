# Lステップ連携・管理 仕様書 (L-Step Integration)

## 概要
- **画面の目的**: Lステップ（LINE公式アカウント拡張ツール）との高度な連携設定、自動配信タグの管理、およびマーケティング施策の効果分析。
- **URLパターン**: 
  - 連携設定: `/settings/integrations/lstep`
  - タグ管理: `/lstep/tags`
  - 健診対象者抽出: `/lstep/checkup-sync`
  - 分析レポート: `/lstep/analytics`
- **アクセス権限**: 医院管理者権限および分析専用権限（`ResourceLstepAnalytics`）

---

## 1. 連携・ロジック設定 (`/settings`)
システムと Lステップを接続し、顧客を自動分類するための「脳」となる設定エリアです。
- **API接続**: Lステップおよび LINE Messaging API の認証情報を登録。
- **CPM判定基準**: 累計売上や来院頻度に基づき、V1（詳細）/V2（シンプル）のロジックを切り替え・閾値設定。
- **通知タイミング**: ワクチン期限の何日前に通知するか、休眠とみなす日数は何日か等の詳細パラメータを管理。

## 2. タグ分布管理 (`/tags`)
現在、Lステップ側に付与されているタグ（CPMステージ、動物種、来院状況等）の分布をリアルタイムに俯瞰します。
- **サマリー**: カテゴリごとの対象人数と、カルテ側との最終同期日時を表示。
- **詳細ドロワー**: タグをクリックすると、該当する飼主の一覧を CSV 出力したり、一括でタグを解除したりできます。

## 3. 健診対象者抽出 (`/checkup-sync`)
「健診を1年以上受けていない犬」などの特定のセグメントを抽出し、ダイレクトにアプローチします。
- **条件抽出**: 動物種、年齢、最終来院日、CPM ステージ等を組み合わせた柔軟なフィルタリング。
- **一括タグ付与**: 抽出したリストに対し、Lステップ側での配信トリガーとなるタグをワンクリックで付与。

## 4. 分析レポート (`/analytics`)
実施したマーケティング施策がどれだけ実際の来院（売上）に結びついたかを可視化します。
- **配信実績**: 自動メッセージの送信成功・失敗・除外数の推移。
- **来院転換率**: メッセージ配信から30日以内に来院した顧客の割合を施策別に算出。

---

## 主要な安全制御

- **配信除外の徹底**: 飼主側で「配信停止」を選択している、またはスタッフが「配信除外」に設定している場合、すべての自動連携は物理的にバイパスされます。
- **API接続テスト**: 設定変更時には必ず疎通テストを実行し、設定ミスによる配信失敗を未然に防ぎます。

---

## 技術仕様

### 使用コンポーネント
- **`LstepSettingsPage`**: 閾値管理を含む統合設定画面。
- **`CheckupSyncPage`**: リストプレビュー機能付きの抽出・連携画面。
- **`LstepAnalyticsPage`**: Recharts を活用した転換率の可視化。

### API連携
| メソッド | エンドポイント | 用途 |
|:---|:---|:---|
| GET | `/api/v1/lstep-settings` | 連携設定と判定閾値の取得。 |
| GET | `/api/v1/lstep/tags/summary` | 現在のタグ保有者数の統計取得。 |
| POST | `/api/v1/lstep/checkup-sync` | 指定条件の対象者へのタグ一括付与。 |
| GET | `/api/v1/lstep/analytics/conversion` | 来院転換データの集計。 |
