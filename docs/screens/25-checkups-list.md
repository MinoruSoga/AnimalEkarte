## 概要
- **画面の目的**: 全ペットの定期健診記録（身体測定・一般健診等）を一覧表示・検索する。定期健診データは電子カルテの一部として保存されるため、本画面は「カルテ内の健診データ」を横断的に検索するためのビューとして機能する。
- **URLパターン**: `/checkups`
- **アクセス権限**: 認証済ユーザー全員（`ResourceCheckups` 権限が必要）

## 画面構成
- **ヘッダー**: タイトル「定期健診」、新規登録ボタン。
- **検索・フィルタ**: 
  - `NotionFilter`: 健診日の期間指定（**サーバーサイドフィルタ**）、キーワード検索（ペット名・飼主名・種別・結果/所見）。
- **データテーブル**: `DataTable` による一覧表示。20件ごとのページネーション。

## 表示項目（テーブル）

| フィールド名 | 型 | 説明 | ソート | 備考 |
|------------|-----|------|--------|------|
| 実施日 | string | 健診実施日 | ○ | `date` (YYYY-MM-DD) |
| 飼主名 | string | 飼い主氏名 | ○ | `ownerName` |
| ペット名 | string | ペット名 | ○ | `petName` |
| 健診種別 | string | 健診の種類 | ○ | `checkupTypeName` |
| 次回予定 | string | 次回予定日 | ○ | `nextDate` (YYYY-MM-DD) |
| 結果・所見 | string | 健診結果の抜粋 | - | `result` (切捨て表示) |
| 担当医 | string | 担当獣医師名 | - | `doctorName` |
| 操作 | - | カルテ参照ボタン | - | `RowActionButton` |

## ユーザーアクション
- **新規登録**: カルテのペット選択画面 (`/medical-records/select-pet`) へ遷移し、カルテ作成を通じて健診を記録する。
- **詳細表示・編集**: 行クリックまたは操作ボタンから、該当する **カルテ詳細画面 (`/medical-records/:id`)** へ遷移する。

## UI コンポーネント
| コンポーネント | 種別 | 説明 |
|---|---|---|
| `CheckupsList` | `[R]` | メインページ。 |
| `NotionFilter` | `[S]` | 期間・キーワード・動的オプションに対応した検索パネル。 |
| `Pagination` | `[S]` | ページ切り替えコンポーネント。 |
| `FilteringIndicator`| `[S]` | フィルタ計算中の視覚的フィードバック。 |

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/checkups` | 定期健診一覧取得（期間・キーワード検索対応） | 実装済 |
| DELETE | `/api/v1/checkups/:id` | 健診レコード削除 | 実装済 |
