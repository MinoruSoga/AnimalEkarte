# 定期健診一覧 仕様書

## 概要
- **画面の目的**: 全ペットの定期健診記録（身体測定・一般健診等）を時系列で一覧表示・検索・管理する。
- **URLパターン**: `/checkups`
- **アクセス権限**: 認証済ユーザー全員（操作権限は `usePermission` で制御）

## 画面構成
- **ヘッダー**: タイトル、新規健診登録ボタン。
- **ツールバー**: 
  - `NotionFilter`: 健診日の期間指定（サーバーサイドフィルタ）、キーワード検索（飼主名・ペット名・結果/所見）、動的な「健診種別」フィルタ。
  - `FilteringIndicator`: 非同期計算中の透過表示。
- **データテーブル**: `DataTable` による一覧表示。20件ごとのページネーション。

## 主要機能
- **動的検索・ソート**: `useSortableData` を使用し、実施日、飼主名、次回予定日等での柔軟な並び替えに対応。
- **URL同期**: ページ番号を URL クエリパラメータ (`?page=N`) と同期し、状態を保持。
- **遷移設計**: 
  - 「新規登録」: ペット選択画面 (`/checkups/select-pet`) へ遷移。
  - 「詳細・編集」: 該当するカルテ画面の「定期健診」タブへ直接遷移し、即座に編集可能な状態にする。
- **パフォーマンス**: `useDeferredValue` により、大規模な健診データセットに対してもスムーズなフィルタリング体験を提供。

## UI コンポーネント
| コンポーネント | 種別 | 説明 |
|---|---|---|
| `CheckupsList` | `[R]` | メインページ。 |
| `NotionFilter` | `[S]` | 期間・キーワード・動的オプションに対応した検索パネル。 |
| `Pagination` | `[S]` | ページ切り替えコンポーネント。 |
| `FilteringIndicator`| `[S]` | フィルタ計算中の視覚的フィードバック。 |

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/checkups` | 定期健診一覧取得（期間・キーワード検索対応） | 実装済 |
| DELETE | `/api/v1/checkups/:id` | 健診レコード削除 | 実装済 |
