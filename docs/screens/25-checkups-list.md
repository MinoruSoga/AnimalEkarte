# 定期健診一覧 仕様書

## 概要
- **画面の目的**: 全ペットの定期健診記録（フィラリア・混合ワクチン・狂犬病等）を一覧表示・検索する。
- **URLパターン**: `/checkups`
- **アクセス権限**: 認証済ユーザー全員

## 画面構成
- **ヘッダー**: タイトル「定期健診」
- **検索バー**: ペット名・飼主名・健診種別での非同期フィルタ（`useDeferredValue`）
- **データテーブル**: `DataTable` による一覧表示
- **ページネーション**: 20件/ページ

## 表示項目（テーブル）

| フィールド名 | 型 | 説明 | 備考 |
|------------|-----|------|------|
| 飼主名 | string | 飼い主氏名 | |
| ペット名 | string | ペット名 | 太字表示 |
| 健診種別 | string | 健診の名称 | |
| 実施日 | date | 実施日（等幅フォント） | |
| 次回予定 | date | 次回予定日（等幅フォント） | |
| 結果・所見 | string | 健診結果の要約 | 省略表示 |
| 担当医 | string | 担当獣医師名 | |

## ユーザーアクション
- **検索**: テキスト入力によるリアルタイムフィルタリング。
- **カルテ参照**: （将来的な拡張：行クリックで該当カルテへ遷移）

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/checkups` | 定期健診一覧取得 | 実装済 |

## 備考
- 本画面は参照専用ポータル。新規登録や編集はカルテ画面（`/medical-records/:id`）の「定期健診」タブから行う。
