# トリミング一覧 仕様書

## 概要
- **画面の目的**: トリミング施術記録の検索・一覧管理。
- **URLパターン**: `/trimming`
- **アクセス権限**: 認証済ユーザー全員

## 画面構成
- **ヘッダー**: タイトル（Scissors アイコン）、新規登録ボタン
- **検索・フィルタ**: 
  - `NotionFilter`: 日時範囲（サーバーサイド）、種（動的）、担当（動的）、キーワード検索
  - `FilteringIndicator`: 計算中の視覚的フィードバック
- **データテーブル**: `DataTable` による一覧表示
- **ページネーション**: 10件/ページ。URLパラメータ `?page=N` と同期。

## 表示項目（テーブル）

| フィールド名 | 型 | 説明 | ソート | 備考 |
|------------|-----|------|--------|------|
| 診療日 | date | 施術日（等幅フォント） | ○ | `date` |
| 飼主名 | string | 飼い主氏名 | ○ | `ownerName` |
| ペット名 | string | ペット名（ペット番号併記） | ○ | `petName` |
| 種 | string | 動物種 | ○ | `species` |
| 体重 | decimal | 当日の体重 | - | `weight` |
| スタイル希望 | string | カットスタイルの要望 | - | |
| 担当 | string | 担当トリマー名 | ○ | `staff` |
| ステータス | enum | 予約 / 進行中 / 完了 | ○ | `status` |
| 操作 | - | 編集・削除 | - | `RowActionDropdown` |

## ユーザーアクション
- **新規登録**: ペット選択画面を経てトリミング登録フォームへ遷移。
- **編集**: 行クリックまたは操作ボタンから編集フォームへ遷移。
- **削除**: 確認ダイアログ後、論理削除を実行。

## API連携
| メソッド | エンドポイント | 用途 |
|---------|--------------|------|
| GET | `/api/v1/trimmings` | トリミング一覧取得 |
| DELETE | `/api/v1/trimmings/:id` | トリミング削除 |
