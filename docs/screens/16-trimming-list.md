# トリミング一覧 仕様書 (Trimming List)

## 概要
- **画面 of Purpose**: 院内で実施されるトリミング施術の予約・実績・進捗管理。
- **URLパターン**: `/trimming`
- **アクセス権限**: 認証済ユーザー全員（`ResourceTrimming` 権限が必要）

---

## 1. 画面構成

### 1.1 高機能検索・フィルタ (`NotionFilter`)
- **施術日指定**: 施術が行われた、または予定されている期間での絞り込み。
- **ステータスフィルタ**: 「予約済 (scheduled)」「施術中 (processing)」「完了 (completed)」による進捗状況の抽出。
- **全文検索**: 患者名、飼主名、スタイル要望キーワードによる検索。
- **トリマー指定**: 担当スタッフによる絞り込み。

### 1.2 施術管理テーブル (`DataTable`)
トリミング室の業務フローに最適化された情報表示。

| カラム | 説明 |
|:---|:---|
| **診療日** | 施術実施（予定）日。 |
| **患者・飼主** | ペット名とオーナー名。動物種に応じたアイコン付。 |
| **コース名** | シャンプー、カット等のメインメニュー（マスタ連動）。 |
| **担当トリマー** | 施術を担当するスタッフ名。 |
| **ステータス** | 進捗状況を示すカラーバッジ。 |
| **スタイルサマリ** | 前回のスタイルや今回の主要な要望の抜粋。 |

---

## 2. 主要な運営連携

- **予約管理との統合**: 予約カレンダー (`/reservations`) で作成されたトリミング枠は、当日自動的にこの一覧の「予約済」として出現します。
- **会計への自動連携**: 施術完了時に記録されたコース・オプション料金は、即座に会計セクションへドラフトとして送信されます。

---

## 3. 技術仕様

### 3.1 描画の最適化
- **遅延フィルタリング**: `useDeferredValue` により、多数の過去実績を検索する際も軽快な操作感を維持。
- **透過インジケータ**: フィルタ処理中は `FilteringIndicator` により状態を通知。

### API連携
| メソッド | エンドポイント | 用途 |
|:---|:---|:---|
| GET | `/api/v1/trimmings` | 条件に応じた施術記録の一括取得。 |
| DELETE | `/api/v1/trimmings/:id` | 施術記録の論理削除。 |
