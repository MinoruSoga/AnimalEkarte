# トリミング一覧 仕様書

## 概要
- **画面の目的**: トリミング予約・施術記録の一覧管理
- **URLパターン**: `/trimming`
- **アクセス権限**: 認証済ユーザー全員

## 画面レイアウト
```
┌──────────────────────────────────────────────────────┐
│ トリミング管理  [新規登録ボタン]                      │
├──────────────────────────────────────────────────────┤
│ タブ: [予約] [進行中] [完了] [すべて]                │
├──────────────────────────────────────────────────────┤
│ 🔍 [飼主名 / ペット名 検索]                          │
├──────────────────────────────────────────────────────┤
│ テーブル                                             │
│ 予約日時 | 飼主名 | ペット名 | コース名 |             │
│ 担当者 | 合計金額 | ステータス | 操作                │
└──────────────────────────────────────────────────────┘
```

## 表示項目

| フィールド名 | 型 | 説明 | 備考 |
|------------|-----|------|------|
| 予約日時 | datetime | トリミング予約日時 | `trimmings.appointment_date` |
| 飼主名 | string | 飼い主氏名 | `owners.name` |
| ペット名 | string | ペット名 | `pets.name` |
| 種/品種 | string | 動物種・品種 | `pets.species`, `pets.breed` |
| コース名 | string | トリミングコース | `trimmings.course` |
| オプション | json | 選択したオプション一覧 | `trimmings.options` |
| スタイル要望 | string | カットスタイルの要望 | `trimmings.style_request` |
| 担当者 | string | 担当トリマー名 | `staffs.name` |
| 合計金額 | decimal | コース+オプション合計 | `trimmings.total_price` |
| ステータス | enum | 予約/進行中/完了 | `trimmings.status` |

## フィルタータブ

| タブ名 | フィルター条件 |
|--------|--------------|
| 予約 | status = `予約` |
| 進行中 | status = `進行中` |
| 完了 | status = `完了` |
| すべて | フィルターなし |

## ステータスバッジ色

| ステータス | 色 |
|-----------|-----|
| 予約 | 青（blue） |
| 進行中 | 黄（amber） |
| 完了 | 緑（green） |

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 新規登録 | 「新規登録」ボタン | ペット選択画面へ | `/trimming/select-pet` |
| 詳細/編集 | 行クリック or 操作ボタン | トリミングフォームへ | `/trimming/:id` |
| タブ切替 | タブクリック | ステータスフィルター変更 | 同画面 |
