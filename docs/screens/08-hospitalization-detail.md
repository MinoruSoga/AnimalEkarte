# 入院詳細・デイリーカルテ 仕様書

## 概要
- **画面の目的**: 入院患者のケアプラン管理、デイリーログ（バイタル・ケアログ・スタッフメモ）の記録、入院サマリーの管理。
- **URLパターン**: `/hospitalization/:id`
- **アクセス権限**: 認証済ユーザー全員（操作権限は `usePermission` で制御）

## 画面構成
- **ヘッダー**: タイトル、戻るボタン、退院ボタン、入院サマリー印刷。
- **左エリア (患者・プラン)**:
  - **患者情報カード**: 入院No、ペット名、飼主名、担当医。
  - **ケアプラン**: 実施すべきタスク（投薬・給餌・処置等）のリスト。
- **右エリア (デイリーカルテ)**:
  - **タブ切り替え**: 日次記録（バイタル・ケアログ）、スタッフメモ、検査結果、会計。
  - **時系列表示 (Timeline)**: 朝・昼・夜のセクションに分かれた処置実施状況のタイムライン。

## 主要機能
- **時系列タスク管理**: `DailyRecordSection` において、時間帯ごとのタスク実施確認（`TaskCompleteDialog`）と自動記録。
- **タイムライン統合**: バイタル入力、ケアログ、スタッフメモを時系列で一つのタイムラインに統合表示。
- **退院フロー**: `DischargeAlertDialog` での承認後、会計画面へ自動遷移。既存の未精算会計がある場合は統合し、ない場合は新規会計をペットID付きで作成する（`navigateToAccounting` ロジック）。
- **レスポンシブ配置**: 画面幅に応じて、プランと記録を左右並列（デスクトップ）または上下（モバイル）に自動配置。

## UI コンポーネント
| コンポーネント | 種別 | 説明 |
|---|---|---|
| `HospitalizationDetail` | `[R]` | メインページ。 |
| `HospitalizationExpandedView`| `[C]` | デスクトップ向けの左右分割レイアウト。 |
| `HospitalizationTabbedView` | `[C]` | モバイル向けのタブ形式レイアウト。 |
| `DailyRecordSection` | `[C]` | 時系列のデイリーログ管理。 |
| `TaskCompleteDialog` | `[C][M]` | タスク完了時のメモ入力ダイアログ。 |

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/hospitalizations/:id` | 入院詳細取得 | 実装済 |
| PATCH | `/api/v1/hospitalizations/:id` | ステータス更新（退院等） | 実装済 |
| POST | `/api/v1/hospitalizations/:id/daily-records` | 日次記録作成 | 実装済 |
| GET | `/api/v1/hospitalizations/:id/daily-records` | 日次記録一覧 | 実装済 |
