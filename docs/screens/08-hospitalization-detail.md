# 入院詳細・デイリーカルテ 仕様書

## 概要
- **画面の目的**: 入院患者のケアプラン管理、デイリーログ（バイタル・ケアログ・スタッフメモ）の記録、入院サマリーの印刷
- **URLパターン**: `/hospitalization/:id`
- **コンポーネント**: `[R] HospitalizationDetail`
- **アクセス権限**: 認証済ユーザー全員

## 画面構成
- **ヘッダー**: タイトル、戻るボタン、アクションボタン（印刷、編集、会計連携、退院）
- **メインコンテンツ**: デスクトップ/モバイルで最適化されたレイアウト
  - **患者ヘッダー**: `HospitalizationPatientHeader` (ペット名、飼主名、ケージ、期間、ステータス等)
  - **ケアプラン**: `CarePlanSection` (食事、投薬、処置指示の一覧と編集)
  - **デイリーレコード**: `DailyRecordSection` (日付ナビ、タイムライン、実施記録)

## デイリーレコード詳細
- **日付ナビゲーション**: `DateNavigation` により、過去・未来の日付の記録を表示・操作可能。
- **タスク管理**: ケアプランに基づき、朝・昼・夜のセクションに自動生成されたタスクを `TaskCompleteDialog` で完了報告。
- **バイタル記録**: `VitalDialog` を使用して、体温・体重・心拍数・呼吸数を時刻指定で記録。
- **ケアログ記録**: `LogDialog` を使用して、食事（完食、1/2など）や排泄（良便、軟便など）の状態をクイック入力。
- **スタッフメモ**: `SimpleNoteForm` で、タイムラインに流れる簡易的な申し送り事項を記録。
- **タイムライン**: `Timeline` コンポーネントが、上記すべての活動を時系列で統合表示。

## 主な機能
- **ケアプラン即時反映**: ポップオーバーからケアプランのステータス（実施中/完了）を即座にトグルし、サーバーへ同期。
- **会計連携フロー**: 退院時ダイアログに「退院後、そのまま会計画面へ進む」チェックボックスがある。チェックして実行すると `/accounting/new?petId=XXX` へ遷移。**注意: プラン明細の自動変換はバックエンド未実装（BE-HOSP-001）のため、現状は手動入力になる。**
- **ドキュメント発行**: `PrintPreviewDialog` を経由して、入院期間と費用をまとめた入院サマリーを印刷。

## API連携
| メソッド | エンドポイント | 用途 |
|---------|--------------|------|
| GET | `/api/v1/hospitalizations/:id` | 入院詳細取得 |
| GET | `/api/v1/hospitalizations/:id/care-plans` | ケアプラン一覧 |
| POST | `/api/v1/hospitalizations/:id/daily-records` | 日次記録作成 |
| GET | `/api/v1/hospitalizations/:id/daily-records` | 日次記録一覧 |
| POST | `/api/v1/hospitalizations/:id/discharge-with-billing` | 退院＋会計自動生成（BE-HOSP-001、未実装） |
