# ワクチン一覧 仕様書

## 概要
- **画面の目的**: ペットのワクチン接種記録を一覧表示・管理する
- **URLパターン**: `/vaccinations`
- **アクセス権限**: 認証済ユーザー全員

## 画面レイアウト
```
┌──────────────────────────────────────────────────────┐
│ ワクチン管理  [新規登録ボタン]                        │
├──────────────────────────────────────────────────────┤
│ 🔍 [飼主名 / ペット名 / ワクチン名 検索]             │
├──────────────────────────────────────────────────────┤
│ テーブル                                             │
│ 接種日 | 飼主名 | ペット名 | ワクチン名 |             │
│ 接種医 | 次回予定日 | ロット番号 | 操作              │
└──────────────────────────────────────────────────────┘
```

## 表示項目

| フィールド名 | 型 | 説明 | 備考 |
|------------|-----|------|------|
| 接種日 | date | ワクチン接種日 | `vaccinations.vaccination_date` |
| 飼主名 | string | 飼い主氏名 | `owners.name` |
| ペット名 | string | ペット名 | `pets.name` |
| 種 | string | 動物種 | `pets.species` |
| ワクチン名 | string | ワクチンの名称 | `vaccinations.vaccine_name` |
| 接種医 | string | 接種した獣医師名 | `staffs.name` |
| 次回接種予定日 | date | 次回推奨接種日 | `vaccinations.next_date` |
| ロット番号 | string | ワクチンのロット番号 | `vaccinations.lot_number` |

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 新規登録 | 「新規登録」ボタン | ペット選択画面へ | `/vaccinations/select-pet` |
| 詳細/編集 | 行クリック or 操作ボタン | ワクチンフォームへ | `/vaccinations/:id` |
| 接種予定確認 | 「接種予定」フィルター | 次回接種予定が近いものを表示 | 同画面 |
