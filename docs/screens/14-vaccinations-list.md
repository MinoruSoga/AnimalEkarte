# 予防接種一覧 仕様書

## 概要
- **画面の目的**: 予防接種記録の一覧表示・検索・カルテ遷移。
- **URLパターン**: `/vaccinations`
- **アクセス権限**: 認証済ユーザー全員

## 画面構成
- **ヘッダー**: タイトル、データ取込ボタン、新規登録ボタン
- **検索・フィルタ**: `NotionFilter`（実施日範囲、キーワード検索、ソート機能）
- **データテーブル**: `DataTable` による一覧表示
- **ページネーション**: 標準ページネーション

## 表示項目（テーブル）

| フィールド名 | 型 | 説明 | ソート | 備考 |
|------------|-----|------|--------|------|
| 実施日 | date | 接種日 | ○ | `date` |
| 飼主名 | string | 飼い主氏名 | ○ | `ownerName` |
| ペット名 | string | ペット名 | ○ | `petName` |
| 予防接種名 | string | ワクチン名称 | ○ | `vaccineName` |
| 次回予定 | date | 次回接種予定日 | ○ | `nextDate` |
| 操作 | - | 詳細（カルテへ遷移） | - | `RowActionButton` |

## ユーザーアクション
- **新規登録**: ペット選択画面を経てカルテの予防接種タブへ遷移。
- **詳細表示**: 行クリックまたは操作ボタンからカルテの予防接種タブへ遷移。

## API連携
| メソッド | エンドポイント | 用途 |
|---------|--------------|------|
| GET | `/api/v1/vaccinations` | 予防接種一覧取得 |
| DELETE | `/api/v1/vaccinations/:id` | 予防接種削除 |
