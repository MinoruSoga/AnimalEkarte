## 概要
- **画面の目的**: 予防接種（ワクチン、フィラリア予防等）記録の一覧表示・検索、および次回予定の把握。
- **URLパターン**: `/vaccinations`
- **アクセス権限**: 認証済ユーザー全員（`ResourceVaccinations` 権限が必要）

## 画面構成
- **ヘッダー**: タイトル「予防接種管理」、新規登録ボタン
- **検索・フィルタ**: 
  - `NotionFilter`: 日時範囲（**サーバーサイド**）、担当医（動的）、キーワード検索（クライアントサイド）。
- **データテーブル**: `DataTable` による一覧表示。20件ごとのページネーション。

## 表示項目（テーブル）

| フィールド名 | 型 | 説明 | ソート | 備考 |
|------------|-----|------|--------|------|
| 実施日 | string | 接種日 | ○ | `date` (YYYY-MM-DD) |
| 飼主名 | string | 飼い主氏名 | ○ | `ownerName` |
| ペット名 | string | ペット名 | ○ | `petName` |
| 予防接種名 | string | ワクチン名称 | ○ | `vaccineName` |
| 次回予定 | string | 次回接種予定日 | ○ | `nextDate` (YYYY-MM-DD) |
| 操作 | - | 詳細（予防接種フォームへ遷移） | - | `RowActionButton` |

## ユーザーアクション
- **新規登録**: `/vaccinations/select-pet` を経て `/vaccinations/new` へ遷移。
- **詳細表示**: 行クリックまたは操作ボタンから `/vaccinations/:id` 編集フォームへ遷移。

## API連携
| メソッド | エンドポイント | 用途 |
|---------|--------------|------|
| GET | `/api/v1/vaccinations` | 予防接種一覧取得 |
| DELETE | `/api/v1/vaccinations/:id` | 予防接種削除 |
