# シフトテンプレートマスタ設定 仕様書

## 概要
- **画面の目的**: シフト登録（`/shifts`）で頻繁に使用される勤務パターン（日勤、午前診、午後診等）をテンプレートとして管理し、入力効率を向上させる。
- **URLパターン**: `/settings/shift-template`
- **コンポーネント**: `ShiftTemplateSettings`
- **アクセス権限**: `ResourceShifts` (edit以上) 権限が必要

## 画面構成
- **メインエリア**: `DataTable` によるテンプレート一覧。
  - カラム: ドラッグハンドル、テンプレート名、区分、時間（開始〜終了）、休憩時間、ステータス、操作。
- **サイドパネル**: `ShiftTemplateSidePanel` による詳細編集。

## 表示・フォーム項目

### フォーム項目（サイドパネル）
| フィールド | 項目ID | 入力部品 | 必須 | 備考 |
|-----------|--------|---------|------|------|
| テンプレート名 | `name` | `Input` | ✅ | タイトルエリア（例: 日勤, A当番） |
| ステータス | `isActive` | `NotionStatusPill` | - | 有効/無効トグル |
| シフト種別 | `shiftType` | `Select` | ✅ | 全日 / 午前 / 午後 / 休日 / 有休 |
| 開始時刻 | `startTime`| `input(time)` | - | 30分単位。休日時は入力不可 |
| 終了時刻 | `endTime` | `input(time)` | - | 30分単位。休日時は入力不可 |
| 休憩時間 | `breaks` | 動的リスト | - | **複数登録可能**。`break_start` / `break_end` のペアを追加。 |
| メモ | `notes` | `PropertyInput` | - | シフト登録時に自動反映されるメモ |

## 主要機能
- **ドラッグ&ドロップ**: `dnd-kit` による並び替え（フラットソート）。`PUT /api/v1/shift-templates/reorder` で一括保存。
- **休憩時間の一括定義**: テンプレートに休憩時間を設定しておくことで、LINE予約の空き枠計算の基礎となる休憩時間を効率的にスタッフへ割り当て可能。
- **ステータス管理**: 使用しなくなったテンプレートを「無効」にすることで、シフト登録時の選択肢から除外可能。

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/shift-templates` | テンプレート一覧取得 | 実装済 |
| POST | `/api/v1/shift-templates` | 新規作成 | 実装済 |
| PATCH | `/api/v1/shift-templates/:id` | 更新 | 実装済 |
| DELETE | `/api/v1/shift-templates/:id` | 削除 | 実装済 |
| PUT | `/api/v1/shift-templates/reorder` | 並び順保存 | 実装済 |
