# 締め時間設定 仕様書

## 概要
- **画面の目的**: 日次・月次の集計に使用する境界時刻、休診日、および特別な集計期間（イベント期間等）を管理する。
- **URLパターン**: `/settings/closing-time`
- **コンポーネント**: `ClosingSettingsPage`
- **アクセス権限**: 管理者権限が必要

## 画面構成
画面は大きく3つのセクションで構成されます。

### 1. 標準締め時間設定 (`StandardClosingTimeSection`)
- **目的**: 通常営業時における「午前/午後」の境界時刻、および「1日の終了」とみなす時刻を定義。
- **項目**:
  - **午前/午後 境界**: AM締めとPM締めの境界となる時刻（例: 13:00）。
  - **営業終了境界**: その日の最終データとみなす時刻（例: 23:59）。これを過ぎた会計は翌日分として集計。

### 2. 特別期間設定 (`SpecialPeriodSection`)
- **目的**: 年末年始、お盆、キャンペーン期間など、通常の境界時間とは異なる運用をする期間を定義。
- **項目**:
  - 名称、開始日、終了日、境界時刻、ステータス。

### 3. 休診日設定 (`HolidaySection`)
- **目的**: 病院の休診日（祝日・臨時休診・定期休診）を管理。カレンダーやレジ締めの「休診日アラート」に使用。
- **項目**:
  - 日付、名称（例: 創立記念日）、種別（全日休診 / 午後休診 等）。

## 主要機能
- **即時反映**: 設定された時刻に基づき、レジ締め画面（`/accounting/close`）でのデフォルト集計範囲が動的に計算される。
- **カレンダー連携**: 休診日設定は、予約管理やシフト管理のカレンダー表示にも反映される。

## API連携
| メソッド | エンドポイント | 用途 |
|---------|--------------|------|
| GET | `/api/v1/closing-settings` | 全設定（標準・特別・休診）の一括取得 |
| PATCH | `/api/v1/closing-settings/standard` | 標準締め時間の更新 |
| POST | `/api/v1/closing-settings/special-periods` | 特別期間の作成 |
| DELETE | `/api/v1/closing-settings/special-periods/:id` | 特別期間の削除 |
| POST | `/api/v1/closing-settings/holidays` | 休診日の作成 |
| DELETE | `/api/v1/closing-settings/holidays/:id` | 休診日の削除 |
