# 在庫登録/編集 仕様書

## 概要
- **画面の目的**: 在庫品目（医薬品、消耗品等）の新規登録および既存情報の更新。
- **URLパターン**:
  - 新規登録: `/inventory/new`
  - 編集: `/inventory/:id`
- **アクセス権限**: 認証済ユーザー全員

## 画面構成
- **ヘッダー**: タイトル、一覧に戻るボタン
- **基本情報セクション**: 品名、カテゴリ、単位
- **在庫情報セクション**: 現在庫数、最低在庫数、保管場所、有効期限
- **仕入先情報セクション**: 仕入先、最終入荷日
- **アクション**: キャンセル、登録/更新ボタン

## フォーム項目

### 1. 基本情報
| フィールド名 | 項目ID | 入力部品 | 必須 | 備考 |
|------------|--------|---------|------|------|
| 品名 | `name` | `Input` | ✅ | |
| カテゴリ | `category` | `Select` | ✅ | 医薬品 / 消耗品 / フード / その他 |
| 単位 | `unit` | `Input` | ✅ | 例: 錠, 本, 袋 |

### 2. 在庫情報
| フィールド名 | 項目ID | 入力部品 | 必須 | 備考 |
|------------|--------|---------|------|------|
| 現在庫数 | `quantity` | `Input(number)` | ✅ | 0以上 |
| 最低在庫数 | `minStockLevel`| `Input(number)` | ✅ | アラート発生の閾値 |
| 保管場所 | `location` | `Input` | - | 例: 薬品棚A-1 |
| 有効期限 | `expiryDate` | `NotionDatePicker`| - | |

### 3. 仕入先情報
| フィールド名 | 項目ID | 入力部品 | 必須 | 備考 |
|------------|--------|---------|------|------|
| 仕入先 | `supplier` | `Input` | - | |
| 最終入荷日 | `lastRestocked`| `NotionDatePicker`| - | |

## 主な機能
- **自動アラート連動**: 最低在庫数を下回る現在庫数を入力して保存すると、一覧画面で即座にアラート（残少/在庫切れ）が表示される。
- **フォーム離脱保護**: `NavigationBlocker` により、未保存の変更がある状態での離脱を防止。

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/inventories/:id` | 個別在庫取得 | 実装済 |
| POST | `/api/v1/inventories` | 在庫登録 | 実装済 |
| PATCH | `/api/v1/inventories/:id` | 在庫更新 | 実装済 |
