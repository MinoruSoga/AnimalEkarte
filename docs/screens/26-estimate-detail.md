# 見積書詳細 仕様書

## 概要
- **画面の目的**: 特定の見積書の内容を表示・確認し、編集や削除を行う。
- **URLパターン**: `/estimates/:id`
- **アクセス権限**: 認証済ユーザー全員

## 画面構成
- **ヘッダー**: タイトル（見積番号）、一覧へ戻るボタン、編集ボタン、削除ボタン
- **基本情報セクション**: タイトル、ステータス、見積番号、飼主名、有効期限、作成日、更新日、コメント
- **明細セクション**: `EstimateLineItems` による見積明細テーブルと金額サマリ
- **備考セクション**: 社内用メモの表示

## 表示項目（基本情報）
| フィールド | 説明 |
|-----------|------|
| 見積番号 | 見積書の一意識別子（等幅フォント） |
| タイトル | 見積書の名称 |
| ステータス | `EstimateStatusBadge` による表示 |
| 飼主名 | 宛先 |
| 有効期限 | 見積の有効期限 |
| 作成日 / 更新日 | レコードの管理日時 |
| コメント | 飼主向けのメッセージ（改行保持） |

## 見積明細テーブル
- 診療項目名、単価、数量、割引、保険適用、小計
- 合計金額サマリ: 小計、消費税、保険適用額、割引額、総合計金額

## ユーザーアクション
- **一覧へ戻る**: `/estimates` へ遷移。
- **編集**: `/estimates/:id/edit` へ遷移。
- **削除**: `ConfirmDialog` 表示後、レコードを論理削除して一覧へ戻る。

## UI コンポーネント
| コンポーネント | 種別 | 説明 |
|---|---|---|
| `EstimateDetail` | `[R]` | メインページ |
| `EstimateStatusBadge` | `[C]` | ステータス別のバッジ表示 |
| `EstimateLineItems` | `[C]` | 明細テーブルと金額サマリ |
| `ConfirmDialog` | `[S][M]` | 削除確認ダイアログ |

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/estimates/:id` | 見積詳細取得 | 実装済 |
| DELETE | `/api/v1/estimates/:id` | 見積削除 | 実装済 |
