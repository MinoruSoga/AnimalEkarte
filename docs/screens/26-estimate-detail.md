# 見積書詳細 仕様書

## 概要
- **画面の目的**: 特定の見積書の内容を表示・確認し、編集や削除を行う。
- **URLパターン**: `/estimates/:id`
- **アクセス権限**: 認証済ユーザー全員（操作権限は `usePermission` で制御）

## 画面構成
- **ヘッダー**: タイトル（見積番号）、一覧へ戻るボタン、編集ボタン（Pencil）、削除ボタン（Trash2）。
- **基本情報カード**: 
  - ヘッダー: タイトル、ステータスバッジ。
  - グリッド: 見積番号、飼主名、有効期限、作成日、更新日。
  - 下部: 飼主向けコメント（`comment`）。
- **見積明細カード**: 
  - `EstimateLineItems` コンポーネントによる明細テーブル表示。
  - 金額サマリ（小計、消費税、保険、割引、総合計）。
- **備考カード**: 社内用メモ（`notes`）の表示。

## 主要機能
- **権限管理**: `usePermission` により、編集・削除ボタンの表示を制御。
- **ステータス表示**: `EstimateStatusBadge` により、下書き/送付済み/承認済み/却下を色分け表示。
- **日付表示**: 全ての日付データは YYYY-MM-DD 形式に整形。
- **非同期削除**: `useTransition` と `ConfirmDialog` を利用した安全な削除フロー。

## UI コンポーネント
| コンポーネント | 種別 | 説明 |
|---|---|---|
| `EstimateDetail` | `[R]` | メインページ。データ取得とアクションを統括。 |
| `EstimateStatusBadge` | `[C]` | ステータス別のバッジ表示。 |
| `EstimateLineItems` | `[C]` | 明細テーブルと金額計算サマリの表示部品。 |
| `ConfirmDialog` | `[S][M]` | 削除前の最終確認ダイアログ。 |

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/estimates/:id` | 見積詳細取得 | 実装済 |
| DELETE | `/api/v1/estimates/:id` | 見積削除 | 実装済 |
