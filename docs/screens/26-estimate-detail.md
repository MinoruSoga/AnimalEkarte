# 見積書詳細 仕様書

## 概要
- **画面の目的**: 特定の見積書の内容を表示・確認し、編集や削除を行う。
- **URLパターン**: `/estimates/:id`
- **アクセス権限**: 認証済ユーザー全員（操作権限は `usePermission` で制御）

## 画面構成
- **ヘッダー**: タイトル（見積番号）、一覧へ戻るボタン、編集ボタン、削除ボタン。
- **基本情報セクション**: タイトル、ステータスバッジ、見積番号、飼主名、有効期限、作成日、更新日、コメント。
- **明細セクション**: 診療項目名、単価、数量、割引、保険適用、小計。
- **金額サマリ**: 小計、消費税、保険適用額、割引額、総合計金額。
- **備考セクション**: 社内用メモの表示。

## 主要機能
- **権限管理**: `usePermission` により、編集・削除権限がないユーザーに対しては対応するボタンを非表示化。
- **日付の自動フォーマット**: 有効期限や作成・更新日は、実装側で yyyy-MM-dd 形式に整形して表示。
- **状態表示**: `EstimateStatusBadge` により、ステータス（下書き/送付済み/承認済み/却下）を視覚的に判別可能。
- **非同期削除フロー**: `useTransition` を利用し、削除処理実行中の UI ブロックと一覧画面への自動遷移を実現。

## UI コンポーネント
| コンポーネント | 種別 | 説明 |
|---|---|---|
| `EstimateDetail` | `[R]` | メインページ。データ取得とアクションを統括。 |
| `EstimateStatusBadge` | `[C]` | ステータス別のバッジ表示。 |
| `EstimateLineItems` | `[C]` | 明細テーブルと金額計算サマリの表示部品。 |
| `ConfirmDialog` | `[S][M]` | 削除前の最終確認ダイアログ。 |

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/estimates/:id` | 見積詳細取得 | 実装済 |
| DELETE | `/api/v1/estimates/:id` | 見積削除 | 実装済 |
