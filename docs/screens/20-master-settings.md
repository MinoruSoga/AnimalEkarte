# マスタ管理 仕様書

## 概要
- **画面の目的**: 診療項目・ワクチン・薬剤・トリミングコース等のマスタデータ管理。在庫との連携も管理する。
- **URLパターン**: `/settings/master` またはサブルート `/settings/*`
- **アクセス権限**: 管理者権限（将来的なRBAC対応）

## 画面レイアウト
```
┌──────────────────────────────────────────────────────┐
│ 設定  > マスタ管理  [新規登録ボタン]                  │
├──────────────────────────────────────────────────────┤
│ カテゴリタブ:                                         │
│ [診察料] [ワクチン] [薬剤] [スタッフ]                │
│ [保険] [ケージ] [サービス種別]                       │
│ [トリミングコース] [トリミングオプション]             │
├──────────────────────────────────────────────────────┤
│ 🔍 [コード / 品名 検索]                              │
├──────────────────────────────────────────────────────┤
│ テーブル                                             │
│ コード | 名称 | 単価 | ステータス | 説明 | 在庫連携 | 操作 │
└──────────────────────────────────────────────────────┘
```

## 表示項目

| フィールド名 | 型 | 説明 | 備考 |
|------------|-----|------|------|
| コード | string | マスタ項目コード | `master_items.code` |
| 名称 | string | 項目名 | `master_items.name` |
| カテゴリ | enum | 診察料/ワクチン/薬剤等 | `master_items.category` |
| 単価 | decimal | 標準単価 | `master_items.price` |
| ステータス | enum | active/inactive | `master_items.status` |
| 説明 | text | 項目の説明・メモ | `master_items.description` |
| 在庫連携 | lookup | 連携する在庫品目 | `master_items.inventory_id` |
| デフォルト数量 | int | デフォルト使用数量 | `master_items.default_quantity` |

## UI コンポーネント
- **PageLayout**: ページコンテナ
- **Tabs**: カテゴリタブ（カテゴリ別に表示切替）
- **SearchFilterBar**: コード・名称のフリーワード検索
- **DataTable**: マスタ項目一覧テーブル
- **Dialog**: 登録・編集ダイアログ（インラインまたはモーダル）
- **Select**: カテゴリ・ステータス選択
- **Input**: コード・名称・単価入力
- **PrimaryButton**: 「新規登録」ボタン

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 新規登録 | 「新規登録」ボタン | 登録ダイアログ/フォーム表示 | ダイアログ |
| 編集 | 行クリックまたは操作ボタン | 編集ダイアログ/フォーム表示 | ダイアログ |
| 削除 | 削除ボタン | 確認後削除（使用中は不可） | 同画面 |
| カテゴリ切替 | タブクリック | カテゴリフィルター変更 | 同画面 |
| ステータス変更 | ステータストグル | active/inactive切替 | 同画面 |

## バリデーション
- **名称**: 必須
- **カテゴリ**: 必須
- **単価**: 0以上の数値
- **削除制限**: 既に予約・カルテ・入院等で使用されているマスタは削除不可（警告表示）
