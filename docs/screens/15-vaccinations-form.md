# 予防接種フォーム 仕様書

## 概要
予防接種の新規登録および編集は、カルテ画面（`/medical-records/:id`）内の「予防接種」タブとして実装されています。

- **コンポーネント**: `MedicalRecordVaccination`
- **アクセス権限**: 認証済ユーザー全員

## 画面構成（2カラム）
- **ヘッダー**: `PatientInfoCard` (ペット基本情報)、保存・キャンセル・削除ボタン
- **左カラム (VaccinationFormFields)** [3/5幅]:
  - 予防接種日 (`NotionDatePicker`) ＊必須
  - ワクチン選択 (`Select`) ＊必須
  - 補助説明 (`Input`)
  - LOT番号 1〜4（2列グリッド。UI上は4フィールド表示。4項目すべて保存可能）
  - 次回予定設定（`Select`: 3週後 / 4週後 / 1年後 / 以外（手動））
  - 次回予定日 (`NotionDatePicker`、3週後/4週後/1年後選択時は自動計算）
  - 備考テキストエリア
- **右カラム (HistorySection)** [2/5幅]:
  - 過去の予防接種履歴一覧（同一ペットの過去記録、`VaccinationCard` で表示）
  - `HistoryFilterPanel`（キーワード検索、期間フィルタ、昇降順ソート）

## 主な機能
- **次回予定日の自動計算**: 「3週後/4週後/1年後」を選択すると、接種日に基づいて `nextDate` が自動的にセットされる（`calculateNextDate` 関数）。「以外（手動）」選択時は日付ピッカーを手動入力。
- **履歴管理**: 同一ペットの過去の接種記録を右カラムで確認しながら入力が可能。全ワクチン一覧をクライアントサイドで `petId` フィルタして表示。

## 実装状況・制約
| 機能 | 状態 | 備考 |
|------|------|------|
| LOT番号 UI (1〜4) | ✅ 実装済 | UI表示のみ |
| LOT番号 API保存 | ⚠️ lot1のみ | lot2〜4のバックエンド対応が必要 |
| 次回予定自動計算 | ✅ 実装済 | 3週/4週/1年後に対応 |
| 履歴セクション（右カラム）| ✅ 実装済 | クライアントサイドフィルタ |

## API連携
| メソッド | エンドポイント | 用途 |
|---------|--------------|------|
| GET | `/api/v1/vaccinations/:id` | 予防接種詳細取得 |
| POST | `/api/v1/vaccinations` | 予防接種作成 |
| PATCH | `/api/v1/vaccinations/:id` | 予防接種更新 |
