# カルテ一覧 仕様書

## 概要
- **画面の目的**: 全ペットの診療記録（電子カルテ）を一覧表示・検索・管理する
- **URLパターン**: `/medical-records`
- **アクセス権限**: 認証済ユーザー全員

## 画面レイアウト
```
┌──────────────────────────────────────────────────────┐
│ カルテ管理  [新規カルテ作成ボタン]                    │
├──────────────────────────────────────────────────────┤
│ 🔍 [飼主名/ペット名/カルテNo/主訴で検索]  [件数表示] │
├──────────────────────────────────────────────────────┤
│ テーブル                                             │
│ カルテNo | 診療日 | 飼主名 | ペット名 | 種 |         │
│ 主訴 | 担当医 | ステータス | 操作                   │
└──────────────────────────────────────────────────────┘
```

## 表示項目

| フィールド名 | 型 | 説明 | 備考 |
|------------|-----|------|------|
| カルテNo | string | カルテ番号 | `medical_records.record_no` |
| 診療日 | datetime | 診察日時 | `medical_records.visit_date` |
| 飼主名 | string | 飼い主氏名 | `owners.name` |
| ペット名 | string | ペット名 | `pets.name` |
| 種 | string | 犬/猫等 | `pets.species` |
| 主訴 | string | 来院の主訴（省略表示） | `medical_records.chief_complaint` |
| 担当医 | string | 担当獣医師名 | `staffs.name` |
| ステータス | enum | 作成中/確定済 | `medical_records.status` |

## UI コンポーネント
- **PageLayout**: ページコンテナ
- **SearchFilterBar**: フリーワード検索（飼主名・ペット名・カルテNo・主訴）
- **DataTable**: テーブルコンテナ
- **DataTableRow**: クリックでカルテ詳細へ
- **StatusBadge**: ステータスバッジ（作成中=黄色、確定済=緑）
- **PrimaryButton**: 「新規カルテ作成」ボタン
- **RowActionButton**: 行の編集ボタン

## ステータスバッジ色定義

| ステータス | 色 |
|-----------|-----|
| 作成中 | 黄（amber） |
| 確定済 | 緑（green） |

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 新規カルテ作成 | 「新規カルテ作成」ボタン | ペット選択画面へ遷移 | `/medical-records/select-pet` |
| カルテ詳細/編集 | 行クリックまたは操作ボタン | カルテ詳細/編集フォームへ | `/medical-records/:id` |
| 検索 | テキスト入力 | 一覧をリアルタイムフィルタリング | 同画面 |

## 画面遷移

| 遷移元 | 遷移先 | 条件 |
|--------|--------|------|
| サイドバー | `/medical-records` | 常時 |
| 「新規カルテ作成」ボタン | `/medical-records/select-pet` | ボタンクリック |
| 行クリック | `/medical-records/:id` | 行クリック |
| ペット選択完了 | `/medical-records/new?petId=xxx` | ペット選択後 |

## バリデーション
- 検索はフリーワード（部分一致）、複数フィールドをOR検索
