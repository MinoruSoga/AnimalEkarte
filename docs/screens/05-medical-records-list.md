# カルテ一覧 仕様書 (Medical Records List)

![カルテ一覧画面](./images/05-medical-records-list.png)

## 概要
- **画面 of Purpose**: 院内で行われた全診療記録（電子カルテ）の時系列検索、および診察内容の参照。
- **URLパターン**: `/medical-records`
- **アクセス権限**: 認証済ユーザー全員（操作権限は `usePermission` で制御）

---

## 1. 画面構成

### 1.1 インテリジェント検索・フィルタ (`NotionFilter`)
- **全文検索**: 飼主名、ペット名、カルテNo、主訴、病名キーワードによる横断検索。
- **時系列フィルタ**: 診療実施期間での絞り込み。
- **属性フィルタ**: 担当医、動物種、作成ステータス（下書き/確定）による抽出。

### 1.2 診療履歴テーブル (`DataTable`)
| カラム | 説明 |
|:---|:---|
| **診療日時** | 診察が開始された時間。 |
| **患者・飼主** | 飼主名、ペット名、動物種。危険個体バッジ表示対応。 |
| **主訴 (CC)** | 来院理由の要約。 |
| **関連会計** | 会計レコードとの紐付け状況。未精算の場合はアイコンで強調。 |
| **担当医** | 診察を実施した獣医師。 |
| **ステータス** | **「作成中」**: 臨床内容の追記が可能。 / **「確定済」**: 内容がロックされた法的記録。 |

---

## 2. 主要な臨床連携フロー

- **診察室への誘導**: 受付画面（カンバン）で「診察中」へ移動した患者は、この一覧でも「作成中」として最上位に出現。
- **過去履歴の参照**: 診察中に同ペットの過去カルテをサイドパネルで開き、これまでの経過を確認しながら当日の記録を付けることが可能です。
- **会計への橋渡し**: カルテ内容の保存と同時に、自動的に会計ドラフトが作成・更新されます。

---

## 3. 技術仕様

### 3.1 信頼性と真正性
- **ステータス・ロック**: ステータスが `finalized` となった記録は、データベースレベルで通常の `UPDATE` が制限され、変更履歴（Audit）なしの改ざんを防止。

### 3.2 パフォーマンス
- **データローディング**: TanStack Query によるキャッシュ管理により、リストと詳細の往復を高速化。
- **無限スクロール / ページネーション**: 大量の履歴データ（数万件規模）でも、スムーズなスクロールを実現。

### API連携
| メソッド | エンドポイント | 用途 | 必須権限 | 必須アクション |
|:---|:---|:---|:---|:---|
| GET | `/api/v1/medical-records` | 条件に応じた診療記録の一括取得 | `medical-records` | `view` |
| DELETE | `/api/v1/medical-records/:id` | 誤作成カルテの論理削除 | `medical-records` | `delete` |
