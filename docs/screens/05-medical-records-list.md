# カルテ一覧 仕様書

![カルテ一覧画面](./images/05-medical-records-list.png)

## 概要
- **画面の目的**: 全ペットの診療記録（電子カルテ）を一覧表示・検索・管理する
- **URLパターン**: `/medical-records`
- **アクセス権限**: 認証済ユーザー全員

## 画面構成
- **ヘッダー**: タイトル（FileText アイコン）、新規作成ボタン
- **検索・フィルタ**: `NotionFilter`（飼主名・ペット名・カルテNo・主訴での検索、ソート機能）
- **データテーブル**: `DataTable` による一覧表示
- **ページネーション**: 20件/ページ

## 表示項目（テーブル）

| フィールド名 | 型 | 説明 | ソート | 備考 |
|------------|-----|------|--------|------|
| 診療日 | date | 診察日時（等幅フォント） | ○ | `r.date` |
| 飼主名 | string | 飼い主氏名 | ○ | `r.ownerName` |
| ペット名 | string | ペット名 | ○ | `r.petName` |
| 種 | string | 動物種 | ○ | `r.species` |
| 主訴 | string | 主訴（省略表示） | - | `r.chiefComplaint` |
| 関連 | link | 会計詳細へのリンク | - | `r.accountingId` がある場合に表示 |
| 担当医 | string | 担当獣医師名 | ○ | `r.doctor`。無効・非アクティブスタッフの場合は警告アイコン（`AlertTriangle`）を表示 |
| ステータス | enum | 作成中 / 確定済 | ○ | `r.status` |
| 操作 | - | 編集・削除 | - | `RowActionDropdown` |

## 主要機能
- **動的フィルタ**: 担当医および種のフィルター選択肢は、ロードされた全レコードから動的に生成される。
- **日付範囲検索**: `NotionFilter` の `date-range` を使用した診療日の期間絞り込みに対応。
- **URL同期ページネーション**: ページ番号を URL クエリパラメータ (`?page=N`) と同期し、ブラウザの「戻る」操作やブックマークに対応。
- **スタッフ有効性チェック**: `useStaffValidation` フックにより、マスタ上で非アクティブなスタッフが担当のレコードに対して警告アイコンを表示。
- **視覚的フィードバック**: `FilteringIndicator` により、非同期フィルタリング中の透過表示を行う。

## UI コンポーネント

| コンポーネント | 種別 | 説明 |
|---|---|---|
| `MedicalRecords` | `[R]` | メインページ |
| `NotionFilter` | `[S]` | 検索・フィルタ・ソートパネル |
| `DataTable` | `[S]` | データテーブル本体 |
| `StatusBadge` | `[S]` | ステータス表示バッジ |
| `RowActionDropdown` | `[S]` | 行アクション（編集・削除） |

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 新規作成 | 「新規作成」ボタン | ペット選択画面へ | `/medical-records/new` |
| 編集 | 行クリック or 「編集」 | カルテ編集フォームへ | `/medical-records/:id` |
| 削除 | 「削除」アクション | `ConfirmDialog` 後に論理削除 | 同画面 |
| 関連会計参照 | 関連列のアイコンクリック | 会計詳細画面へ | `/accounting/:billingId` |

## API連携
| メソッド | エンドポイント | 用途 |
|---------|--------------|------|
| GET | `/api/v1/medical-records` | カルテ一覧取得（page/per_page/search パラメータ対応） |
| DELETE | `/api/v1/medical-records/:id` | カルテ削除 |
