# 病院情報設定 仕様書

## 概要
- **画面の目的**: 動物病院の基本情報（病院名・住所・電話番号・院長名等）の設定・管理
- **URLパターン**: `/settings/clinic`
- **アクセス権限**: 管理者権限（将来的なRBAC対応）

## 画面レイアウト
```
┌──────────────────────────────────────────────────────┐
│ 設定  > 病院情報                                     │
├──────────────────────────────────────────────────────┤
│ ■ 病院基本情報                                       │
│  病院名 * | 院名                                     │
│  郵便番号 | 住所                                     │
│  電話番号 | FAX番号                                  │
│  登録番号 | 院長名                                   │
│  メールアドレス | Webサイト                          │
│  ロゴ画像                                            │
│                                                      │
│  [保存ボタン]                                        │
└──────────────────────────────────────────────────────┘
```

## 表示項目

| フィールド名 | 型 | 必須 | 説明 | DB列 |
|------------|-----|------|------|------|
| 病院名 | string | ✅ | 病院の正式名称 | `clinics.name` |
| 院名（サブネーム） | string | | 分院名等 | `clinics.branch_name` |
| 郵便番号 | string | | 〒xxx-xxxx形式 | `clinics.postal_code` |
| 住所 | text | | 所在地 | `clinics.address` |
| 電話番号 | string | | 代表電話番号 | `clinics.phone_number` |
| FAX番号 | string | | FAX番号 | `clinics.fax_number` |
| 登録番号 | string | | 獣医師会登録番号等 | `clinics.registration_number` |
| 院長名 | string | | 院長の氏名 | `clinics.director_name` |
| メールアドレス | string | | 代表メールアドレス | `clinics.email` |
| Webサイト | string | | 病院のWebサイトURL | `clinics.website` |
| ロゴ画像 | file | | 병院ロゴ（領収書等に使用） | `clinics.logo_url` |

## UI コンポーネント
- **Card + CardContent**: フォームコンテナ
- **Input**: テキスト入力フィールド
- **Textarea**: 住所入力
- **画像アップロード**: ロゴ画像設定（未実装）
- **PrimaryButton**: 保存ボタン

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 保存 | 「保存」ボタン | バリデーション → API保存 | 同画面（保存完了メッセージ） |

## バリデーション
- **病院名**: 必須、最大100文字
- **電話番号**: 形式チェック
