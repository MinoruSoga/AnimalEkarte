# 会計精算 仕様書

## 概要
- **画面の目的**: 会計明細の確認・編集、保険適用計算、支払処理、領収書/診療明細書の発行
- **URLパターン**:
  - 新規: `/accounting/new?petId=xxx`
  - 既存: `/accounting/:id`
- **アクセス権限**: 認証済ユーザー全員

## 左カラム：明細一覧

### 表示項目

| フィールド名 | 型 | 説明 | DB列 |
|------------|-----|------|------|
| 区分 | enum | 診察/処方/検査/フード/その他 | `accounting_items.category` |
| 項目名 | string | 診療項目名 | `accounting_items.name` |
| 単価 | decimal | 単価（税抜） | `accounting_items.unit_price` |
| 数量 | int | 数量 | `accounting_items.quantity` |
| 保険適用 | boolean | 保険対象かどうか | `accounting_items.is_insurance_applicable` |
| 金額 | calc | 単価×数量 | - |
| ソース | enum | カルテ連携/手動 | `accounting_items.source` |

### 区分バッジ

| 区分 | 表示名 |
|------|--------|
| `examination` | 診察 |
| `medicine` | 処方 |
| `test` | 検査 |
| `food` | フード |
| `goods` | 物販 |
| `other` | その他 |

### 手動追加（物販・その他）
- 区分（療法食・フード/物販・ケア用品/その他）
- 品目名（テキスト入力）
- 単価（数値入力）
- カルテ連携アイテムは削除不可、手動追加アイテムのみ削除可能

## 右カラム：支払い情報

### 金額計算ロジック

```
税抜小計 = Σ(単価 × 数量)
消費税 = Σ(単価 × 数量 × 税率) ※切り捨て
合計金額 = 税抜小計 + 消費税

保険負担額（保険ON時）= Σ(保険対象アイテム金額) × 負担割合 × (-1)

請求金額 = 合計金額 + 保険負担額 + 値引額

お釣り = 預かり金額 - 請求金額（預かり > 請求の場合のみ）
```

### 支払方法

| 方法 | 値 |
|------|-----|
| 現金 | `cash` |
| クレジットカード | `credit_card` |
| 電子マネー | `electronic_money` |

### 保険負担割合選択肢

| 表示 | 値 |
|------|-----|
| 50% | `0.5` |
| 70% | `0.7` |
| 90% | `0.9` |
| 100% | `1.0` |

## UI コンポーネント
- **PageLayout**: ページコンテナ（戻るボタン付き）
- **Card**: 明細カード、支払いカード
- **Table**: 明細テーブル
- **Dialog**: 明細追加ダイアログ、文書プレビューダイアログ
- **Switch**: 保険適用トグル
- **Select**: 保険負担割合、区分選択
- **Input**: お預かり金額入力
- **Button**: 支払方法選択ボタン（3択）、丁度/千円単位/万円単位ショートカット
- **AccountingDocument**: 領収書・診療明細書印刷コンポーネント

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 明細追加 | 「物販・その他追加」ボタン | 追加ダイアログ開く | ダイアログ |
| 明細削除 | 行の削除ボタン（手動追加のみ） | 明細削除 | 同画面 |
| 保険適用切替 | SwitchトグルON/OFF | 保険計算の有効/無効切替 | 同画面 |
| 負担割合変更 | ドロップダウン選択 | 保険負担額の再計算 | 同画面 |
| 支払方法選択 | 支払方法ボタン3択 | 支払方法の選択 | 同画面 |
| 預かり金入力 | テキスト入力 | お釣り自動計算 | 同画面 |
| 丁度/千円/万円 | ショートカットボタン | 請求額に応じた金額自動入力 | 同画面 |
| 会計確定 | 「会計を確定する」ボタン | 支払い情報保存→ステータス更新 | 同画面（確定済表示） |
| 領収書発行 | 「領収書発行」ボタン（確定済後） | 領収書プレビューダイアログ | ダイアログ |
| 診療明細書 | 「診療明細書」ボタン（確定済後） | 明細書プレビューダイアログ | ダイアログ |
| 印刷 | ダイアログ「印刷する」ボタン | ブラウザ印刷ダイアログ | - |
| 戻る | 「戻る」ボタン | 会計一覧へ | `/accounting` |

## バリデーション
- **会計確定ボタン**: お預かり金額が請求金額以上の場合のみ有効化
- **会計確定後**: 再確定不可（ボタン無効化）
