# 飼主・ペット登録/編集 仕様書

## 概要
- **画面の目的**: 飼い主情報とペット情報の登録・編集
- **URLパターン**:
  - 新規登録: `/owners/new`
  - 編集: `/owners/:id`
- **アクセス権限**: 認証済ユーザー全員

## 表示項目（飼い主）

| フィールド名 | 型 | 必須 | 説明 | 備考 |
|------------|-----|------|------|------|
| 氏名 | string | ✅ | 飼い主の氏名 | `owners.name` |
| 氏名カナ | string | ✅ | 氏名のフリガナ | `owners.name_kana` |
| 電話番号 | string | ✅ | 連絡先電話番号 | `owners.phone` |
| メールアドレス | string | | メールアドレス | `owners.email` |
| 住所 | string | | 住所 | `owners.address` |
| 備考 | text | | メモ | `owners.notes` |

| フィールド名 | 型 | 必須 | 説明 | 備考 |

## UI コンポーネント
- **PageLayout**: ページコンテナ（戻るボタン付き）
- **Card + CardContent**: セクションコンテナ（飼い主情報/ペット情報）
- **Input**: テキスト入力フィールド
- **Select**: 種・性別・ステータスのドロップダウン
- **DatePicker**: 生年月日選択
- **Textarea**: 備考・保険詳細等
- **PrimaryButton**: 保存ボタン
- **画像アップロード**: ペットアイコン（未実装）

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 保存 | 「保存」ボタン | バリデーション → API呼び出し → 一覧へ | `/owners` |
| キャンセル/戻る | 「戻る」ボタン | 一覧画面へ戻る | `/owners` |
| 予約作成 | 「予約作成」ボタン（編集画面のみ） | ペットIDを付与して予約管理へ | `/reservations?petId=xxx` |
| カルテ参照 | 「カルテ」ボタン（編集画面のみ） | ペットのカルテ一覧へ | `/medical-records?petId=xxx` |

## 画面遷移

| 遷移元 | 遷移先 | 条件 |
|--------|--------|------|
| 飼主一覧 | `/owners/new` | 新規登録ボタン |
| 飼主一覧 | `/owners/:id` | 行クリック |
| 保存成功 | `/owners` | 保存完了後 |

## バリデーション
- **氏名**: 必須、最大100文字
- **氏名カナ**: 必須、カタカナのみ推奨
- **電話番号**: 必須、形式チェック（ハイフンあり/なし両対応）
- **ペット名**: 必須、最大100文字
- **種**: 必須
- **性別**: 必須
