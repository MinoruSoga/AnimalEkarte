# ログイン 仕様書

![ログイン画面](./images/21-login.png)

## 概要
- **画面の目的**: ユーザーがシステムを利用するための認証を行う。
- **URLパターン**: `/login`
- **アクセス権限**: 未ログインユーザー

## 画面構成
- 中央に配置されたログインフォーム（Notion風のクリーンなデザイン）
- メールアドレス入力、パスワード入力、ログインボタン

## 表示・フォーム項目
| フィールド | 項目ID | 入力部品 | 必須 | 備考 |
|-----------|--------|---------|------|------|
| メールアドレス| `email` | `Input(email)` | ✅ | |
| パスワード | `password` | `Input(password)`| ✅ | 右端のアイコンボタンで表示/非表示を切り替え可能 |

## 機能詳細

### 1. 認証とセッション管理
- **React 19 アクション**: `useActionState` を使用した非同期ログイン処理。
- **リダイレクト**: ログイン済みユーザーがアクセスした場合は `/` へ自動遷移。未ログイン時はオープンリダイレクト対策済みの `from` パラメータ（または `location.state`）に基づき、元のページへ戻る。

### 2. パスワード再設定フロー (現状)
- **制限事項**: **バックエンド API が未実装**のため、フロントエンドの画面遷移のみ存在する「開発中」のステータスです。
- **遷移先**: `/forgot-password`（メールアドレス入力）→ `/reset-password`（新パスワード入力）。

### 3. セキュリティ・UX
- **エラーメッセージ**: HTTPステータスコードに基づき、「メールアドレスまたはパスワードが違います」「アクセスが制限されています」等の具体的な理由をユーザーにフィードバック（BUG-047）。
- **パスワード表示**: `Eye` / `EyeOff` アイコンによりマスク解除が可能。

### 4. デモアカウント機能（開発環境のみ）
- **クイックログイン**: `import.meta.env.DEV` が真の場合のみ、主要なロール（システム管理者、各医院の獣医師、看護師、トリマー）のリストが表示される。
- **自動入力**: デモアカウントを選択すると、メールアドレスと共通パスワード（`password`）がフォームにセットされる。

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| POST | `/api/v1/auth/login` | 認証実行 | 実装済 |
| POST | `/api/v1/auth/forgot-password` | 再設定用メール送信 | **未実装** |
| POST | `/api/v1/auth/reset-password` | 新しいパスワードの保存 | **未実装** |
