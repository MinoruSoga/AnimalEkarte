# 入院登録/編集 仕様書

## 概要
- **画面の目的**: 入院・ペットホテルの新規登録および既存データの編集
- **URLパターン**:
  - 新規登録: `/hospitalization/new?petId=xxx`
  - 編集: `/hospitalization/:id/edit`
- **アクセス権限**: 認証済ユーザー全員

## 画面レイアウト
```
┌──────────────────────────────────────────────────────┐
│ ← 戻る  入院登録/編集  [保存ボタン]                  │
├──────────────────────────────────────────────────────┤
│                                                      │
│ ■ 患者情報（ペット選択または表示）                    │
│                                                      │
│ ■ 入院情報                                           │
│  入院種別 * | ケージ選択 *                           │
│  入院開始日 * | 退院予定日                           │
│  ステータス * |                                      │
│                                                      │
│ ■ 飼い主要望・備考                                   │
│  飼い主要望 | スタッフメモ | 備考                    │
│                                                      │
└──────────────────────────────────────────────────────┘
```

## 表示項目

| フィールド名 | 型 | 必須 | 説明 | DB列 |
|------------|-----|------|------|------|
| ペット（選択） | lookup | ✅ | petIdからペット・飼主情報を表示 | `pets.id` |
| 入院種別 | enum | ✅ | 入院/ホテル | `hospitalizations.type` |
| ケージ | lookup | ✅ | 利用可能ケージから選択 | `cages.id` |
| 入院開始日 | date | ✅ | 入院開始日 | `hospitalizations.start_date` |
| 退院予定日 | date | | 退院予定日 | `hospitalizations.end_date` |
| ステータス | enum | ✅ | 予約/入院中/一時帰宅/退院済 | `hospitalizations.status` |
| 飼い主要望 | text | | 飼い主からの要望・特記事項 | `hospitalizations.owner_request` |
| スタッフメモ | text | | スタッフ向けの内部メモ | `hospitalizations.staff_notes` |
| 備考 | text | | その他備考 | `hospitalizations.memo` |

## UI コンポーネント
- **PageLayout**: ページコンテナ（戻るボタン付き）
- **Card + CardContent**: セクションコンテナ
- **Select**: 入院種別・ステータス・ケージ選択
- **DatePicker**: 入院開始日・退院予定日
- **Textarea**: 飼い主要望・スタッフメモ・備考
- **PrimaryButton**: 保存ボタン

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 保存 | 「保存」ボタン | バリデーション → API呼び出し → 詳細画面へ | `/hospitalization/:id` |
| キャンセル/戻る | 「戻る」ボタン | 一覧または詳細へ | `/hospitalization` |

## 画面遷移

| 遷移元 | 遷移先 | 条件 |
|--------|--------|------|
| ペット選択 | `/hospitalization/new?petId=xxx` | ペット選択後 |
| 入院詳細「編集」 | `/hospitalization/:id/edit` | ボタンクリック |
| 保存成功 | `/hospitalization/:id` | 保存完了後 |

## バリデーション
- **入院種別**: 必須
- **ケージ**: 必須（利用可能ケージのみ選択可）
- **入院開始日**: 必須
- **ステータス**: 必須、デフォルト「予約」
