# 検査一覧 仕様書

## 概要
- **画面の目的**: 検査オーダー・結果の一覧管理。
- **URLパターン**: `/examinations`
- **アクセス権限**: 認証済ユーザー全員

## 画面構成
- **ヘッダー**: タイトル、検査データ取込ボタン、新規検査登録ボタン
- **検索・フィルタ**: `NotionFilter`（日時、ステータス、キーワード検索、ソート）
- **データテーブル**: `DataTable` による一覧表示
- **ページネーション**: 標準ページネーション

## 表示項目（テーブル）

| フィールド名 | 型 | 説明 | ソート | 備考 |
|------------|-----|------|--------|------|
| 日時 | date | 検査実施日時 | ○ | `date` |
| 飼主名 | string | 飼い主氏名 | ○ | `ownerName` |
| ペット名 | string | ペット名 | ○ | `petName` |
| 検査種別 | string | 検査の種類 | ○ | `testType` |
| 結果概要 | string | 結果のテキストサマリ | - | `resultSummary` |
| 担当医 | string | 担当獣医師名 | ○ | `doctor` |
| ステータス | enum | 依頼中 / 検査中 / 完了 | ○ | `status` |
| 操作 | - | 詳細（カルテへ遷移） | - | `RowActionButton` |

## ユーザーアクション
- **新規検査登録**: ペット選択画面を経てカルテの検査タブへ遷移。
- **詳細表示**: 行クリックまたは操作ボタンからカルテの検査タブへ遷移。
- **フィルタ・ソート**: `NotionFilter` を使用した動的な一覧更新。

## API連携
| メソッド | エンドポイント | 用途 |
|---------|--------------|------|
| GET | `/api/v1/examinations` | 検査一覧取得 |
| DELETE | `/api/v1/examinations/:id` | 検査削除 |
