# 検査一覧 仕様書

## 概要
- **画面の目的**: 院内・院外検査のオーダーと結果を一覧管理する
- **URLパターン**: `/examinations`
- **アクセス権限**: 認証済ユーザー全員

## 画面レイアウト
```
┌──────────────────────────────────────────────────────┐
│ 検査管理  [新規検査登録ボタン]                        │
├──────────────────────────────────────────────────────┤
│ タブ: [依頼中] [検査中] [完了] [すべて]              │
├──────────────────────────────────────────────────────┤
│ 🔍 [飼主名 / ペット名 / 検査種別 検索]               │
├──────────────────────────────────────────────────────┤
│ テーブル                                             │
│ 検査日 | 飼主名 | ペット名 | 検査種別 | 依頼医 |     │
│ ステータス | 操作                                    │
└──────────────────────────────────────────────────────┘
```

## 表示項目

| フィールド名 | 型 | 説明 | 備考 |
|------------|-----|------|------|
| 検査日時 | datetime | 検査実施日時 | `examinations.examination_date` |
| 飼主名 | string | 飼い主氏名 | `owners.name` |
| ペット名 | string | ペット名 | `pets.name` |
| 種 | string | 動物種 | `pets.species` |
| 検査種別 | string | 検査の種類 | `examinations.test_type` |
| 使用機器 | string | 使用した機器・外注先 | `examinations.machine` |
| 依頼医 | string | 依頼した獣医師名 | `staffs.name` |
| ステータス | enum | 依頼中/検査中/完了 | `examinations.status` |

## フィルタータブ

| タブ名 | フィルター条件 |
|--------|--------------|
| 依頼中 | status = `依頼中` |
| 検査中 | status = `検査中` |
| 完了 | status = `完了` |
| すべて | フィルターなし |

## ステータスバッジ色

| ステータス | 色 |
|-----------|-----|
| 依頼中 | 青（blue） |
| 検査中 | 黄（amber） |
| 完了 | 緑（green） |

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 新規検査登録 | 「新規検査登録」ボタン | ペット選択画面へ | `/examinations/select-pet` |
| 詳細/編集 | 行クリック or 操作ボタン | 検査フォームへ | `/examinations/:id` |
| タブ切替 | タブクリック | ステータスフィルター変更 | 同画面 |
| 検索 | テキスト入力 | 一覧フィルタリング | 同画面 |
