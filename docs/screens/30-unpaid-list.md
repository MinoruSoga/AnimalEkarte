# 未納者一覧（売掛管理） 仕様書

## 概要
- **画面の目的**: 月末締めの売掛金把握や未精算会計の管理。基準日時点で支払が完了していない会計を、飼主単位または会計単位で集計・表示する。
- **URLパターン**: `/accounting/unpaid`
- **コンポーネント**: `UnpaidCustomerList`
- **アクセス権限**: 認証済ユーザー全員（操作は経理・管理者推奨）

## 画面構成
- **ヘッダー**: タイトル「未納者一覧」、説明文、戻るボタン（`/accounting` へ）。
- **ツールバー**:
  - **基準日**: カレンダー入力。指定した日付時点で未納のものを抽出。デフォルトは当日。
  - **表示単位切替**: 「飼主単位」と「会計単位」をトグルボタンで切り替え。
- **サマリーカード**:
  - **売掛金総額**: 抽出されたデータの税込合計金額。
  - **件数 / 人数**: 合計会計件数と該当する飼主数。
- **データテーブル**: 表示単位に応じてカラムが変化。

## 表示項目

### 1. 飼主単位表示
| フィールド名 | 説明 | 備考 |
|------------|------|------|
| 飼主名 | 飼主氏名 | クリックで飼主詳細へ遷移 |
| 件数 | 未納会計の件数 | |
| 未納額合計 | 対象飼主の未納額累計 | 右寄せ・通貨形式 |
| 最古未納日 | 最も古い未納会計の日付 | |
| 最新未納日 | 最も新しい未納会計の日付 | |
| 経過日数 | 基準日から最古未納日までの日数 | |

### 2. 会計単位表示
| フィールド名 | 説明 | 備考 |
|------------|------|------|
| 飼主名 | 飼主氏名 | |
| ペット名 | 対象ペット名 | |
| 診療日 | 会計予定日 | クリックで会計詳細へ遷移 |
| 未納額 | 該当会計の請求残額 | 右寄せ・通貨形式 |
| 経過日数 | 基準日から診療日までの日数 | |

## 主要機能
- **動的フィルタリング**: 基準日や表示単位の変更は URL パラメータ（`reference_date`, `group_by`）と同期し、再ロード後も維持される。
- **ページネーション**: 20件/ページ。

## API連携
| メソッド | エンドポイント | 用途 |
|---------|--------------|------|
| GET | `/api/v1/accountings/unpaid?base_date=YYYY-MM-DD&group_by=owner` | 飼主単位での未納集計取得 |
| GET | `/api/v1/accountings/unpaid?base_date=YYYY-MM-DD&group_by=billing` | 会計単位での未納一覧取得 |
