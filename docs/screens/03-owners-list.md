# 飼主・ペット一覧 仕様書

## 概要
- **画面の目的**: 登録されている飼い主とそのペットの一覧表示・検索・管理
- **URLパターン**: `/owners`
- **アクセス権限**: 認証済ユーザー全員

│ 🔍 [飼主名、ペット名、飼主No、種別... 検索]  [N件]   │

## 機能詳細

### 1. 高速な絞り込み（Deferred Search）
- **パフォーマンス最適化**: `useDeferredValue` を使用し、検索入力中の頻繁な再レンダリングを抑制。大量のデータ（ペットリスト）に対しても軽快な検索体験を提供する。
- **検索対象**: 飼主名、ペット名、飼主No、種別の各フィールドを横断的に検索する。

### 2. テーブル制御
- **ソート機能**: `useTableSort` フックにより、各ヘッダーをクリックすることで昇順/降順の並び替えが可能。初期状態は「飼主No」の降順。
- **ページネーション**: 1ページあたり20件を表示。

### 3. データ連携
- **飼主削除の伝播**: 飼主を削除した場合、その飼主に紐づくすべてのペット情報もバックエンドで論理削除（`deleted_at` 更新）される。

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 新規登録 | 「新規登録」ボタン | 新規作成フォームへ遷移 | `/owners/new` |
| 詳細/編集 | 行クリック or 操作ドロップダウン「編集」 | 編集フォームへ遷移（`ownerId` 使用） | `/owners/:ownerId` |
| 削除 | 操作ドロップダウン「削除」 | `ConfirmDialog` 表示後に削除 | 同画面 |
| 検索 | テキスト入力 | 一覧をリアルタイムフィルタリング | 同画面 |
| ソート | カラムヘッダークリック | 昇順/降順ソート切替 | 同画面 |
| ページ移動 | ページネーション操作 | 前後ページへ移動 | 同画面 |

## 画面遷移

|--------|--------|------|
| サイドバー | `/owners` | 常時 |

## バリデーション
- 検索はフリーワード（部分一致）、複数フィールドをOR検索（飼主名・ペット名・飼主No・種別）
- 削除時: 「関連するカルテ・会計データも影響を受ける可能性があります」の警告文を表示

## 状態管理

| 状態 | 型 | 説明 |
|------|-----|------|
| `searchTerm` | `string` | 検索キーワード |
| `deleteTarget` | `{ id: string; label: string } \| null` | 削除対象（`ConfirmDialog` 用） |
| `sortedData` | `Pet[]` | ソート済みペットデータ（`useTableSort`） |
| `paginatedData` | `Pet[]` | ページネーション済みデータ（`usePagination`） |

## ソートキー
`ownerId` / `ownerName` / `name` / `species` / `birthDate` / `lastVisit`

## API連携

| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/pets` | ペット一覧取得（検索パラメータ・飼主情報Preload含む） | 実装済 |
| DELETE | `/api/v1/owners/:id` | 飼主削除（関連ペット含む） | 実装済 |

## 備考
- テーブルはペット単位で表示（1ペット＝1行）。飼主が複数ペットを持つ場合は複数行に展開される
- 旧仕様では「患者番号・電話番号」検索だったが、現在は「飼主名・ペット名・飼主No・種別」検索に変更
- 旧仕様では「年齢・電話番号・最終来院日・ステータス」表示だったが、現在は「体重・環境・前回来院・生死（StatusBadge）」表示に変更
