# 飼主・ペット一覧 仕様書

## 概要
- **画面の目的**: 登録されている飼い主とそのペットの一覧表示・検索・管理
- **URLパターン**: `/owners`
- **アクセス権限**: 認証済ユーザー全員

## 画面レイアウト
```
┌──────────────────────────────────────────────────────┐
│ 飼主・ペット管理  [新規登録ボタン]                    │
├──────────────────────────────────────────────────────┤
│ 🔍 [飼主名 / ペット名 / 患者番号 / 電話番号 検索]   │
├──────────────────────────────────────────────────────┤
│ テーブル                                             │
│ 患者番号 | ペット名 | 種/品種 | 年齢 | 飼主名 |      │
│ 電話番号 | 最終来院日 | ステータス | 操作            │
└──────────────────────────────────────────────────────┘
```

## 表示項目

| フィールド名 | 型 | 説明 | 備考 |
|------------|-----|------|------|
| 患者番号 | string | ペットの患者番号 | `pets.pet_number` |
| ペット名 | string | ペットの名前 | `pets.name` |
| 種 | string | 犬/猫等 | `pets.species` |
| 品種 | string | 品種名 | `pets.breed` |
| 年齢 | calc | 生年月日から計算 | `pets.birth_date` |
| 飼主名 | string | 飼い主氏名 | `owners.name` |
| 電話番号 | string | 飼い主の電話番号 | `owners.phone` |
| 最終来院日 | date | 最後に来院した日付 | `pets.last_visit` |
| ステータス | enum | 生存/死亡 | `pets.status` |

## UI コンポーネント
- **SearchFilterBar**: 飼主名・ペット名・患者番号・電話番号のリアルタイム検索
- **DataTable**: ソート・ページネーション付きテーブル
- **DataTableRow**: クリックで詳細/編集画面へ遷移
- **PrimaryButton**: 「新規登録」ボタン
- **StatusBadge**: 生存/死亡ステータスバッジ
- **RowActionButton**: 行ごとの編集アクション

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 新規登録 | 「新規登録」ボタン | 新規作成フォームへ遷移 | `/owners/new` |
| 詳細/編集 | 行クリック or 操作ボタン | 編集フォームへ遷移 | `/owners/:id` |
| 検索 | テキスト入力 | 一覧をリアルタイムフィルタリング | 同画面 |

## 画面遷移

| 遷移元 | 遷移先 | 条件 |
|--------|--------|------|
| サイドバー | `/owners` | 常時 |
| 行クリック | `/owners/:id` | ペット選択後 |
| 新規登録ボタン | `/owners/new` | ボタンクリック |

## バリデーション
- 検索はフリーワード（部分一致）、複数フィールドをOR検索
