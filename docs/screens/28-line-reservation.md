# LINE予約設定 仕様書

![LINE予約設定画面](./images/28-line-reservation-settings.png)
![ページ編集画面](./images/28-line-reservation-editor.png)

## 概要
- **画面の目的**: LINE公式アカウント経由の予約受付に関する各種設定、および予約ページの表示内容を管理する。
- **URLパターン**:
  - 基本設定: `/line-reservation/settings`
  - ページ編集: `/line-reservation/page-editor`
- **アクセス権限**: 認証済ユーザー全員（要 clinic 権限）

## 1. 基本設定 (`/line-reservation/settings`)

LINE予約システムの稼働状態、営業時間、定休日、予約枠のルールを詳細に設定します。

### 画面構成
- **稼働状態**: 予約受付の開始/停止を切り替えるスイッチ。
- **営業時間・定休日**: 
  - 定休曜日の選択（月〜日、複数選択可）。
  - 祝日休診の有無。
  - 特定定休日（特定の日付を休診日として追加）。
  - 通常営業時間（開始・終了時刻）。
  - 曜日別営業時間（特定の曜日のみ異なる営業時間を設定可能）。
  - 休憩時間（複数時間帯の設定が可能）。
- **予約枠設定**:
  - 最短/最長予約受付期間（何日前から何日前まで予約可能か）。
  - 表示カレンダー月数（最大6ヶ月）。
  - タイムスロットモード（空き時間を最小化 / 空き時間を許容）。
  - スロット間隔（5分単位）。
  - スタッフ不在モード（最初の空き / 優先度最上位）。
- **連絡先・通知**:
  - 表示用電話番号。
  - 通知用メールアドレス。
- **LINE連携設定**:
  - チャネルID、LIFF ID の設定。

## 2. ページ編集 (`/line-reservation/page-editor`)

LINE予約ページの各セクションに表示されるテキストコンテンツを編集します。

### 編集項目
| フィールド | 内容 |
|-----------|------|
| ヘッダーテキスト | 予約ページの最上部に表示される挨拶や説明文。 |
| 予約時の注意事項 | 予約確定前にユーザーに確認してもらう重要事項。 |
| キャンセル時の注意事項 | キャンセルポリシーや連絡方法など。 |
| プライバシーポリシー | 個人情報の取り扱いに関する記述。 |
| リクエスト例 | 自由入力欄への記入例を提示し、ユーザーの入力をサポート。 |

## UI コンポーネント
| コンポーネント | 種別 | 説明 |
|---|---|---|
| `LineReservationSettings` | `[R]` | 基本設定メインページ |
| `LineReservationPageEditor` | `[R]` | ページ編集メインページ |
| `WeekdayHoursEditor` | `[C]` | 曜日別の営業時間を入力するグリッド |
| `BreakHoursEditor` | `[C]` | 休憩時間を動的に追加・削除するエディタ |
| `ClosedDatesEditor` | `[C]` | 特定の休診日（日付）を管理するエディタ |

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/clinics/:id/line-reservation-setting` | 設定情報の取得 | 実装済 |
| PATCH | `/api/v1/clinics/:id/line-reservation-setting` | 設定情報の更新 | 実装済 |

## 特記事項
- **JSONB フィールドの扱い**: 営業時間や定休日などの複雑なデータ構造は、DB上で JSONB 形式で保存されており、フロントエンドでは適切なオブジェクト/配列としてパースして管理されます。
- **即時反映**: 設定を保存すると、LINE上の予約ページに即座に反映されます。
