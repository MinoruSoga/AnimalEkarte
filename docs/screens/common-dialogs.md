# 共通ダイアログ・高度コンポーネント 仕様書

本ドキュメントでは、複数の画面から呼び出される複雑な業務ロジックを持つ共通UIコンポーネントを定義します。

---

## 1. 診療項目検索ダイアログ（`TreatmentSearchDialog`）

### 概要
マスタから「診察・検査・処置・予防・入院・薬剤」を検索し、各画面の明細テーブルに追加するための共通検索UI。

### 採用テクノロジー
- `CommandDialog` (cmdk) ベースのインクリメンタル検索。

### UI構成
- **検索入力**: コードまたは名称（部分一致）で検索。
- **カテゴリフィルタ**: `Badge` 形式のボタンで特定カテゴリ（診察/予防 等）に絞り込み。
- **結果リスト**: 名称、コード、単価（税込）を表示。

### 項目定義
| 項目 | 型 | 説明 |
|------|-----|------|
| id | uuid | マスタアイテムID |
| code | string | 項目コード |
| name | string | 項目名称 |
| unitPrice| number | マスタ単価（税込） |
| category | string | 診療カテゴリ |

## 2. 飼主情報クイックビュー（`OwnerQuickViewModal`）

### 概要
ペット名や飼主名をクリックした際に、画面遷移することなく飼主の連絡先や住所を確認できる参照専用モーダル。

### 表示項目
- 飼主名、フリガナ
- 電話番号（自宅/会社）
- 住所（自宅/会社）
- 危険人物フラグ、備考

---

## 3. 入院日数自動調整（`StayDaysAdjustDialog`）

### 概要
入院期間（終了日）が変更された際に、治療プランにある「入院基本料」等の数量を、変更後の日数に一括更新するかをユーザーに確認する。

### ロジック
- 変更前の「入院日数」と「明細数量」が一致する項目を自動抽出。
- ユーザーが承認した場合のみ、該当項目の数量を新しい日数で上書きする。
