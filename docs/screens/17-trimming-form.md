# トリミング登録/編集 仕様書

## 概要
- **画面の目的**: トリミング施術記録の新規登録・編集。
- **URLパターン**:
  - 新規: `/trimming/new?petId=xxx`
  - 編集: `/trimming/:id`
- **アクセス権限**: 認証済ユーザー全員

## 画面構成（3カラム）
- **ヘッダー**: `PatientInfoCard` (ペット・担当スタッフ情報)、保存・削除ボタン
- **左カラム (施術基本)**:
  - コース選択 (`MasterSelectModal`)
  - スタイルの希望テキスト
  - メモ（スタッフ内部メモ、見積明細には表示されない）
  - オプション（チェックボックス形式。マスタ連携）
  - 希望スタイル画像アップロード
- **中カラム (身体情報・詳細)**:
  - 体重 (BW)、体温 (BT)
  - 使用シャンプー、使用リボン
  - 備考テキスト
  - 完成画像アップロード
- **右カラム (施術履歴)**:
  - 過去のトリミング履歴一覧
  - `HistoryFilterPanel`（キーワード検索、期間フィルタ、昇降順ソート）
  - 履歴からの「引用（コピー）」機能

## 主要機能
- **React 19 アクション**: `useActionState` を使用した記録の保存。バリデーションエラー時には、担当スタッフ（`staffId`）やコース（`courseId`）などの入力欄へ自動でスクロール・フォーカスするアクセシビリティ対応。
- **臨床安全ガード**: `PatientInfoCard` での死亡ステータス強調。死亡済みのペットに対する新規登録や重要アクションには制限がかかる。
- **履歴引用**: 過去のスタイル希望や担当スタッフ情報を、ワンクリックで現在のフォームへ反映可能（`HistoryFilterPanel` 連携）。
- **マスタ連携**: コース・担当スタッフは `MasterSelectModal` で選択。オプションはマスタから取得したチェックボックス形式で提供。
- **離脱防止**: `NavigationBlocker`（`unstable_useBlocker`）により、未保存時の意図しない画面遷移を警告。

## API連携
| メソッド | エンドポイント | 用途 |
|---------|--------------|------|
| GET | `/api/v1/trimmings/:id` | トリミング詳細取得 |
| POST | `/api/v1/trimmings` | トリミング作成 |
| PATCH | `/api/v1/trimmings/:id` | トリミング更新 |
| GET | `/api/v1/pets/:petId/trimmings` | ペット別過去履歴取得 |
| GET | `/api/v1/masters/trimming-courses` | コースマスタ取得 |
| GET | `/api/v1/masters/trimming-options` | オプションマスタ取得 |
