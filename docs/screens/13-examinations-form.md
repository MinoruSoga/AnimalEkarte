# 検査入力/結果登録 仕様書

## 概要

**検査の新規登録・編集・結果入力は、専用の独立した画面ではなく、カルテ入力画面（`/medical-records/:id`）内の「検査」タブ（Tab 5）として実装されている。**

- **URLパターン**: `/medical-records/:id`（state: `{ activeTab: "検査" }`）
- **コンポーネント**: `[C] MedicalRecordExamination`（カルテの Tab 5）
- **アクセス権限**: 認証済ユーザー全員

## 遷移フロー

```
検査一覧画面 → 行クリック → /medical-records/:medicalRecordId（activeTab: "検査"）
カルテ画面 → Tab 5「検査」選択
ダッシュボード → 診療中カードの「検査」ボタン → カルテ検査タブへ
```

## カルテ内「検査」タブのレイアウト

```

│                               [検査] ...              │
├──────────────────────────────────────────────────────┤
│ Tab 5: 検査（2カラムレイアウト lg:6+6）              │

│ 左カラム: ExaminationForm        右カラム: ExaminationHistory │
```

## 左カラム: `ExaminationForm` フォーム項目

| フィールド | 入力部品 | 必須 | 備考 |
|---|---|---|---|
| 検査種別 | `MasterSelectModal`（examination マスタ連動） | ✅ | FlaskConical アイコン、`MasterLink`付き |
| 担当医 | `Select`（staff マスタ連動、active のみ） | ✅ | `MasterLink`付き |
| 検査項目テーブル | `Table`（マスタ連動で自動生成） | - | 列: 項目名、測定値（Input）、単位、基準値 |
| 備考・所見 | `Textarea` | - | |

### アクション

| ボタン | 動作 |
|--------|------|
| 結果を登録 | 検査結果を保存 |
| クリア | 入力内容をリセット |

## 右カラム: `ExaminationHistory`（検査結果履歴）

- 過去の検査結果を一覧表示
- 検査結果セクション: 日付別画像グループ（`ImageGalleryGroup`）でファイル管理

## 検査マスタ連携

検査種別選択時（`MasterSelectModal` - examination マスタ）:
- 選択した検査種別に紐づく検査項目が自動的にテーブルに生成される
- 各行に: 項目名（読み取り専用）、測定値（`Input`）、単位（読み取り専用）、基準値（読み取り専用）

## 検査データのDB項目

| フィールド名 | 型 | 必須 | 説明 | DB列 |
|------------|-----|------|------|------|
| 検査種別 | string | ✅ | 検査の種類（マスタ連動） | `examination_type_items.name` |
| 担当医 | lookup | ✅ | 担当獣医師 | `staffs.id` |
| 検査日時 | datetime | ✅ | 検査実施日時 | `exams.examination_date` |
| 検査項目 | json | | 各検査項目の測定値 | `exams.items` |
| 結果サマリー | textarea | | 検査結果の概要 | `exams.result_summary` |
| 備考 | textarea | | その他メモ | `exams.notes` |
| ステータス | enum | ✅ | 依頼中/検査中/完了 | `exams.status` |
| 関連カルテ | lookup | ✅ | カルテとの紐付け | `medical_records.id` |

## ステータス値

| 表示名 | 値 |
|--------|-----|
| 依頼中 | `pending` |
| 検査中 | `in_progress` |
| 完了 | `completed` |

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 検査種別選択 | `MasterSelectModal` | 検査項目テーブルを自動生成 | 同タブ |
| 担当医選択 | `Select` | 担当医を設定 | 同タブ |
| 測定値入力 | テーブル各行 `Input` | 測定値を入力 | 同タブ |
| 結果を登録 | 「結果を登録」ボタン | バリデーション → API保存 | 同タブ（履歴に追加） |
| クリア | 「クリア」ボタン | 入力内容リセット | 同タブ |
| カルテへ戻る | タブ切替または戻るボタン | カルテの別タブへ遷移 | カルテ同画面 |
| 検査一覧へ | 戻るボタン（from="/examinations"の場合） | 検査一覧へ | `/examinations` |

## 画面遷移

| 遷移元 | 遷移先 | 条件 |
|--------|--------|------|
| 検査一覧 | `/medical-records/:id`（state: `{ activeTab: "検査", from: "/examinations" }`） | 行クリック |
| カルテのタブ | 同一URL内でタブ切替 | タブ「検査」クリック |
| ダッシュボード | `/medical-records/:id`（state: `{ activeTab: "検査" }`） | 「検査」ボタン |

## 備考

- 検査専用の独立したページルートは存在しない
- 新規検査登録の導線: カルテ一覧/ダッシュボードからカルテを開き、「検査」タブを選択
- 検査データはカルテ（`medical_records`）と1対多で紐付く
- 検査一覧画面（`/examinations`）はカルテの検査タブへのビューポータルとして機能する
