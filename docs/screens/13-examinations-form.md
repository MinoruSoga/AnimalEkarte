# 検査登録/編集 仕様書

## 概要
- **画面の目的**: 検査オーダーの作成・結果の入力・編集
- **URLパターン**:
  - 新規: `/examinations/new?petId=xxx`
  - 編集: `/examinations/:id`
- **アクセス権限**: 認証済ユーザー全員

## 画面レイアウト
```
┌──────────────────────────────────────────────────────┐
│ ← 戻る  検査登録/編集  [保存ボタン]                  │
├──────────────────────────────────────────────────────┤
│ ■ 患者情報（ペット情報表示）                          │
│ ■ 検査情報                                           │
│  検査日時 * | 検査種別 * | 使用機器                  │
│  依頼医 * | 関連カルテ（選択）                       │
│  ステータス *                                        │
│ ■ 検査結果                                           │
│  結果サマリー | 検査項目詳細（JSON）                  │
│ ■ 備考                                               │
└──────────────────────────────────────────────────────┘
```

## 表示項目

| フィールド名 | 型 | 必須 | 説明 | DB列 |
|------------|-----|------|------|------|
| ペット | lookup | ✅ | petIdからペット・飼主情報表示 | `pets.id` |
| 検査日時 | datetime | ✅ | 検査実施日時 | `examinations.examination_date` |
| 検査種別 | string | ✅ | 血液検査/尿検査/X線等 | `examinations.test_type` |
| 使用機器 | string | | 使用機器や外注先名 | `examinations.machine` |
| 依頼医 | lookup | ✅ | 担当獣医師選択 | `staffs.id` |
| 関連カルテ | lookup | | カルテとの紐付け | `medical_records.id` |
| ステータス | enum | ✅ | 依頼中/検査中/完了 | `examinations.status` |
| 結果サマリー | textarea | | 検査結果の概要 | `examinations.result_summary` |
| 検査項目詳細 | json | | 各検査項目の値 | `examinations.items` |
| 備考 | textarea | | その他メモ | `examinations.notes` |

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 保存 | 「保存」ボタン | バリデーション → API保存 | `/examinations` |
| 検査完了 | 「完了」ボタン | ステータスを完了に更新 | 同画面 |
| 戻る | 「戻る」ボタン | 検査一覧へ | `/examinations` |

## バリデーション
- **検査日時**: 必須
- **検査種別**: 必須
- **依頼医**: 必須
- **ステータス**: 必須、デフォルト「依頼中」
