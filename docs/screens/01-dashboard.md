# ダッシュボード 仕様書

## 概要
- **画面の目的**: 病院全体の当日受付状況をリアルタイムで把握するホーム画面。カンバンボード形式で患者フローを管理する。
- **URLパターン**: `/`
- **アクセス権限**: 認証済ユーザー全員

## 画面レイアウト
```
┌──────────────────────────────────────────────────────┐
│ 当日の受付  [日付]  [フィルター] [新規予約ボタン]     │
├──────────────────────────────────────────────────────┤
│ [フィルターパネル（折り畳み）]                        │
│  診察区分: □初診 □再診                               │
│  指名: [ドクター選択]                                 │
│  種類: □トリミングのみ表示                           │
├──────────┬──────────┬──────────┬──────────┬──────────┤
│ 受付予約  │ 受付済   │ 診療中   │ 会計待ち │ 会計済   │
│ [+追加]  │ [+追加]  │          │          │          │
│          │          │          │          │          │
│ カード1  │ カード2  │ カード3  │ カード4  │ カード5  │
│ カード...│ カード...│ カード...│ カード...│ カード...|
└──────────┴──────────┴──────────┴──────────┴──────────┘
```

## カンバンカラム構成

| カラム名 | 説明 | 追加ボタン | 対応ステータス |
|---------|------|-----------|--------------|
| 受付予約 | 本日来院予定の予約 | あり（予約管理へ遷移） | `pending`, `confirmed` |
| 受付済 | 来院済み・待合室待機中 | あり（予約管理へ遷移） | `checked_in` |
| 診療中 | 診察室・処置室で対応中 | なし | `in_consultation` |
| 会計待ち | 診察終了・会計計算待ち | なし | `accounting` |
| 会計済 | 会計完了・帰宅 | なし | `completed` |

## 表示項目（アポイントメントカード）

| フィールド名 | 型 | 説明 | 備考 |
|------------|-----|------|------|
| 時刻 | time | 予約時刻 | `reservations.start_time` |
| 飼主名 | string | 飼い主氏名 | `owners.name` |
| ペット名 | string | ペット名 | `pets.name` |
| 動物種別 | string | 犬/猫等 | `pets.species` |
| 来院種別 | string | 初診/再診 | `reservations.visit_type` |
| サービス種別 | string | 診療/トリミング等 | `reservations.service_type` |
| 担当医 | string | 担当獣医師名 | `staffs.name` |
| 指名フラグ | boolean | 指名かどうか | `reservations.is_designated` |

## UI コンポーネント
- **KanbanColumn**: カラムコンテナ、ドラッグ&ドロップ対応
- **AppointmentCard**: 予約カード（ドラッグ可能）
- **DashboardDetailModal**: カード詳細・ステータス変更モーダル
- **ReservationFormModal**: 予約編集モーダル（共有コンポーネント）
- **FormHeader**: ページヘッダー（タイトル・日付・アクションボタン）
- **フィルターパネル**: 診察区分・指名・種類フィルター（折り畳み式）

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| カード詳細表示 | カードクリック | DashboardDetailModal開く | モーダル表示 |
| ステータス進行 | 詳細モーダル「確認」ボタン | カードを次のカラムに移動 | 同画面 |
| カード編集 | 詳細モーダル「編集」ボタン | ReservationFormModal開く | モーダル表示 |
| 予約キャンセル | 詳細モーダル「取り消し」ボタン | 確認ダイアログ後、カード削除 | 同画面 |
| カード移動 | ドラッグ&ドロップ | ステータス変更 | 同画面 |
| 新規予約 | ヘッダー「新規予約」ボタン | 予約管理画面へ遷移 | `/reservations` |
| フィルター | フィルターボタン | フィルターパネル開閉 | 同画面 |
| 受付済に追加 | 受付予約カラム「+」ボタン | 予約管理へ遷移 | `/reservations` |

## 画面遷移

| 遷移元 | 遷移先 | 条件 |
|--------|--------|------|
| サイドバー「ダッシュボード」 | `/` | 常時 |
| 「新規予約」ボタン | `/reservations` | ボタンクリック |
| 受付予約カラム「+」ボタン | `/reservations` | ボタンクリック |

## バリデーション
- フィルター適用時、条件に合致しないカードは非表示（フロントエンドフィルタリング）
- ドラッグ&ドロップは順方向のみ許容（会計済から受付予約へは不可 ※実装による）
