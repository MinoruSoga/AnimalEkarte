# シフト管理カレンダー 仕様書

## 概要
- **画面の目的**: スタッフの勤務シフトをカレンダー形式で確認・管理する。
- **URLパターン**: `/shifts`

## 機能詳細

### 1. シフト可視化ロジック
- **色分け表示**: 職種（獣医師/看護師/トリマー）やシフト種別（日勤/夜勤/休暇）に応じてカレンダー上のセルを自動的に色分けし、視覚的な判読性を高める。
- **スタッフフィルタ**: 特定のスタッフのみを表示させ、自身の勤務予定や特定担当者の出勤日を容易に確認できる。

### 2. 月次ナビゲーション
- **動的表示**: 前月・翌月ボタンにより表示期間を切り替え、その都度該当月のシフトデータを API から取得する。

## 表示項目
- スタッフ名
- 勤務日、勤務区分
- 担当医院（複数医院運営時）

## フォーム項目（ShiftFormDialog）

セルをクリック（または既存シフトを選択）して表示されるダイアログ。

| フィールド | 入力部品 | 備考 |
|-----------|----------|------|
| 勤務日 | `Input(date)` | 選択したセルから自動入力、編集不可 |
| スタッフ名 | 読み取り専用 | 選択したスタッフ名を表示 |
| 勤務区分 | `Select` | 日勤 / 夜勤 / 午前休 / 午後休 / 有給 / 欠勤 |
| 担当医院 | `Select` | 所属する医院から選択（複数医院対応時） |

## コンポーネント構成

| コンポーネント | 種別 | 説明 |
|---|---|---|
| `ShiftCalendarPage` | `[R]` | メインページ |
| `ShiftCalendar` | `[C]` | カレンダー本体（ツールバー、グリッド、スタッフ列） |
| `ShiftCell` | `[C]` | 1日分のシフト表示セル（クリックで追加・編集） |
| `ShiftFormDialog` | `[C][M]` | シフト登録・編集ダイアログ |
| `useGetShifts` / `useStaffsForShift` | `[H]` | データ取得・フィルタリング |

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/shifts` | シフトデータ取得 | 実装済 |
| GET | `/api/v1/staffs` | スタッフ一覧（フィルタ用） | 実装済 |
