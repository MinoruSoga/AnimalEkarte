# シフト管理カレンダー 仕様書

## 概要
- **画面の目的**: スタッフの勤務シフトをカレンダー形式で確認・管理する。
- **URLパターン**: `/shifts`
- **アクセス権限**: 認証済ユーザー全員（操作は `ResourceShifts` 権限が必要）

## 機能詳細

### 1. シフト可視化ロジック
- **色分け表示**: 職種（獣医師/看護師/トリマー）やシフト種別（全日/午前/午後/休日/有休）に応じてカレンダー上のセルを自動的に色分け。
- **スタッフフィルタ**: 画面上部のセレクトボックスから特定のスタッフのみを表示可能。

### 2. 月次ナビゲーション
- **動的表示**: 前月・翌月ボタンにより期間を切り替え。`YYYY-MM` 形式のクエリで API からデータを取得。

### 3. 休診日管理
- **日付ヘッダークリック**: カレンダーの日付部分（曜日・日付）をクリックすると、医院全体の休診設定（`ClinicHolidayModal`）を開く。
- **休診日表示**: 休診設定された日は、カレンダーの該当列がグレーアウト（または赤枠強調）され、「休診」ラベルと理由が表示される。

## 表示項目
- スタッフ名（行ヘッダー）
- 日付（列ヘッダー）
- シフト区分、勤務時間、休憩時間（セル内）

## フォーム項目（ShiftFormDialog）

セルをクリックして表示されるダイアログ。

| フィールド | 入力部品 | 備考 |
|-----------|----------|------|
| 勤務日 | 読み取り専用 | |
| スタッフ名 | 読み取り専用 | |
| シフト種別 | `Select` | 全日 / 午前 / 午後 / 休日 / 有休 |
| 開始時刻 | `Input(time)` | 30分単位。休日時は非活性 |
| 終了時刻 | `Input(time)` | 30分単位。休日時は非活性 |
| メモ | `Input(text)` | |
| 休憩時間 | 動的リスト | **複数登録可能**。`break_start` / `break_end` のペアを「追加」ボタンで増やす。LINE予約の予約不可枠として計算される。 |

## コンポーネント構成

| コンポーネント | 種別 | 説明 |
|---|---|---|
| `ShiftCalendarPage` | `[R]` | メインページ |
| `ShiftCalendar` | `[C]` | カレンダー本体（ツールバー、グリッド、スタッフ列） |
| `ShiftCell` | `[C]` | 1日分のシフト表示セル（クリックで追加・編集） |
| `ShiftFormDialog` | `[C][M]` | シフト登録・編集ダイアログ |
| `ClinicHolidayModal` | `[C][M]` | 医院単位の休診日設定ダイアログ |
| `useGetShifts` / `useStaffsForShift` | `[H]` | データ取得・フィルタリング |
| `useGetClinicHolidays` | `[H]` | 休診日データ取得 |

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/shifts` | シフトデータ取得（breaks 含む） | 実装済 |
| POST | `/api/v1/shifts` | シフト作成（breaks 含む） | 実装済 |
| PATCH | `/api/v1/shifts/:id` | シフト更新（breaks 含む） | 実装済 |
| DELETE | `/api/v1/shifts/:id` | シフト削除（breaks は CASCADE） | 実装済 |
| GET | `/api/v1/staffs` | スタッフ一覧（フィルタ用） | 実装済 |
| GET | `/api/v1/clinics/:id/holidays` | 休診日取得 | 実装済 |
| POST | `/api/v1/clinics/:id/holidays` | 休診日設定 | 実装済 |
| DELETE | `/api/v1/clinics/:id/holidays/:id` | 休診日解除 | 実装済 |
