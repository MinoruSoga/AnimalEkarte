# 予約管理 仕様書

## 概要
- **画面の目的**: 診療・トリミング・手術等の予約をカレンダー形式で一元管理する。
- **URLパターン**: `/reservations`
- **アクセス権限**: 認証済ユーザー全員

## 画面レイアウト
```
┌──────────────────────────────────────────────────────┐
│ 予約管理  [新規予約ボタン]                            │
├──────────────────────────────────────────────────────┤
│ [← 今日 →]  [yyyy年 M月]        [月表示 / 週表示]  │
├──────────────────────────────────────────────────────┤
│                                                      │
│  カレンダービュー（月表示 or 週表示）                 │
│  - 週表示: タイムライン形式（時間軸 × 曜日）         │
│  - 月表示: グリッド形式（日付 × 予約一覧）           │
│                                                      │
└──────────────────────────────────────────────────────┘
```

## 表示項目（予約カード）

| フィールド名 | 型 | 説明 | 備考 |
|------------|-----|------|------|
| 開始日時 | datetime | 予約開始時刻 | `reservations.start_time` |
| 終了日時 | datetime | 予約終了時刻 | `reservations.end_time` |
| 飼主名 | string | 飼い主氏名 | `owners.name` |
| ペット名 | string | ペット名 | `pets.name` |
| 来院種別 | enum | 初診/再診 | `reservations.visit_type` |
| サービス種別 | enum | 診療/トリミング等 | `reservations.service_type` |
| 担当医 | string | 担当医名 | `staffs.name` |
| 指名 | boolean | 指名有無 | `reservations.is_designated` |
| ステータス | enum | pending/confirmed/checked_in等 | `reservations.status` |

## UI コンポーネント
- **MonthView**: 月表示カレンダー（グリッド形式）
- **WeekView**: 週表示カレンダー（タイムライン、ドラッグ&ドロップ対応）
- **ReservationFormModal**: 予約作成・編集モーダル
- **ReservationDetailModal**: 予約詳細モーダル（ステータス変更、削除、記録作成）
- **PatientSearch / PatientSelectionTable**: ペット検索・選択コンポーネント（モーダル内）
- **FormHeader**: ページヘッダー

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 新規予約作成 | 「新規予約」ボタン | ReservationFormModal開く | モーダル表示 |
| タイムスロットクリック | 週表示の空き時間クリック | 選択時間でReservationFormModal開く | モーダル表示 |
| 予約詳細表示 | 予約カードクリック | ReservationDetailModal開く | モーダル表示 |
| 予約編集 | 詳細モーダル「編集」ボタン | ReservationFormModal開く（編集モード） | モーダル表示 |
| 予約削除 | 詳細モーダル「削除」ボタン | 確認ダイアログ後、削除 | 同画面 |
| ステータス変更 | 詳細モーダルのステータス選択 | ステータス更新 | 同画面 |
| カルテ作成 | 詳細モーダル「記録作成」ボタン | サービス種別に応じた作成画面へ遷移 | `/medical-records/new?petId=xxx` 等 |
| 予約移動 | 週表示でカードD&D | 時間変更・重複チェック | 同画面 |
| 月/週表示切替 | ドロップダウン選択 | ビュー切替 | 同画面 |
| 前後移動 | ← → ボタン | 前/次の週または月へ | 同画面 |

## 画面遷移

| 遷移元 | 遷移先 | 条件 |
|--------|--------|------|
| ダッシュボード「新規予約」 | `/reservations` | ボタンクリック |
| 詳細モーダル「カルテ作成」 | `/medical-records/new?petId=xxx` | サービス種別:診療系 |
| 詳細モーダル「カルテ作成」 | `/trimming/new?petId=xxx` | サービス種別:トリミング |
| 詳細モーダル「カルテ作成」 | `/hospitalization/new?petId=xxx` | サービス種別:入院/ホテル |

## バリデーション
- 新規作成・編集時の重複チェック: 同一担当医の同時間帯予約は不可（エラートースト表示）
- 1予約に複数ペット選択可能（作成時のみ、ペットごとに個別予約が生成される）
