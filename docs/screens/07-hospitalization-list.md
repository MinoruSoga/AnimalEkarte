# 入院管理一覧 仕様書

## 概要
- **画面の目的**: 入院中・入院予約・退院済のペット一覧管理。ボードビューとリストビューを切り替えて使用する。
- **URLパターン**: `/hospitalization`
- **アクセス権限**: 認証済ユーザー全員

## 画面レイアウト


## 表示項目

| フィールド名 | 型 | 説明 | 備考 |
|------------|-----|------|------|
| 入院No | string | 入院番号 | `hospitalizations.hospitalization_no` |
| ペット名 | string | ペット名 | `pets.name` |
| 種/品種 | string | 動物種と品種 | `pets.species`, `pets.breed` |
| 飼主名 | string | 飼い主氏名 | `owners.name` |
| 入院種別 | enum | 入院/ホテル | `hospitalizations.type` |
| 入院開始日 | date | 入院開始日 | `hospitalizations.start_date` |
| 退院予定日 | date | 退院予定日 | `hospitalizations.end_date` |
| ケージ | string | 割り当てケージ名 | `cages.name` |
| ステータス | enum | 入院中/退院済/予約/一時帰宅 | `hospitalizations.status` |

## フィルタータブ

| タブ名 | フィルター条件 |
|--------|--------------|
| 入院中 | status = `入院中` |
| 予約 | status = `予約` |
| 退院済 | status = `退院済` |
| すべて | フィルターなし |

## UI コンポーネント
- **PageLayout**: ページコンテナ
- **Tabs**: ステータスフィルタータブ
- **SearchFilterBar**: 飼主名・ペット名・入院Noの検索
- **ToggleGroup**: ボードビュー/リストビュー切替
- **HospitalizationBoard**: ケージボードビュー（ドラッグ&ドロップでケージ移動）
- **HospitalizationListView**: リストビュー（テーブル形式）
- **PrimaryButton**: 「新規入院登録」ボタン

## ユーザーアクション

| アクション | トリガー | 処理内容 | 遷移先 |
|-----------|---------|---------|--------|
| 新規入院登録 | 「新規入院登録」ボタン | ペット選択画面へ | `/hospitalization/select-pet` |
| 詳細表示 | ケージカードorリスト行クリック | 入院詳細画面へ | `/hospitalization/:id` |
| ケージ移動 | ボードビューD&D | ケージ変更 | 同画面 |
| タブ切替 | タブクリック | ステータスフィルター変更 | 同画面 |
| ビュー切替 | ToggleGroup | ボード/リスト切替 | 同画面 |

## 画面遷移

| 遷移元 | 遷移先 | 条件 |
|--------|--------|------|
| サイドバー | `/hospitalization` | 常時 |
| 新規入院登録ボタン | `/hospitalization/select-pet` | ボタンクリック |
| ペット選択完了 | `/hospitalization/new?petId=xxx` | ペット選択後 |
| ケージカード/行クリック | `/hospitalization/:id` | クリック |
