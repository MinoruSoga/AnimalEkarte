# 入院管理一覧 仕様書

## 概要
- **画面の目的**: 入院・ホテル患者の一覧管理。ボードビューとリストビューを切り替えて使用する。
- **URLパターン**: `/hospitalization`
- **アクセス権限**: 認証済ユーザー全員

## 画面構成
- **ヘッダー**: タイトル、新規登録ボタン
- **フィルタ**: ステータス別のタブ（入院中 / 予約 / 退院済 / すべて）
- **ツールバー**: `NotionFilter`（飼主名・ペット名・入院Noでの検索）、ボード/リスト表示切替トグル
- **表示エリア**:
  - **ボードビュー**: ケージごとのカード表示、ドラッグ&ドロップでのケージ移動に対応。
  - **リストビュー**: `DataTable` による一覧表示。

## 表示項目（テーブル）

| フィールド名 | 型 | 説明 | 備考 |
|------------|-----|------|------|
| 入院No | string | 入院受付番号 | `hospitalizationNo` |
| 飼主名 | string | 飼い主氏名 | |
| ペット名 | string | ペット名 | |
| 種 | string | 動物種 | |
| タイプ | enum | 入院 / ホテル | |
| 入院開始日 | date | 入院開始日 | |
| 退院予定日 | date | 退院予定日 | |
| ステータス | enum | 入院中 / 予約 / 退院済 | |
| 操作 | - | 詳細ボタン | |

## 主な機能
- **ビュー切替**: 「入院中」タブではボード形式とリスト形式を選択可能。その他のタブはリスト形式固定。
- **ケージ管理**: ボードビューにて、ペットを別のケージへドラッグして移動させることが可能。
- **クイック退院**: ボード上のカードから直接退院処理を開始。

|---------|--------------|------|
