# 入院管理一覧 仕様書

## 概要
- **画面の目的**: 入院・ホテル患者の一覧管理。ボードビューとリストビューを切り替えて使用する。
- **URLパターン**: `/hospitalization`
- **アクセス権限**: 認証済ユーザー全員（操作権限は `usePermission` で制御）

## 画面構成
- **ヘッダー**: タイトル、新規入院登録ボタン。
- **フィルタタブ**: ステータス別に「入院中」「予約」「退院済」「すべて」を即座に切り替え。
  - 「入院中」タブには `active`（入院中）と `temp_discharge`（一時退院）の両方が含まれる。
- **ツールバー**: 
  - `NotionFilter`: 入院日の期間指定（**サーバーサイドフィルタ**）、キーワード検索（飼主名・ペット名・入院No）、動的な「種」フィルタ（ロード済みデータから自動生成）。
  - 表示切替: `ToggleGroup` を使用したボード/リスト表示の切り替え。設定は `localStorage` に保存され、ページ再訪時に維持される。
- **表示エリア**:
  - **ボードビュー**: ケージマスタに基づいたグリッド表示。各ケージに入院患者カードを配置。
  - **リストビュー**: `DataTable` による一覧表示。20件ごとのページネーション。

## 主要機能
- **サーバーサイドフィルタ**: 日付範囲指定時、API (`/api/v1/hospitalizations`) へクエリを送信。
- **クライアントサイドフィルタ**: 入院区分（入院/ホテル）、種、検索ワード、ステータスタブはクライアントサイドで高速にフィルタリングされる。
- **URL同期**: ページ番号を URL クエリパラメータ (`?page=N`) と同期。
- **ドラッグ&ドロップ**: ボードビューにおいて、患者カードを別の空きケージへ移動（ケージ変更 API 連携）。
- **非同期計算の可視化**: `useDeferredValue` により、検索ワード入力中の UI ブロッキングを防止。

## UI コンポーネント
| コンポーネント | 種別 | 説明 |
|---|---|---|
| `HospitalizationList` | `[R]` | メインページ。表示モードとフィルタ状態を管理。 |
| `HospitalizationBoard` | `[C]` | ケージレイアウトに基づいたボード表示。 |
| `HospitalizationCard` | `[C]` | 入院情報の概要を表示するカード部品。 |
| `NotionFilter` | `[S]` | 期間指定・キーワード検索・ソート用共有パネル。 |

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/hospitalizations` | 入院一覧取得 | 実装済 |
| DELETE | `/api/v1/hospitalizations/:id` | 入院データ削除 | 実装済 |
