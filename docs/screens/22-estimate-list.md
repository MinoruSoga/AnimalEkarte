# 見積書一覧 仕様書

## 概要
- **画面の目的**: 作成済みの見積書を一覧管理・検索する。
- **URLパターン**: `/estimates`
- **アクセス権限**: 認証済ユーザー全員（操作権限は `usePermission` で制御）

## 画面構成
- **ヘッダー**: タイトル、新規見積作成ボタン。
- **ツールバー**: 
  - `NotionFilter`: ステータス（下書き/送付済み/承認済み/却下）、有効期限（期間指定）、キーワード検索、ソート機能。
  - `FilteringIndicator`: 非同期でのフィルタリング中に視覚的なフィードバックを表示。
- **データテーブル**: `DataTable` による一覧表示。20件ごとのページネーション。

## 主要機能
- **ステータス別フィルタ**: クライアントサイドでの高度なステータス絞り込みに対応。
- **権限管理**: `usePermission` により、ロールに応じた「新規登録」ボタンの表示、およびアクションメニュー（詳細・編集・削除）の有効化。
- **パフォーマンス最適化**: `useDeferredValue` を使用し、検索キーワード入力時の UI 応答性を維持。
- **URL同期**: ページ番号を URL クエリパラメータ (`?page=N`) と同期。

## UI コンポーネント
| コンポーネント | 種別 | 説明 |
|---|---|---|
| `EstimateList` | `[R]` | メインページ。 |
| `EstimateStatusBadge` | `[C]` | ステータスに応じた色分け表示（青・黄・緑・赤）。 |
| `RowActionDropdown` | `[S]` | 権限に応じたアクション（編集・削除等）を集約したドロップダウン。 |
| `NotionFilter` | `[S]` | Notion 風の高度な検索パネル。 |

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/estimates` | 見積一覧取得 | 実装済 |
| DELETE | `/api/v1/estimates/:id` | 見積レコード削除 | 実装済 |
