# 見積書一覧 仕様書

## 概要
- **画面の目的**: 作成済みの見積書を一覧管理・検索する。
- **URLパターン**: `/estimates`
- **アクセス権限**: 認証済ユーザー全員（操作権限は `usePermission` で制御）

## 画面構成
- **ヘッダー**: タイトル「見積書管理」（FileText アイコン）、新規見積作成ボタン。
- **検索・フィルタ**: 
  - `NotionFilter`: ステータス（下書き/送付済み/承認済み/却下）、有効期限（期間指定）、キーワード検索（見積番号・タイトル・飼主名）、ソート機能。
- **データテーブル**: `DataTable` による一覧表示。20件ごとのページネーション。

## 表示項目（テーブル）

| フィールド名 | 型 | 説明 | ソート | 備考 |
|------------|-----|------|--------|------|
| 見積番号 | string | 見積の一意識別番号 | ○ | `estimateNo` (等幅) |
| タイトル | string | 見積の件名 | ○ | `title` (太字) |
| 飼主名 | string | 飼い主氏名 | ○ | `ownerName` |
| 有効期限 | string | 見積の有効期限 | ○ | `validUntil` (YYYY-MM-DD) |
| 合計金額 | decimal | 税込合計額（右寄せ） | ○ | `totalAmount` (等幅) |
| ステータス | enum | 下書き/送付済み/承認済み/却下 | ○ | `EstimateStatusBadge` で配色 |
| 操作 | - | 詳細・編集・削除 | - | `RowActionDropdown` |

## ユーザーアクション
- **新規見積作成**: `/estimates/new` (ペット選択) へ遷移。
- **詳細表示**: 行クリックまたは操作ボタン「詳細」から `/estimates/:id` へ遷移。
- **編集**: 操作ボタン「編集」から `/estimates/:id/edit` へ遷移。
- **削除**: `ConfirmDialog` を経て論理削除。

## UI コンポーネント
| コンポーネント | 種別 | 説明 |
|---|---|---|
| `EstimateList` | `[R]` | メインページ。 |
| `EstimateStatusBadge` | `[C]` | ステータスに応じた色分け表示（青・黄・緑・赤）。 |
| `RowActionDropdown` | `[S]` | 権限に応じたアクション（編集・削除等）を集約したドロップダウン。 |
| `NotionFilter` | `[S]` | Notion 風の高度な検索パネル。 |

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/estimates` | 見積一覧取得 | 実装済 |
| DELETE | `/api/v1/estimates/:id` | 見積レコード削除 | 実装済 |
