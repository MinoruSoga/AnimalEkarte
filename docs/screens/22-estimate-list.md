# 見積書一覧 仕様書

## 概要
- **画面の目的**: 作成済みの見積書を一覧管理・検索する。
- **URLパターン**: `/estimates`
- **アクセス権限**: 認証済ユーザー全員

## 画面構成
- ヘッダー: タイトル + 新規見積作成ボタン
- 検索フィルタバー（`NotionFilter`）: ステータス、有効期限、キーワード検索、ソート
- データテーブル: `DataTable`

## フィルタ機能
| 項目 | 入力部品 | 選択肢 |
|---|---|---|
| ステータス | `Select` | 全て / 下書き / 送付済み / 承認済み / 却下 |
| 有効期限 | `DateRange` | 期間指定 |
| キーワード | `Input` | 見積番号、タイトル、飼主名で検索 |

## 表示項目（テーブル）
| フィールド | 説明 | 備考 |
|-----------|------|------|
| 見積番号 | 自動採番された一意識別子 | `estimateNo`（等幅フォント） |
| タイトル | 見積書の名称 | `title` |
| 飼主名 | 宛先 | `ownerName` |
| 有効期限 | 見積の有効期限 | `validUntil`（yyyy-MM-dd形式） |
| 合計金額 | 税込合計額 | 通貨形式（¥） |
| ステータス | 現在の状態 | `EstimateStatusBadge` による色分け |
| 操作 | 行アクション | 詳細、編集、削除 |

## UI コンポーネント
| コンポーネント | 種別 | 説明 |
|---|---|---|
| `EstimateList` | `[R]` | メインページ |
| `EstimateStatusBadge` | `[C]` | ステータス別のバッジ表示 |
| `NotionFilter` | `[S]` | 検索フィルタバー |
| `DataTable` | `[S]` | データテーブル |
| `RowActionDropdown` | `[S]` | 行アクションメニュー |
| `ConfirmDialog` | `[S][M]` | 削除確認ダイアログ |

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/estimates` | 見積一覧取得 | 実装済 |
| DELETE | `/api/v1/estimates/:id` | 見積削除 | 実装済 |
