# 見積書一覧 仕様書

## 概要
- **画面の目的**: 作成済みの見積書を一覧管理・検索する。
- **URLパターン**: `/estimates`
- **アクセス権限**: 認証済ユーザー

## 機能詳細

### 1. ステータス管理とフィルタ
- **進捗可視化**: 「下書き」「送付済み」「承認済み」「却下」のステータスごとにタブ形式でフィルタリングが可能。
- **有効期限の監視**: 期限が切れた見積書について、一覧上で視覚的に警告（グレーアウト等）を表示する。

### 2. データ連携
- **カルテ引用**: カルテ詳細から作成された見積書は、自動的に該当するペット情報と紐付いた状態で本一覧に表示される。

## 表示項目（テーブル）
| フィールド | 説明 | 備考 |
|-----------|------|------|
| 見積番号 | 自動採番された一意識別子 | `estimateNo`（等幅フォント） |
| タイトル | 見積書の名称 | |
| 飼主名 | 宛先 | |
| 有効期限 | 見積の有効期限 | `validUntil`（yyyy-MM-dd形式） |
| 合計金額 | 税込合計額 | 通貨形式（¥） |
| ステータス | 現在の状態 | `EstimateStatusBadge` による色分け |

## API連携
| メソッド | エンドポイント | 用途 | 状態 |
|---------|--------------|------|------|
| GET | `/api/v1/estimates` | 見積一覧取得 | 実装済 |
| DELETE | `/api/v1/estimates/:id` | 見積削除 | 実装済 |
