# 当日の受付 仕様書 (Reception Kanban)

## 概要
- **画面の目的**: 院内全体の稼働状況をリアルタイムに把握・管理するためのカンバンボード型ホーム画面。
- **URLパターン**: `/`
- **アクセス権限**: 認証済ユーザー全員（権限に基づきアクション制限あり）

---

## 主要機能

### 1. 患者フローの管理 (Kanban)
患者の滞在ステータスを5つのカラムで可視化し、ドラッグ&ドロップ（DnD）で直感的にフェーズを進行させます。

| カラム名 | 説明 | 対応ステータス |
|:---|:---|:---|
| **受付予約** | 本日の来院予定。LINE予約（source=line）と手動予約が含まれます。 | `pending`, `confirmed` |
| **受付済** | 患者が来院し、待合室で待機している状態。 | `checked_in` |
| **診療中** | 診察室・処置室・検査室等で医師が対応している状態。 | `in_consultation` |
| **会計待ち** | 診療が終了し、レジでの精算・処方待ちの状態。 | `accounting` |
| **会計済** | 精算が完了し、帰宅または入院へ移行した状態。 | `completed` |

### 2. 患者カード (`AppointmentCard`)
一目で「誰が・いつ・何で」来院しているかを把握するための情報が集約されています。

| 項目 | 説明 |
|:---|:---|
| **時刻** | 予約時刻（HH:mm）。 |
| **患者・飼主** | ペット名（犬猫アイコン付）と飼い主氏名。 |
| **区分バッジ** | 初診/再診、および診療区分（一般診察、ワクチン、トリミング等）。 |
| **担当医** | 指名がある場合は「指」ラベルを表示。 |
| **アラートバッジ** | **「次回予約済」**: 既に次回の枠が確保されている。 |
| | **「精算未確認」**: 過去に未精算の会計レコードが存在する場合に警告。 |

## 操作詳細

### 進行・ナビゲーション
- **詳細表示**: カードをクリックすると `ReceptionDetailModal` が開き、より詳細な情報の確認やステータスの手動変更が可能です。
- **クイックリンク (ミニアクション)**:
    - **カルテ作成**: カラムが「受付済」以降の場合、直接 `/medical-records/new` へ遷移。
    - **会計**: `/accounting/new` への直接リンク。
    - **入院**: 診療区分に入院が含まれる場合、`/hospitalization/new` へ遷移。

### フィルタリング
ヘッダーの「フィルター」ボタンより、以下の条件でボード上の表示を絞り込めます。
- **担当医**: ログイン中の医師自身、または特定のスタッフで抽出。
- **初診/再診**: 特定の来院種別のみを表示。
- **トリミング限定**: トリミング業務専用のビューに切り替え。

## 技術仕様

### 状態管理と通信
- **DnD エンジン**: `dnd-kit` を使用。物理的な移動距離（8px以上）に基づきドラッグを開始。
- **即時同期**: カード移動成功時、バックエンドの `reservation.status` が即座に更新され、他端末の画面にも反映（または再ロード時に最新化）されます。

### 使用コンポーネント
- **`Reception`**: メインページコンテナ。
- **`useReceptionKanban`**: DnD ロジックとフィルタリングを統合したカスタムフック。
- **`ReceptionDetailModal`**: ステータスに応じた動的アクションボタンを提供。

### API連携
| メソッド | エンドポイント | 用途 | 必須権限 | 必須アクション |
|:---|:---|:---|:---|:---|
| GET | `/api/v1/reservations` | 本日の予約・受付状況一覧の取得 | `reservations` | `view` |
| PATCH | `/api/v1/reservations/:id` | 予約・受付ステータスの更新 | `reservations` | `edit` |
| GET | `/api/v1/masters/staffs` | 担当医フィルター用スタッフマスタ取得 | `master-staff` | `view` |
