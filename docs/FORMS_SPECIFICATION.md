# 画面フォーム仕様書（完全版）

本ドキュメントは、各画面のフォーム項目について、すべてのフィールドの詳細仕様（必須/任意、バリデーションルール、デフォルト値、入力制約）を網羅的に記載します。

> **本ドキュメントの目的**: `/SCREENS.md`の画面仕様書を補完し、すべての入力フィールドの詳細仕様を一元管理します。

---

## 1. 予約管理

### 1.1 予約フォーム（ReservationFormFields）

| フィールド名 | 入力部品 | 必須/任意 | バリデーションルール | デフォルト値 | 備考 |
|------------|----------|-----------|-------------------|------------|------|
| 日付 | `Popover` + `Calendar` | 必須 | 未選択時エラー | 新規: セルクリック日 / 編集: 既存値 | Calendar アイコン付き |
| 時間帯（開始） | `Select` | 必須 | 未選択時エラー、終了時刻より前 | 新規: 10:00 / 編集: 既存値 | 30分刻み 0:00〜23:30、Clock アイコン |
| 時間帯（終了） | `Select` | 必須 | 未選択時エラー、開始時刻より後 | 新規: 11:00 / 編集: 既存値 | 30分刻み 0:00〜23:30、ArrowRight で接続 |
| 予約区分 | `Select` | 必須 | 未選択時エラー | 未選択 | serviceType マスタ連動、`MasterLink` 付き |
| 初診/再診 | `RadioGroup` | 必須 | 未選択時エラー | `revisit`（再診） | カスタムラベルUI（カラードット付き） |
| 担当者 | `Select` | 必須 | 未選択時エラー、active スタッフのみ | 未選択 | staff マスタ連動、`MasterLink` 付き |
| 指名 | `Checkbox` | 任意 | - | `false` | 担当者選択後に表示 |
| メモ | `Textarea` | 任意 | 最大1000文字 | 空文字 | - |

- 同じ担当医の予約と時間帯が重複する場合、警告トースト表示（`toast.warning`）
- 重複時も保存は可能（警告のみ）

## 10. バリデーション共通ルール

### 10.1 必須フィールドの検証タイミング

- **インライン検証**: 入力中はリアルタイムで検証しない
- **フォーカスアウト時**: フィールドからフォーカスが外れた時に検証（`onBlur`）
- **保存時**: 保存ボタンクリック時に全フィールドを一括検証
- **エラー表示**: `FormFieldError` コンポーネント（`role="alert"`）でエラーメッセージ表示
- **トースト通知**: 重大なエラー（必須フィールド未入力等）は `toast.warning` で通知

### 10.2 数値入力の共通ルール

- **小数点**: `step` 属性で制御（体温=0.1、体重=0.01、整数=1）
- **負の値**: 金額・数量・率は0以上のみ許可
- **最大値**: フィールドごとに適切な上限を設定（体温=50℃、心拍数=500回/分など）
- **空白許可**: 任意フィールドは空白可、必須フィールドは0以上

### 10.3 文字列入力の共通ルール

- **最大文字数**: フィールドごとに適切な上限を設定
- **全角/半角**: 特に制限なし、ユーザー入力をそのまま保存
- **トリミング**: 保存時に前後の空白を自動削除
- **改行**: Textarea では改行許可、Input では禁止

### 10.4 日付入力の共通ルール

- **未来日制約**: 生年月日・実施日などは未来日不可
- **過去日制約**: 予定日・次回予定日などは過去日不可
- **日付範囲**: 開始日≦終了日の検証
- **空白許可**: 任意フィールドは `null` 許可

### 10.5 マスタ連動フィールドの共通ルール

- **active フィルタ**: スタッフ選択時は `status = 'active'` のみ表示
- **親フィルタ**: 診断名選択時は選択されたカテゴリの子項目のみ表示
- **動的リロード**: マスタ設定リンクからマスタ変更後、自動的に選択肢を再取得
- **無効スタッフ警告**: 既存データで inactive スタッフが選択されている場合、赤文字 + AlertTriangle アイコン表示

## 11. アクセシビリティ共通仕様

### 11.1 エラー通知

- **aria-invalid**: エラー時に `true` を設定
- **aria-describedby**: `FormFieldError` の id を参照
- **role="alert"**: `FormFieldError` コンポーネントに設定
- **フォーカス移動**: バリデーションエラー時、最初のエラーフィールドに自動フォーカス

### 11.2 モーダル・ダイアログ

- **role="dialog"**: すべてのモーダルに設定
- **aria-labelledby**: タイトル要素の id を参照
- **aria-modal="true"**: モーダル表示時に設定
- **フォーカストラップ**: モーダル内でフォーカスを循環
- **Escキー**: モーダルを閉じる

### 11.3 フォーム全体

- **label 明示**: すべての入力フィールドに `<Label>` または `aria-label` を設定
- **placeholder**: 補助情報として使用、label の代替としない
- **required マーク**: 必須フィールドには視覚的な必須マーク表示（`*` は使用せず「必須」バッジ推奨）
