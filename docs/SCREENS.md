# 動物病院管理システム 画面仕様書

本ドキュメントは、全画面（ルート）ごとの仕様を定義します。
各画面のルートパス、目的、構成コンポーネント、データフロー、ユーザー操作を網羅しています。

---

## 凡例

| 記号 | 意味 |
|------|------|
| `[R]` | ルートコンポーネント (`routes/` 配下) |
| `[C]` | 機能固有コンポーネント (`components/` 配下) |
| `[S]` | 共有コンポーネント (`/components/shared/`) |
| `[H]` | フック (`hooks/` 配下) |
| `[M]` | モーダル / ダイアログ |

## 1. ダッシュボード

### 1.1 ダッシュボード（カンバンボード）

| 項目 | 内容 |
|------|------|
| **ルート** | `/` |
| **コンポーネント** | `[R] Dashboard` |
| **目的** | 病院全体の来院フローをカンバンボード形式で俯瞰管理する |

**画面構成:**
- ヘッダー: タイトル（「当日の受付」）+ フィルターボタン + 新規予約ボタン
- フィルターバー（トグル表示）: 診察区分（初診/再診チェックボックス）、指名（担当医Select）、種類（トリミングのみCheckbox）
- カンバンボード: 5カラム（受付予約 → 受付済 → 診療中 → 会計待ち → 会計済）
- 患者カード（`[C] AppointmentCard`）: DnD対応、ミニアクションボタン（カルテ/施術、会計、入院）
- 詳細モーダル（`[C] DashboardDetailModal`）: ステータス別の遷移アクション、関連ページリンク

## 4. 電子カルテ

### 4.1 カルテ一覧

| 項目 | 内容 |
|------|------|
| **ルート** | `/medical-records` |
| **コンポーネント** | `[R] MedicalRecords` |
| **目的** | 全カルテの検索・一覧表示 |

**データテーブル列:**
- 診療日、飼主名、ペット名、種、主訴、関連（会計リンク）、担当医、ステータス、操作

### 4.2 カルテ入力/編集

| 項目 | 内容 |
|------|------|
| **ルート** | `/medical-records/new` / `/medical-records/:id` |
| **コンポーネント** | `[R] MedicalRecordForm` |
| **目的** | 診療記録の全項目を9タブ構成で入力・編集する |

**画面構成:**
- スティッキーヘッダー: `[S] PatientInfoCard`（基本情報・担当・診療種別）、タブバー
- フローティングボタン: 削除（問診タブのみ）、バイタル記録（モーダル）、保存

**タブ詳細:**
1. **問診**: `InterviewChiefComplaint` (主訴)、`InterviewTreatmentPolicy` (方針)、`InterviewHistory` (履歴)
2. **診察/治療プラン**: `DiagnosisHeader` (身体検査・診断)、`ClinicalPlanSection` (過去)、`TreatmentTable` (算定入力)
3. **治療**: `MedicalRecordTreatment` (完了処置の記録)
4. **予防接種**: `VaccinationForm` (入力)、`VaccinationHistory` (履歴)
5. **定期健診**: `CheckupsTab` (健診項目・履歴)
6. **検査**: `MedicalRecordExamination` (オーダー・結果)
7. **画像**: `MedicalRecordImage` (ギャラリー)
8. **見積書**: `MedicalRecordEstimate` (概算見積)
9. **会計(医師確認)**: `MedicalRecordBillCheck` (算定確認)

## 14. 共通ペット選択画面

各機能（カルテ、入院、トリミング、会計、検査、予防接種）の `/select-pet` パスで使用される共通UI。

| 項目 | 内容 |
|------|------|
| **コンポーネント** | `[S] PetSelection` |
| **検索項目** | 飼主名、ペット名、飼主ID |
| **表示項目** | 飼主名、飼主ID、ペット名、種 |
| **機能** | ペットの検索・フィルタ、選択中ペットの表示、複数選択対応 |
