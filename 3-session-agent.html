運用

  • Issue クローズ → 本表から行を削除。履歴は GitHub / git のみ。
  • 分類変更はその場で直す。依存待ち → 着手可能を見落とさない。
  • 着手前に Issue 本文を読む。「次のアクション」は要約だけ。
  • 新規 open Issue → 行を追加。TASK-* は todo.md のみ。
  • 排他は AGENTS.md の claim protocol。claim 解放は USER。
