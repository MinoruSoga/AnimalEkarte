## 詳細分析

### 診察/治療プランタブ - 診断コンボボックス

```javascript
// 現在の表示値:
診断1: "消化器疾患"
右隣: "食道炎"
診断2: "未選択"
```

**確認すべき項目:**
1. ドロップダウンが複数のマスタオプションを表示しているか
2. それらのオプションが DB（diagnosis_categories など）から動的ロードされているか
3. UI 上の値とマスタテーブルの値が一致しているか

**検証不可の理由:**
- ブラウザ UIでドロップダウンオプションが表示されない（クリック後も反応なし）
- JavaScript console にエラーがないため、ドロップダウン機構自体は動作していそう
- 単なるレンダリング遅延か、実装欠損か判断できない

## DB 側の確認

診断関連マスタテーブルが存在するか確認が必要：
```sql
-- 確認すべきテーブル
SELECT * FROM diagnosis_categories WHERE clinic_id = ... LIMIT 10;
SELECT * FROM diagnosis_master WHERE clinic_id = ... LIMIT 10;
```

現在は backend の schema を確認していないため、これが必要。

## 推定原因

1. **FE-006 と同じ** - コンボボックスがハードコード（固定値）で、マスタ API 呼び出しがない

3. **API エンドポイント未実装** - backend が診断カテゴリ取得 API を提供していない
