## 残存問題

### ⚠️ FE-009の部分的問題: マスタ設定ボタン → 404
- **状況**: 「マスタ設定を編集」ボタンがクリック可能だが、遷移先（`/settings/interview/chief-complaint`）が404で応答
- **原因**:
  - router.tsx に `/settings/interview/*` ルートが定義されていない
  - 対応するコンポーネント（ChiefComplaintSettings.tsx など）が存在しない
  - MasterLink.tsx が "chief_complaint" カテゴリをマッピングしていない
- **デモデータでの運用**: 問題なし（ドロップダウンから直接選択可能）
- **関連チケット**: FE-012

## 技術的背景

### スタッフAPI修正の詳細
医療記録ページの読み込み時に以下のエラーが発生していた：
```
TypeError: staffs.filter is not a function
```

**原因**: Backend の ListStaffs handler が `newPaginatedResponse()` で包括的に応答するが、frontend hook が直接配列を期待していた。

**修正内容**:
```typescript
// Before
return data;  // {data: [...], total, page, limit} が返される

// After
return data.data;  // 配列を抽出
```
