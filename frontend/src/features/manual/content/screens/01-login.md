# ログイン

## どんな画面か

スタッフがメールアドレスとパスワードでシステムにログインする画面です。パスワードを忘れた場合のリセット機能も提供します。

## 開き方

システムの URL にアクセスすると、ログインしていない時は自動的にログイン画面が表示されます。

ログアウト後もこの画面に戻ります。

![ログイン 画面](images/01-login.png)

---

## ログインする

1. **メールアドレス** に登録済みのメールアドレスを入力します。
2. **パスワード** を入力します。右側の目のアイコンで一時的に伏せ字を解除できます。
3. 「**ログイン**」ボタンをクリックします。

### ログイン成功

- 当日の受付画面（サイドバー「当日の受付」）に遷移します

### ログイン失敗

エラーメッセージが表示されます：

| エラー                                               | 原因                                     |
| ---------------------------------------------------- | ---------------------------------------- |
| 「メールアドレスまたはパスワードが正しくありません」 | 認証情報が一致しません                   |
| 「アカウントが無効化されています」                   | 管理者が無効化したアカウントです         |
| 短時間に何度も拒否される（レート制限）               | 同一 IP からの試行が 5 回 / 1 分を超えた |

---

## パスワードを忘れた時

1. ログイン画面の「**パスワードをお忘れですか？**」リンクをクリックします。
2. メールアドレス入力画面が開きます。
3. 登録メールアドレスを入力して「**送信**」をクリックします。

### 送信すると

- 登録メールアドレスにリセットリンクが送信されます
- リンクの有効期限は **1 時間** です
- 画面に「送信しました」と表示されます（メール送信成否は明示されません）

---

## 新しいパスワードを設定する

メールに記載されたリンクをクリックすると、パスワード再設定画面が開きます。

1. 新パスワードを入力します（**8 文字以上、英字と数字を含む**）。
2. 確認のためもう一度同じパスワードを入力します。
3. 「**設定**」ボタンをクリックします。

### 設定すると

- パスワードが更新されます
- ログイン画面に戻ります

### エラーになる場合

| エラー                 | 原因                                             |
| ---------------------- | ------------------------------------------------ |
| 「トークンが無効です」 | リンクの有効期限が切れている、または既に使用済み |
| パスワード不一致       | 確認入力が新パスワードと一致しない               |
| パスワード強度不足     | 8 文字未満、または英数字混在でない               |

---

## ログイン後にパスワードを変更する

1. サイドバー左下の **鍵アイコン** をクリックします。
2. パスワード変更ダイアログが開きます。
3. 現在のパスワード・新パスワード・新パスワード（確認）を入力します。
4. 「**変更**」をクリックします。

### 変更すると

- パスワードが更新されます
- **自動的にログアウトされます**（セキュリティのため）
- 新しいパスワードで再ログインします

---

## デモアカウント（ローカル開発と STG）

ローカル開発（Vite DEV）と STG では、ログイン画面に **デモアカウント一覧** が表示されます。本番環境では非表示です。

- 行を選ぶとメールとパスワードが入ります（STG も同じ。本番では一覧自体がありません）

---

## レート制限（ブルートフォース対策）

ログインは **同一 IP につき 5 回 / 1 分** までしか試行できません（総当たり攻撃対策）。

- 超過すると一時的に拒否されますが、**アカウント自体はロックされません**
- **約 1 分待つと自動的に再試行可能** になります（解除操作は不要・存在しません）
- それでもログインできない場合は次の順で対処します：
  1. 1〜2 分待って再試行する
  2. ログイン画面の「**パスワードをお忘れですか？**」からパスワードをリセットする
  3. 管理者にスタッフマスタでアカウントの **有効/無効** 状態を確認してもらう

---

## パスワードのルール

- 8 文字以上
- 英字と数字を **両方** 含むこと
- パスワードは暗号化されて保存されます（保存後はシステムから取得できません）
