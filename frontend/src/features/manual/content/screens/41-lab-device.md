# 検査受信

## どんな画面か

院内の検査機器（血液検査機など）から送信された検査結果を受信し、診療中のペットのカルテに紐付ける画面です。

## 開き方

サイドバー左メニューの「**検査受信**」をクリックします。

## 画面イメージ

![検査受信 画面](images/41-lab-device.png)

## 画面の構成

| セクション           | 内容                                             |
| -------------------- | ------------------------------------------------ |
| 検査機器             | 受信待ち（wait）状態と機器スロットの状況         |
| 本日診療中のカルテ   | 本日診療中のペット一覧。受信対象をここで選択     |
| 未紐付け             | 受信済みだがペットに紐付いていない検査結果       |
| 受信一覧             | 本日受信しペットに紐付け済みの検査結果           |
| ローカル受信機       | 検査機器との連携を担うローカルエージェントの状態 |

---

## 検査結果を受信する

1. 「**本日診療中のカルテ**」から、検査を行うペットのカルテを選択します。
2. 画面が「**受信中**」（wait）状態になります。
3. 検査機器で検査を実行すると、結果が自動受信され選択中のペットに紐付きます。

> 受信には **lab-import の作成権限** が必要です。権限がない場合、画面上部に権限不足の案内が表示され受信できません。

## 未紐付けの結果を紐付ける

受信対象を選ばないまま機器から送信された結果は「**未紐付け**」に入ります。

1. 「**本日診療中のカルテ**」で紐付け先のペットを選択（受信中にする）します。
2. 「**未紐付け**」の該当カードを選択すると、選択中のペットに紐付けられます。

## 紐付けを解除する

「**受信一覧**」の紐付け済み結果を解除できます。解除された結果は未紐付けに戻ります。

---

## 必要な権限

- 画面を見る → 閲覧権限
- 受信する → `lab-import` の作成権限
- 紐付け・解除 → 編集権限
