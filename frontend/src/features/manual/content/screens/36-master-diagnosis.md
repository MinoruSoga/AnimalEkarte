# 診断マスタ

## どんな画面か

カルテで使用する **診断病名** とそのカテゴリを管理するマスタです。診断入力時の選択肢になります。

## 開き方

サイドバー「**マスタ設定**」→「**診断病名**」

## データ構造

```
診断カテゴリ（消化器疾患・皮膚疾患 等）
  └─ 診断名（胃炎・アトピー性皮膚炎 等）
```

カテゴリと診断名の階層構造。

---

## 一覧画面のタブ

| タブ         | 内容                                      |
| ------------ | ----------------------------------------- |
| 診断カテゴリ | 大分類（消化器系 / 皮膚系 / 整形外科 等） |
| 診断名       | 具体的な病名                              |

---

## カテゴリの登録

1. 「**診断カテゴリ**」タブ → 「**新規追加**」
2. 入力：
   - カテゴリ名
   - 表示順
3. 「**保存**」

---

## 診断名の登録

1. 「**診断名**」タブ → 「**新規追加**」
2. 入力：

   | 項目     | 必須                   |
   | -------- | ---------------------- |
   | 診断名   | ✅                     |
   | カテゴリ | ✅                     |
   | コード   | 任意（慢性疾患タグ用） |

3. 「**保存**」

---

## 慢性疾患コードの設定

診断名に **コード**（例: `ckd` `diabetes`）を設定すると、Lステップ連携で自動タグ付与の対象になります。

設定対応例：

- 「慢性腎不全」→ コード `ckd` → タグ `chronic_ckd` 自動付与
- 「糖尿病」→ コード `diabetes` → タグ `chronic_diabetes`

タグ変換ルールは `/settings/integrations/lstep` で設定。

詳細は画面マニュアル「**Lステップ連携**」参照。

---

## 編集・無効化

- カテゴリの統合は事前計画のうえ実施（過去カルテの参照影響）
- 無効化推奨

---

## 関連する画面

- 画面マニュアル「**カルテ**」: 診断入力時に選択
- 画面マニュアル「**Lステップ連携**」: 慢性疾患コード変換
