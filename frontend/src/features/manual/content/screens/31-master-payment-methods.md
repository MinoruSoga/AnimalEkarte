# 支払方法マスタ

## どんな画面か

会計時に選択する **支払方法の種別** を管理するマスタです。現金・クレジット・電子マネー等、扱う決済種別を定義します。

## 開き方

サイドバー「**マスタ設定**」→「**支払方法**」

## 一覧の表示項目

- **支払方法名**: 現金 / クレジットカード / 電子マネー / 未収金 等
- **集計分類**: 現金系 / カード系 / その他
- **表示順**
- **有効/無効**

---

## 既定の支払方法

導入時に以下が登録されていることが多い：

- 現金
- クレジットカード
- 電子マネー（PayPay / Suica 等）
- デビットカード
- 振込
- 未収金（後払い扱い）

---

## 新規支払方法の追加

1. 「**新規追加**」ボタン
2. 情報入力：

   | 項目       | 必須 | 内容                       |
   | ---------- | ---- | -------------------------- |
   | 支払方法名 | ✅   | 例「QR コード決済」        |
   | 集計分類   | ✅   | 現金系 / カード系 / その他 |
   | 表示順     | 任意 | 数値（小さいほど上）       |

3. 「**保存**」

### 登録後

- 会計画面の「支払方法」プルダウンに表示される
- 月次集計の「支払方法別内訳」にカテゴリ別表示

---

## 「未収金」を有効化する

「未収金」がプルダウンに表示されない場合、このマスタで登録が必要です。

登録例：

- 支払方法名: 「未収金」
- 集計分類: その他

→ 会計画面の支払方法選択肢に「未収金」が表示されるようになります。

---

## 編集・無効化

- 表示順の変更: プルダウンの並び順を変更
- 廃止する決済方法: 「有効」スイッチ OFF（過去会計の参照は維持）

---

## 関連する画面

- 画面マニュアル「**会計**」: 支払方法選択
- 画面マニュアル「**月次集計レポート**」: 支払方法別内訳
- 画面マニュアル「**レジ締め**」: 現金以外は理論残高に影響しない
