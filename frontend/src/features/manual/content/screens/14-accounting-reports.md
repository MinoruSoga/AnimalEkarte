# 月次集計レポート

## どんな画面か

月単位または任意期間の売上・支払内訳・消費税・日次推移を表示し、CSV・印刷（PDF）する画面です。

## 開き方

サイドバー「**月次集計レポート**」→ URL: `/accounting/reports`

## 集計の前提

- 会計の完了データ（`completed_at` 等）を期間で集計します
- 日次明細の **AM 締 / PM 締** 列は、レジ締め（`/accounting/close`）の実行有無を示します
- 返金は発生日の負値として部門×支払マトリクスに載る契約です（KPI の純売上定義と一致しない場合があり得ます）

## 期間を指定する

上部の集計単位で切り替えます。

| 単位 | 入力 |
|------|------|
| 月次 | 年・月 |
| 期間指定 | 開始日・終了日 |

選ぶとデータが読み込まれて表示されます。

> 四半期／半期／年の専用プリセット UI を前提にした操作は不要です。年単位や四半期が必要な場合は期間指定で日付を入れます。

---

## 表示される情報

| ゾーン | 内容 |
|--------|------|
| 日次明細 | 日付・曜日・午前／午後の件数と売上・日計・返金・AM 締／PM 締 |
| KPI | 診療日数・会計件数・売上合計（返金併記）・純売上 |
| 内訳 | 支払方法別・部門別・消費税（税率ごと。医院設定閲覧権限がある場合は税率設定リンク） |
| 部門×支払方法統合表 | カテゴリ×支払方法の 1 表（割引適用後の支払実額基準） |

AM/PM いずれかが締め済みの行は、レジ締め閲覧権限がある場合に締め履歴（`/accounting/close/history`）へドリルダウンできます。

---

## CSV で出力する

ヘッダーの「**CSV出力**」から、表示中の集計期間の CSV をダウンロードします。

- Excel で開いても文字化けしにくい形式です
- 外部会計ソフトへの取込補助として使えます

---

## 印刷 / PDF

ヘッダーの「**印刷 / PDF出力**」からブラウザ印刷します。

推奨: A4 横向き。印刷面は画面と同じ集計データを描画します。

---

## 表示されない時の確認点

| 症状 | 確認 |
|------|------|
| データの取得に失敗 | ネットワーク・サーバー・権限 |
| 集計が 0 | 期間内に精算済会計があるか |
| AM/PM 締が未 | `/accounting/close` で該当区分を締めたか |
| 権限エラー | `accounting-reports:view` があるか |

---

## 必要な権限

- 画面の閲覧: `accounting-reports:view`（経理・管理者向け）
- 締め履歴へのドリルダウン: 加えて `cash-register-close:view`

---

## 関連する画面

| 画面 | 関係 |
|------|------|
| レジ締め（`/accounting/close`） | 日次締め |
| 締め履歴（`/accounting/close/history`） | 日次明細からの遷移先 |
| 集計・分析（`/aggregation`） | 飼主単位の LTV／来院分析 |
| 会計管理（`/accounting`） | 明細の元データ |
