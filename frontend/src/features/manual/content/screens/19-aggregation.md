# 集計・分析

## どんな画面か

飼主単位の **売上（LTV）・来院回数・最終来院** を集計し、上位飼主や離脱懸念の飼主を抽出する画面です。画面上のタイトルは「**顧客集計ダッシュボード**」です。

## 開き方

サイドバー「**集計・分析**」→ URL: `/aggregation`

## 画面イメージ

![集計・分析 画面](images/19-aggregation.png)

## 画面の見方

### タブ

| タブ           | 内容                               |
| -------------- | ---------------------------------- |
| 売上ランキング | 期間内売上の大きい順（既定）       |
| 来院回数       | 期間内来院回数の多い順             |
| 最終来院       | 最終来院が古い順（離脱懸念の抽出） |

タブごとにフィルタパネルがあり、金額基準（売上総額／入金額／返金控除後）や期間プリセットを切り替えられます。

### CPM セグメント

画面上部に CPM ステージ別人数サマリー（チップ）が出ます。クリックで一覧を絞り込めます。

| セグメント              | 意味の目安       |
| ----------------------- | ---------------- |
| Encounter（初回・新規） | 初診から間もない |
| Growing（成長中）       | 定着し始め       |
| Core（コア顧客）        | 安定通院         |
| Spot（単発高額）        | 単回高額後の途絶 |
| Noah（最上位）          | 高貢献           |
| Dormant（休眠）         | 長期未来院       |

本画面の判定は **CPM V1 方式**（金額と期間の多次元）です。医院の CPM バージョン設定が V2 でも、このダッシュボードの 6 区分表示は切り替わりません。V2 の回数階層は Lステップタグ同期側で使われます。

> 「90 日以内＝アクティブ」のような固定日数セグメント表は、本画面の正本ではありません。閾値は Lステップ連携設定や実装ロジックに依存します。

---

## 集計結果を見る

一覧テーブル（チェックボックス付き）に対象飼主が並びます。

- 共通: 飼主名、CPM セグメント
- タブ別: 年間診療費・会計件数、来院回数、最終来院日・経過日数など

絞り込み・並び替えを変えると集計が再計算されます。

---

## 飼主を選択する / CSV 出力

1. 行のチェック、または全選択で対象を選びます。
2. 「**CSV出力**」でダウンロードします。

未選択時は出力できません。UTF-8 BOM 付きで Excel でも文字化けしにくい形式です。

---

## 飼主詳細に遷移する

飼主名をクリックすると `/owners/:id` の飼主詳細へ遷移し、カルテ・会計履歴を確認できます。

---

## Lステップとの関係

- 休眠・来院間隔などのタグ付与は Lステップ連携のバッチ／同期側で行われます
- 本画面は分析・抽出が主目的です。タグの自動付与条件の詳細は連携設定と業務フロー「Lステップ連携の設定とタグ運用」を参照してください
- Lステップ Write API が一時停止中の環境では、内部タグキャッシュは更新されても外部タグが変わらない場合があります

---

## 必要な権限

- 画面を見る: `owners:view`（サイドバーも同じリソースで表示制御）
