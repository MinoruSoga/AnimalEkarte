# 薬剤マスタ

## どんな画面か

院内で **処方・使用する医薬品の登録・編集** を行うマスタです。カルテの処方欄で選択する薬剤の元データになります。

## 開き方

サイドバー「**マスタ設定**」→「**カルテ関連**」→「**薬剤マスタ**」

## 画面の見方

### 一覧の表示項目

- **薬剤名**: 一般名・商品名
- **略称**
- **剤形**: 錠剤 / 液剤 / 粉末 / 注射薬 等
- **最小単位**: 1 錠 / 1 mL / 1 g 等
- **税込単価**
- **在庫紐付け**: ありかなしか
- **有効/無効**

### 検索

- 一般名・商品名・略称で検索

---

## 新規薬剤を登録する

1. 画面右上の「**新規追加**」ボタンをクリックします。
2. 薬剤情報を入力します：

   | 項目               | 必須 | 内容                           |
   | ------------------ | ---- | ------------------------------ |
   | 一般名             | ✅   | 薬剤の正式名称                 |
   | 商品名             | 任意 | 商標名                         |
   | 略称               | 任意 | カルテ表示用                   |
   | 剤形               | ✅   | 錠剤 / 液剤 / 粉末 / 注射薬 等 |
   | 最小単位           | ✅   | 「1錠」「1mL」等               |
   | 税込単価           | ✅   | 最小単位あたりの価格           |
   | 在庫アイテム紐付け | 任意 | 在庫マスタから選択             |
   | 用法デフォルト     | 任意 | カルテ処方時の初期値           |
   | 警告メモ           | 任意 | アレルギー注意等               |

3. 「**保存**」ボタンをクリックします。

### 登録すると

- 薬剤が保存されます
- カルテの処方タブで選択肢として表示されます
- 在庫紐付けがあれば、カルテ確定時に自動減算されます

---

## 在庫紐付け（重要）

薬剤マスタと **在庫管理** のアイテムを接続します。

例：

- 薬剤「アモキシシリン 250mg錠」 → 在庫「アモキシシリン 250mg 100錠瓶」

接続すると：

- カルテで処方確定時、在庫が自動減算される
- 取消時に在庫が自動で戻る
- 在庫切れの警告が表示される

> 在庫紐付けがないと自動減算は機能しません。

---

## 用法デフォルトの設定

「**用法デフォルト**」に標準的な用法を設定しておくと、カルテで処方する時に自動入力されます。

例：

- 「1日 2回 朝晩 食後」
- 「症状時のみ」

カルテで個別に変更も可能。

---

## 薬剤を編集する

1. 一覧で該当薬剤をクリックします。
2. サイドパネルで項目を変更します。
3. 「**保存**」をクリックします。

### 単価変更の影響

- 過去の処方・会計には影響しません
- 今後の処方時から新単価が適用されます

---

## 薬剤を無効化する

廃番・取扱中止になった薬剤を非表示にします。

1. 該当薬剤を開きます。
2. 「**有効**」スイッチを OFF にします。
3. 「**保存**」をクリックします。

### 無効化すると

- カルテの処方選択肢から消えます
- 過去の処方履歴からは引き続き参照されます

---

## アレルギー警告

薬剤マスタに「**警告メモ**」を設定すると、カルテで該当薬剤を選択時にメッセージが表示されます。

例：

- 「ペニシリン系アレルギー注意」
- 「猫には禁忌」

ペットマスタにアレルギー情報がある場合、警告がより目立つように表示されます（実装による）。

---

## 必要な権限

- 画面を見る → カルテマスタの閲覧権限
- 編集 → カルテマスタの編集権限

---

## 関連する画面

| 画面         | 関係                   |
| ------------ | ---------------------- |
| カルテ       | 処方で薬剤を選択       |
| 入院・ホテル | 投薬実施記録で選択     |
| 在庫管理     | 在庫紐付け先           |
| 予防接種     | ワクチンマスタは別画面 |
