## 画面の関係図

主要な画面の連動関係です。

```
 ┌──────────────┐
 │  飼主・ペット  │
 └───────┬──────┘
         │ 飼主・ペット登録
         ↓
 ┌──────────────┐    ┌──────────────┐
 │  予約管理    │ →  │  当日の受付  │
 └──────────────┘    └───────┬──────┘
                            │ ペット名クリック
                            ↓
                     ┌──────────────┐
                     │   カルテ     │
                     └───────┬──────┘
                            │ 検査が必要なら
                            ↓
                     ┌──────────────┐
                     │   検査管理   │
                     └───────┬──────┘
                            │ カルテ確定で自動作成
                            ↓
                     ┌──────────────┐
                     │   会計       │ → 領収書 PDF
                     └───────┬──────┘
                            │ 1 日の終わりに
                            ↓
                     ┌──────────────┐
                     │   レジ締め   │ → 月次集計レポートに反映
                     └──────────────┘
```

ポイント：

- **カルテを確定すると会計が自動で作られます**（手動作成不要）
- **会計を確定すると受付ステータスが自動で「会計済」になります**
- **レジ締めをすると、その日の会計は編集できなくなります**

| 項目                    | 内容                                   |

## 用語解説

マニュアルや画面に出てくる略語・専門用語の意味です。

### LINE / Lステップ関連

| 用語            | 意味                                                                                         |
| --------------- | -------------------------------------------------------------------------------------------- |
| **LINE**        | LINE 公式アカウントによる予約受付・メッセージ配信                                            |
| **Lステップ**   | LINE の自動配信ツール。タグに応じて飼主にメッセージを自動送信します                          |
| **LIFF ID**     | LINE が発行するアプリの識別子                                                                |
| **タグ**        | 飼主の状態を分類するラベル（例: 「初診」「休眠予防」「期限間近」）                           |
| **CPM**         | 飼主のセグメント区分（出会い / 良好 / ファミリー / NOAH 等）。来院数や売上で自動分類されます |
| **LTV**         | 累計売上（Life Time Value）。その飼主が今までに支払った金額の合計                            |
| **EXCL**        | 配信除外フラグ。LINE 配信エラーが続いた飼主に自動付与されます                                |
| **休眠**        | 一定期間来院がない飼主の状態（180 / 210 / 240 / 365 日経過で区分）                           |
| **CPM V1 / V2** | CPM 集計ロジックのバージョン。設定で切替できます                                             |

### システム関連

| 用語           | 意味                                                                  |
| -------------- | --------------------------------------------------------------------- |
| **マスタ**     | 事前に登録しておく基本データ（診療項目・薬剤・スタッフ・支払方法 等） |
| **ステータス** | データの状態（例: 受付予約 / 受付済 / 診療中 / 会計待ち / 会計済）    |
| **ロット番号** | 医薬品・ワクチンの製造番号。副反応追跡のため必要                      |
| **ケージ**     | 入院・ホテルでペットを収容する箱                                      |

### 会計関連

| 用語       | 意味                                               |
| ---------- | -------------------------------------------------- |
| **未収金** | その場で支払いが終わらず、後払いになった会計       |
| **取消**   | 確定済みの会計を無効化すること（編集ではなく取消） |
| **締め**   | その日の会計を集計し、翌日以降の編集を禁止する処理 |

## よくある質問

### Q. 会計に明細が出てこない

**A.** 紐付くカルテが「作成中」のままです。カルテ画面で「確定」ボタンを押すと、自動的に会計に明細が入ります。

### Q. 確定した会計を直したい

**A.** 直接編集はできません。「取消」ボタンで取消して、新しく作り直してください。

### Q. レジ締めの「締め確定」ボタンが押せない

**A.** その日に「会計待ち」のままの会計が残っています。会計管理画面で全件確定してから締めてください。

### Q. 物販の在庫が減らない

**A.** マスタ設定で物販と在庫アイテムの紐付けがされていません。管理者に依頼してください。

### Q. 過去のカルテが見つからない

**A.** 別の医院に登録されている可能性があります。サイドバー上部の医院名から切替できます。

### Q. ログインできない

**A.** 同一 IP からのログインは 5 回 / 1 分までに制限されます。超過時は **約 1 分待って再試行** してください（アカウント単位のロックや解除操作はありません）。パスワード忘れはログイン画面の「パスワードをお忘れですか？」から再設定できます。続く場合は管理者にアカウントの有効/無効を確認してもらってください。詳細は画面マニュアル「**ログイン**」を参照。

### Q. 画面が真っ白で動かない

**A.** ブラウザを再読み込みしてください（Cmd/Ctrl + R）。それでも解決しない場合は管理者・サポートに連絡してください。

詳しいトラブル対応は業務フロー「エラー・トラブル対応」を参照してください。

## 基本的な操作

- **ログイン**: メールアドレスとパスワードでログインします
- **画面の切替**: 左サイドバーのメニューから機能を選択します
- **複数医院をご利用の場合**: サイドバー上部の医院名から切替できます（権限のある医院のみ表示）
- **ログアウト**: サイドバー左下の「ログアウト」アイコン
- **パスワード変更**: サイドバー左下の鍵アイコン
