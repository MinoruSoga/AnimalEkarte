# トリミング

## どんな画面か

トリミング予約・施術・完了管理の画面です。完了処理で会計が自動で作られます。

## 開き方

サイドバー左メニューの「**トリミング**」をクリックします。

## 画面イメージ

![トリミング 画面](images/10-trimming.png)

## 画面の見方

### 一覧の表示項目

- **診療日**
- **飼主名・ペット名**
- **種**: 動物種
- **体重**
- **スタイル希望**
- **担当**: トリマー
- **ステータス**: 予約 / 進行中 / 完了 / キャンセル

---

## 新規トリミングを登録する

1. 画面右上の「**新規登録**」ボタンをクリックします。
2. ペットを検索・選択します。
3. トリミング情報を入力します：

   | 項目 | 必須 | 内容 |
   |------|---|------|
   | 実施日時 | ✅ | |
   | コース | ✅ | マスタから選択 |
   | オプション | 任意 | 複数選択可 |
   | 担当トリマー | ✅ | スタッフから選択 |
   | 預かり時間 | 任意 | |
   | お渡し時間 | 任意 | |
   | 特記事項 | 任意 | |

4. 「**登録**」ボタンをクリックします。

### 登録すると

- トリミング記録が保存されます
- ステータスが「**予約**」になります

---

## ステータスを進める

| 現在 | 操作 | 次 |
|------|------|---|
| 予約 | 「開始」ボタン | 進行中 |
| 進行中 | 「完了」ボタン | 完了 |
| 任意 | 「キャンセル」 | キャンセル |

### 「完了」ボタンを押すと

- ステータスが「**完了**」になります
- 完了時刻が記録されます
- **会計が自動で作られます**（「会計待ち」状態）
  - 明細: コース単価 + オプション単価 + 消耗品

---

## 施術前後の画像を添付する

トリミング詳細画面の「**画像添付**」ボタンから、施術前後の写真をアップロードできます。

### 添付すると

- 画像がアップロードされます
- サムネイルが表示されます

---

## 必要な権限

- 画面を見る → 閲覧権限
- 新規・編集 → 編集権限
