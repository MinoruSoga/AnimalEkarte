# トリミング

## どんな画面か

トリミングの予約・施術内容・進捗を管理する画面です。コース・オプション・スタイル・画像を記録し、会計時に未請求明細として取り込まれます。

## 開き方

サイドバー「**トリミング**」→ URL: `/trimming`

関連 URL:

| 用途       | URL                    |
| ---------- | ---------------------- |
| 一覧       | `/trimming`            |
| ペット選択 | `/trimming/select-pet` |
| 新規       | `/trimming/new`        |
| 詳細・編集 | `/trimming/:id`        |

当日の受付（`/`）や予約管理（`/reservations`）の詳細からも作成を開始できます。

## 画面の見方

### 一覧の表示項目

- **診療日**
- **飼主名・ペット名・種・犬種**
- **体重**
- **スタイル希望**
- **担当**（トリマー）
- **ステータス**: **予約** / **進行中** / **完了**

絞り込み: 施術日・ステータス・動物種・担当・全文検索。

## 新規トリミングを登録する

1. 「**新規登録**」（`trimming:create`）をクリックします。
2. ペットを選択します。
3. 次を入力します。

   | 項目                   | 必須             | 内容                         |
   | ---------------------- | ---------------- | ---------------------------- |
   | 登録時ステータス       | 新規のみ         | **進行中**（既定）／**予約** |
   | コース                 | ✅               | マスタから選択（価格表示）   |
   | オプション             | 任意             | 複数選択可（価格表示）       |
   | スタイル要望           | 任意             | 飼主からの指示               |
   | 体重・体温             | 任意             | BW / BT                      |
   | 使用シャンプー・リボン | 任意             |                              |
   | 担当スタッフ           | 画面の入力に従う |                              |
   | 備考                   | 任意             | 皮膚の気づきなど             |

4. 保存します。

予約カレンダーで作ったトリミング枠は、一覧に **予約** ステータスとして現れる場合があります。

### 前回のカルテをコピーする（過去履歴の引用）

前回と同じコース・スタイルで施術する場合、過去の記録をワンクリックで現在のフォームへ取り込めます。

1. トリミングの新規登録（または編集）画面を開きます。
2. 画面右側の「**過去の施術履歴**」パネルに、このペットの過去の施術がカードで一覧表示されます。
3. 必要に応じて絞り込みます。

   | 絞り込み     | 内容                                                   |
   | ------------ | ------------------------------------------------------ |
   | 検索単語     | スタイル希望の文言で検索（ひらがな・カタカナ不問）     |
   | 並び順       | 「新→古」/「古→新」                                    |
   | 実施日       | 開始日〜終了日で期間を指定                             |
   | クリア       | すべての絞り込みを解除                                 |

4. 取り込みたい履歴のカードをクリックします。
5. フォームに内容が反映されます。当日の体重・担当などを入力・調整し、「**登録**」（または「**更新**」）で保存します。

クリック時にフォームへ反映される項目：

| 反映される                     | 反映されない（当日の入力が必要） |
| ------------------------------ | ------------------------------ |
| コース                         | 体重（BW）・体温（BT）         |
| オプション                     | 画像（希望スタイル・完成）     |
| スタイル要望                   | 日付・ステータス・次回予定日   |
| 使用シャンプー・使用リボン     | 担当者の確定選択               |
| 備考                           |                                |
| 前回の担当者名（表示のみ）     |                                |

> ⚠️ **担当者名について**: 履歴をクリックすると前回の担当者名が「担当医」欄に表示されますが、担当者の選択自体はコピーされません。保存の前に必ず「担当医」欄から担当者を選択して確定してください（前回と同じ担当なら、選択画面でその名前が最初からハイライトされています）。

## ステータスを進める

一覧・詳細で進捗を更新します（編集権限が必要）。

| 状態   | 意味     |
| ------ | -------- |
| 予約   | 施術前   |
| 進行中 | 施術中   |
| 完了   | 施術完了 |

削除は `trimming:delete` 権限がある場合、確認ダイアログ経由で行えます。

### 完了と会計の関係（重要）

- 施術完了を契機に **会計ドラフトが自動 push される仕組みではありません**
- 予約が **会計待ち（accounting）** になったあと、会計画面（`/accounting/new`）を開くと、コース・オプションが **未請求明細** として取り込まれます
- 同日の診察処置とまとめて 1 会計に統合できます

---

## 画像を添付する

- **希望スタイル画像**: 飼主の参考写真
- **完成画像**: 仕上がり写真

詳細フォームの画像欄からアップロードします。

## 必要な権限

| 操作       | 権限の目安        |
| ---------- | ----------------- |
| 画面を見る | `trimming:view`   |
| 新規       | `trimming:create` |
| 編集       | `trimming:edit`   |
| 削除       | `trimming:delete` |
