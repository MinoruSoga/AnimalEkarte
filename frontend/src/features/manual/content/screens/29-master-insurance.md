# 保険マスタ

## どんな画面か

**ペット保険会社** を登録・管理するマスタです。会計画面で保険適用する際の選択肢になります。

## 開き方

サイドバー「**マスタ設定**」→「**保険マスタ**」

## 一覧の表示項目

- **保険会社名**: アニコム / アイペット 等
- **適用率パターン**: 50% / 70% / 100% 等
- **連絡先**: 電話番号・問い合わせ窓口
- **書類フォーマット**: 専用書類の要件
- **有効/無効**

---

## 新規保険会社の登録

1. 「**新規追加**」ボタン
2. 保険情報を入力：

   | 項目           | 必須 | 内容                          |
   | -------------- | ---- | ----------------------------- |
   | 保険会社名     | ✅   |                               |
   | 適用率パターン | ✅   | 複数選択可（50%/70%/100% 等） |
   | 連絡先         | 任意 | 電話番号                      |
   | 担当者         | 任意 |                               |
   | 書類要件メモ   | 任意 | 院長サイン・医院印等          |
   | 注意事項       | 任意 |                               |

3. 「**保存**」

---

## 保険適用の流れ

### 会計時

1. 飼主から保険証を提示してもらう
2. 会計画面の「**保険適用**」タブを開く
3. 保険会社を選択
4. 適用率を選択（例: 70%）
5. 対象明細にチェック
6. 控除額・飼主負担額が自動計算

### 書類対応

- 保険会社ごとに必要書類が異なる
- 院長サイン・医院印が必要な場合あり
- 「**書類要件メモ**」欄に記載しておくと参考になる

詳細は画面マニュアル「**会計**」参照。

---

## 飼主・ペットマスタへの紐付け

会計時に毎回保険選択するのが面倒な場合：

- 飼主・ペット詳細画面で「**契約保険**」を設定可能（実装による）
- 設定すると、その飼主・ペットの会計時に自動的に保険選択肢が表示される

---

## 編集・無効化

- 適用率変更: 過去会計には影響しない、今後の保険適用から反映
- 無効化: 過去会計の参照は維持、新規選択肢から消える

---

## 関連する画面

- 画面マニュアル「**会計**」: 保険適用の操作
- 画面マニュアル「**飼主・ペット管理**」: 飼主単位の保険登録
