# 同一飼主・ペット連携

## どんな画面か

重複して登録された飼主・ペットのレコードを、同一のものとして手動で連携（リンク）する画面です。所属医院内のレコードのみが対象で、権限のない医院のデータはサーバ側で拒否されます。

## 開き方

サイドバー左メニューの「**同一飼主・ペット連携**」をクリックします。

## 画面イメージ

![同一飼主・ペット連携 画面](images/42-identity-links.png)

## 画面の構成

| セクション   | 内容                                                     |
| ------------ | -------------------------------------------------------- |
| 飼主リンク   | 飼主の検索・選択と、連携グループへのリンク・解除           |
| ペットリンク | ペットの検索・選択と、連携グループへのリンク・解除・履歴参照 |

各セクションには「**検索**」欄と検索候補の一覧、選択中のレコードを示す「**選択:**」行、操作ボタンが並びます。選択したレコードが既存の連携グループに属している場合は「**連携グループ #番号**」も表示されます。

> 「**ペットリンク**」の利用には、親となる飼主の連携グループが先に必要です。飼主グループが未作成の場合、「**ペットをリンク**」ボタンは有効になりません。

---

## 飼主をリンクする

重複レコードを同一の連携グループにまとめる操作です。

1. 「**飼主リンク**」の検索欄に氏名・カナ・電話の一部を入力します。
2. 候補一覧から連携したい飼主をクリックして選択します（複数選択可）。「**選択:**」行に選んだ ID が並びます。
3. 2件以上選択すると「**飼主をリンク**」が有効になるのでクリックします。

## ペットをリンクする

1. 先に「飼主リンク」で、親となる飼主の連携グループを作成しておきます。
2. 「**ペットリンク**」の検索欄にペット名・番号を入力し、候補からペットを複数選択します。
3. 「**ペットをリンク**」をクリックします。

## 連携を解除する

誤ってリンクした場合の操作です。

1. 検索で対象のレコードを選択します（連携グループに所属しているレコード）。
2. 選択中のレコードごとに表示される「**連携解除**」ボタンをクリックします。グループに属していないレコードの解除ボタンは無効です。

## 連携履歴を見る

「**ペットリンク**」でペットを選択すると「**連携履歴**」ボタンが表示され、クリックで過去のリンク・解除履歴が一覧の下に表示されます。

---

## 必要な権限

- 画面を見る → `identity-links` の閲覧権限（権限がない場合はホームへリダイレクト）
- リンク・解除 → `identity-links` の編集権限（閲覧のみの場合は「閲覧のみ」の表示が出て操作ボタンは非表示）
