# 同一飼主・ペット連携

## どんな画面か

重複して登録された飼主・ペットのレコードを、同一のものとして手動で連携（リンク）する画面です。所属医院内のレコードのみが対象で、権限のない医院のデータはサーバ側で拒否されます。

## 開き方

サイドバー左メニューの「**同一飼主・ペット連携**」をクリックします。

## 画面の構成

| セクション     | 内容                                           |
| -------------- | ---------------------------------------------- |
| 飼主の連携     | 飼主レコードの連携グループの確認・リンク・解除   |
| ペットの連携   | ペットレコードの連携グループの確認・リンク・解除 |

各セクションでは、連携済みのグループ（連携グループ #番号）と、メンバーごとの「**連携解除**」ボタン・「**連携履歴**」が表示されます。

---

## 飼主・ペットをリンクする

重複レコードを同一の連携グループにまとめる操作です。

1. 「**飼主をリンク**」または「**ペットをリンク**」ボタンをクリックします。
2. 連携したいレコードを選択します。
3. 同一グループにリンクされます。

## 連携を解除する

誤ってリンクした場合の操作です。

1. 連携済みグループ内の該当メンバーの「**連携解除**」ボタンをクリックします。
2. そのメンバーがグループから外れます。

## 連携履歴を見る

「**連携履歴**」から、過去のリンク・解除の履歴を確認できます。

---

## 必要な権限

- 画面を見る → `identity-links` の閲覧権限
- リンク・解除 → `identity-links` の編集権限
