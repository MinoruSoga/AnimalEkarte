# 見積書管理

## どんな画面か

会計前に **見積書** を作成・発行する画面です。手術や長期入院など、事前に金額を提示する必要がある時に使用します。

## 開き方

> ⚠️ この画面はサイドバーには表示されていません。直接 URL（`/estimates`）でアクセスするか、関連する画面から遷移する必要があります。

ブラウザのアドレス欄に以下を入力してアクセスします：

```
（システムのURL）/estimates
```

頻繁に使う場合は、ブラウザのブックマークに登録しておくのがおすすめです。

## 画面の見方

### 一覧の表示項目

- **見積番号**: 自動採番される識別番号
- **タイトル**: 見積書の件名（例: 手術費用見積）
- **飼主名**
- **有効期限**: 見積書の有効期限
- **合計金額**: 税込合計
- **ステータス**: 作成中 / 提出済 / 承認済 / 期限切れ など

### 絞り込みと検索

- 検索: 見積番号・タイトル・飼主名で検索
- フィルタ: ステータス・有効期限など

---

## 新規見積書を作成する

1. 画面右上の「**新規見積書登録**」ボタンをクリックします。
2. 見積書情報を入力します：

   | 項目         | 必須 | 内容                        |
   | ------------ | ---- | --------------------------- |
   | 飼主・ペット | ✅   | 検索選択                    |
   | タイトル     | ✅   | 見積書の件名                |
   | 有効期限     | ✅   | 日付                        |
   | 見積明細     | ✅   | 品目・数量・単価を 1 行以上 |
   | 備考         | 任意 | 飼主への注記                |

3. 「**登録**」ボタンをクリックします。

### 登録すると

- 見積書が保存されます
- 見積番号が自動採番されます
- 一覧に追加されます

---

## 見積書を編集する

1. 一覧で該当行をクリックして詳細画面を開きます。
2. 「**編集**」ボタンをクリックします。
3. 各項目を変更します。
4. 「**保存**」をクリックします。

---

## 見積書を印刷・PDF 出力する

1. 該当見積書の詳細画面を開きます。
2. 「**印刷**」または「**PDF**」ボタンをクリックします。
3. 飼主にお渡しする見積書 PDF が生成されます。

---

## 見積書を会計に変換する

見積書を提示した後、飼主が承諾して施術 → 会計に進む場合：

1. 該当見積書の詳細画面を開きます。
2. 「**会計に転送**」または「**会計を作成**」ボタンをクリックします（実装による）。
3. 見積内容を元に新規会計が作成されます。
4. 通常の会計確定の手順で進めます。

> 💡 直接「会計画面」で新規作成 + 同じ内容を再入力する方法もあります。

---

## 見積書を削除する

1. 一覧の該当行で操作メニュー → 「**削除**」をクリックします。
2. 確認ダイアログで「削除する」を選びます。

### 削除すると

- 見積書が削除されます
- ただし、既に飼主に提示済みの場合は **キャンセル状態** とすることが推奨されます

---

## 必要な権限

- 画面を見る → 見積書の閲覧権限
- 新規作成・編集 → 見積書の編集権限

---
