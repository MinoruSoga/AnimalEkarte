# 入院プランマスタ

## どんな画面か

入院・ペットホテルの **料金プラン** を管理するマスタです。退院処理時の会計に自動連動します。

## 開き方

サイドバー「**マスタ設定**」→「**入院・ケージ**」（同画面内に入院プランタブ）

## 一覧の表示項目

- **プラン名**: 「通常入院」「ICU 入院」「ペットホテル」等
- **動物種**: 犬 / 猫 / 共通
- **体格区分**: 小型 / 中型 / 大型
- **日額（税込）**
- **食事代の取扱**: 含む / 別途
- **有効/無効**

---

## 新規プランの登録

1. 「**新規追加**」ボタン
2. プラン情報を入力：

   | 項目         | 必須 | 内容                         |
   | ------------ | ---- | ---------------------------- |
   | プラン名     | ✅   |                              |
   | 入院区分     | ✅   | 入院 / ペットホテル / 預かり |
   | 動物種       | ✅   | 犬 / 猫 / 共通               |
   | 体格区分     | ✅   | 小型 / 中型 / 大型           |
   | 日額（税込） | ✅   |                              |
   | 食事代       | 任意 | 別途請求の場合の単価         |

3. 「**保存**」

---

## 料金体系の例

| プラン                 | 体格 | 日額    |
| ---------------------- | ---- | ------- |
| 通常入院（犬）         | 小型 | ¥3,500  |
| 通常入院（犬）         | 中型 | ¥5,000  |
| 通常入院（犬）         | 大型 | ¥7,000  |
| ICU 入院               | 共通 | ¥10,000 |
| ペットホテル（犬・猫） | 共通 | ¥4,000  |

---

## 入院会計への自動連動

退院処理時、システムが以下を自動計算：

- 入院日数 × プラン日額 = 入院費小計
- 食事代別途の場合: 日数 × 食事代を追加
- ケア中の処置・投薬・物販を加算

詳細は業務フロー「**入院の登録から退院・会計まで**」参照。

---

## 単価変更の影響

- 過去の入院・会計には影響しない
- 入院中（未退院）の場合、退院時の日額に反映される

---

## 関連する画面

- 画面マニュアル「**入院・ホテル**」: 入院登録時にプランを選択
- 画面マニュアル「**ケージマスタ**」: 同マスタ画面内
- 画面マニュアル「**会計**」: 入院会計の確認
