# 割引キャンペーンマスタ

期間限定の **割引キャンペーン**（例: 初回割引・シーズンキャンペーン）を管理するマスタです。会計画面の割引選択肢に反映されます。

## 開き方

サイドバー「**マスタ設定**」→「**割引キャンペーン**」をクリックします。

## 画面イメージ

![割引キャンペーンマスタ 画面](images/45-master-campaigns.png)

## キャンペーンを登録する

1. 「**新規登録**」ボタンをクリックすると右側に編集パネルが開きます。
2. キャンペーン情報を入力します：

   | 項目             | 内容                                          |
   | ---------------- | --------------------------------------------- |
   | 名称             | 例: 「初回診察10%OFF」                         |
   | 開始日・終了日   | キャンペーン期間                               |
   | 割引種別         | 割引率（%）または割引額（円）                  |
   | 割引率/割引額    | 種別に応じて「割引率(%)」または「割引額(円)」を入力 |
   | 対象カテゴリ     | 割引対象のカテゴリを限定する場合に選択         |
   | 対象商品         | 割引対象の商品を限定する場合に選択             |

3. 「**保存**」をクリックします。

## 編集・削除・無効化する

一覧の該当行をクリックすると編集パネルが開きます。内容の変更・有効/無効の切替・削除ができ、変更後は「**保存**」をクリックします。

---

## 必要な権限

- 画面を見る → `accounting` の閲覧権限
- 登録・編集・削除 → `accounting` の編集権限
