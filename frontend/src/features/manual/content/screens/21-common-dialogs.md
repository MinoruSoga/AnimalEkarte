# 共通の UI 機能・ダイアログ

## どんな画面か

特定の画面ではなく、**システム全体で共通して表示される画面要素・ダイアログ** の解説です。複数の画面で同じ操作・表示が使われています。

---

## 患者情報カード（ペット情報の表示）

カルテ・検査・入院・トリミング・予防接種など、ペット単位の画面の **最上部** に常駐する「ペット基本情報」カードです。

### 表示される情報

- ペット名・動物種・品種
- 年齢・性別・最新体重
- 担当医・保険会社
- LINE 連携状態

### 重要なアラート（バッジ表示）

以下の情報があると、目立つバッジで警告されます：

| バッジ           | 意味                               | 対応                             |
| ---------------- | ---------------------------------- | -------------------------------- |
| **死亡**         | 死亡したペットの過去カルテを表示中 | 新規操作不可。過去履歴の参照のみ |
| **慢性疾患**     | 慢性疾患の記録あり                 | 投薬・処置の選択時に注意         |
| **狂犬病未接種** | 法定接種が未実施                   | 飼主に接種を案内                 |
| **アレルギー**   | アレルギー情報あり                 | 薬剤選択時に注意                 |

## 飼主の付け替え

患者情報カードの **飼主名をクリック** すると、飼主検索モーダルが開きます。

### 用途

- 誤って別の飼主に紐付けてしまった
- 家族間でペットを譲渡した
- 婚姻・離婚等で飼主名が変わった

### 操作手順

1. 患者情報カードで飼主名をクリック
2. 飼主検索モーダルが開く
3. 検索ボックスに新しい飼主名・電話番号を入力
4. 候補から選択

### ⚠️ 警告ダイアログ

新しい飼主の **会員区分・割引率が異なる場合**、警告ダイアログが表示されます：

> 割引率・会員区分が変わる可能性があります

- 「**変更を適用**」: 新飼主の割引率で再計算
- 「**キャンセル**」: 変更を取り消す

---

## 担当医の変更

患者情報カードの **担当医名をクリック** すると、スタッフ選択モーダルが開きます。

### 操作手順

1. 担当医名をクリック
2. スタッフ選択モーダルが開く
3. その日に出勤しているスタッフ（または全スタッフ）から選択

---

## 離脱防止ガード（未保存変更の警告）

カルテ・会計・飼主情報など、入力フォームに **変更があるのに保存していない状態** で別画面に移動しようとすると、警告ダイアログが表示されます：

> 変更を破棄しますか？

### 表示される操作

- **「離れる」**: 変更を破棄して移動
- **「キャンセル」**: 元の画面に留まる（変更を保持）

### 保存し忘れ防止

このダイアログにより、入力データの **意図しない消失を防止** できます。慌てて別画面に移動しようとした時の安全装置です。

> 💡 ブラウザの「戻る」ボタン押下時も同様の警告が出ます。

---

## 確認ダイアログ（重要操作の前）

以下のような **元に戻せない操作・影響の大きい操作** の前には確認ダイアログが表示されます：

| 操作             | 確認内容                                     |
| ---------------- | -------------------------------------------- |
| 会計の取消       | 「本当に取り消しますか？」                   |
| カルテの確定     | 「確定後は編集できません。よろしいですか？」 |
| 削除操作         | 「削除しますか？元に戻せません」             |
| レジ締めの確定   | 「締めを確定すると編集不可になります」       |
| スタッフの無効化 | 「このスタッフをログイン不可にしますか？」   |

### 操作ボタン

- 確認: 「**取り消す**」「**確定する**」「**削除する**」など（赤色の場合が多い）
- 中止: 「**キャンセル**」

慎重に判断してから確認ボタンを押してください。

## 検索モーダル

ペット選択や飼主選択で使われる、検索用のモーダルウィンドウです。

### 検索方法

- 飼主名（漢字・カナ）
- ペット名
- 電話番号
- 飼主 No・ペット No

### 操作のヒント

- 検索ボックスに 2 文字以上入力すると、リアルタイムに候補が絞り込まれます
- 候補リストから該当する行をクリックして選択
- 「Esc」キーまたは画面外クリックでキャンセル

---

## 一覧画面の共通機能

複数の画面で共通する一覧表示の機能です。

### 検索

画面上部の検索ボックスで絞り込み。リアルタイム検索。

### フィルタを追加

「**フィルタを追加**」ボタンで、画面ごとの絞り込み条件を追加可能。

### 並べ替え

列名をクリックすると、その列で昇順・降順に並べ替え。

### ソート

「**並べ替え**」ボタンで、複数の並べ替え条件を組み合わせ可能。

### ページネーション

- 一覧下部に「**前へ**」「**次へ**」ボタン
- 1 ページあたりの件数表示（既定: 20 件）

---

## アクションメニュー（縦三点ドット）

一覧の各行や画面右上に表示される **縦三点ドット（︙）** をクリックすると、その項目に対する操作メニューが開きます。

例：

- カルテ詳細: 追記 / 印刷 / 削除（権限による）
- 会計詳細: 取消 / 領収書再発行 / 明細書発行
- 受付カード: ステータス変更 / キャンセル / カルテ遷移 / 会計遷移

---

## 通知（トースト）

操作の成功・失敗時、画面右下に **通知（トースト）** が一定時間表示されます。

| 種類   | 色  | 例                           |
| ------ | --- | ---------------------------- |
| 成功   | 緑  | 「保存しました」「登録完了」 |
| 警告   | 黄  | 「在庫が不足しています」     |
| エラー | 赤  | 「保存に失敗しました」       |
| 情報   | 青  | 「同期中です」               |

通知は **数秒で自動的に消えます**。気になる場合はクリックで閉じることもできます。

---

## キーボード操作

| キー                 | 動作                         |
| -------------------- | ---------------------------- |
| Tab                  | 次の入力欄に移動             |
| Shift + Tab          | 前の入力欄に戻る             |
| Enter                | フォーム送信・確定           |
| Esc                  | モーダル・ダイアログを閉じる |
| Cmd/Ctrl + P         | ブラウザ印刷                 |
| Cmd/Ctrl + R         | ページ再読み込み             |
| Cmd/Ctrl + Shift + R | キャッシュクリア再読み込み   |

---

## 関連する画面

すべての画面で共通的に使われる機能です。各画面マニュアルでも個別に解説しています。
