# 診療項目マスタ

## どんな画面か

診察・処置・検査・予防接種・定期健診の **項目と価格** を管理するマスタです。カルテで選択する診療項目の元データになります。

## 開き方

サイドバー「**マスタ設定**」→「**カルテ関連**」→「**診療項目**」

## 画面の見方

### タブ

| タブ     | 内容                          |
| -------- | ----------------------------- |
| 診察     | 初診・再診など                |
| 検査     | 血液検査・尿検査・画像診断 等 |
| 処置     | 投薬・注射・縫合 等           |
| ワクチン | 各種ワクチン                  |
| 定期健診 | 健診プラン                    |

### 一覧の表示項目

- **項目名**
- **略称**
- **診療コード**
- **税込単価**
- **税区分**: 標準 10% / 軽減 8% / 非課税
- **有効/無効**

### 検索・絞り込み

- 名称・略称・診療コードで検索
- ステータス（有効・無効）で絞り込み

---

## 新規項目を追加する

1. 該当タブを開きます。
2. 画面右上の「**新規追加**」ボタンをクリックします。
3. 項目情報を入力します：

   | 項目               | 必須 | 内容                           |
   | ------------------ | ---- | ------------------------------ |
   | 項目名             | ✅   | 例: 「血液検査（CBC）」        |
   | 略称               | 任意 | 一覧表示用の短い名前           |
   | 診療コード         | 任意 | 内部管理用コード               |
   | 標準単価（税込）   | ✅   | 数値                           |
   | 税区分             | ✅   | 標準 10% / 軽減 8% / 非課税    |
   | 変動価格フラグ     | 任意 | カルテ入力時に価格変更可にする |
   | カルテで選択可能   | 任意 | OFF にすると見積専用           |
   | 見積専用項目       | 任意 | 見積書のみで使用               |
   | 在庫アイテム紐付け | 任意 | 在庫マスタから選択             |

4. 「**保存**」ボタンをクリックします。

### 登録すると

- 項目が保存されます
- カルテの該当タブで選択肢として表示されるようになります
- 在庫紐付けがあれば、カルテ確定時に自動減算されます

---

## 項目を編集する

1. 一覧で該当行をクリックします。
2. サイドパネルが開きます。
3. 各項目を変更します。
4. 「**保存**」をクリックします。

### 単価を変更した場合の影響

- **過去のカルテ・会計には影響しません**（保存時の単価で記録済み）
- 今後のカルテ作成時から新単価が適用されます

---

## 項目を無効化する

不要になった項目（古い検査メニュー等）を非表示にする操作です。

1. 該当行を開きます。
2. 「**有効**」スイッチを OFF にします。
3. 「**保存**」をクリックします。

### 無効化すると

- 一覧で「無効」表示になります
- カルテの選択肢から消えます
- 過去のカルテ・会計からは引き続き参照されます

> ⚠️ 削除ではなく **無効化** を使用すること。物理削除すると過去データの整合性が崩れます。

---

## 変動価格フラグの使い方

「**変動価格フラグ**」を ON にすると、カルテで該当項目を選択した時に **その場で価格を変更可能** になります。

### 使用例

- 「外科手術」: 内容によって金額が大きく異なる → ON
- 「初診料」: 固定 → OFF

---

## 見積専用項目の使い方

「**見積専用項目**」を ON にすると、見積書では選択可能だが **カルテ確定時の自動連動には含まれません**。

### 使用例

- 「概算費用」のような実費以外の項目
- 飼主への概算提示用の項目

---

## 在庫紐付け

「**在庫アイテム紐付け**」で、診療項目と在庫マスタを接続します。

例：

- 診療項目「フィラリア予防注射」 → 在庫「フィラリア予防注射 1.5mL」

接続後、カルテ確定時に在庫が自動減算されます。

> 紐付けがない場合、自動減算は機能しません。

---

## 必要な権限

- 画面を見る → カルテマスタの閲覧権限
- 編集 → カルテマスタの編集権限
