# 当日の受付

## どんな画面か

当日の来院ペットをステータス別に管理する **カンバンボード** です。受付登録・ステータス進行・カルテ／会計／入院への導線をまとめて扱います。ログイン直後のホーム画面でもあります。

## 開き方

- サイドバー左メニューの「**当日の受付**」をクリックします
- URL: `/`（ホーム）

## 画面イメージ

![当日の受付 画面](images/02-reception.png)

## 画面の見方

画面は **5 つのカラム** に分かれ、来院ステータスごとにカードが並びます。

| カラム | 意味 | 対応ステータス |
|-------|------|----------------|
| 受付予約 | 来院前。予約済または仮予約 | `pending` / `confirmed` |
| 受付済 | 来院して受付完了 | `checked_in` |
| 診療中 | 診察・処置・検査など対応中 | `in_consultation` |
| 会計待ち | 精算待ち | `accounting` |
| 会計済 | 精算完了 | `completed` |

各カードには次の情報が表示されます。

- 予約時刻
- ペット名・飼主名
- 動物種
- 区分バッジ（初診／再診、診療区分）
- 担当医（指名がある場合は「指」ラベル）

ヘッダー直下の **受付テレメトリ** には、本日受付件数・平均待ち／最長待ちが表示されます（待ち時間は `checked_in_at` 基準。対象 0 件時は「—」）。

## 新規予約を登録する

1. 画面右上の「**新規予約登録**」ボタンをクリックします（`reservations:create` 権限が必要）。
2. 予約フォームが開きます。既存ペットを検索するか、必要に応じて飼主・ペットを登録します。
3. 予約区分・日時・担当医などを入力して登録します。

### 登録後に起きること

- カードが「**受付予約**」カラムに追加されます
- 予約管理カレンダー（`/reservations`）にも同じ予約が表示されます

> 新規飼主の本登録は、通常「**飼主・ペット**」（`/owners`）で行ってから受付に進む運用が安全です。電話番号の重複時は警告が出ます。

## ステータスを変更する

### 方法 A: ドラッグ&ドロップ（推奨）

カードを掴んで別カラムへドロップします。ドロップ確定時のみステータス更新 API が呼ばれます。

### 方法 B: 詳細モーダルの操作ボタン

1. カードをクリックして詳細モーダルを開きます。
2. ステータスに応じたボタンを押します。

| 現在 | 代表操作 | 次の状態 |
|------|----------|----------|
| 受付予約 | 「受付済にする」 | 受付済 |
| 受付済 | 「カルテ作成」／「トリミングカルテ作成」など | 診療中（作成と同時に進行） |
| 診療中 | 詳細からステータス進行、または DnD | 会計待ち |
| 会計待ち | 「会計へ進む」 | 会計画面へ遷移（精算完了後に会計済へ） |
| 会計済 | 参照中心 | — |

### 変更後に起きること

- カードが該当カラムへ移動します
- 他端末への反映はポーリング（約 30 秒）およびウィンドウフォーカス時の再取得です

> ⚠️ カルテ確定や会計確定だけで、受付カラムが **必ず** 自動で進むとは限りません。受付ボード上の進行（DnD／操作ボタン）と、会計画面での精算完了による「会計済」反映を組み合わせて運用します。

---

## カルテ・会計・入院へ遷移する

カード上のクイックリンク、または詳細モーダルのボタンから遷移します。表示条件はカラムと診療区分で変わります。

| 導線 | 条件の目安 | 遷移先 |
|------|------------|--------|
| カルテ作成／カルテ入力 | 一般診療区分。受付済・診療中など | `/medical-records/new` または既存詳細 |
| トリミングカルテ | トリミング区分。受付済など | `/trimming/new` |
| 会計 | 診療中以外で表示される場合あり | `/accounting/new` または既存詳細 |
| 入院 | 入院／ホテル区分が含まれる場合 | `/hospitalization/new` |

ペット未紐付けの場合は、先にペット選択画面へ進みます。

---

## 受付をキャンセルする

1. カードの詳細モーダルを開きます。
2. 「**取消**」を選びます（`reservations:delete` 権限が必要）。
3. 確認ダイアログで確定します。

### キャンセル後に起きること

- 予約がキャンセル状態になります
- カンバン上からは見えなくなります（キャンセル済みは受付ボードの 5 カラム対象外）

---

## 絞り込み

ヘッダーの「**フィルター**」から次を指定できます。

| フィルタ | 内容 |
|---------|------|
| 指名 | 稼働中スタッフ、または「医師指名なし」 |
| 初診／再診 | 来院種別 |
| トリミング限定 | トリミング業務向けビュー |

---

## 必要な権限

| 操作 | 権限の目安 |
|------|------------|
| 画面を見る | `reception:view` |
| 新規予約登録 | `reservations:create` |
| ステータス変更・編集 | `reservations:edit` |
| 取消 | `reservations:delete` |
| カルテ作成導線 | `medical-records:create` |
| 会計導線 | `accounting:create`（および会計閲覧） |
| 入院導線 | `hospitalization:create` |

権限が無い操作ボタンは表示されません。
