# 当日の受付

## どんな画面か

当日の来院ペットをステータス別に管理する画面です。受付登録・ステータス更新・カルテや会計画面への遷移ができます。受付スタッフが最もよく使う画面です。

## 開き方

サイドバー左メニューの「**当日の受付**」をクリックします。ログイン直後の初期画面でもあります。

## 画面イメージ

![当日の受付 画面](images/02-reception.png)

## 画面の見方

画面は **5 つのカラム** に分かれていて、来院ステータスごとにペットのカードが並んでいます：

| カラム | 状態 |
|-------|------|
| 受付予約 | 来院前。予約済または事前登録 |
| 受付済 | 来院して受付完了 |
| 診療中 | 診察室に案内・診察中 |
| 会計待ち | 診察終了・カルテ確定済 |
| 会計済 | 会計確定・お見送り済 |

各カードには次の情報が表示されます：

- ペット名・飼主名
- 動物種・品種
- 予約区分（色分けバッジ）
- 来院目的
- **経過時間**（現ステータスでの経過分数）
- 担当医（指定されている場合）

---

## 新規予約を登録する（既存飼主）

来院した飼主・ペットがすでに登録済みの場合の手順です。

1. 画面右上の「**新規予約登録**」ボタンをクリックします。
2. ペット選択画面が開きます。
3. 検索欄に **飼主名・ペット名・電話番号** のいずれかを入力します。
4. 候補リストから該当ペットをクリックします。
5. 受付情報入力画面に切り替わります。
6. 次の項目を入力します：

   | 項目 | 必須 | 内容 |
   |------|---|------|
   | 来院目的 | ✅ | 主訴・症状 |
   | 予約区分 | ✅ | 診察 / トリミング / ワクチン 等から選択 |
   | 予約日時 | ✅ | 既定は現在時刻 |
   | 担当医 | 任意 | スタッフから選択 |
   | メモ | 任意 | |

7. 「**登録**」ボタンをクリックします。

### 登録後に起きること

- カードが「**受付予約**」カラムに追加されます
- 予約管理カレンダーにも自動で表示されます

---

## 新規予約を登録する（新規飼主）

初診の飼主・ペットを登録するときの手順です。

1. 「**新規予約登録**」ボタン → ペット選択画面
2. 「**新規飼主登録**」リンクをクリックします。
3. 飼主情報を入力します：

   | 項目 | 必須 | 内容 |
   |------|---|------|
   | 姓 / 名 | ✅ | |
   | 電話番号 | ✅ | 重複時は警告 |
   | フリガナ・住所・メール等 | 任意 | |

4. ペット情報を入力します：

   | 項目 | 必須 |
   |------|---|
   | ペット名 | ✅ |
   | 動物種 | ✅ |
   | 品種 | ✅ |

5. 続けて受付情報を入力して「**登録**」をクリックします。

### 登録後に起きること

- 飼主とペットが新規保存されます
- 受付カードが「受付予約」カラムに追加されます
- 飼主一覧（サイドバー「**飼主・ペット**」）と飼主詳細画面でも確認できるようになります

### 警告が出る場合

同じ電話番号で既に登録されている飼主がいる時、警告が表示されます（同居家族など意図的な重複の場合は、強行して登録できます）。

## ステータスを変更する

ペットの状況が変わるたびに、ステータスを進めていきます。

### 通常の遷移順

| 現在の状態 | 操作 | 次の状態 |
|----------|------|---------|
| 受付予約 | 「受付」ボタン | 受付済 |
| 受付済 | 「診察開始」ボタン | 診療中 |
| 診療中 | （カルテ確定で自動） | 会計待ち |
| 会計待ち | （会計確定で自動） | 会計済 |

### 変更方法

- カードのステータスバッジをクリック → メニューから次の状態を選択
- または「受付」「診察開始」などの操作ボタンを直接クリック

### 変更後に起きること

- カードが該当カラムに自動で移動します
- 経過時間カウントがリセットされます

---

## カルテ画面に遷移する

カード上のペット名をクリックします。

| 状況 | 遷移先 |
|------|-------|
| 当日のカルテが未作成 | 新規カルテ作成画面 |
| 当日のカルテが作成済 | カルテ詳細画面 |

---

## 会計画面に遷移する

「**会計待ち**」または「**会計済**」のカードに表示される「**会計**」ボタンをクリックします。

| 状況 | 遷移先 |
|------|-------|
| 会計が未作成 | 新規会計画面 |
| 会計が作成済 | 会計詳細画面 |

---

## 受付をキャンセルする

1. カードの **操作メニュー（縦三点ドット）** をクリックします。
2. 「**キャンセル**」を選びます。
3. キャンセル理由（任意）を入力して確定します。

### キャンセル後に起きること

- カードのステータスが「**キャンセル**」に変わります
- 紐付く予約もキャンセル状態になります
- カレンダー上では薄色 / 取消線で表示されます

> ⚠️ 元のステータスに戻すには管理者権限が必要です。

---

## 絞り込みと検索

画面上部のフィルタで一覧を絞り込めます：

| フィルタ | 入力 |
|---------|-----|
| 検索 | 飼主名・ペット名・電話番号 |
| 予約区分 | 区分を選択 |
| 担当医 | スタッフを選択 |
| ステータス | カラムを選択 |

---

## 別の日の受付を見る

画面上部の **日付ナビゲーション** で前日・翌日に切り替えられます。

- **過去日**: 参照モード（編集不可）
- **未来日**: 予約のみ表示（ステータス遷移不可）

---

## 必要な権限

- 画面を見る → 閲覧権限
- 新規受付登録 → 作成権限
- ステータス変更・キャンセル → 編集権限
