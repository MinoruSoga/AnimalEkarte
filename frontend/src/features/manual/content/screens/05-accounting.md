# 会計

## どんな画面か

診療・検査・物販・トリミングなどの **請求（会計）** を作成し、支払を記録して明細兼領収書を発行する画面です。

## 開き方

- サイドバー「**会計管理**」→ URL: `/accounting`
- 当日の受付（`/`）の「会計」「会計へ進む」
- カルテ一覧の「会計」ボタン（紐付く会計がある場合）

関連 URL:

| 用途             | URL                         |
| ---------------- | --------------------------- |
| 一覧             | `/accounting`               |
| ペット選択       | `/accounting/select-pet`    |
| 新規             | `/accounting/new`           |
| 詳細・精算       | `/accounting/:id`           |
| レジ締め         | `/accounting/close`         |
| 締め履歴         | `/accounting/close/history` |
| 月次集計レポート | `/accounting/reports`       |

## 画面の見方

### タブ

| タブ       | 内容                                     |
| ---------- | ---------------------------------------- |
| 会計一覧   | 期間・条件での会計一覧（既定）           |
| 当日会計   | 指定日の精算済会計と日計（`?tab=daily`） |
| 未納者一覧 | 売掛・未入金の抽出（`?tab=unpaid`）      |

### 会計一覧の表示項目

- **日時**: 会計予定日
- **飼主名・ペット名**
- **請求金額**: 税込合計
- **支払方法**: 精算済の場合に表示
- **ステータス**: **未精算** / **保留** / **精算済** / **取消**
- **返金あり** バッジ（返金がある場合）
- **カルテ** リンク（紐付きがある場合）

絞り込み: 日付範囲・ステータス・支払方法・飼主／ペット名検索。

## 新規会計を作る

1. 「**新規会計登録**」→ ペット選択（`/accounting/select-pet`）→ `/accounting/new?petId=...`
2. 対象ペットに **未請求明細** がある場合、明細が自動で取り込まれます。
   - カルテの処置・処方など
   - 会計待ち状態のトリミング予約のコース・オプション
   - その他、未請求として残っている項目
3. 必要に応じて物販・手動明細を追加します。

> カルテ確定だけで会計レコードが自動生成されるわけではありません。未請求明細は会計作成時に **pull** で取り込まれます。

---

## 明細・割引・保険・支払

### 明細

- 品目・数量・単価・税率（標準／軽減／非課税、内税／外税）を管理します
- 小計・税・合計はリアルタイム再計算されます

### 割引

飼主に紐づく割引やキャンペーン設定がある場合は初期値として入ります。権限とマスタ設定に従い調整します。

### 保険

明細ごとの保険適用フラグと、負担割合（選択式）に応じて控除額を算出します。

### 支払（複数可）

現金・カード・電子マネー・銀行振込などを **分割して** 入力できます（例: 現金 + カード残額）。お釣り計算の補助もあります。

未払いとする場合は、支払を完了させず未精算のまま残す／未納管理の運用に従います。「未収金」という固定の支払方法名は、医院の支払方法マスタに登録されている場合にのみ選択肢に出ます。

---

## 会計を確定する

1. 明細・保険・支払を確認します。
2. 「**会計を確定する**」を押します。
3. 精算済になると「**明細兼領収書**」からプレビュー・印刷ができます。

### 確定後に起きること

- ステータスが **精算済** になります
- 同日同一ペットの **会計待ち予約** などが完了（会計済）へ更新される場合があります
- 物販など在庫連動対象は、確定時の在庫処理に従います
- 明細兼領収書（インボイス対応の帳票）を発行できます

### 確定後の修正

- 通常は直接の自由編集ではなく、確認ダイアログ付きの修正フローになります
- **キャンセル**（取消）は `accounting-cancel` 権限が必要です。取消理由が残り、ステータスは **取消** になります
- **レジ締め済み期間** の修正は、締め後編集権限（`accounting-post-close-edit`）と理由入力が必要です
- カード金額の確定後訂正は専用ダイアログ（権限がある場合のみ）

> 締め自体を「取り消してから直す」操作は用意されていません。締め済み日の修正は post-close 編集経路を使います。

---

## 明細兼領収書

- 精算済会計で「**明細兼領収書**」ボタンが表示されます
- 診療明細書と領収書を 1 枚に集約（A4 縦）。税率別内訳・事業者登録番号などに対応
- 再表示は何度でも可能です

---

## 未納者一覧

「**未納者一覧**」タブ（`/accounting?tab=unpaid`）で売掛・未入金を確認します。会計画面には飼主の未納残高カードが出る場合もあります。

---

## 必要な権限

| 操作                   | 権限の目安                        |
| ---------------------- | --------------------------------- |
| 画面を見る             | `accounting:view`                 |
| 新規作成               | `accounting:create`               |
| 編集・確定             | `accounting:edit`                 |
| キャンセル（取消）     | `accounting-cancel:edit`          |
| 締め後修正・カード訂正 | `accounting-post-close-edit:edit` |
| 返金記録               | `accounting:create`（返金 API）   |
