# 権限グループ

## どんな画面か

スタッフの役割（院長・獣医師・看護師・受付・トリマー等）に応じて **何ができるかを定義する** 画面です。スタッフ登録時に必須の前提マスタ。

## 開き方

サイドバー「**マスタ設定**」→「**権限グループ**」

## 必要な権限

最高管理者権限のみアクセス可。一般スタッフは表示・編集不可。

## 画面の見方

### 一覧の表示項目

- **グループ名**: 例「院長」「獣医師」「受付スタッフ」
- **説明**
- **所属スタッフ数**
- **有効/無効**

### 既定のグループ（システム導入時）

導入時に以下のような既定グループが作成されることが多い：

- 院長（フルアクセス）
- 獣医師
- 看護師
- 受付スタッフ
- トリマー
- 経理担当
- 研修生（閲覧のみ）

---

## 新規権限グループを作成する

1. 画面右上の「**新規グループ**」ボタンをクリックします。
2. グループ情報を入力します：

   | 項目       | 必須 | 内容           |
   | ---------- | ---- | -------------- |
   | グループ名 | ✅   | 例「夜間担当」 |
   | 説明       | 任意 | 用途のメモ     |

3. **権限マトリクス** で各機能に対して操作を設定します（次節）。
4. 「**保存**」をクリックします。

---

## 権限マトリクスの設定

各機能（リソース）に対し、4 段階のアクセスレベルをチェックボックスで設定します。

### アクションの種類

| アクション         | できること                       |
| ------------------ | -------------------------------- |
| **閲覧（View）**   | データを見る・一覧表示           |
| **作成（Create）** | 新規データを登録                 |
| **編集（Edit）**   | 既存データを修正・ステータス変更 |
| **削除（Delete）** | データを削除・取り消し           |

### 管理する主要リソース

| カテゴリ | リソース                                |
| -------- | --------------------------------------- |
| 医療     | カルテ / 検査 / 予防接種 / 入院・ホテル |
| フロント | 受付 / 飼主・ペット / 予約              |
| 会計     | 会計 / レジ締め / 月次集計レポート      |
| 在庫     | 在庫管理 / 物販                         |
| マスタ   | 各種マスタ / スタッフ / 動物種類 等     |
| 連携     | LINE予約 / Lステップ                    |

---

## 役職別の権限設定例

### 院長（フルアクセス）

全リソースに対し View / Create / Edit / Delete すべて ON

### 獣医師

- 医療系: すべて ON
- 会計: View / Edit
- 在庫: View
- マスタ: View（編集は管理者へ）

### 看護師

- カルテ: View / Edit
- 在庫: View / Edit（投薬時の在庫消費）
- 受付: View / Edit
- マスタ: View

### 受付スタッフ

- 受付: すべて ON
- 飼主・ペット: View / Create / Edit
- 予約: すべて ON
- 会計: View / Create / Edit
- レジ締め: すべて ON
- カルテ: View（医療判断はしない）
- マスタ: 閲覧不可（または View のみ）

### トリマー

- トリミング: すべて ON
- 受付: View / Edit（ステータス更新）
- 飼主・ペット: View
- その他: 閲覧不可

### 経理担当

- 会計: すべて ON
- レジ締め: すべて ON
- 月次集計レポート: すべて ON
- 集計・分析: View
- マスタ（支払方法等）: View / Edit

### 研修生（閲覧のみ）

- すべてのリソースで View のみ ON

---

## 権限グループを編集する

1. 一覧で該当グループをクリックします。
2. 権限マトリクスでチェックボックスを変更します。
3. 「**保存**」をクリックします。

### 編集後の反映タイミング

- 該当グループに属するスタッフが **次回ログイン時** から新権限が適用されます
- 既存セッションには即時反映されません

---

## グループを削除する（無効化）

スタッフが属しているグループは削除できません。

### 削除前の手順

1. スタッフマスタで、該当グループのスタッフを別のグループに変更。
2. 全員の移動完了後、グループを削除。

### 無効化（推奨）

- 「**無効**」スイッチを OFF にして残しておく
- 過去の権限変更履歴を辿りやすい

---

## 注意事項

- **権限を厳しくしすぎない**: スタッフが必要な操作ができないと業務停滞
- **権限を緩すぎない**: セキュリティ・誤操作リスク
- **最小権限の原則**: 初期は最低限から始めて、必要に応じて追加
- **削除権限は慎重に**: 削除は取り戻せない場合が多い

---

## 必要な権限

権限グループの編集には、**最高管理者権限** が必要です。誤って自分のアクセス権を削除しないよう注意。

---
