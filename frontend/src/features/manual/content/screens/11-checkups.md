# 定期健診

## どんな画面か

ペットの定期健診（年次・半年など）を記録し、次回健診予定日を自動で算出する画面です。Lステップの健診タグ抽出の元データになります。

## 開き方

サイドバー左メニューの「**定期健診**」をクリックします。

サイドバーのリンクには **期限間近のペット数** がバッジで表示されます。

## 画面イメージ

![定期健診 画面](images/11-checkups.png)

## 画面の見方

### 一覧の表示項目

- **実施日**
- **飼主名・ペット名**
- **健診種別**: 年次 / シニア / 子犬・子猫 等
- **次回予定**: 自動算出された日付
- **結果・所見**
- **担当医**

---

## 新規健診を登録する

1. 画面右上の「**新規登録**」ボタンをクリックします。
2. ペットを検索・選択します。
3. 健診情報を入力します：

   | 項目           | 必須 | 内容                           |
   | -------------- | ---- | ------------------------------ |
   | 健診種別       | ✅   | 年次 / シニア / 子犬・子猫 等  |
   | 実施日         | ✅   |                                |
   | 検査項目       | 任意 | 複数（別の検査記録として作成） |
   | 所見・サマリー | ✅   |                                |
   | 担当医         | ✅   |                                |

4. 「**登録**」ボタンをクリックします。

### 登録すると

- 健診記録が保存されます
- **次回予定日が自動で算出されます**（実施日 + 健診種別の間隔月数）
- 関連検査がある場合、検査記録も別途生成されます

---

## サイドバーバッジについて

サイドバー「**定期健診**」のリンクに、**期限間近のペット数** がバッジで表示されます。

クリックすると一覧で対象を確認できます。

---

## Lステップ健診抽出との関係

サイドバー「**Lステップ連携**」→「**健診対象者抽出**」で「**抽出実行**」ボタンを押すと、次回予定日を基準に対象飼主が自動抽出され、健診関連のタグが付与されます。

詳細は業務フロー「Lステップ連携の設定とタグ運用」を参照。
