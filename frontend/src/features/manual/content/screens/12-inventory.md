# 在庫管理

## どんな画面か

薬剤・物販・消耗品の在庫を管理する画面です。入荷登録・棚卸・廃棄処理ができます。カルテ・会計などの操作で在庫が自動的に減算されます。

## 開き方

サイドバー左メニューの「**在庫管理**」をクリックします。

## 画面イメージ

![在庫管理 画面](images/12-inventory.png)

## 画面の見方

### 一覧の表示項目

- **品名**
- **カテゴリ**: 医薬品 / 消耗品 / フード / その他
- **在庫数**: 現在の数量 + 単位
- **最低在庫**: アラート閾値 + 単位
- **保管場所**
- **有効期限**: 最早期限のロット
- **ステータス**: 在庫切れ / 残少 / 十分

### 一覧上部のサマリー

- 在庫切れの件数
- 残少の件数

### ステータスの仕組み

| ステータス | 条件              |
| ---------- | ----------------- |
| 在庫切れ   | 在庫数 0          |
| 残少       | 在庫数 ≤ 最低在庫 |
| 十分       | 在庫数 > 最低在庫 |

## 新規アイテムを登録する

1. 画面右上の「**新規登録**」ボタンをクリックします。
2. アイテム情報を入力します：

   | 項目                 | 必須 | 内容                              |
   | -------------------- | ---- | --------------------------------- |
   | 品名                 | ✅   |                                   |
   | カテゴリ             | ✅   | 医薬品 / 消耗品 / フード / その他 |
   | 単位                 | ✅   | バイアル / 錠 / 個 / 袋 等        |
   | 仕入価格             | 任意 |                                   |
   | 販売価格             | 任意 | 物販扱いの場合                    |
   | 最低在庫             | 任意 | アラート閾値                      |
   | 保管場所             | 任意 |                                   |
   | 有効期限管理         | 任意 | ON にするとロット管理になります   |
   | 紐付けマスタアイテム | 任意 | 薬剤 / 物販 / 検査消耗品から選択  |

3. 「**登録**」ボタンをクリックします。

### 登録すると

- アイテムが保存されます（初期在庫数 0）

---

## 入荷を登録する

1. 在庫一覧で該当アイテムをクリックします。
2. 詳細画面の「**入荷**」ボタンをクリックします。
3. 入荷情報を入力します：

   | 項目       | 必須 | 内容           |
   | ---------- | ---- | -------------- |
   | 入荷数量   | ✅   |                |
   | ロット番号 | 任意 | 医薬品は推奨   |
   | 有効期限   | 任意 | 医薬品は推奨   |
   | 仕入価格   | 任意 | 変動がある場合 |
   | 仕入先     | 任意 |                |

4. 「**登録**」ボタンをクリックします。

### 登録すると

- 入荷記録が保存されます
- **在庫数が増加します**
- 有効期限管理 ON の場合、ロット別在庫が記録されます

---

## 棚卸（実数補正）をする

1. 一覧の「**棚卸モード**」ボタンをクリックします。
2. 各アイテム行の「**実数入力**」欄に、数えた実数を入力します。
3. システム値との **差異が即時表示** されます。
4. 「**棚卸確定**」ボタンをクリックします。

### 確定すると

- 差異がある場合、補正記録が保存されます
- **在庫数が実数で上書きされます**
- 棚卸履歴に記録されます

---

## 廃棄処理をする

1. アイテム詳細画面の「**廃棄**」ボタンをクリックします。
2. 廃棄情報を入力します：

   | 項目     | 必須 | 内容                            |
   | -------- | ---- | ------------------------------- |
   | 廃棄数量 | ✅   |                                 |
   | 廃棄理由 | ✅   | 期限切れ / 破損 / 紛失 / その他 |
   | メモ     | 任意 |                                 |

3. 「**廃棄登録**」をクリックします。

### 登録すると

- 廃棄記録が保存されます
- **在庫数が廃棄分だけ減算されます**

---

## 自動減算（出庫）の仕組み

スタッフが手動で出庫操作する必要はありません。以下の操作で **自動的に** 在庫が減算されます：

| 次の操作が行われた時   | 減算される在庫       |
| ---------------------- | -------------------- |
| カルテ確定（処方明細） | 薬剤に紐付く在庫     |
| 予防接種登録           | ワクチンに紐付く在庫 |
| トリミング完了         | オプション消耗品     |
| 会計確定（物販明細）   | 物販に紐付く在庫     |
| 入院中の投薬記録       | 薬剤に紐付く在庫     |

### 取消した場合

上記操作を取り消すと、**在庫が自動で戻されます**。

### 自動減算の前提

マスタ設定で、診療項目・薬剤・物販と在庫アイテムが紐付けされている必要があります。

---

## ロット管理（有効期限 ON 時）

アイテム詳細画面の「**ロット**」タブで管理します：

- ロット番号別の在庫数
- 各ロットの有効期限
- 期限 30 日以内のロットはハイライト表示

### 自動減算のルール

古いロットから先に減算されます（**先入れ先出し**）。

---

## マスタとの紐付けについて

在庫の自動減算には、診療項目・薬剤・物販マスタとの紐付けが必要です：

| 設定する場所                                | 紐付け対象      |
| ------------------------------------------- | --------------- |
| サイドバー「マスタ設定」→「診療項目マスタ」 | 診療項目 → 在庫 |
| サイドバー「マスタ設定」→「薬剤マスタ」     | 薬剤 → 在庫     |
| サイドバー「マスタ設定」→「物販マスタ」     | 物販 → 在庫     |

紐付けがないと、自動減算は機能しません。

---

## 必要な権限

- 画面を見る → 閲覧権限
- 新規・編集・棚卸・廃棄 → 編集権限
