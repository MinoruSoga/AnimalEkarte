# 在庫管理

## どんな画面か

薬剤・物販・消耗品の在庫を管理する画面です。アイテムの登録・編集・検索・絞り込みができます。カルテの処置登録で在庫アイテムを指定すると、数量が自動的に減算されます。

## 開き方

サイドバー左メニューの「**在庫管理**」をクリックします。

## 画面イメージ

![在庫管理 画面](images/12-inventory.png)

## 画面の見方

### 一覧の表示項目

- **品名**
- **カテゴリ**: 医薬品 / 消耗品 / フード / その他
- **在庫数**: 現在の数量 + 単位
- **最低在庫**: アラート閾値 + 単位
- **保管場所**
- **有効期限**
- **ステータス**: 在庫切れ / 残少 / 十分

### 一覧上部のサマリー

- 在庫切れの件数
- 残少の件数

### ステータスの仕組み

| ステータス | 条件              |
| ---------- | ----------------- |
| 在庫切れ   | 在庫数 0          |
| 残少       | 在庫数 ≤ 最低在庫 |
| 十分       | 在庫数 > 最低在庫 |

### 検索・絞り込み

- 検索ボックスは **品名・保管場所・仕入先** が対象です
- カテゴリ・ステータスで絞り込めます
- 検索・並び替えは現在表示中のページ内のみが対象です。他のページの在庫を確認する場合はカテゴリ・ステータスでの絞り込みをご利用ください

## 新規アイテムを登録する

1. 画面右上の「**新規登録**」ボタンをクリックします。
2. アイテム情報を入力します：

   | 項目       | 必須 | 内容                              |
   | ---------- | ---- | --------------------------------- |
   | 品名       | ✅   |                                   |
   | カテゴリ   | ✅   | 医薬品 / 消耗品 / フード / その他 |
   | 単位       | ✅   | バイアル / 錠 / 個 / 袋 等        |
   | 在庫数     | ✅   | 現在の数量                        |
   | 最低在庫数 | ✅   | アラート閾値                      |
   | 保管場所   | 任意 | 例: 薬品棚A-1                     |
   | 有効期限   | 任意 |                                   |
   | 仕入先     | 任意 |                                   |
   | 最終入荷日 | 任意 |                                   |

3. 「**登録**」ボタンをクリックします。

### 登録すると

- アイテムが一覧に追加されます

---

## 在庫数を更新する（入荷・棚卸・廃棄）

在庫数の変更は、アイテムの編集画面で「**在庫数**」を直接修正します。

1. 一覧で該当アイテムを開き、「**編集**」ボタンをクリックします。
2. 「**在庫数**」を新しい数量に変更します。入荷した場合は「**最終入荷日**」もあわせて更新してください。
3. 保存します。

> ⚠️ 入荷・棚卸・廃棄ごとの履歴は記録されません。数量の変更は現在値の上書きです。

---

## 自動減算（出庫）の仕組み

カルテの処置登録で在庫アイテムを指定すると、登録数量ぶんの在庫が **自動的に** 減算されます。

### 自動減算の前提

処置の登録フォームで対象の在庫アイテムを選択（紐付け）する必要があります。紐付けがない処置では在庫は減算されません。

---

## 必要な権限

- 画面を見る → 閲覧権限
- 新規登録・編集・削除 → 編集権限
