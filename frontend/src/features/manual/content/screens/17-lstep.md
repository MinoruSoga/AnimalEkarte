# Lステップ連携

## どんな画面か

LINE 配信ツール「Lステップ」と連携して、飼主への自動配信・タグ管理を行う画面群です。

## 開き方

サイドバー左メニューの「**Lステップ連携**」をクリックするとサブメニューが展開します。

| サブメニュー   | 用途                               |
| -------------- | ---------------------------------- |
| 連携設定       | API キー・配信設定・タグマッピング |
| タグ管理       | 自動管理タグの一覧・管理           |
| 健診対象者抽出 | 定期健診時期の対象者を抽出・配信   |
| 配信モニター   | 配信ログの確認                     |
| 分析レポート   | 配信実績・タグ別来院統計           |

---

## 連携設定

サイドバー「**Lステップ連携**」→「**連携設定**」を開きます。

主な設定セクション：

1. **接続情報**: API キー / LINE Channel / LIFF ID
2. **CPM 設定**: バージョン（V1 / V2）+ 各セグメント閾値
3. **休眠予防閾値**: 180 / 210 / 240 / 365 日
4. **同期 ON/OFF**: 連携処理の有効化トグル
5. **配信優先順位**: 各配信種別の優先度
6. **タグコードマッピング**: 健診・予防タグの判定条件
7. **自動管理タグプレフィックス**: 手動付与を拒否するタグ
8. **慢性疾患コードマッピング**: コード → タグ自動変換
9. **LINE 送信目的マッピング**: 送信目的別のタグプレフィックス

詳細な操作は業務フロー「Lステップ連携の設定とタグ運用」を参照してください。

---

## 接続テストをする

「**Lステップ接続テスト**」「**LINE接続テスト**」各ボタンをクリックします。

### ボタンを押すと

- 各 API へテスト送信されます
- 成否が画面に表示されます

---

## 設定を保存する

各セクション下部の「**保存**」ボタンをクリックします。

### 保存すると

- 設定が保存されます
- 操作履歴に変更内容が記録されます

---

## タグ管理画面

サイドバー「**Lステップ連携**」→「**タグ管理**」を開きます。

### 自動管理プレフィックス一覧

以下のプレフィックスから始まるタグは **手動付与・削除ができません**（システムが自動管理）：

| プレフィックス  | カテゴリ | 用途               |
| --------------- | -------- | ------------------ |
| canceled_visit  | B        | キャンセル予約タグ |
| no_show_        | B        | 無断未来院タグ     |
| reserved_       | B        | 予約タグ           |
| birth_year_     | C1       | 生年タグ           |
| breed_          | C1       | 犬種・猫種タグ     |
| intact          | C1       | 未避妊去勢タグ     |
| pet_birthday_   | C1       | 誕生日タグ         |
| sex_            | C1       | 性別タグ           |
| spay_neutered   | C1       | 避妊去勢済みタグ   |
| checkup_        | C2       | 健診タグ           |
| chronic_        | C2       | 慢性疾患タグ       |
| next_checkup_   | C2       | 次回健診タグ       |
| next_visit_     | C2       | 次回来院タグ       |
| refill_due_     | C2       | 処方箋補充期限タグ |
| vaccine_        | C2       | ワクチンタグ       |
| cert_sent_      | C3       | 証明書送付タグ     |
| pet_deceased_   | C3       | ペット死亡タグ     |
| post_discharge_ | C3       | 退院フォロータグ   |
| post_surgery_   | C3       | 術後フォロータグ   |

### プレフィックスを追加・削除する

| 項目           | 必須 | 内容             |
| -------------- | ---- | ---------------- |
| プレフィックス | ✅   | 例: `vaccine_`   |
| カテゴリ       | ✅   | B / C1 / C2 / C3 |

「**追加**」ボタンで保存、各行右の「**削除**」で削除します。

## 健診対象者を抽出する

サイドバー「**Lステップ連携**」→「**健診対象者抽出**」を開きます。

「**抽出実行**」ボタンをクリックします。

### 抽出すると

- 経過月数の条件で対象飼主が検索されます
- 該当飼主に健診関連のタグが自動で付与されます
- Lステップ API にタグ追加リクエストが送信されます

### 確認する場所

- 画面に対象者一覧が表示されます
- サイドバー「Lステップ連携」→「タグ管理」でタグ付与状況を確認できます

---

## 配信モニターを確認する

サイドバー「**Lステップ連携**」→「**配信モニター**」を開きます。

表示される内容：

- 配信日時
- 受信飼主
- 配信種別
- 配信結果（成功 / エラー）

配信エラーが連続する飼主には、自動的に **EXCL タグ** が付与され、以後の配信から除外されます。

---

## 分析レポートを確認する

サイドバー「**Lステップ連携**」→「**分析レポート**」を開きます。

| セクション   | 内容                   |
| ------------ | ---------------------- |
| タグ別来院数 | タグごとの来院ペット数 |
| タグ別売上   | タグごとの累計売上     |
| 配信実績     | 配信件数・開封率       |
| 休眠復帰率   | 休眠タグ付与後の来院率 |

期間切替プルダウンで対象期間を変更できます。
