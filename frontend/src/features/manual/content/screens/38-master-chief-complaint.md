# 主訴マスタ

## どんな画面か

カルテ・受付で **主訴（来院目的）の選択肢** を管理するマスタです。受付登録時に「来院目的」のプルダウンに表示される定型項目を定義します。

## 開き方

サイドバー「**マスタ設定**」→「**問診設定**」（同画面内に主訴タブ）

## 主訴の例

| カテゴリ | 主訴                                       |
| -------- | ------------------------------------------ |
| 一般症状 | 元気がない / 食欲不振 / 嘔吐 / 下痢 / 発熱 |
| 皮膚     | 痒み / 脱毛 / 皮膚の赤み / フケ            |
| 整形     | 跛行 / 痛がる                              |
| 予防     | ワクチン接種 / フィラリア予防              |
| 美容     | トリミング希望 / 爪切り                    |
| 健診     | 定期健診                                   |
| その他   | 検査希望 / 経過観察                        |

---

## 新規主訴の登録

1. 「**新規追加**」ボタン
2. 入力：

   | 項目     | 必須 |
   | -------- | ---- |
   | 主訴名   | ✅   |
   | カテゴリ | 任意 |
   | 表示順   | 任意 |

3. 「**保存**」

---

## 主訴の効果

- 受付登録時の「来院目的」プルダウンに表示
- カルテ作成時の「主訴」セクションのテンプレ選択肢
- カテゴリ別の集計に利用可能（実装による）

---

## 編集・無効化

- 既存主訴の表記揺れ統一は事前計画のうえ実施
- 廃止する主訴は「有効」スイッチ OFF

---

## 関連する画面

- 画面マニュアル「**当日の受付**」: 来院目的の選択
- 画面マニュアル「**カルテ**」: 主訴セクション
- 画面マニュアル「**問診テンプレートマスタ**」: 関連マスタ
