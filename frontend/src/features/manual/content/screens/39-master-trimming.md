# トリミングマスタ

## どんな画面か

トリミング画面で使用する **コース・オプション** を管理するマスタです。トリミング登録時の料金体系の元データになります。

## 開き方

サイドバー「**マスタ設定**」→「**トリミング**」

## タブ

| タブ       | 内容                                       |
| ---------- | ------------------------------------------ |
| コース     | カット・シャンプー等の基本サービス         |
| オプション | 部分カット・歯磨き・耳掃除等の追加サービス |

---

## コースの登録

### 一覧の表示項目

- **コース名**: フルコース / シャンプーコース / カットコース 等
- **対応動物種**: 犬 / 猫 / 共通
- **体格区分**: 小型 / 中型 / 大型
- **標準所要時間**: 60 分 / 90 分 等
- **料金（税込）**
- **含まれるサービス**: シャンプー・カット・爪切り・耳掃除 等

### 新規コース登録

1. 「**コース**」タブ → 「**新規追加**」
2. 入力：

   | 項目             | 必須 |
   | ---------------- | ---- |
   | コース名         | ✅   |
   | 動物種           | ✅   |
   | 体格区分         | ✅   |
   | 標準所要時間     | ✅   |
   | 料金（税込）     | ✅   |
   | 含まれるサービス | 任意 |

3. 「**保存**」

### 料金体系の例

| コース                 | 体格 | 料金    |
| ---------------------- | ---- | ------- |
| フルコース（犬）       | 小型 | ¥6,000  |
| フルコース（犬）       | 中型 | ¥8,000  |
| フルコース（犬）       | 大型 | ¥10,000 |
| シャンプーコース（犬） | 共通 | ¥4,000  |
| カットのみ（犬）       | 共通 | ¥3,000  |

---

## オプションの登録

### 一覧の表示項目

- **オプション名**: 歯磨き / 肛門腺絞り / 部分カット 等
- **料金（税込）**
- **所要追加時間**

### 新規オプション登録

1. 「**オプション**」タブ → 「**新規追加**」
2. 入力：

   | 項目         | 必須 |
   | ------------ | ---- |
   | オプション名 | ✅   |
   | 料金（税込） | ✅   |
   | 所要追加時間 | 任意 |

3. 「**保存**」

### オプションの例

| オプション   | 料金   |
| ------------ | ------ |
| 歯磨き       | ¥1,000 |
| 肛門腺絞り   | ¥500   |
| 耳掃除       | ¥500   |
| 部分カット   | ¥1,500 |
| アロマ仕上げ | ¥800   |

---

## 編集・無効化

- 料金変更: 過去のトリミング・会計には影響しない、今後の予約から反映
- 廃止コース・オプション: 「有効」スイッチ OFF

---

## 関連する画面

- 画面マニュアル「**トリミング**」: コース・オプションの選択
- 画面マニュアル「**会計**」: トリミング会計の確認
- 業務フロー「**診察なしの単独サービス来院**」: トリミングのみ来院フロー
