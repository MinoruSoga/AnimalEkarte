# コース種別マスタ

トリミングの **コース種別**（例: シャンプーコース / カットコース）を管理するマスタです。トリミング受付時のコース選択肢になります。

## 開き方

サイドバー「**マスタ設定**」→「**トリミング**」→「**コース種別マスタ**」をクリックします。

## 画面イメージ

![コース種別マスタ 画面](images/44-master-trimming-course-type.png)

## コース種別を登録する

1. 「**新規登録**」ボタンをクリックすると右側に編集パネルが開きます。
2. コース種別名を入力します。
3. 「**保存**」をクリックします。

## 編集・削除する

一覧の該当行をクリックすると編集パネルが開き、名称の変更・有効/無効の切替・削除ができます。変更後は「**保存**」をクリックします。

---

## 必要な権限

- 画面を見る → `master-trimming` の閲覧権限
- 登録・編集・削除 → `master-trimming` の編集権限
