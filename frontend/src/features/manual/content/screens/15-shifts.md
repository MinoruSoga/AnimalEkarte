# シフト管理

## どんな画面か

スタッフのシフト（勤務予定）をスタッフ × 日付のマトリクスで管理する画面です。

## 開き方

サイドバー左メニューの「**シフト管理**」をクリックします。

## 画面イメージ

![シフト管理 画面](images/15-shifts.png)

## 画面の見方

- **行**: スタッフ一覧
- **列**: 日付（月単位）
- **セル**: その日のシフト種別

### セル表示

| 表示 | 意味 |
|------|------|
| 全日 09:00-18:00 | 終日勤務 |
| 午前 09:00-13:00 | 午前のみ |
| 午後 14:00-18:00 | 午後のみ |
| 休日 | 休日 |
| シフトを追加 | 未設定（クリックで追加） |

---

## 個別セルにシフトを登録する

1. 空きセル または「**シフトを追加**」をクリックします。
2. シフト情報を入力します：

   | 項目 | 必須 | 内容 |
   |------|---|------|
   | 種別 | ✅ | 全日 / 午前 / 午後 / 休日 / カスタム |
   | 開始時刻 | カスタム時 | |
   | 終了時刻 | カスタム時 | |
   | メモ | 任意 | |

3. 「**登録**」ボタンをクリックします。

### 登録すると

- シフトが保存されます
- セルに該当種別が表示されます

---

## シフトテンプレートを適用する

繰り返しの勤務パターン（月-金 9:00-18:00 等）はテンプレートとして適用できます。

1. スタッフ行頭の「**テンプレート適用**」ボタンをクリックします。
2. テンプレートを選択します。
3. 適用日付範囲を指定します。
4. 「**適用**」をクリックします。

### 適用すると

- 選択期間に該当スタッフのシフトが一括登録されます

---

## 定休日を設定する

各日付列ヘッダーの「**定休日設定**」ボタンをクリックします。

### 設定すると

- その日の全スタッフのシフトが「**休日**」になります
- または医院全体の休診日として登録され、全予約をブロックします

---

## 月を切り替える

画面上部の「**前月**」「**翌月**」ボタンで表示対象月を変更できます。

---

## 職種・スタッフで絞り込む

画面右上のフィルタで表示する行を絞れます（表示のみ。他スタッフのシフトは消えません）。

1. **職種絞り込み**: 「すべての職種」または医院の職種（occupations マスタ）、「未設定」を選びます。
2. **スタッフ絞り込み**: 職種で絞ったあと、その中の1名だけにさらに絞れます。

医師だけ出勤を確認したいときなどは、職種で「医師」を選ぶと行が減って見やすくなります。

---

## シフトテンプレートを管理する

サイドバー「**マスタ設定**」→「**シフトテンプレートマスタ**」を開きます。

| 項目 | 必須 | 内容 |
|------|---|------|
| テンプレート名 | ✅ | |
| 曜日別シフト | ✅ | 月〜日に種別・時刻 |

「**保存**」でテンプレートが保存されます。

---

## 必要な権限

- 画面を見る → 閲覧権限
- 編集 → 編集権限
