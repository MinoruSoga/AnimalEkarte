# 検査管理

## どんな画面か

血液検査・尿検査などの **検査オーダーと結果** を管理する画面です。結果の異常値は基準値との比較でハイライトされます。

## 開き方

サイドバー「**検査管理**」→ URL: `/examinations`

関連 URL:

| 用途 | URL |
|------|-----|
| 一覧 | `/examinations` |
| ペット選択 | `/examinations/select-pet` |
| 新規 | ペット選択後、当日カルテの検査タブ (`/medical-records/new?petId=:id&tab=検査`) |
| 詳細・結果入力 | カルテに紐づく検査は `/medical-records/:id?tab=検査&examId=:id`。未紐付けのみ `/examinations/:id` |

## 画面の見方

### 一覧の表示項目

- **日時**
- **飼主名・ペット名**
- **検査種別**
- **結果概要**（広い画面幅でのみ表示）
- **担当医**
- **ステータス**（5 段階）

| ステータス | 意味 |
|----------|------|
| 依頼中 | オーダー直後 |
| 検査中 | 実施中 |
| 結果入力済み | 数値入力済み |
| 完了 | 完了 |
| 確定 | ロック済み（編集不可） |

絞り込み: 実施期間・進捗・検査種別・担当医・全文検索。

---

## 新規検査を登録する

1. 「**新規検査登録**」（`examinations:create`）をクリックします。
2. ペットを選択します（`/examinations/select-pet`）。
3. 検査種別・担当医など必須項目を入力して保存します。

検査種別を選ぶと、マスタ定義の測定項目テーブルが展開されます。

---

## 結果を入力する

各項目に測定値を入力して保存します。

### 判定の表示

マスタの基準値（Min〜Max）に基づき、保存・再読込後にハイライトされます。

- **高値**: 赤系
- **低値**: ブランドカラー（teal）系
- 範囲内: 通常表示

画面右カラムには **同一ペットの過去検査履歴** が表示され、期間・キーワードで絞り込めます。

未保存のまま他画面へ移ろうとすると確認が出ます。

---

## 検査を確定する

ステータスを **確定** にすると編集がロックされます。

### カルテ・会計との関係

- カルテの「検査」タブでは、既存の検査を **取り込み** して紐付けます（検査画面の確定だけでカルテへ自動 push されるわけではありません）
- 会計明細への反映は、会計作成時の未請求明細取込やカルテ側の会計確認フローに従います
- 確定後の数値の直接編集はできません。訂正が必要な場合は運用ルールに従い、新規検査として記録するなどの対応を取ります

---

## 検査項目マスタ

正常範囲・単位などの定義は検査マスタから行います。

- サイドバー「**マスタ設定**」→「**カルテ関連**」→「**検査マスタ**」
- URL の目安: `/settings/treatment-items?tab=examination`

---

## 必要な権限

| 操作 | 権限の目安 |
|------|------------|
| 画面を見る | `examinations:view` |
| 新規 | `examinations:create` |
| 編集・結果入力 | `examinations:edit` |
| 削除 | `examinations:delete` |

編集権限が無い場合、フォームは入力不可になります。
