# 飼主・ペット管理

## どんな画面か

飼主とそのペットの情報を一元管理する画面です。新規登録・編集・過去履歴の参照ができます。

## 開き方

サイドバー左メニューの「**飼主・ペット**」をクリックします。

## 画面イメージ

![飼主・ペット管理 画面](images/03-owners.png)

## 画面の見方

### 一覧に表示される項目

- **飼主 No**: 飼主の通し番号
- **飼主名**: 姓 名
- **ペット番号**: 飼主No-ペット順（例: 3-2 = 飼主 No 3 さんの 2 頭目）
- **ペット名**
- **生死**: 生存 / 死亡
- **種**: 動物種
- **生年月日**
- **体重**: 最新値
- **環境**: 室内 / 室外 / 両方
- **前回来院**: 最終来院日

### 絞り込みと検索

| フィルタ | 入力             |
| -------- | ---------------- |
| 検索     | 氏名・電話番号   |
| 動物種   | 犬 / 猫 / その他 |
| 生死     | 生存 / 死亡      |
| 来院期間 | 期間で絞り込み   |

ソート: 飼主No / 飼主名 / ペット名 / 種 / 生年月日 / 前回来院

## 新規飼主・ペットを登録する

1. 画面右上の「**新規登録**」ボタンをクリックします。
2. 飼主情報を入力します：

   | 項目                     | 必須 | 内容               |
   | ------------------------ | ---- | ------------------ |
   | 姓                       | ✅   |                    |
   | 名                       | ✅   |                    |
   | フリガナ姓 / フリガナ名  | 推奨 | 検索性向上         |
   | 電話番号                 | ✅   | 重複時は警告       |
   | 郵便番号                 | 任意 | 住所自動入力に使用 |
   | 都道府県・市区町村・番地 | 任意 |                    |
   | メール                   | 任意 |                    |
   | 性別 / 生年月日          | 任意 |                    |
   | 割引率                   | 任意 | 0〜100%            |
   | 会員区分                 | 任意 | マスタから選択     |
   | 紹介者                   | 任意 |                    |
   | メモ                     | 任意 |                    |

3. 「**ペット情報**」タブに切り替えます。
4. ペットを 1 頭以上登録します：

   | 項目                             | 必須 | 内容             |
   | -------------------------------- | ---- | ---------------- |
   | ペット名                         | ✅   |                  |
   | 動物種                           | ✅   | マスタから選択   |
   | 品種                             | ✅   | 動物種で絞り込み |
   | 性別 / 避妊去勢 / 生年月日       | 任意 |                  |
   | 体重 / 毛色 / マイクロチップ番号 | 任意 |                  |
   | アレルギー情報 / 環境            | 任意 |                  |

5. 「**登録**」ボタンをクリックします。

### 登録すると

- 飼主とペットが保存されます
- 飼主 No・ペット番号が自動で採番されます
- 一覧に追加されます

### 警告が出る場合

同じ電話番号で既に登録されている飼主がいる時、警告が表示されます（同居家族など意図的な重複の場合は強行できます）。

---

## 飼主情報を編集する

1. 一覧で該当行をクリックします。
2. 詳細画面で各タブの項目を編集します。
3. 「**保存**」をクリックします。

### 保存すると

- 飼主情報が更新されます
- ペット情報は別操作（後述）で編集します

---

## ペットを追加する

既存飼主に新しいペットを追加する操作です。

1. 飼主詳細画面の「**ペット**」タブを開きます。
2. 「**ペット追加**」ボタンをクリックします。
3. ペット情報を入力します。
4. 「**登録**」をクリックします。

---

## ペットをアーカイブする（死亡・利用停止）

1. ペット編集モードで「**アーカイブ**」ボタンをクリックします。
2. 理由を入力します：

   | 項目   | 必須   | 内容                 |
   | ------ | ------ | -------------------- |
   | 理由   | ✅     | 死亡 / 譲渡 / その他 |
   | 死亡日 | 死亡時 | 日付                 |

3. 「**確定**」をクリックします。

### アーカイブすると

- ペットがアーカイブ状態になります
- 死亡時は「生死」が「死亡」になります
- **過去カルテ・会計は保持されます**
- 新規受付・予約から該当ペットは選択できなくなります

---

## 来院履歴を見る

飼主詳細画面の「**来院履歴**」タブで、過去のカルテ・会計を時系列で確認できます。

カルテ番号をクリックすると該当カルテ画面に遷移します。

---

## 必要な権限

- 画面を見る → 閲覧権限
- 新規作成 → 作成権限
- 編集 → 編集権限

---

## 関連する画面

| 画面                       | 関係               |
| -------------------------- | ------------------ |
| 当日の受付                 | 新規受付登録の起点 |
| カルテ                     | 過去カルテへの遷移 |
| 会計                       | 過去会計の参照     |
| 予防接種・検査・トリミング | 履歴参照           |
