# 入院・ホテル

## どんな画面か

入院・ペットホテル滞在を管理する画面です。退院処理を行うと会計が自動で作られます。

## 開き方

サイドバー左メニューの「**入院・ホテル**」をクリックします。

## 画面イメージ

![入院・ホテル 画面](images/09-hospitalization.png)

## 画面の見方

### 表示モード

| モード             | 内容                 |
| ------------------ | -------------------- |
| ボード表示（既定） | ケージ別のカード形式 |
| リスト表示         | テーブル形式         |

### タブ

| タブ   | 表示対象               |
| ------ | ---------------------- |
| 入院中 | 現在入院中             |
| 予約   | 予約済（入院日が未来） |
| 退院済 | 退院処理済             |
| すべて | 全件                   |

ケージ稼働状況タブで各ケージの占有状況がカレンダー形式で見られます。

---

## 新規入院を登録する

1. 画面右上の「**新規入院登録**」ボタンをクリックします。
2. ペットを検索・選択します。
3. 入院情報を入力します：

   | 項目       | 必須 | 内容                         |
   | ---------- | ---- | ---------------------------- |
   | 入院区分   | ✅   | 入院 / ペットホテル / 預かり |
   | 入院日     | ✅   |                              |
   | 予定退院日 | ✅   | 入院日以降                   |
   | ケージ番号 | ✅   | 空きケージから選択           |
   | 食事制限   | 任意 |                              |
   | 投薬指示   | 任意 |                              |
   | 特記事項   | 任意 |                              |

4. 「**登録**」ボタンをクリックします。

### 登録すると

- 入院記録が保存されます
- ステータスが「**入院中**」になります
- **該当ケージが期間中ロックされます**
- ケージ稼働状況タブで占有が表示されます

### エラーになる場合

- 予定退院日が入院日より前
- 選択したケージが期間中に他予約と競合（選択肢から除外されます）

## ケア記録を追加する

1. 入院詳細画面で「**ケア記録追加**」ボタンをクリックします。
2. ケア情報を入力します：

   | 項目     | 入力                      |
   | -------- | ------------------------- |
   | 記録日時 | 既定: 現在時刻            |
   | 担当者   | スタッフから選択          |
   | 体温     | 数値（℃）                 |
   | 体重     | 数値（kg）                |
   | 食欲     | 完食 / 半分 / 少量 / 廃絶 |
   | 排尿     | 正常 / 少 / 無            |
   | 排便     | 正常 / 軟 / 下痢 / 無     |
   | メモ     | フリーテキスト            |

3. 「**保存**」をクリックします。

### 保存すると

- ケア記録が入院詳細画面に時系列で表示されます

---

## 投薬実施を記録する

1. ケア記録ダイアログの「**投薬実施**」タブを開きます。
2. 投薬情報を入力します：

   | 項目     | 必須 |
   | -------- | ---- |
   | 薬剤     | ✅   |
   | 用量     | ✅   |
   | 投与時刻 | ✅   |
   | 担当者   | ✅   |

3. 「**追加**」ボタンをクリックします。

### 追加すると

- 投薬記録が保存されます
- 薬剤の在庫減算が予約されます（確定は会計時）

---

## 退院処理をする

1. 入院詳細画面の右上「**退院処理**」ボタンをクリックします。
2. 退院情報を入力します：

   | 項目         | 必須 | 内容               |
   | ------------ | ---- | ------------------ |
   | 退院日時     | ✅   | 既定: 現在時刻     |
   | 退院サマリー | ✅   | 期間中の経過・所見 |
   | 帰宅後の指示 | 任意 |                    |

3. 「**確定**」ボタンをクリックします。

### 確定すると

- ステータスが「**退院済**」になります
- 退院日時・サマリーが記録されます
- **該当ケージが空き状態になります**
- **会計が自動で作られます**（「会計待ち」状態）
  - 明細: 入院日数 × プラン単価 + ケア中の処置・投薬 + 物販

---

## 入院期間を延長する

1. 入院詳細画面で「**編集**」モードを開きます。
2. 「**予定退院日**」を新しい日付に変更します。
3. 「**保存**」をクリックします。

### 変更すると

- 予定退院日が更新されます
- **ケージ占有期間が自動で延長** されます
- 会計時の入院日数が自動で再計算されます

### 警告が出る場合

延長期間で他予約とケージが競合する時、警告が表示されます。

---

## ケージを変更する

1. 入院詳細画面で「**編集**」モードを開きます。
2. 「**ケージ番号**」プルダウンで別のケージを選びます。
3. 「**保存**」をクリックします。

### 変更すると

- 元のケージが空きになります
- 新しいケージがロックされます
- ケージ変更履歴が記録されます

---

## 必要な権限

- 画面を見る → 閲覧権限
- 新規・編集 → 編集権限
