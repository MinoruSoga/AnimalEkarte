# ケージマスタ

## どんな画面か

入院・ペットホテルで使用する **ケージ（収容箱）の登録・管理** を行うマスタです。入院登録時にケージを選ぶ際の選択肢になります。

## 開き方

サイドバー「**マスタ設定**」→「**入院・ケージ**」

## 一覧の表示項目

- **ケージ番号**: 識別番号（例: A-1、ICU-3）
- **種類**: 犬用・猫用・小動物用 等
- **サイズ**: 小・中・大
- **設置場所**: 病棟・フロア等
- **対応動物種**: 犬 / 猫 / その他
- **特別設備**: ICU / 酸素ケージ / 温度管理 等
- **有効/無効**

---

## 新規ケージ登録

1. 画面右上の「**新規追加**」ボタンをクリックします。
2. ケージ情報を入力：

   | 項目                       | 必須 |
   | -------------------------- | ---- |
   | ケージ番号                 | ✅   |
   | 種類（犬用/猫用/小動物用） | ✅   |
   | サイズ                     | ✅   |
   | 設置場所                   | 任意 |
   | 対応動物種                 | ✅   |
   | 特別設備                   | 任意 |

3. 「**保存**」

### 登録後

- 入院登録画面のケージ選択肢に表示される
- 「ケージ稼働状況」タブで該当ケージが表示される

---

## ケージの変更・無効化

### 変更

- 一覧で該当ケージをクリック → 編集
- サイズ・設置場所・特別設備等を更新
- 「**保存**」

### 無効化（撤去時）

- 「**有効**」スイッチを OFF
- 過去の入院記録は保持される
- 新規入院時の選択肢から消える

---

## 注意事項

- 入院記録から参照されているケージは **削除不可**。無効化を使用
- ケージ番号は重複不可
- 撤去予定のケージは事前に無効化し、新規入院での誤選択を防ぐ

---

## 関連する画面

- 業務フロー「**入院の登録から退院・会計まで**」: 入院フロー全体
- 画面マニュアル「**入院プランマスタ**」: 入院料金設定
