# ケージマスタ

## どんな画面か

入院・ペットホテルで使用する **ケージ（収容箱）の登録・管理** を行うマスタです。入院登録時にケージを選ぶ際の選択肢になります。

## 開き方

サイドバー「**マスタ設定**」→「**入院・ケージ**」→「**ケージマスタ**」

## 一覧の表示項目

- **ケージ番号**: 識別番号（例: A-1、ICU-3）
- **種類**: 犬用・猫用・小動物用 等
- **サイズ**: 小・中・大
- **設置場所**: 病棟・フロア等
- **対応動物種**: 犬 / 猫 / その他
- **特別設備**: ICU / 酸素ケージ / 温度管理 等
- **有効/無効**
- **連結状態**: 連結中のケージにはバッジが表示されます
  - メンバーケージ: 「連結中: 代表ケージ名」
  - 代表ケージ: 「連結中（代表）: 構成ケージ名…」

---

## ケージの一時連結（複数ケージを1室として運用）

隣接する複数のケージを一時的に合体させ、**1つの入院スペース**として使う機能です。大型動物や多頭入院に対応します。

### 連結する

1. 一覧で連結したいケージの **チェックボックスを2つ以上** 選択します。
   - 選べるのは **有効・未連結・占有中でない** ケージだけです（連結済み・無効なケージのチェックボックスは選べません）。
2. 「**選択したケージを連結**」ボタンをクリックします。
3. 確認ダイアログで **代表ケージ** を選び、「連結する」で確定します。
   - 代表ケージの単価が入院料金に使われます。

> 入院ボード（`/hospitalization`）の「連結モード」から、ケージ同士をドラッグ&ドロップして連結することもできます。

### 解除する

- 連結済みの行（メンバー・代表どちらでも）の「**連結解除**」ボタン → 確認ダイアログで「解除」
- グループ内のいずれかのケージに **入院中・予約中** の動物がいる場合は解除できません

### 連結中の動作

- 入院登録のケージ選択肢では **代表ケージだけ** が選べます（構成ケージは選べません。表示名は「代表名 + 構成名…」）
- 連結中のケージ（代表・メンバーとも）は **無効化・削除できません**。先に連結を解除してください
- **退院しても連結は自動で解除されません**。運用が終わったら明示的に解除してください

## 新規ケージ登録

1. 画面右上の「**新規追加**」ボタンをクリックします。
2. ケージ情報を入力：

   | 項目                       | 必須 |
   | -------------------------- | ---- |
   | ケージ番号                 | ✅   |
   | 種類（犬用/猫用/小動物用） | ✅   |
   | サイズ                     | ✅   |
   | 設置場所                   | 任意 |
   | 対応動物種                 | ✅   |
   | 特別設備                   | 任意 |

3. 「**保存**」

### 登録後

- 入院登録画面のケージ選択肢に表示される
- 「ケージ稼働状況」タブで該当ケージが表示される

---

## ケージの変更・無効化

### 変更

- 一覧で該当ケージをクリック → 編集
- サイズ・設置場所・特別設備等を更新
- 「**保存**」

### 無効化（撤去時）

- 「**有効**」スイッチを OFF
- 過去の入院記録は保持される
- 新規入院時の選択肢から消える

---

## 注意事項

- 入院記録から参照されているケージは **削除不可**。無効化を使用
- ケージ番号は重複不可
- 撤去予定のケージは事前に無効化し、新規入院での誤選択を防ぐ
