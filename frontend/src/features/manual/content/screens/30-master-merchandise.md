# 物販マスタ

## どんな画面か

院内で販売する **フード・サプリ・グッズ等の物販商品** を管理するマスタです。会計画面で物販追加する際の選択肢になります。

## 開き方

サイドバー「**マスタ設定**」→「**物販・フード**」

## 一覧の表示項目

- **商品名**: フード商品名・サプリ名 等
- **カテゴリ**: フード / サプリ / グッズ / その他
- **販売単価（税込）**
- **税区分**: 標準 10% / 軽減 8%
- **在庫紐付け**: あり/なし
- **有効/無効**

---

## 新規商品の登録

1. 「**新規追加**」ボタン
2. 商品情報を入力：

   | 項目               | 必須 | 内容                     |
   | ------------------ | ---- | ------------------------ |
   | 商品名             | ✅   |                          |
   | カテゴリ           | ✅   | フード / サプリ / グッズ |
   | 販売単価（税込）   | ✅   |                          |
   | 税区分             | ✅   | 標準 10% / 軽減 8%       |
   | 在庫アイテム紐付け | 任意 | 在庫マスタから選択       |
   | バーコード         | 任意 |                          |
   | メモ               | 任意 |                          |

3. 「**保存**」

### 登録後

- 会計画面の物販選択肢に表示される
- 在庫紐付けがあれば、会計確定時に自動減算

---

## 軽減税率（8%）の使い分け

| カテゴリ           | 税率        |
| ------------------ | ----------- |
| フード（飲食料品） | 8%（軽減）  |
| サプリ（食品扱い） | 8%（軽減）  |
| グッズ・玩具       | 10%（標準） |
| 消耗品             | 10%（標準） |

詳細は税務担当・院長と相談のうえ設定。

---

## 在庫紐付け（重要）

物販と在庫アイテムを接続すると、会計確定時に **在庫が自動減算** されます。

詳細は画面マニュアル「**在庫管理**」参照。

---

## 編集・無効化

- 単価変更: 過去会計には影響しない、今後の販売から反映
- 廃番商品: 「有効」スイッチ OFF で無効化

---
