# 検査マスタ

## どんな画面か

カルテ・検査管理で使用する **検査種別** と、各検査の **入力項目（検査項目）・単位・正常値・動物種別の基準範囲** を管理するマスタです。

検査種別を登録するとカルテの検査項目選択肢に表示され、検査項目を定義すると検査結果の入力欄と正常範囲の自動判定に使われます。

## 開き方

サイドバー「**マスタ設定**」→「**カルテ関連**」→「**検査マスタ**」

> 「診療項目」画面の「**検査**」タブがそのまま開きます（URL: `/settings/treatment-items?tab=examination`）。他のタブ（診察 / 処置 / 予防接種 / 定期健診）は画面マニュアル「**診療項目**」を参照してください。

## 一覧の表示項目

- **項目名**: 「血液検査（CBC）」「生化学検査」等の検査種別
- **略称** / **診療コード**
- **税込単価** / **税区分**
- **有効/無効**

## 検査種別の登録

1. 「**検査**」タブで「**新規追加**」ボタン
2. 項目名・単価・税区分などを入力（詳しくは画面マニュアル「**診療項目**」と同じ）
3. 「**保存**」

## 検査項目（フィールド）の定義

検査種別を開くと、サイドパネル下部に「**検査項目**」セクションが表示されます。ここでその検査を構成する各項目を定義します。

| 項目       | 内容                                             |
| ---------- | ------------------------------------------------ |
| 検査項目名 | 例: WBC（白血球数）、Hb（ヘモグロビン）          |
| 単位       | 検査値の単位（例: mg/dL、%）                     |
| 検査値     | 検査項目のコード／識別用の値                     |
| 正常値     | 正常とみなす基準値。数値範囲や定性値で指定       |

- 「**追加**」ボタンで検査項目を追加
- 一覧は **ドラッグ＆ドロップで並べ替え** できます（検査結果の表示順に反映）
- 各項目の「**動物種別の基準範囲**」で、動物種ごとに基準値の下限・上限を個別設定できます

### 動物種別の基準範囲

犬・猫など動物種ごとに正常範囲が異なる場合、基準範囲を動物種ごとに設定できます。

- 「**（動物種名）の基準範囲を使用**」にチェック → その動物種の下限・上限を入力
- 未設定の動物種は「正常値」の値が共通の基準として使われます
- 動物種の選択肢は「**動物種類**」マスタの登録内容が使われます

### 効果

検査結果入力時、入力値はこの基準範囲と **自動比較** されます：

- 上限超 → 高値として強調表示
- 下限未満 → 低値として強調表示

## 編集・無効化

- 一覧行をクリック → サイドパネルで編集 → 「**保存**」
- 廃止した検査は「**有効**」スイッチを OFF（削除ではなく無効化を推奨）

## 必要な権限

- 閲覧・編集には「**カルテマスタ**」の権限が必要です

## 関連する画面

- 画面マニュアル「**診療項目**」: 診察 / 処置 / 予防接種 / 定期健診タブ
- 画面マニュアル「**検査機器マスタ**」: 検査機器の受信結果と検査項目のマッピング
- 画面マニュアル「**検査管理**」: 検査結果の入力・確認
- 画面マニュアル「**動物種類**」: 基準範囲で使う動物種の登録
- 業務フロー「**導入時の初期設定チェックリスト**」: 検査マスタを含む初期設定の順序
