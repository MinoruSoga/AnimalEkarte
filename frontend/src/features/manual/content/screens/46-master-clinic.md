# 医院マスタ

医院の基本情報（院名・住所・連絡先）に加えて、消費税率や **明細兼領収書の表示設定**、**インボイス登録番号** を管理するマスタです。領収書・診断書などの出力レイアウトに直接影響します。

## 開き方

サイドバー「**マスタ設定**」→「**医院**」をクリックします。

## 画面イメージ

![医院マスタ 画面](images/46-master-clinic.png)

## 一覧の表示項目

- **院名**: 医院の名称
- **電話番号**: 代表電話番号
- **メール**: 連絡先メールアドレス
- **ステータス**: 有効 / 無効

検索欄で院名・電話番号・メールから絞り込めます。

## 医院を登録・編集する

1. 「**新規登録**」ボタン（または一覧の該当行）をクリックすると、右側に編集パネルが開きます。
2. 各項目を入力します：

   | 項目           | 内容                                             |
   | -------------- | ------------------------------------------------ |
   | 医院名         | 必須                                             |
   | ステータス     | 有効 / 無効の切替                                |
   | 郵便番号・住所 | 領収書などのヘッダーに印字される所在地           |
   | 電話番号・FAX  | 連絡先                                           |
   | 登録番号       | 動物病院の届出番号など                           |
   | 院長名         | 代表者名                                         |
   | メール         | 連絡先メールアドレス                             |
   | Webサイト      | 医院ホームページの URL                           |

3. 「**保存**」をクリックします。

## 消費税率

「**通常課税**」と「**軽減税率**」の税率を設定します。会計計算に反映されます。

## 明細兼領収書の表示設定

領収書に表示する要素を ON / OFF で切り替えます：

- ロゴ表示
- 登録番号警告
- 項目カテゴリ
- 医院情報ヘッダー
- 飼主・ペット情報
- 明細テーブル
- お会計サマリー
- セクションの表示順
- フッターテキスト

## インボイス登録番号

一覧上部の「**法人情報（インボイス）**」カードで、適格請求書（インボイス）の登録番号を入力して「**保存**」をクリックします。

## 削除する

編集パネル上部の削除アイコンから削除できます。「**医院を削除しますか？**」の確認が表示され、この操作は取り消せません。

---

## 必要な権限

- 画面を見る → `hospital-settings` の閲覧権限
- 登録・編集・削除 → `hospital-settings` の編集・削除権限
