# カルテ

## どんな画面か

診察内容・処置・処方・検査の記録を作成・編集する画面です。カルテを確定すると、自動的に会計が作られ、受付ステータスも自動で進みます。

## 開き方

- サイドバー左メニューの「**カルテ**」をクリック
- または、当日の受付画面で **ペット名をクリック**（カルテ作成画面に直接遷移）

## 画面イメージ

![カルテ 画面](images/04-medical-records.png)

## 画面の見方

### 一覧の表示項目

- **診療日**
- **飼主名**
- **ペット名**
- **種**: 動物種
- **主訴**: 来院目的
- **関連**: 紐付く会計がある場合「会計」ボタン
- **担当医**
- **ステータス**: 作成中 / 確定済

絞り込み: 日付 / 動物種 / ステータス / 担当医

---

## 新しいカルテを作成する

### A. 受付一覧から作成（推奨）

1. サイドバー「**当日の受付**」画面を開きます。
2. 該当ペットのカードでペット名をクリックします。
3. カルテ作成画面が開き、受付情報が自動で連動します。

### B. カルテ画面から作成

1. サイドバー「**カルテ**」を開きます。
2. 右上の「**新規カルテ**」ボタンをクリックします。
3. ペット選択画面でペットを検索・選びます。
4. カルテ作成画面が開きます。

---

## カルテを入力する

カルテ画面には以下のセクションがあります：

| セクション | 入力内容 |
|----------|---------|
| 基本情報 | 来院日時 / 診察医 / 看護師 / 体重 / 体温 |
| 主訴 | 飼主の相談内容（問診テンプレートから選択も可） |
| 所見 | 視診・触診・聴診の結果 |
| 診断 | 病名（マスタ選択 / 自由入力） |
| 処置 | 治療項目（マスタから選択） |
| 処方 | 薬剤・数量・用法 |
| 検査 | 別画面の「検査管理」と連動 |
| 次回案内 | 次回来院予定日 |
| メモ | フリーテキスト |

### 保存するには

| ボタン | 動作 |
|--------|------|
| 「下書き保存」 | ステータス「作成中」で保存。後で続きを編集できます |
| 「確定」 | ステータス「確定済」になります（詳細は後述） |

---

## カルテを確定する

入力完了後、画面上の「**確定**」ボタンをクリックします。

### 確定後に起きること

- カルテのステータスが「**確定済**」になります
- **カルテは編集できなくなります**
- 受付ステータスが **「会計待ち」** に自動で変わります
- **会計が自動で作られます**
  - カルテの処置・処方・検査が会計の明細に自動で入ります
- 処方薬剤の在庫減算が予約されます（確定は会計時）

### 確認する場所

- 受付一覧で「会計待ち」カラムにカードが移動します
- 会計一覧に新しい会計が表示されます

### 確定後にできなくなること

- 明細の **直接編集はできません**
- 修正したい時は「**追記（Addendum）**」機能を使います（後述）

### エラーになる場合

- 必須項目が未入力
- 処方薬剤の在庫が数量より少ない（警告のみ。強行できる場合あり）

---

## 確定後にカルテを修正する（追記）

確定済カルテの内容を修正する場合は「**追記**」を使います。

1. 該当カルテの詳細画面を開きます。
2. 「**追記**」ボタンをクリックします。
3. 追記内容を入力します。
4. 「**追加**」ボタンをクリックします。

### 追記後

- 元のカルテはそのまま残ります
- 追記内容が時系列で追加されます
- 追記者・追記時刻が自動で記録されます

---

## ファイルを添付する

カルテに画像（皮膚状態・X線・エコー画像など）や PDF を添付できます。

1. 「**ファイル添付**」ボタンをクリックします。
2. ファイルを選択します。

### 添付の制約

- 形式: JPEG / PNG / PDF
- サイズ上限: 1 ファイル 10MB

### 添付後

- カルテ詳細画面にサムネイルが表示されます

---

## 過去履歴を参照する

カルテ画面の **右側パネル** に過去履歴が表示されます（読み取り専用）：

| パネル | 内容 |
|-------|------|
| 直近カルテ | 過去 5 件のサマリー |
| 投薬履歴 | 過去の処方薬 |
| アレルギー情報 | ペット情報から |
| ワクチン履歴 | 接種記録 |
| 検査結果 | 検査記録 |
| 慢性疾患 | ペット情報から |

慢性疾患の経過観察や投薬の継続判断に活用できます。

---

## 他のスタッフが同時に編集すると

複数のスタッフが同じカルテを同時に編集した場合、後から保存したスタッフにエラーが表示されます：

> 他のスタッフが編集中です。画面を更新してください

画面を再読み込みしてから、もう一度編集してください。

---

## 必要な権限

- 画面を見る → 閲覧権限
- 新規作成 → 作成権限
- 編集・確定・追記 → 編集権限

---

|------|------|

| 検査管理 | 検査結果が自動連動します |
