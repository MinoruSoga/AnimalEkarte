# カルテ

## どんな画面か

診察内容・処置・処方・検査・画像・見積などを **SOAPS 形式** で記録する画面です。確定後は編集がロックされ、訂正は追記（addendum）で行います。

## 開き方

- サイドバー「**カルテ**」→ URL: `/medical-records`
- 当日の受付（`/`）のカード／詳細から「カルテ作成」「カルテ入力」
- 予約管理（`/reservations`）の詳細から「カルテ作成」

関連 URL:

| 用途 | URL |
|------|-----|
| 一覧 | `/medical-records` |
| ペット選択 | `/medical-records/select-pet` |
| 新規 | `/medical-records/new` |
| 詳細・編集 | `/medical-records/:id` |

## 画面の見方（一覧）

| 項目 | 内容 |
|------|------|
| 診療日 | 診療が行われた日付 |
| 飼主名／ペット名／種 | 各カラム |
| 主訴 | 来院理由の要約 |
| 関連 | 紐付く会計がある場合「会計」ボタン |
| 担当医 | 診察医 |
| ステータス | **作成中** / **確定済** |

絞り込み: 全文検索・期間・担当医・動物種・ステータス。複数医院所属時は拠点横断フィルタも使えます。

---

## 新しいカルテを作成する

### A. 受付・予約から（推奨）

1. 当日の受付または予約管理で対象を開きます。
2. 「**カルテ作成**」を押します。
3. 予約が受付済／予約確定の一般診療の場合、カルテが **best-effort で自動作成** されていることがあります（トリミング・入院／ホテル予約は対象外）。一覧に「作成中」として出ている場合はそれを開きます。

### B. カルテ画面から

1. `/medical-records` を開きます。
2. 「**新規カルテ**」→ ペット選択（`/medical-records/select-pet`）。
3. `/medical-records/new` に遷移すると、表示と同時に draft カルテが自動作成され、URL が `/medical-records/:id` に置き換わります。

## カルテを入力する（9 タブ）

| タブ | 内容 |
|------|------|
| 問診 | 主訴・症状・生活環境 |
| 診察／治療プラン | 身体検査所見（S/O/A）、診断、治療方針（Plan） |
| 治療 | 処置・処方明細（行ごとに即時保存） |
| 予防接種 | 接種記録・次回予定 |
| 定期健診 | 健診結果 |
| 検査 | 既存検査の取込・一覧。新規検査は `/examinations/new` で作成 |
| 画像 | 写真・PDF の添付 |
| 見積書 | 概算費用 |
| 会計（医師確認） | 診療費の医師確認（チェック完了／差戻） |

### 保存のしかた

- 画面右下の「**保存**」は **開いているタブの内容** を保存します（問診／診察・治療プランなど）。
- 「治療」タブの明細は、追加・編集・削除のたびに個別 API へ即時送信されます。
- 担当医・来院種別・診察日・次回予定などヘッダー項目は、変更時に個別保存されるものがあります。
- 未保存のまま離れると確認が出ます。

> 「下書き保存」「確定で一括送信」という単一ボタン構成ではありません。

---

## カルテを確定する

入力が終わったら、フローティング操作の「**確定する**」を押し、確認ダイアログで確定します（編集権限・保存済み・未確定のときのみ表示）。

### 確定後に起きること

- ステータスが **確定済** になり、カルテ本体と紐付く検査・処置・処方・バイタル・画像などの更新がロックされます
- 修正は **追記（addendum）のみ**（確定の取り消し API はありません）
- 予約に紐づくカルテの場合、no-show／キャンセル済み予約では確定できません

### 確定後に起きないこと（重要）

- **会計レコードが自動作成されるわけではありません**
- 受付カラムが必ず「会計待ち」に自動で進むわけではありません
- 会計の明細は、会計画面（`/accounting/new` など）を開いたときに **未請求明細として取り込まれます**（医師確認や処置・検査の状態により候補が変わります）

### 処方の安全ガード

- 体重・動物種から数量が自動プリフィルされる場合があります
- マスタ上限を超える数量は保存できません（理由を表示して送信しません）

---

## 確定後にカルテを修正する（追記）

1. 確定済カルテを開きます。
2. 「**追記**」から訂正内容を入力して追加します。
3. 元の記録は残り、追記が時系列で追加されます。

---

## ファイルを添付する

「画像」タブから患部写真・X 線・エコー・PDF などを添付できます。確定済カルテでは追加・削除できません。

---

## 過去履歴を参照する

タブごとに履歴パネルがあります（問診タブの過去問診、予防接種タブの接種履歴など）。フォーム全体で 1 つの固定サイドパネルという構成ではありません。

---

## 他のスタッフが同時に編集すると

バージョン不一致などで後から保存した側にエラーが出ることがあります。画面を更新してからやり直してください。

---

## 必要な権限

| 操作 | 権限の目安 |
|------|------------|
| 一覧・詳細を見る | `medical-records:view` |
| 新規作成 | `medical-records:create` |
| 編集・確定・追記 | `medical-records:edit` |
| 誤作成の削除 | `medical-records:delete` |
| 会計ボタン表示 | `accounting:view` |
| 見積タブ | `estimates` の閲覧／作成／編集 |

---

## 関連する画面

| 画面 | 関係 |
|------|------|
| 当日の受付（`/`） | 作成導線。カルテ作成と同時に診療中へ進む場合あり |
| 検査管理（`/examinations`） | 検査の作成・結果。カルテの検査タブで取込 |
| 会計管理（`/accounting`） | 未請求明細の取込と精算 |
| 予防接種（`/vaccinations`） | 接種記録の別管理画面 |
| 見積（`/estimates`） | 見積の一覧・詳細 |
