# 予約区分マスタ

## どんな画面か

予約・受付・カルテで使用する **予約区分** を管理するマスタです。診察 / トリミング / ワクチン / 入院 等の区分定義。

## 開き方

サイドバー「**マスタ設定**」→「**予約区分**」

## 一覧の表示項目

- **区分名**: 診察 / 再診 / トリミング / ワクチン 等
- **カテゴリ**: 診療系 / 予防系 / 美容系 / 入院系 / その他
- **デフォルト所要時間**: 30 分 / 60 分 等
- **色**: カレンダー表示の色分け
- **有効/無効**

---

## 既定の予約区分例

| 区分名     | カテゴリ | 所要時間 | 色  |
| ---------- | -------- | -------- | --- |
| 初診       | 診療系   | 30 分    | 青  |
| 再診       | 診療系   | 15 分    | 青  |
| ワクチン   | 予防系   | 15 分    | 緑  |
| 健診       | 予防系   | 30 分    | 緑  |
| トリミング | 美容系   | 90 分    | 紫  |
| 入院       | 入院系   | 60 分    | 茶  |
| 手術       | 診療系   | 120 分   | 赤  |

---

## 新規区分の登録

1. 「**新規追加**」ボタン
2. 区分情報を入力：

   | 項目               | 必須 | 内容           |
   | ------------------ | ---- | -------------- |
   | 区分名             | ✅   |                |
   | カテゴリ           | ✅   |                |
   | デフォルト所要時間 | ✅   | 分単位         |
   | 色                 | ✅   | カラーピッカー |
   | 表示順             | 任意 |                |

3. 「**保存**」

---

## 色設定の効果

- 予約管理カレンダー: 区分ごとに予約ブロックが色分けされる
- 当日の受付: カードに色付きバッジ表示
- 視覚的に予約種別を識別しやすくなる

---

## カテゴリの効果

月次集計レポートの「**診療カテゴリ別売上**」で、カテゴリごとに集計されます：

- 診療系 vs 予防系 vs 美容系 の売上構成比を把握

---

## 編集・無効化

- 区分名変更: 表示のみ反映、過去予約は元データのまま
- 廃止する区分: 「有効」スイッチ OFF

---

## 関連する画面

- 画面マニュアル「**予約管理**」: 予約区分を選択
- 画面マニュアル「**当日の受付**」: 区分別色分け
- 画面マニュアル「**月次集計レポート**」: カテゴリ別集計
