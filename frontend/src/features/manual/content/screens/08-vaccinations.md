# 予防接種

## どんな画面か

ワクチン接種を記録し、次回接種予定日を自動で算出する画面です。期限管理と LINE 自動配信タグの起点になります。

## 開き方

サイドバー左メニューの「**予防接種**」をクリックします。

## 画面イメージ

![予防接種 画面](images/08-vaccinations.png)

## 画面の見方

### 一覧の表示項目

- **実施日**
- **飼主名・ペット名**
- **予防接種名**
- **次回予定**: 自動算出された日付
- **期限ステータス**: 期限内 / 期限間近 / 期限切れ

### 絞り込み

| フィルタ       | 入力                         |
| -------------- | ---------------------------- |
| 期限ステータス | 期限内 / 期限間近 / 期限切れ |
| ワクチン種別   | マスタ定義のワクチン         |
| 動物種         | 犬 / 猫 / その他             |

---

## 新規接種を登録する

1. 画面右上の「**新規登録**」ボタンをクリックします。
2. ペットを検索・選択します。
3. 接種情報を入力します：

   | 項目           | 必須 | 内容                  |
   | -------------- | ---- | --------------------- |
   | ワクチン種別   | ✅   | マスタから選択        |
   | 接種日         | ✅   | 既定: 当日            |
   | ロット番号     | ✅   | 副反応追跡用          |
   | 有効期限       | ✅   | 自動算出 or 手動入力  |
   | 担当医         | ✅   | スタッフから選択      |
   | 接種部位       | 任意 | 左肩 / 右肩 / 背部 等 |
   | 副反応観察記録 | 任意 |                       |

4. 「**登録**」ボタンをクリックします。

### 登録すると

- 接種記録が保存されます
- **次回接種予定日が自動で算出されます**（接種日 + マスタの間隔）
- **該当ワクチンの在庫が自動で減算されます**

### 確認する場所

- 予防接種一覧に行が追加されます
- 在庫管理画面でワクチン在庫の減算が確認できます

---

## 期限ステータスの仕組み

次回予定日と現在日付の差分で自動計算されます：

| ステータス | 条件                    |
| ---------- | ----------------------- |
| 期限内     | 次回予定 - 今日 > 30 日 |
| 期限間近   | 30 日以内               |
| 期限切れ   | 次回予定を過ぎている    |

---

## 接種記録を編集する

1. 一覧で該当行をクリックします。
2. 編集モードで項目を変更します。
3. 「**保存**」をクリックします。

### 保存すると

- 接種記録が更新されます
- 変更履歴が記録されます

---

## Lステップタグの自動付与

Lステップ連携が有効な場合、期限間近・期限切れの飼主に自動的にタグが付与されます（定期バッチで実行）。

- 期限間近 → `vaccine_期限間近_30日前` などのタグ
- 期限切れ → `vaccine_期限切れ` などのタグ

これらのタグに紐付くシナリオが Lステップ側で設定されていれば、自動で配信されます。

### 確認する場所

サイドバー「**Lステップ連携**」→「**タグ管理**」
