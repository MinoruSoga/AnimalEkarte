# LINE予約管理

## どんな画面か

飼主向け LINE 予約の **稼働状態・受付ルール・表示文言・予約可能枠** を設定する画面です。

## 開き方

サイドバー「**LINE予約管理**」からサブメニューを開きます。

| サブメニュー         | URL                                                     | 内容                      |
| -------------------- | ------------------------------------------------------- | ------------------------- |
| （トップ／基本設定） | `/line-reservation` または `/line-reservation/settings` | 稼働・受付ルール・連携 ID |
| ページ編集           | `/line-reservation/page-editor`                         | 飼主向け文言              |
| 予約枠               | `/line-reservation/slots`                               | 区分別の予約可能開始時刻  |

## 基本設定（`/line-reservation/settings`）

### 稼働・受付ルール

| 項目                 | 内容                                             |
| -------------------- | ------------------------------------------------ |
| LINE予約受付         | 受付中／停止中の切替                             |
| 受付期間             | 最短・最長の予約受付日数（何日前から何日先まで） |
| タイムスロットモード | 空き時間を最小化／許容                           |

営業時間・定休日・スロット間隔など、画面に表示されている項目を医院の運用に合わせて設定します。固定の既定日数をマニュアル上の仕様として扱わず、画面の現在値を正とします。

### LINE 連携 ID

| 項目        | 内容           |
| ----------- | -------------- |
| チャネル ID | Channel ID     |
| LIFF ID     | LIFF アプリ ID |

> チャネルシークレットやアクセストークンは **この画面では入力しません**（平文 UI に置かない設計）。別経路で保持されます。

保存すると LIFF 側の動作に反映されます。設定 API は医院設定系の権限も関与するため、画面遷移権限（予約）と API 権限が異なる場合があります。権限エラー時は管理者に確認してください。

## ページ編集（`/line-reservation/page-editor`）

飼主が LINE 内で見る文言を、次のテキストエリアで編集します（フェーズ別タブではありません）。

| 項目                   | 内容               |
| ---------------------- | ------------------ |
| ヘッダーテキスト       | ページ上部の文言   |
| 予約時の注意事項       | 予約時の案内       |
| キャンセル時の注意事項 | キャンセル時の案内 |
| プライバシーポリシー   | 個人情報の取扱い   |
| リクエスト例           | 記入例             |

「保存」で反映されます。ヘッダー画像アップロードやリッチテキスト編集を前提にした操作は、現行 UI にはありません。

## 予約枠（`/line-reservation/slots`）

予約区分ごとの **予約可能な開始時刻** を週カレンダーで管理します。

- 左の区分ツリーで対象を切替（`?typeId=` で事前選択可）
- 日付セルをクリックして特定日の開始時刻を追加・削除（15 分刻み）
- **毎週枠** はカレンダー上は参照表示。登録・削除は予約区分マスタ側

> 登録した開始時刻は営業時間から自動生成される枠に **加算** されます（ホワイトリストで他時刻を塞ぐ方式ではありません）。枠未登録の日も、営業時間から通常どおり枠が生成されます。

予約枠の API は予約区分マスタ権限（`master-reservation-type`）でガードされます。

## LINE 予約受信の流れ

1. 飼主が LINE 公式アカウントから予約ページ（LIFF）を開きます。
2. 区分・日時・ペット情報を入力して送信します。
3. 予約管理カレンダー（`/reservations`）に表示されます（ソース: LINE）。
4. 当日分は当日の受付（`/`）にも並びます。
5. 完了・キャンセル時は Messaging API 経由の通知と、設定された通知メールが送られる場合があります。

既存飼主との紐付けは電話番号等による auto-link（best-effort）です。
