# LINE予約管理

## どんな画面か

LINE 公式アカウント経由で受け付ける予約の **受付条件と予約ページの内容** を設定する画面です。

## 開き方

サイドバー左メニューの「**LINE予約管理**」をクリックすると、サブメニューが展開します。

| サブメニュー | 内容 |
|-----------|------|
| 基本設定 | 受付可能曜日・時間帯・予約枠の設定 |
| ページ編集 | 飼主が見る LINE 予約ページの内容編集 |

---

## 基本設定

サイドバー「**LINE予約管理**」→「**基本設定**」を開きます。

### 稼働状態

| 項目 | 入力 | 効果 |
|------|------|------|
| LINE予約受付 | トグル ON/OFF | OFF で予約受付停止 |

### 営業時間・定休日

| 項目 | 入力 | 効果 |
|------|------|------|
| 定休曜日 | 月〜日の複数選択 | 該当曜日は予約不可 |
| 祝日休診 | トグル | 祝日マスタを参照 |
| 特定定休日 | 日付リスト | 該当日を予約不可 |
| 通常営業時間 | 開始・終了時刻 | 全曜日のデフォルト |
| 曜日別営業時間 | トグル + 各曜日入力 | ON で曜日別に上書き |
| 休憩時間 | 開始・終了時刻 | 予約不可時間帯 |

### 予約枠設定

| 項目 | 入力 | 既定 |
|------|------|------|
| 最短予約受付（日前） | 数値 | 2 |
| 最長予約受付（日前） | 数値 | 30 |
| 表示カレンダー月数 | 数値 | 2 |
| タイムスロットモード | 選択 | 空き時間を最小化 |
| スロット間隔（分） | 数値 | 15 |
| スタッフ不在モード | 選択 | 最初の空き |

### 連絡先・通知

| 項目 | 入力 |
|------|------|
| 電話番号 | テキスト |
| 通知メール | メール |

### LINE 連携設定

| 項目 | 入力 |
|------|------|
| チャネルID | テキスト |
| LIFF ID | テキスト |

---

## 設定を保存する

各セクション下部の「**設定を保存**」ボタンをクリックします。

### 保存すると

- 設定が保存されます
- LINE 予約ページの動作に即時反映されます

---

## ページ編集

サイドバー「**LINE予約管理**」→「**ページ編集**」を開きます。

飼主が LINE 経由で見る予約ページの内容を編集できます。

| 項目 | 入力 |
|------|------|
| ヘッダー画像 | 画像アップロード |
| 医院紹介 | リッチテキスト |
| 予約区分の説明文 | 各区分に対し |
| 予約完了後の案内メッセージ | リッチテキスト |

「**保存**」ボタンで反映されます。

---

## LINE 予約受信の流れ

1. 飼主が LINE 公式アカウントから予約ページを開きます。
2. 予約区分・日時・ペット情報を入力して送信します。
3. システムが予約を受信します。
4. **予約管理カレンダーに自動で表示** されます（LINE バッジ付き）。
5. 既存飼主は電話番号で自動マッチング、新規飼主は仮登録されます。
