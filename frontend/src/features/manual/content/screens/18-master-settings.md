# マスタ設定

## どんな画面か

システム全体で参照される基本データ（マスタ）を管理する画面群です。

## 開き方

サイドバー左メニューの「**マスタ設定**」をクリックするとサブメニューが展開します。

## 画面イメージ

![マスタ設定 画面](images/18-master-settings.png)

## 共通の操作

各マスタ画面で行う操作はほぼ同じです：

### 一覧表示

- 各マスタの項目が一覧テーブルで表示されます
- 検索・ソートできます（マスタによる）

### 新規追加

1. 画面右上の「**新規追加**」ボタンをクリックします。
2. 各項目を入力します。
3. 「**保存**」ボタンをクリックします。

### 保存すると

- 項目が保存されます
- 関連画面のプルダウン等に表示されるようになります

### 編集

1. 一覧行をクリックして編集モードに入ります。
2. 各項目を変更します。
3. 「**保存**」をクリックします。

## 削除（無効化）について

他のデータから参照されているマスタは **削除できません**：

- 「**無効化**」して非表示にします（有効 / 無効の切替）
- 過去のデータからは引き続き参照されます
- 新規作成時の選択肢からは表示されなくなります

### 削除が制限される主なマスタ

| マスタ   | 削除制限の理由                           |
| -------- | ---------------------------------------- |
| 診療項目 | 過去会計から参照されている               |
| 薬剤     | カルテの処方履歴から参照されている       |
| スタッフ | カルテ・会計の担当者として参照されている |
| 予約区分 | 過去予約から参照されている               |
| ケージ   | 入院記録から参照されている               |

## 主なマスタの解説

### 医院情報

サイドバー「**マスタ設定**」→「**医院**」

| 項目     | 入力       |
| -------- | ---------- |
| 医院名   | テキスト   |
| 住所     | テキスト   |
| 電話番号 | テキスト   |
| メール   | メール     |
| 営業時間 | 開始〜終了 |
| 休診日   | 曜日選択   |

---

### 動物種類

サイドバー「**マスタ設定**」→「**動物種類**」

- 動物種（犬・猫・鳥 等）
- 品種（柴犬・トイプードル 等）

品種は動物種に紐付けて登録します。

---

### 診療項目

サイドバー「**マスタ設定**」→「**診療項目**」

タブ:

- 検査
- ワクチン
- 診察
- 処置

| 項目               | 入力         |
| ------------------ | ------------ |
| 名称               | テキスト     |
| 単価（税込）       | 数値         |
| カテゴリ           | 選択         |
| 在庫アイテム紐付け | 在庫から選択 |
| 有効/無効          | トグル       |

---

### 権限グループ

サイドバー「**マスタ設定**」→「**権限グループ**」

詳細は業務フロー「スタッフアカウント・権限の管理」を参照してください。

権限マトリクス：機能ごとに「閲覧 / 新規作成 / 編集 / 削除」のチェックボックスで権限を設定します。

---

### 締め時間設定

サイドバー「**マスタ設定**」→「**締め時間設定**」

| 項目          | 内容   | 既定  |
| ------------- | ------ | ----- |
| 1日の境界時刻 | 時刻   | 23:59 |
| 午前終了時刻  | 時刻   | 12:30 |
| 午後開始時刻  | 時刻   | 14:00 |
| 特別期間      | リスト | -     |

深夜営業のクリニックでは「1日の境界時刻」を翌 05:00 等に設定することもできます。

---

## 必要な権限

各マスタの編集には、それぞれ対応する権限が必要です。詳細は権限グループの設定を参照してください。
