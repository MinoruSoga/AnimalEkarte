# 問診テンプレートマスタ

## どんな画面か

カルテの **主訴・問診欄でテンプレート選択** できる定型文を管理するマスタです。よく入力する問診項目をテンプレ化することで入力時間を短縮します。

## 開き方

サイドバー「**マスタ設定**」→「**問診設定**」

## テンプレートの例

| 種類     | テンプレート内容                                      |
| -------- | ----------------------------------------------------- |
| 一般初診 | 主訴 / 経過 / 既往歴 / 現病歴 / 食事・排泄            |
| 皮膚科   | 痒みの程度 / 発症時期 / シャンプー頻度 / アレルギー歴 |
| 消化器   | 嘔吐回数 / 食欲 / 便の状態 / 摂取物                   |
| 整形外科 | 跛行の状態 / 発症時期 / 痛がる部位                    |
| 予防接種 | 過去接種歴 / 副反応経験 / 体調確認                    |

---

## 新規テンプレートの登録

1. 「**新規追加**」ボタン
2. 入力：

   | 項目           | 必須 | 内容                         |
   | -------------- | ---- | ---------------------------- |
   | テンプレート名 | ✅   | 例「皮膚科初診」             |
   | カテゴリ       | 任意 | 一般 / 専門科別              |
   | 内容           | ✅   | 問診項目を改行で記述         |
   | 適用区分       | 任意 | 初診のみ / 再診も / 専門外来 |

3. 「**保存**」

---

## カルテでの使用

カルテ作成画面の **主訴・問診** セクションで：

1. 「**テンプレート選択**」ボタン
2. 該当テンプレートを選択
3. 内容が自動入力される
4. 必要に応じて編集

詳細は画面マニュアル「**カルテ**」参照。

---

## 編集・無効化

- テンプレートの編集は過去カルテには影響しない
- 廃止する場合は「有効」スイッチ OFF
