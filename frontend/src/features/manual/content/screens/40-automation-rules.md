# システムの自動化ルール一覧

スタッフが操作した時に **システムが自動的に行うこと** の全体俯瞰です。「何が自動で何が手動か」を把握できると、業務がスムーズになります。

---

## カルテに関する自動化

| あなたの操作 | システムが自動で行うこと |
|----------|-------------------|
| カルテを **確定** する | 会計が自動で作られる（処置・処方・検査が明細に入る） |
| カルテを **確定** する | 受付ステータスが「会計待ち」に変わる |
| カルテを **確定** する | 処方薬剤の在庫減算が予約される |
| カルテに **検査を追加** する | 検査管理画面に自動連動 |

---

## 会計に関する自動化

| あなたの操作 | システムが自動で行うこと |
|----------|-------------------|
| 会計を **確定** する | 受付ステータスが「会計済」に変わる |
| 会計を **確定** する | 物販分の在庫が自動減算 |
| 会計を **確定** する | 領収書 PDF が生成される |
| 会計を **確定** する | 月次集計の対象になる |
| 会計を **取消** する | 物販在庫が自動で戻る |
| 会計を **取消** する | 一覧に「返金あり」表示 |
| 会計を **取消** する | 領収書に「無効」スタンプ |
| 飼主を **変更** する | 新飼主の割引率で再計算（警告ダイアログ後） |

---

## 受付に関する自動化

| あなたの操作 | システムが自動で行うこと |
|----------|-------------------|
| 当日予約を登録する | 予約管理カレンダーにも自動表示 |
| カルテを確定する | 受付ステータスが「会計待ち」に自動更新 |
| 会計を確定する | 受付ステータスが「会計済」に自動更新 |
| ペット名をクリック | 当日カルテが無ければ新規作成画面へ |

---

## 在庫に関する自動化

スタッフが手動で出庫操作する必要なし。以下で **自動的に減算** されます：

| あなたの操作 | 減算される在庫 |
|----------|-------------|
| カルテ確定（処方明細） | 薬剤に紐付く在庫 |
| 予防接種登録 | ワクチンに紐付く在庫 |
| トリミング完了 | オプション消耗品 |
| 会計確定（物販明細） | 物販に紐付く在庫 |
| 入院中の投薬記録 | 薬剤に紐付く在庫 |

**取消・キャンセル時には在庫が自動で戻されます。**

---

## 入院に関する自動化

| あなたの操作 | システムが自動で行うこと |
|----------|-------------------|
| 入院を **登録** | 該当ケージが期間中ロックされる |
| 退院処理を **確定** | 該当ケージが空き状態になる |
| 退院処理を **確定** | 会計が自動で作成（入院日数 × プラン料金）|
| 入院期間を **延長** | ケージ占有期間も自動延長 |

---

## 予防接種・健診に関する自動化

| あなたの操作 | システムが自動で行うこと |
|----------|-------------------|
| ワクチン接種を登録 | 次回接種予定日が自動算出（接種日 + マスタの間隔） |
| ワクチン接種を登録 | 該当ワクチンの在庫が自動減算 |
| 定期健診を登録 | 次回健診予定日が自動算出 |
| 期限間近・期限切れ | サイドバーバッジで自動表示 |

---

## レジ締めに関する自動化

| あなたの操作 | システムが自動で行うこと |
|----------|-------------------|
| プレビューボタン | 集計が自動計算（売上・件数・支払方法別） |
| 現金実数入力 | 理論残高との差額を自動表示 |
| 締めを確定 | その日の全会計が編集不可になる |
| 締めを確定 | 月次集計の対象になる |

---

## Lステップ連携の自動化（連携 ON 時）

| 発生条件 | 自動付与・解除されるタグ |
|---------|-------------------|
| 来院数が一定数を超える | CPM セグメントタグ（出会い / 良好 / ファミリー / NOAH） |
| 最終来院から 180/210/240/365 日経過 | 休眠予防タグ |
| ワクチン期限間近 | `vaccine_期限間近_30日前` 等 |
| 健診経過月数到達 | `checkup_` 系タグ |
| 慢性疾患の診断 | `chronic_` 系タグ |
| ペット死亡登録 | `pet_deceased_<ペット名>`、関連リマインダータグ解除 |
| 配信エラー連続発生 | `EXCL` タグ（以後配信除外） |

---

## ペット死亡時の自動化

| あなたの操作 | システムが自動で行うこと |
|----------|-------------------|
| ペットを「死亡」でアーカイブ | 患者情報カードに「死亡」バッジ |
| 同上 | Lステップに `pet_deceased_` タグ自動付与 |
| 同上 | 既存のワクチン期限等のタグが自動解除 |
| 同上 | 関連リマインダーの配信が自動停止 |

詳細は業務フロー「**ペット死亡時の処理**」参照。

---

## 認証・セキュリティの自動化

| 発生条件 | システムの動作 |
|---------|------------|
| 同一 IP からログイン試行が 5 回 / 1 分を超過 | 一時的に拒否（約 1 分で自動回復。アカウント単位のロックなし） |
| パスワード変更直後 | 強制ログアウト → 再ログイン要求 |
| 一定時間操作なし | 自動ログアウト |
| 退職スタッフの「無効化」 | 次回ログイン以降アクセス不可 |

ログイン制限の詳細は画面マニュアル「**ログイン**」を参照。

---

## マスタ変更の自動化

| あなたの操作 | システムが自動で行うこと |
|----------|-------------------|
| 診療項目の単価変更 | 過去のカルテ・会計には影響しない（保存時の単価で記録済）|
| 同上 | 今後のカルテ作成から新単価適用 |
| マスタを「無効化」 | 新規選択肢から消える、過去データは保持 |

---

## 自動化されていないこと（手動が必要）

参考：以下は **スタッフが手動で操作** する必要があります。

- 受付ステータス「受付予約」→「受付済」
- 受付ステータス「受付済」→「診療中」
- カルテの確定（自動確定はしない）
- 会計の確定（自動確定はしない）
- 物販の明細追加
- 飼主・ペットの新規登録
- 入院の登録
- レジ締めの実行
- マスタの編集

---

## 業務効率の意識ポイント

- **「次は何を自動でやってくれるか」** を意識すると、無駄な確認作業が減る
- カルテ確定後に **「会計が作られているか」を都度確認する必要はない**（自動）
- 物販販売時に **在庫数を都度引く必要はない**（自動減算）
- ワクチン接種後に **次回案内タグ付与** をスタッフがする必要はない（自動）
