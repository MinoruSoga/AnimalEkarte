# 予約管理

## どんな画面か

診療・トリミング・手術などの全予約を **カレンダー形式** で統合管理する画面です。

## 開き方

サイドバー「**予約管理**」→ URL: `/reservations`

## 画面イメージ

![予約管理 画面](images/06-reservations.png)

## 画面の見方

### 表示モード

| モード | 内容 |
|-------|------|
| 月表示 | 日付ごとの件数・概要。日付セルクリックで週表示へ |
| 週表示 | 15 分単位の時間軸。表示日数は 5 日／7 日切替 |

> 日表示専用ビューやリスト表示は主UIではありません。

### ツールバー

- 予約区分のカラー凡例（マスタ連動）
- ソースフィルタ（手動予約 / LINE 予約）
- 担当医フィルタ

---

## 新規予約を登録する

1. 「**新規予約登録**」、またはカレンダー上の空き枠をクリックします。
2. ペットを検索して選択します（死亡ペットは選択不可）。
3. 開始・終了・予約区分・担当医などを入力します。
   - 時刻は 15 分刻み
   - 終了時刻は区分の所要時間から自動設定される場合があります
4. 登録します（`reservations:create`）。

### 登録すると

- カレンダーに表示されます
- **当日** の予約は当日の受付カンバン（`/`）にも並びます
- 一般診療で予約確定／受付済になると、カルテが best-effort で自動作成される場合があります

### 警告が出る場合

同一担当者・同一時間帯の重複があるとき、保存前に警告が出ます（新規・編集・DnD 変更時）。

---

## 予約日時を変更する

### 方法 A: ドラッグ&ドロップ（週表示）

予約ブロックを上下にドラッグし、15 分単位で時刻を変更します。

### 方法 B: 詳細・編集

予約をクリックして詳細を開き、編集から日時を変更して保存します（`reservations:edit`）。

---

## 予約をキャンセルする

1. 予約詳細を開きます。
2. キャンセル（削除）操作を行います（`reservations:delete`）。
3. 確認後、ステータスが **キャンセル** になります。

キャンセル済みはカレンダー表示から除外される設定があります。紐づく draft カルテは best-effort で論理削除される場合があります。

---

## 予約のステータス

| 表示 | 意味 |
|------|------|
| 予約確定 | 確定済み予約 |
| 仮予約 | 仮の予約 |
| 受付済 | 来院受付済み |
| 診療中 | 対応中 |
| 会計待ち | 精算待ち |
| 完了 | 完了（受付カンバンでは「会計済」カラム） |
| キャンセル | 取消 |
| 未来院 | 無断不参加（no_show） |

詳細モーダルからステータスを進めたり、カルテ／入院／トリミング記録の作成を開始できます。予約経路（LINE／電話／受付など）は編集モードで別途記録できます。

---

## LINE 予約の表示

LINE 経由の予約も同じカレンダーに表示されます（ソースフィルタで「LINE予約」に絞り込み可能）。受付条件の設定は LINE 予約管理（`/line-reservation`）で行います。

---

## 必要な権限

| 操作 | 権限の目安 |
|------|------------|
| 画面を見る | `reservations:view` |
| 新規 | `reservations:create` |
| 編集・ステータス・時刻変更 | `reservations:edit` |
| キャンセル | `reservations:delete` |

---

## 関連する画面

| 画面 | 関係 |
|------|------|
| 当日の受付（`/`） | 当日予約のカンバン |
| 飼主・ペット（`/owners`） | 患者マスタ |
| LINE予約管理（`/line-reservation`） | LINE 受付条件・ページ・枠 |
| シフト管理（`/shifts`） | スタッフ稼働 |
