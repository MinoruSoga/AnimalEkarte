# 予約管理

## どんな画面か

予約をカレンダー形式で管理する画面です。新規予約・日時変更・キャンセル・ステータス管理ができます。

## 開き方

サイドバー左メニューの「**予約管理**」をクリックします。

## 画面イメージ

![予約管理 画面](images/06-reservations.png)

## 画面の見方

### 表示モード

| モード | 表示単位 |
|-------|---------|
| 月表示 | 日 |
| 週表示 | 時刻スロット |
| 日表示 | 時刻スロット |
| リスト表示 | テーブル形式 |

切替は画面上部のプルダウンから。

---

## 新規予約を登録する

1. 画面右上の「**新規予約登録**」ボタンをクリックします。
   - またはカレンダー上の空き枠をクリックしても OK です。
2. ペット選択画面で **既存ペットを検索** するか、新規飼主を登録します。
3. 予約情報を入力します：

   | 項目 | 必須 | 内容 |
   |------|---|------|
   | 開始日時 | ✅ | カレンダーから選択 or 直接入力 |
   | 終了日時 | ✅ | 予約区分のデフォルト所要時間で自動設定 |
   | 予約区分 | ✅ | マスタから選択 |
   | 担当医・担当者 | 任意 | スタッフから選択 |
   | メモ | 任意 | |

4. 「**登録**」ボタンをクリックします。

### 登録すると

- 予約がカレンダーに表示されます
- 当日の予約の場合、「**当日の受付**」画面にも自動で表示されます

### 警告が出る場合

同じ時間帯・同じ担当者で既存予約がある時、警告が表示されます（強行可）。

---

## 予約日時を変更する

### 方法 A: ドラッグ&ドロップ

カレンダーの予約ブロックを掴んで別時刻にドロップします。確認ダイアログで日時が更新されます。

### 方法 B: 編集ダイアログ

1. 予約ブロックをダブルクリックします。
2. 編集ダイアログで日時欄を変更します。
3. 「**保存**」をクリックします。

### 警告が出る場合

変更後の時間帯で既存予約と競合する時、警告が表示されます。

---

## 予約をキャンセルする

1. 予約ブロックをクリックします。
2. 編集ダイアログの「**キャンセル**」ボタンをクリックします。
3. キャンセル理由（任意）を入力します。
4. 「**キャンセルする**」を選びます。

### キャンセルすると

- 予約のステータスが「**キャンセル**」になります
- カレンダー上では薄色・取消線で表示されます
- 当日予約の場合、紐付く受付もキャンセル状態になります

> ⚠️ 元のステータスに戻すには管理者権限が必要です。

---

## 予約のステータスを変える

予約には以下のステータスがあります：

| ステータス | 設定タイミング |
|----------|--------------|
| 予約済 | 初期状態 |
| 確認済 | 飼主への確認連絡が完了した時（手動） |
| 来院済 | 当日の受付で「受付済」になると **自動** |
| キャンセル | キャンセル操作時 |
| 無断不参加 | 当日来院がなく一定時間経過 |

編集ダイアログの「**ステータス**」プルダウンで変更できます。

---

## 絞り込みと検索

| フィルタ | 入力 |
|---------|-----|
| 表示モード | 月 / 週 / 日 / リスト |
| 予約区分 | 区分を選択 |
| 担当医 | スタッフを選択 |
| 検索 | 飼主名・ペット名・電話番号 |

---

## LINE 予約の表示

LINE 公式アカウント経由で受け付けた予約も同じカレンダーに表示されます（**LINE バッジ**付き）。

操作方法は通常の予約と同じです。

---

## 必要な権限

- 画面を見る → 閲覧権限
- 新規・編集 → 編集権限

| LINE予約管理 | LINE 経由予約の設定 |
