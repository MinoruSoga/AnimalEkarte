# レジ締め

## どんな画面か

その日の会計を集計して、レジ内の現金と照合する画面です。締めを確定すると、その日の会計は編集できなくなります。

## 開き方

サイドバー左メニューの「**レジ締め**」をクリックします。

## 画面イメージ

![レジ締め 画面](images/13-cash-register.png)

## 画面の見方

画面の上部に **対象日** と **区分** を選ぶ欄があります。

| 項目 | 内容 |
|------|------|
| 対象日 | 締めたい日付。当日または過去日を選択できます（未来日は不可） |
| 区分 | 締める時間帯。「午前」「午後」「全日」から選びます |

「区分」がどう分かれるかは、事前に「締め時間設定」（マスタ設定画面）で決められています。

---

## 集計内容をプレビューする

1. 対象日と区分を選びます。
2. 「**プレビュー**」ボタンをクリックします。
3. その日・その区分の集計が画面に表示されます。

表示される内容：

| 項目 | 内容 |
|------|------|
| 売上総額 | その日の会計済合計金額 |
| 会計件数 | 件数 |
| 支払方法別内訳 | 現金 / カード / 電子マネー / その他 |
| 取消・返金額 | 取消した会計の合計 |

この時点ではまだ何も保存されません。確認だけです。

---

## 現金実数を入力する

レジ・金庫の現金を実査し、システムに入力します。

### 金種別の入力

「**現金実数入力**」エリアでは、**金種別** に枚数を入力します：

| 金種 | 入力 |
|------|------|
| 一万円札 | 枚数 |
| 五千円札 | 枚数 |
| 二千円札（あれば） | 枚数 |
| 千円札 | 枚数 |
| 五百円硬貨 | 枚数 |
| 百円硬貨 | 枚数 |
| 五十円硬貨 | 枚数 |
| 十円硬貨 | 枚数 |
| 五円硬貨 | 枚数 |
| 一円硬貨 | 枚数 |

各金種の枚数を入力すると、**合計額が自動計算** されます。

### 理論残高との照合

システムは以下の計算式で **理論現金残高** を自動算出します：

```
理論現金残高 ＝ 前回の残高 ＋ 現金売上 ＋ 入金 ー 支出
```

- **前回の残高**: 前回締め時の現金残高（朝の釣銭額）
- **現金売上**: その日の現金支払の会計合計
- **入金**: 釣銭補充など、当日新たに入れた現金
- **支出**: 経費精算等の現金支出

入力した実数と理論残高との **差額（過不足）が自動表示** されます。

### 差額が出た時の対応

| 差額 | 対応 |
|-----|------|
| 0 円 | 完璧。締め確定へ |
| 数百円程度の不足 | 釣銭間違いの可能性。当日の現金会計を再確認 |
| 数百円程度の余剰 | 同上 |
| 数千円以上の差 | 必ず原因特定。会計記録・領収書控えを全件照合・管理者に報告 |

入力するだけではまだ保存されません。「**締め確定**」ボタンで初めて確定します。

---

## 締めを確定する

1. 差額に問題がなければ「**締め確定**」ボタンをクリックします。
2. 確認ダイアログが表示されたら「確定する」を選びます。

### 確定後に起きること

- その日の **締め記録が保存** されます
- 締め履歴一覧に追加されます
- **その日のすべての会計が編集できなくなります**
- 会計画面を開いても「閲覧専用」と表示されるようになります
- 月次集計レポートに反映されます

### 確定後にできなくなること

- 会計の明細編集・保存
- 会計の取消（管理者のみ可能。締めを巻き戻す必要があります）
- その日に新規会計を作成すること

### 確定できない場合

ボタンが押せない、またはエラーが出る場合：

| 表示 | 原因 |
|------|------|
| 「未確定の会計があります」 | その日に「会計待ち」のままの会計が残っています |
| 「既に締め済みです」 | 同じ日・同じ区分で既に締めを実行しています |
| 権限不足のメッセージ | 締めを実行する権限がありません |

---

## 締めた後の修正方法

確定後に修正が必要になった場合は、**管理者** が締めを取り消して、会計を直してから再度締める必要があります。

1. 「**締め履歴**」画面で該当の行を開きます。
2. 「**締めを取消す**」ボタンをクリックします（管理者のみ表示）。
3. 該当日の会計が再び編集できる状態に戻ります。
4. 必要な修正を行ってから、もう一度「締め確定」を実行します。

取消した記録は履歴に残ります。

---

## 締め履歴を確認する

「**レジ締め**」画面の「**履歴**」タブをクリックすると、過去の締め記録が一覧で確認できます。

- **対象日**
- **区分**: 午前 / 午後 / 全日
- **売上総額**: 集計値
- **現金実数**: 入力された実数
- **差額**: 集計と実数の差
- **締め実施者**: 操作したスタッフ名
- **締め時刻**: 確定した日時

一覧右上のボタンで PDF・CSV 出力ができます。

---

## 必要な権限

- 画面を見る → 閲覧権限
- 締めを確定する → 編集権限
- 締めを取り消す → 削除権限（管理者）
