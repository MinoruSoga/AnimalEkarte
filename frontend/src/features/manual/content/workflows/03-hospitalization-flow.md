# 入院の登録から退院・会計まで

入院・ペットホテルの **入院登録から退院処理・会計までの全手順** です。

## 使う画面

| 順番 | 画面         | 開き方                     |
| ---- | ------------ | -------------------------- |
| 1    | 入院・ホテル | サイドバー「入院・ホテル」 |
| 2    | 入院詳細     | 入院一覧の該当行クリック   |
| 3    | 会計         | 退院処理後に自動遷移       |

---

## Step 1: 入院を登録する

サイドバー「**入院・ホテル**」をクリックします。

1. 画面右上の「**新規入院登録**」ボタンをクリックします。
2. ペット選択画面でペットを検索・選びます。
3. 入院情報を入力します：

   | 項目       | 必須 | 内容                         |
   | ---------- | ---- | ---------------------------- |
   | 入院区分   | ✅   | 入院 / ペットホテル / 預かり |
   | 入院日     | ✅   |                              |
   | 予定退院日 | ✅   | 入院日以降                   |
   | ケージ番号 | ✅   | 空きケージから選択           |
   | 食事制限   | 任意 |                              |
   | 投薬指示   | 任意 |                              |
   | 特記事項   | 任意 |                              |

4. 「**登録**」ボタンをクリックします。

### 登録すると

- 入院記録が保存されます
- ステータスが「**入院中**」になります
- **該当ケージが期間中ロックされます**（他の予約から選択不可になります）
- 入院一覧にカードが追加されます
- 「**ケージ稼働状況**」タブで該当ケージが期間中ロック表示されます

### エラーになる場合

- 予定退院日が入院日より前
- 選択したケージが期間中に他予約と競合（選択肢から除外されます）

---

## Step 2: 入院中ケアを記録する

入院期間中、定期的にケア記録を入力します。

1. 入院一覧の該当行をクリック → 入院詳細画面が開きます。
2. 「**ケア記録追加**」ボタンをクリックします。
3. ケア記録を入力します：

   | 項目     | 入力                      |
   | -------- | ------------------------- |
   | 記録日時 | 既定: 現在時刻            |
   | 担当者   | スタッフから選択          |
   | 体温     | 数値（℃）                 |
   | 体重     | 数値（kg）                |
   | 食欲     | 完食 / 半分 / 少量 / 廃絶 |
   | 排尿     | 正常 / 少 / 無            |
   | 排便     | 正常 / 軟 / 下痢 / 無     |
   | メモ     | フリーテキスト            |

4. 「**保存**」をクリックします。

### 保存すると

- ケア記録が入院詳細画面に時系列で表示されます

---

## Step 3: 投薬実施を記録する

ケア記録ダイアログの「**投薬実施**」タブで入力します。

| 項目     | 必須 |
| -------- | ---- |
| 薬剤     | ✅   |
| 用量     | ✅   |
| 投与時刻 | ✅   |
| 担当者   | ✅   |

「**追加**」をクリックすると、投薬記録が保存されます。薬剤の在庫減算が予約されます（確定は会計時）。

---

## Step 4: 退院処理する

退院当日、入院詳細画面で退院処理を行います。

1. 入院詳細画面の右上「**退院処理**」ボタンをクリックします。
2. 退院情報を入力します：

   | 項目         | 必須 | 内容               |
   | ------------ | ---- | ------------------ |
   | 退院日時     | ✅   | 既定: 現在時刻     |
   | 退院サマリー | ✅   | 期間中の経過・所見 |
   | 帰宅後の指示 | 任意 |                    |

3. 「**確定**」ボタンをクリックします。

### 確定すると

- ステータスが「**退院済**」になります
- 退院日時・サマリーが記録されます
- **該当ケージが空き状態になります**
- **会計が自動で作られます**（「会計待ち」状態）
  - 明細: 入院日数 × プラン単価 + ケア中の処置・投薬 + 物販

---

## Step 5: 会計を確定する

退院処理後、自動的に会計画面が起動するか、受付一覧から会計画面を開きます。

通常の会計確定の手順で進めます（「**会計**」画面のマニュアル参照）。

### 確定すると

- 会計が「**会計済**」になります
- **物販・薬剤の在庫が自動で減算されます**
- 領収書 PDF が生成されます

---

## 入院期間を延長したい場合

予定退院日を変更したい場合の操作です。

1. 入院詳細画面の「**編集**」モードを開きます。
2. 「**予定退院日**」を新しい日付に変更します。
3. 「**保存**」をクリックします。

### 変更すると

- 予定退院日が更新されます
- **ケージ占有期間が自動で延長** されます
- 会計時の入院日数が自動で再計算されます

### 警告が出る場合

延長期間で他の予約とケージが競合する時、警告が表示されます。

---

## ケージを変更したい場合

1. 入院詳細画面の「**編集**」モードを開きます。
2. 「**ケージ番号**」プルダウンで別のケージを選びます。
3. 「**保存**」をクリックします。

### 変更すると

- 元のケージが空きになります
- 新しいケージがロックされます
- ケージ変更履歴が記録されます

---

## ケージの空き状況を確認する

サイドバー「**入院・ホテル**」→ 「**ケージ稼働状況**」タブを開きます。

各ケージの期間別占有状況がカレンダー形式で表示されます。新規入院登録時の空きケージ確認に使えます。

---
