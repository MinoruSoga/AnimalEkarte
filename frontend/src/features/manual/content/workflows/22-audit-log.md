# 監査ログ・操作履歴の確認

「誰が」「いつ」「何を」操作したかを **追跡・確認** する手順です（管理者向け）。

## なぜ必要か

- 不審な操作の発見
- 誤操作の原因特定
- データ漏洩・改ざんの追跡
- 法定保存期間のための証跡保存
- 業務改善のための操作パターン分析

---

## 自動的に記録される操作

システムは以下を **自動的に記録** しています（スタッフが意識しなくても OK）：

| 種別 | 記録内容 |
|------|---------|
| ログイン・ログアウト | 日時・端末情報 |
| カルテの作成・確定・追記 | 操作者・日時・操作前後の内容 |
| 会計の確定・取消 | 操作者・日時・取消理由 |
| 飼主・ペット情報の変更 | 変更前後のスナップショット |
| マスタ編集 | 変更項目・前後の値 |
| スタッフ権限変更 | 変更前後の権限 |
| レジ締めの確定 | 差額・実施者（締めの取消は不可・append-only） |
| 締め後会計編集 | 理由・操作者・訂正台帳への追記 |
| 大量データ操作 | エクスポート・削除 |

---

## 操作履歴の確認方法

> ⚠️ 監査ログの参照は **管理者専用機能** です。一般スタッフはアクセス不可。

### A. カルテごとの履歴

カルテ詳細画面に「**操作履歴**」または「**追記履歴**」セクションがあります（実装による）。
- 作成者・確定者・追記者の一覧
- 各操作の日時
- 内容の変更履歴

### B. 会計ごとの履歴

会計詳細画面で、取消されている場合は：
- 取消時刻
- 取消実施者
- 取消理由

が表示されます。

### C. 全体の監査ログ（管理者画面）

管理者向けの監査ログビューワー（実装による）：
- 期間指定（開始日〜終了日）
- 操作種別（作成・編集・削除・閲覧）
- 操作対象（カルテ・会計・スタッフ 等）
- 操作者（スタッフ名）

---

## 不審操作の検知ポイント

定期的に以下をチェック：

| チェック項目 | 頻度 |
|-----------|------|
| 異常な時間帯のログイン（深夜・休日） | 月次 |
| 大量の取消・削除操作 | 月次 |
| 通常使わない機能へのアクセス | 月次 |
| 同一アカウントの異常な端末からの操作 | 月次 |
| 退職予定スタッフの操作頻度・内容 | 退職前 |

---

## 監査ログのエクスポート

法定保存期間や外部監査のために、ログを CSV / PDF で出力可能（実装による）：

1. 管理者画面の監査ログ機能を開く
2. 期間を指定
3. 「**エクスポート**」ボタン

> 保存形式・期間は院内ルールに従う。詳細は業務フロー「**法定保存期間とデータ保護**」参照。

---

## インシデント発生時の対応

不審な操作・データ漏洩が疑われた時：

1. **即座に該当スタッフのアカウントを無効化**
2. 監査ログを保全（エクスポート・印刷）
3. 関連データのスナップショットを取得
4. 院長・サポートに報告
5. 外部監査が必要な場合は弁護士・専門家に相談

---

## 監査の定期化（推奨）

| 監査タイミング | 内容 |
|-------------|------|
| 毎日 | 当日のレジ締め差額・取消件数 |
| 毎週 | スタッフ別操作件数のバランス |
| 毎月 | 大量取消・削除の有無 |
| 四半期 | 権限グループ・スタッフアカウントの棚卸し |
| 年次 | 監査ログのエクスポート・保存 |
