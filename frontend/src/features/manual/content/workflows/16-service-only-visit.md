# 診察なしの単独サービス来院

診察 (カルテ作成) を伴わない **単独サービスのみの来院** の手順です。よくあるケース：

- ワクチン接種だけ
- 定期健診だけ
- トリミングだけ
- 物販 (フード等) 購入だけ
- 検査だけ（採血等）

## 使う画面（ケースにより異なる）

| ケース       | 主に使う画面                     |
| ------------ | -------------------------------- |
| ワクチン接種 | 当日の受付 → 予防接種 → 会計     |
| 定期健診     | 当日の受付 → 定期健診 → 会計     |
| トリミング   | 当日の受付 → トリミング → 会計   |
| 物販のみ     | 会計管理（受付不要のケースあり） |
| 検査のみ     | 当日の受付 → 検査管理 → 会計     |

---

## A. ワクチン接種のみの来院

1. サイドバー「**当日の受付**」を開きます。
2. 「**新規予約登録**」 → ペットを検索・選択 → 予約区分「**ワクチン**」を選択。
3. 受付を登録します。
4. 飼主が来院したらステータスを「**受付済 → 診療中**」。
5. サイドバー「**予防接種**」を開きます。
6. 「**新規登録**」 → 該当ペット → ワクチン情報入力 → 「**登録**」。

### 確定すると

- 接種記録が保存されます
- **会計が自動で作られます**（接種料金が明細に入ります）
- 在庫が自動減算されます

7. 受付カードの「**会計**」ボタン → 「**確定して領収書発行**」。
8. 領収書を渡します。

---

## B. 定期健診のみの来院

1. サイドバー「**当日の受付**」で「**新規予約登録**」 → 予約区分「**健診**」。
2. 受付完了 → ステータスを「**診療中**」に更新。
3. サイドバー「**定期健診**」を開きます。
4. 「**新規登録**」 → 健診情報を入力 → 「**登録**」。
5. 必要なら検査も追加（サイドバー「**検査管理**」）。

### 健診を登録すると

- 健診記録が保存されます
- 次回健診予定日が自動算出されます
- 会計が自動で作られます

6. 「**会計**」ボタンで会計確定 → 領収書発行。

---

## C. トリミングのみの来院

1. サイドバー「**当日の受付**」で「**新規予約登録**」 → 予約区分「**トリミング**」。
2. 受付完了 → ステータスを「**診療中**」に。
3. サイドバー「**トリミング**」を開きます。
4. 「**新規登録**」 → トリミング情報（コース・オプション・担当）を入力 → 「**登録**」。
5. 施術完了後、「**完了**」ボタンをクリック。

### 完了すると

- ステータスが「**完了**」に
- 会計が自動で作られます（コース料金 + オプション料金）

6. 受付カードの「**会計**」ボタン → 会計確定 → 領収書発行。

---

## D. 物販のみの購入

診察・受付なしで、フード・サプリ等の物販だけを購入する場合です。

1. サイドバー「**会計管理**」を開きます。
2. 「**新規会計登録**」ボタンをクリック。
3. 該当ペットを検索・選択（飼主・ペット情報がシステムに登録されている前提）。
4. 新規会計画面で「**明細追加**」ボタン → 物販を選択して数量入力。
5. 必要に応じて複数の物販を追加。
6. 支払方法を選択。
7. 「**確定して領収書発行**」。

### 確定すると

- 会計が「**会計済**」になります
- 物販分の在庫が自動減算されます
- 領収書 PDF が生成されます

> 💡 **受付登録は不要**。ただし、来院した記録を残したい場合は通常通り受付登録もしてから会計を作ることも可能です。

---

## E. 検査のみの来院

採血や再検査など、診察を伴わない検査のみの来院です。

1. サイドバー「**当日の受付**」で「**新規予約登録**」 → 予約区分「**検査**」。
2. 受付完了 → ステータスを「**診療中**」に。
3. サイドバー「**検査管理**」を開きます。
4. 「**新規検査登録**」 → 検査項目選択 → 「**登録**」。
5. 結果値入力 → 「**確定**」。

### 確定すると

- 検査結果が確定（編集不可）
- 会計が自動で作られます（検査料金が明細に入る）

6. 受付カードの「**会計**」ボタンで会計確定。

---

## カルテ作成は必要か？

このシナリオでは **カルテ作成は不要** です：

- ワクチン接種記録 → 予防接種マスタに記録
- 健診結果 → 定期健診マスタに記録
- トリミング記録 → トリミングマスタに記録
- 検査結果 → 検査管理に記録

ただし、副反応・特記事項があれば、サイドバー「**カルテ**」から該当ペットのカルテに **追記** できます。

| -------------- | ---- | -------- | ---- | ---------- | ---- | ------ | ---- |
| ワクチンのみ   | ✓    | ✓        | -    | -          | -    | -      | ✓    |
| 健診のみ       | ✓    | -        | ✓    | -          | -    | -      | ✓    |
| トリミングのみ | ✓    | -        | -    | ✓          | -    | -      | ✓    |
| 物販のみ       | 任意 | -        | -    | -          | -    | -      | ✓    |
| 検査のみ       | ✓    | -        | -    | -          | ✓    | -      | ✓    |
