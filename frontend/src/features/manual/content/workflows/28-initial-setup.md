# 導入時の初期設定チェックリスト

Animal Ekarte の利用を開始する際に、**医院の管理者（院長・事務長など）** が行う初期設定の全体手順です。マスタには依存関係があるため、以下の順番で進めるのがおすすめです。

> 最初のシステム管理者アカウントの発行は導入担当者が行います。管理者がログインできるようになってから、このページの手順を進めてください。

### 旧システムからのデータ移行がある場合

既存の飼主・ペット・過去カルテ等の **一括データ移行（CSV カットオーバー）自体は導入担当者が実施** します。医院側でやることは以下の確認です：

- 移行が完了したと連絡を受けたら、「飼主・ペット」画面で件数・代表データを確認する
- 移行で重複した飼主・ペットは「**同一飼主・ペット連携**」で整理する
- **新規開業の場合はこの確認は不要** です。STEP 1 に進んでください

| 画面       | 開き方                                       |
| ---------- | -------------------------------------------- |
| マスタ設定 | サイドバー「マスタ設定」→ 各サブメニュー     |

## 設定の全体像

| 順番 | ステップ                     | なぜこの順か                                                   |
| ---- | ---------------------------- | -------------------------------------------------------------- |
| 1    | 医院情報                     | 領収書・税率など全機能の前提                                   |
| 2    | 権限グループ → 職種 → スタッフ | スタッフ登録が職種と権限グループに依存する                     |
| 3    | 動物種類                     | ペット登録・検査の正常範囲の前提                               |
| 4    | カルテ語彙系マスタ           | 主訴・問診・診断はカルテ入力の選択肢                           |
| 5    | 在庫 → 診療項目 → 薬剤       | 診療項目・薬剤の在庫自動減算が在庫アイテムに依存               |
| 6    | 会計系マスタ                 | 支払方法・保険・締め時間は会計・レジ締めの前提                 |
| 7    | 予約・サービス系マスタ       | 予約区分・入院・ケージ・トリミングは稼働したい機能に合わせて   |
| 8    | 検査機器                     | 院内に検査機器がある場合のみ                                   |
| 9    | 外部連携（LINE / Lステップ） | API キー等の外部側準備が必要なため後半で                       |
| 10   | 動作確認                     | 本番運用前に一通りの流れを試す                                 |

## STEP 1: 医院情報を登録する

サイドバー「**マスタ設定**」→「**医院**」

| 設定する項目                 | 用途                                             |
| ---------------------------- | ------------------------------------------------ |
| 医院名・郵便番号・住所       | 領収書のヘッダーに印字                           |
| 電話番号・FAX・メール        | 連絡先                                           |
| 登録番号・院長名             | 領収書・書類の表示                               |
| 消費税率（通常課税・軽減）   | 会計計算に反映                                   |
| 明細兼領収書の表示設定       | 領収書レイアウトの ON / OFF                      |
| インボイス登録番号           | 適格請求書対応（「法人情報（インボイス）」カード） |

詳細は画面マニュアル「**医院マスタ**」を参照。

> 複数医院を運用する場合は、ここで医院を追加し、以降の設定は医院を切り替えて行います。

---

## STEP 2: スタッフが使えるようにする

**権限グループ → 職種 → スタッフ** の順で確認・登録します。

### 1. 権限グループを確認する（マスタ設定 → 権限グループ）

- 導入時に既定グループ（院長 / 獣医師 / 看護師 / 受付スタッフ / トリマー 等）が登録されていることが多い
- 既定で足りなければ新規作成。権限は **最小限から始めて追加** が安全
- この画面は **最高管理者権限** のみアクセス可

### 2. 職種を確認する（マスタ設定 → 職種マスタ）

- 院長 / 獣医師 / 看護師 / トリマー / 受付 等が導入時に登録済みのことが多い
- 不足する呼称があれば追加（職種は肩書き、権限グループは操作許可。別物です）

### 3. スタッフを登録する（マスタ設定 → スタッフ管理）

- ログインするスタッフにはメールアドレス + パスワード（8 文字以上）を設定
- 管理者が入力したパスワードは **本人へ直接伝達**（保存後はシステムから確認不可）
- カルテの担当者としてだけ載せたい場合は、アカウントなしでも登録可

詳細は業務フロー「**スタッフアカウント・権限の管理**」を参照。

---

## STEP 3: 動物種類を確認する

サイドバー「**マスタ設定**」→「**動物種類**」

- 犬・猫・小動物・鳥などの主要な動物種・品種は導入時に登録済み
- 取り扱う動物種（例: 爬虫類・両生類）がなければ追加
- 品種は動物種に紐付けて登録します

詳細は画面マニュアル「**動物種類マスタ**」を参照。

---

## STEP 4: カルテで使う言葉を整える

カルテ・受付の選択肢になるマスタ群です。空でも運用は始められますが、登録しておくと入力が速くなります。

| マスタ             | 開き方                                     | 内容                                 |
| ------------------ | ------------------------------------------ | ------------------------------------ |
| 主訴               | マスタ設定 → カルテ関連 → 主訴カテゴリ     | 受付・カルテの「来院目的」選択肢     |
| 問診テンプレート   | マスタ設定 → カルテ関連 → 問診設定         | 問診欄の定型文                       |
| 診断病名           | マスタ設定 → カルテ関連 → 診断マスタ       | 診断入力の選択肢・カテゴリ           |
| 検査項目           | マスタ設定 → カルテ関連 → 検査マスタ       | 検査種別の入力項目・正常範囲の定義   |

---

## STEP 5: 在庫・診療項目・薬剤を登録する

**在庫 → 診療項目・薬剤** の順がポイントです。先に在庫アイテムを作っておくと、診療項目・薬剤の登録時に「在庫紐付け」がすぐ設定でき、カルテ確定時の在庫自動減算が機能します。

### 1. 在庫アイテムを登録する（サイドバー → 在庫管理）

- 薬剤・ワクチン・物販・消耗品の実物アイテムと現在庫数を登録

### 2. 診療項目を登録する（マスタ設定 → カルテ関連 → 診療項目）

- 診察 / 検査 / 処置 / 予防接種 / 定期健診 の各タブで、項目名・税込単価・税区分を登録
- 価格がその場で変わる項目（外科手術など）は「**変動価格フラグ**」を ON
- 在庫を消費する項目は「**在庫アイテム紐付け**」を設定

### 3. 薬剤を登録する（マスタ設定 → カルテ関連 → 薬剤マスタ）

- 一般名・剤形・最小単位・税込単価を登録
- 「用法デフォルト」に標準用法を入れておくと処方入力が速い
- 「警告メモ」に禁忌・アレルギー注意を入れるとカルテで警告表示

詳細は画面マニュアル「**診療項目マスタ**」「**薬剤マスタ**」「**在庫管理**」を参照。

---

## STEP 6: 会計まわりを整える

| マスタ           | 開き方                    | 確認・設定すること                                   |
| ---------------- | ------------------------- | ---------------------------------------------------- |
| 支払方法         | マスタ設定 → 支払方法     | 現金・カード等は導入時に登録済みのことが多い。未収金を使う場合は有効か確認 |
| 保険             | マスタ設定 → 保険マスタ   | 取り扱うペット保険会社・適用率を登録                 |
| 締め時間設定     | マスタ設定 → 締め時間設定 | 1 日の境界時刻・午前/午後の区切り。深夜営業なら翌 05:00 等に |
| 物販・フード     | マスタ設定 → 物販・フード | 販売する商品・単価。在庫連動する商品は在庫アイテム紐付けも設定（STEP 5 の在庫が前提） |
| 割引キャンペーン | マスタ設定 → 割引キャンペーン | 期間限定割引を行う場合のみ                       |

---

## STEP 7: 稼働するサービスのマスタを整える

医院が実施する業務に合わせて設定します（使わない機能は後回しで構いません）。

| マスタ             | 開き方                                   | 設定すること                         |
| ------------------ | ---------------------------------------- | ------------------------------------ |
| 予約区分           | マスタ設定 → 予約区分                    | 診察 / トリミング / ワクチン 等      |
| 入院プラン・ケージ | マスタ設定 → 入院・ケージ → 入院マスタ / ケージマスタ | 入院料金プラン・ケージ番号           |
| トリミング         | マスタ設定 → トリミング → トリミングマスタ | コース・オプション                   |
| コース種別         | マスタ設定 → トリミング → コース種別マスタ | シャンプーコース / カットコース 等 |
| シフトテンプレート | マスタ設定 → シフトテンプレート          | 繰り返し勤務パターン（任意）         |

---

## STEP 8: 検査機器を接続する（機器がある場合）

サイドバー「**マスタ設定**」→「**カルテ関連**」→「**検査機器マスタ**」

1. 「**既定項目を用意**」ボタンで代表的な機器・項目を一括投入できます（揃っている場合は「既定項目は揃っています」と表示）。
2. 院内機器との対応を確認・追加します。

受信した検査結果をカルテに紐付ける運用は画面マニュアル「**検査受信**」を参照。

---

## STEP 9: 外部連携を設定する（LINE / Lステップ）

外部サービス側のアカウント・API キーの準備が必要です。導入担当者と調整して進めてください。

| 画面         | 設定すること                                                     |
| ------------ | ---------------------------------------------------------------- |
| LINE予約管理 | 稼働状態・受付ルール・連携 ID・予約枠・飼主向けページ文言        |
| Lステップ連携 | API キー・配信設定・タグマッピング。既存 LINE 友だちがいる場合は友だち属性の CSV インポートも実施 |

詳細は画面マニュアル「**LINE予約管理**」「**Lステップ連携**」、業務フロー「**Lステップ連携の設定とタグ運用**」を参照。

---

## STEP 10: 動作確認をする（本番運用前）

設定がそろったら、**テスト用の飼主・ペット** で一通りの流れを試してください。

- [ ] テスト飼主・ペットを登録できる
- [ ] 当日の受付に登録できる（主訴・予約区分が選択肢に出る）
- [ ] カルテに診療項目・薬剤を入力して「確定」できる
- [ ] 確定したカルテの明細が会計に取り込まれる
- [ ] 会計で支払方法を選んで確定し、領収書を印刷できる（医院情報・インボイスの見え方を確認）
- [ ] 在庫紐付けした項目で在庫数が減る
- [ ] レジ締めのプレビューでその日の会計が集計される
- [ ] 各スタッフが自分のアカウントでログインし、担当業務の画面が開ける

問題があれば該当マスタに戻って修正します。テストデータは取消・無効化で整理してください。

## 導入時に登録済みのことが多いマスタ

以下は導入時に既定データが入っていることが多いので、**確認と不足分の追加**から始めます。

| マスタ       | 既定データの例                                   |
| ------------ | ------------------------------------------------ |
| 権限グループ | 院長 / 獣医師 / 看護師 / 受付 / トリマー 等      |
| 職種         | 院長 / 獣医師 / 看護師 / トリマー / 受付 等      |
| 動物種類     | 犬・猫・小動物・鳥と主要品種                     |
| 支払方法     | 現金 / クレジットカード / 電子マネー / 未収金 等 |
| 検査機器     | 「既定項目を用意」ボタンで一括投入               |

## 運用を始めてからの追加について

すべてを揃えてからでなくても運用は開始できます。

- **最低限あれば動く**: 医院情報・権限グループ・職種・スタッフ・診療項目・支払方法
- **後から追加できる**: 薬剤・主訴・問診・診断・物販・入院プラン・トリミング 等
- マスタの追加・編集は運用中も随時可能です。参照中のマスタは削除できず「無効化」になります（詳細は画面マニュアル「**マスタ設定**」）
