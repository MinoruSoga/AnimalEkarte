# 受付ステータスの変え方

当日の受付画面でペットのステータスを変える操作と、自動で起きる連動の説明です。

## 関わる画面

サイドバー「**当日の受付**」が中心です。カルテ・会計画面に遷移することもあります。

## ステータスの種類

ペットのカードは状況に応じて以下のステータスを取ります：

| ステータス | 意味 |
|----------|------|
| 受付予約 | 来院前。予約済または事前登録 |
| 受付済 | 飼主・ペットが来院し受付完了 |
| 診療中 | 診察室に案内・診察中 |
| 会計待ち | 診察終了・カルテ確定済 |
| 会計済 | 会計確定済 |
| キャンセル | キャンセル状態 |

---

## 受付予約 → 受付済 にする

来院した飼主・ペットを受け付けた時の操作です。

1. 「**受付予約**」カラムの該当カードを探します。
2. ステータスバッジ（「受付予約」と表示されているところ）をクリックします。
3. メニューから「**受付**」を選びます。
4. または「**受付**」ボタンを直接クリックします。

### 変更すると

- ステータスが「**受付済**」になります
- カードが「受付済」カラムに移動します
- 受付済時刻が記録されます

---

## 受付済 → 診療中 にする

診察室に案内した時の操作です。

1. カードのステータスバッジをクリックします。
2. メニューから「**診療中**」を選びます。
3. または「**診察開始**」ボタンを直接クリックします。

### 変更すると

- ステータスが「**診療中**」になります
- カードが「診療中」カラムに移動します
- 診察開始時刻が記録されます

---

## 診療中 → 会計待ち（自動）

スタッフが手動でステータスを変える必要はありません。**カルテ確定で自動的に変わります**。

### 自動で起きること

カルテ画面で「**確定**」ボタンを押すと：

- カルテが編集不可（確定済）になります
- **会計が自動で作られます**（カルテの処置・処方・検査が会計の明細に自動で入ります）
- 受付ステータスが「**会計待ち**」に自動で変わります
- カードが「会計待ち」カラムに移動します

### 確認する場所

- 当日の受付画面の「会計待ち」カラム
- 会計管理画面の一覧に新規会計が表示されます

---

## 会計待ち → 会計済（自動）

これも手動で変える必要はありません。**会計確定で自動的に変わります**。

### 自動で起きること

会計画面で「**確定して領収書発行**」ボタンを押すと：

- 会計のステータスが「**会計済**」になります
- **物販の在庫が自動で減算されます**
- 領収書 PDF が生成されます
- 受付ステータスが「**会計済**」に自動で変わります
- カードが「会計済」カラムに移動します

---

## 任意のステータスに変える

緊急時など、順序を飛ばして直接ステータスを変えたい場合：

1. カードのステータスバッジをクリックします。
2. メニューで任意のステータスを直接選びます。

例：受付予約から直接「診療中」へ（急患対応の場合）

> 順序を飛ばしてもエラーにはなりませんが、業務上は順序通りに進めるのが基本です。

---

## キャンセルする

1. カードの **操作メニュー（縦三点ドット）** をクリックします。
2. 「**キャンセル**」を選びます。
3. キャンセル理由（任意）を入力して確定します。

### キャンセルすると

- ステータスが「**キャンセル**」になります
- キャンセル理由・時刻が記録されます
- 紐付く予約もキャンセル状態になります

> ⚠️ 元のステータスに戻すには **管理者権限** が必要です。

---

## カードから他の画面に移る

カードに表示されるボタン・リンクで関連画面に直接遷移できます：

| 操作 | 遷移先 |
|------|-------|
| ペット名をクリック | カルテ画面（新規 or 既存） |
| 「会計」ボタン | 会計画面（新規 or 既存） |
| 「カルテを開く」 | 既存カルテ画面 |

---

## 経過時間の表示

カード右上に、現在のステータスでの **経過時間（分）** が表示されます。

例：「受付済」になってから 25 分経過 → 「受付済 25 分」

ステータスを変更すると、経過時間カウントがリセットされます。

---

## 各操作で自動的に更新される情報

| 操作 | 受付 | 予約 | カルテ | 会計 |
|------|------|------|--------|------|
| 新規受付登録 | 作成 | 作成 | - | - |
| 受付 | 更新 | - | - | - |
| 診察開始 | 更新 | - | - | - |
| カルテ確定 | **自動更新** | - | 更新 | **自動作成** |
| 会計確定 | **自動更新** | - | - | 更新 |
| キャンセル | 更新 | 更新 | - | - |
