# 既存飼主の受付から会計まで

既に登録済みの飼主・ペットが来院した時の **受付から会計までの全手順** です。

## 使う画面

| 順番 | 画面               | 開き方                       |
| ---- | ------------------ | ---------------------------- |
| 1    | 当日の受付         | サイドバー「当日の受付」     |
| 2    | カルテ             | 受付カードのペット名クリック |
| 3    | 検査管理（必要時） | サイドバー「検査管理」       |
| 4    | 会計               | 受付カードの「会計」ボタン   |

---

## Step 1: 受付ステータスを更新する

サイドバー「**当日の受付**」をクリックします。

### A. 予約がある場合

1. 「**受付予約**」カラムで該当ペットのカードを探します。
2. ステータスバッジをクリック → 「**受付済**」を選びます。

### B. 予約なし（飛び込み）の場合

業務フロー「予約なし来院の受付登録」を参照してください。

---

## Step 2: 診察開始

診察室に呼び込んだ時、ステータスを「**診療中**」に変更します。

カードのステータスバッジをクリック → 「**診療中**」を選びます。

---

## Step 3: カルテを作成する

受付カードの **ペット名をクリック** すると、カルテ作成画面に直接遷移します。

### 過去履歴を参照する

カルテ画面右側のパネルに、過去履歴が表示されます：

| パネル         | 内容                |
| -------------- | ------------------- |
| 直近カルテ     | 過去 5 件のサマリー |
| 投薬履歴       | 過去の処方薬        |
| アレルギー情報 | ペット情報から      |
| ワクチン履歴   | 接種記録            |
| 検査結果       | 検査記録            |

慢性疾患の経過観察や投薬の継続判断に活用できます。

### 入力して確定

各セクションを入力し、「**確定**」ボタンをクリックします。

### 確定すると

- カルテが編集不可になります
- **会計が自動で作られます**（カルテの明細が会計に自動で入ります）
- 受付ステータスが「**会計待ち**」に自動で変わります

---

## Step 4: 検査の登録（必要時）

検査が必要な場合は、サイドバー「**検査管理**」を開きます。

1. 画面右上の「**新規検査登録**」ボタンをクリックします。
2. ペットを当日受付のペットから選びます。
3. 検査項目を選びます（マスタから複数選択可）。
4. 担当医を選びます。
5. 「**登録**」をクリックします。

検査結果を入力します：

- 各検査項目の結果値を入力
- **異常値は自動でハイライト** されます（高値は赤、低値は黄）

「**確定**」ボタンをクリックします。

### 確定すると

- 検査結果が確定（編集不可）になります
- **当日のカルテの検査セクションに自動で連動** します
- **会計の明細にも追加** されます

---

## Step 5: 会計を確定する

受付カードの「**会計**」ボタンをクリックします。

1. カルテと検査から自動で入った明細を確認します。
2. 必要なら物販を追加します。
3. 割引率を確認します。
4. 保険適用があれば設定します。
5. 支払方法を選びます。
6. 「**確定して領収書発行**」をクリックします。

### 確定すると

- 会計が「**会計済**」になります
- **物販の在庫が自動で減算** されます
- 領収書 PDF が生成されます
- 受付ステータスが「**会計済**」に自動で変わります

---

## 異常値判定の仕組み

検査結果はマスタに定義された **正常範囲と自動比較** されます：

- 値が **上限超** → 赤背景（高値）
- 値が **下限未満** → 黄背景（低値）
- 範囲内 → 通常表示

正常範囲はマスタ設定で動物種別・年齢別に定義できます。

---

## カルテ確定後の修正方法

カルテを確定した後は明細を直接編集できません。修正は「**追記（Addendum）**」機能を使います：

1. 該当カルテの詳細画面を開きます。
2. 「**追記**」ボタンをクリックします。
3. 追記内容を入力して「**追加**」をクリックします。

元のカルテはそのまま残り、追記履歴が時系列で追加されます。

---

## 各 Step で起きる更新

| Step | 受付           | カルテ             | 検査       | 会計         |
| ---- | -------------- | ------------------ | ---------- | ------------ |
| 1    | ステータス更新 | -                  | -          | -            |
| 2    | ステータス更新 | -                  | -          | -            |
| 3    | **自動連動**   | 作成・確定         | -          | **自動作成** |
| 4    | -              | 検査セクション更新 | 作成・確定 | 明細追加     |
| 5    | **自動連動**   | -                  | -          | 確定         |
