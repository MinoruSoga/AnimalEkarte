# エラー・トラブル対応

よく起きるエラー・トラブルとその対処方法のリファレンスです。

---

## ログインできない

### 「メールアドレスまたはパスワードが正しくありません」

**原因**: 入力情報が登録と一致しません。

**対処**:
- 入力を確認して再試行します
- パスワードを忘れた場合はログイン画面の「**パスワードをお忘れですか？**」からリセットします

### 短時間に何度もログインが拒否される（レート制限）

**原因**: 同一 IP からのログイン試行が **5 回 / 1 分** を超えました（総当たり攻撃対策）。アカウント自体はロックされません。

**対処**:
- **1〜2 分待ってから再試行** します（時間経過で自動回復。解除操作はありません）
- 続く場合はログイン画面の「**パスワードをお忘れですか？**」からリセットします
- それでもダメなら管理者にスタッフマスタでアカウントの **有効/無効** 状態を確認してもらいます

詳細は画面マニュアル「**ログイン**」を参照。

### 「アカウントが無効化されています」

**原因**: 管理者がスタッフを「無効」状態に設定しています。

**対処**: 管理者に有効化を依頼します。

### 「権限がありません」（403 エラー）

**原因**: 操作した機能の権限がスタッフに付与されていません。

**対処**: 管理者に権限グループの変更を依頼します。

## カルテに関するトラブル

### カルテを確定できない

| 原因 | 対処 |
|------|------|
| 必須項目が未入力 | エラーメッセージの項目を入力します |
| 別スタッフが編集中 | 編集完了を待ち、画面を再読み込みします |
| 権限不足 | 管理者にカルテの編集権限付与を依頼します |

### 過去のカルテが見つからない

| 原因 | 対処 |
|------|------|
| 別医院に登録されている | サイドバー上部の医院切替で別医院に切り替えます |
| 検索条件が違う | 電話番号で検索します |
| アーカイブされている | 飼主管理でアーカイブ表示フィルタを有効にします |

## 会計に関するトラブル

### 会計画面に明細が出てこない

| 原因 | 対処 |
|------|------|
| カルテが未確定 | カルテ画面で「確定」ボタンを押します |
| 検査が未確定 | 検査管理画面で検査結果を確定します |
| 同じ会計を別タブで開いている | 片方を閉じます |

### 確定済み会計を修正したい

**できないこと**: 確定後の直接編集はできません。

**対処手順**:
1. 「**取消**」ボタンで該当会計を取消します
2. 「**新規会計登録**」で正しい内容の会計を作り直します
3. 詳細は業務フロー「会計を取り消す・領収書を再発行する」を参照

### 「締め済の会計は取消できません」エラー

**原因**: その日のレジ締めがすでに確定されています。レジ締め自体の取消・巻き戻しはできません（append-only）。

**対処手順**:
1. `accounting-post-close-edit` 権限を持つスタッフが会計詳細を開きます
2. 「レジ締め済み期間の編集」として **修正理由を入力** し、会計を保存します
3. 監査ログと訂正台帳に記録されます（締め履歴の close レコード自体は変わりません）

### 領収書 PDF が生成されない

| 原因 | 対処 |
|------|------|
| ブラウザのポップアップブロック | ブラウザのブロック解除をします |
| プリンタ接続なし | PDF ダウンロードで代替します |

## 在庫に関するトラブル

### 在庫数が合わない

**対処手順**:
1. サイドバー「**在庫管理**」を開きます
2. 「**棚卸モード**」をクリックします
3. 実数を入力します
4. 「**棚卸確定**」ボタンを押します
5. システム値が実数で上書きされます

### カルテ・会計を確定したのに在庫が減らない

**原因**: マスタアイテムと在庫の紐付けが設定されていません。

**対処**:
- マスタ設定で該当マスタ（診療項目 / 薬剤 / 物販）を編集
- 「**在庫アイテム**」フィールドで該当の在庫を選択
- 「**保存**」をクリック

## レジ締めに関するトラブル

### 「未確定の会計があります」エラー

**原因**: 該当日に「**会計待ち**」状態の会計がまだ残っています。

**対処手順**:
1. サイドバー「**会計管理**」を開きます
2. その日の「**会計待ち**」を絞り込みます
3. 全件を確定します
4. もう一度レジ締めを試します

### 「既に締め済みです」エラー

**原因**: 同じ日・同じ区分で既に締めが完了しています。締めの取消・再開はできません。

**対処**:
- サイドバー「**レジ締め**」→「**履歴**」で既存締めを確認します
- 会計の誤りがある場合は、締めを取り消さず **締め後編集**（理由必須）で訂正します
- 同一区分の再締めは不要・不可です

### 大幅な差額が出る

**システムの動き**: 差額は記録されます。月次集計の売上は確定済みの値で集計されます（差額は集計外）。

**対処手順**:
1. サイドバー「**会計管理**」で当日 + 現金 で絞り込みます
2. 各会計を 1 件ずつ確認します
3. 未締めなら「**取消**」→ 「**新規会計登録**」。締め済みなら締め後編集（理由必須）で訂正します

## LINE / Lステップに関するトラブル

### LINE 予約が反映されない

| 原因 | 対処 |
|------|------|
| LINE 連携設定エラー | サイドバー「LINE予約管理」→「基本設定」で確認します |
| LINE Channel Access Token 失効 | サイドバー「Lステップ連携」→「連携設定」で再設定します |
| LINE からの通知受信に失敗 | 管理者にサポートを依頼します |

### タグが付与されない

**確認手順**:
1. サイドバー「**Lステップ連携**」→「**連携設定**」を開きます
2. 「**同期を有効にする**」が ON か確認します
3. 「**Lステップ接続テスト**」ボタンで API キーの有効性を確認します
4. CPM 閾値・休眠予防閾値が正しく設定されているか確認します

### EXCL タグが付与されている

**原因**: 配信エラーが連続して発生しています（飼主側でブロック等）。

**確認**: サイドバー「**Lステップ連携**」→「**タグ管理**」で該当飼主のタグを確認します。

**解除**: 自動管理タグのため、手動削除はできません。管理者対応が必要です。

## システム全般のトラブル

### 画面が真っ白・応答しない

**対処手順**:
1. ブラウザを再読み込みします（Cmd/Ctrl + R）
2. キャッシュをクリアして再読み込みします（Cmd/Ctrl + Shift + R）
3. 別のブラウザで試します
4. それでも解決しない場合は管理者・サポートに連絡します

### 「データの取得に失敗しました」

**主な原因**:
- サーバーの一時的な障害
- ネットワーク切断
- セッション切れ

**対処手順**:
1. ネットワーク接続を確認します
2. ブラウザを再読み込みします
3. 再ログインします
4. それでも解決しない場合は管理者に連絡します

### 医院を切替えたあとデータが古い

**システムの動き**: 医院切替で自動的にデータが再取得されますが、表示反映に時間差があります。

**対処**: 画面を再読み込みすると強制的に最新データに更新されます。

## エラーコードと意味

| コード | 意味 | 一般的な対処 |
|-------|------|----------|
| 400 | 入力内容のエラー | 入力を確認します |
| 401 | 認証エラー | 再ログインします |
| 403 | 権限エラー | 管理者に権限確認を依頼します |
| 404 | データが存在しない | URL・ID を確認します |
| 409 | 競合（別スタッフが先に保存等） | 画面を再読み込みします |
| 500 | サーバーエラー | 管理者・サポートに連絡します |

## 操作履歴の確認（管理者）

不審な操作やデータ変更を確認する場合は、管理者画面で操作履歴を参照できます：

- 期間・操作種別・対象データ・操作者で絞り込み可能
- 操作前後のスナップショットが記録されます
