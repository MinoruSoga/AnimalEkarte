# 月次集計レポートを出す

月単位または任意期間の売上・指標を表示し、CSV・印刷（PDF）する操作です。

## 使う画面

- サイドバー「**月次集計レポート**」→ URL: `/accounting/reports`
- 日次の締め状況確認: `/accounting/close` および `/accounting/close/history`

---

## 集計の前提

- 期間内の精算済会計が集計の元になります
- 日次明細の **AM 締 / PM 締** は、レジ締め（`/accounting/close`）の実行結果を示します
- 月次の前に、対象月の各営業日で必要な区分（午前／午後／緊急）の締めが済んでいるかを履歴で確認します

> 締め未実行を確認したい場合: `/accounting/close/history` で月内の各日・区分を確認します。

---

## 期間を指定する

画面上部の集計単位で切り替えます。

| 単位     | 入力           |
| -------- | -------------- |
| 月次     | 年・月         |
| 期間指定 | 開始日・終了日 |

変更するとデータが再読込されます。四半期・半期・年が必要な場合は期間指定で日付を設定します。

---

## 表示される情報

| セクション    | 内容                                       |
| ------------- | ------------------------------------------ |
| 日次明細      | 日別の午前／午後売上・件数・返金・AM/PM 締 |
| KPI           | 診療日数・会計件数・売上合計・純売上       |
| 支払方法別    | 医院の支払方法マスタ順の合計               |
| 部門別        | 診療・物販・トリミング等                   |
| 消費税内訳    | 標準／軽減など医院設定に基づく             |
| 部門×支払方法 | 1 表でカテゴリ×支払を確認                  |

AM/PM 締め済みの日次行は、権限があれば締め履歴へドリルダウンできます。

---

## CSV で出力する

ヘッダーの「**CSV出力**」をクリックします。

- ブラウザでダウンロードされます
- 外部会計ソフトへの取込補助に利用できます

---

## 印刷 / PDF

「**印刷 / PDF出力**」→ ブラウザの印刷ダイアログで「PDF として保存」などを選びます。

推奨: A4 横向き。印刷面は画面と同じ集計データを使います。

---

## 表示されない時の確認点

| 症状         | 原因の例                           |
| ------------ | ---------------------------------- |
| 取得失敗     | サーバー／ネットワーク／権限       |
| 数値が 0     | 期間内の精算済が無い、期間指定ミス |
| AM/PM 締が未 | `/accounting/close` 未実施         |
| 権限エラー   | `accounting-reports:view` が無い   |

---

## 必要な権限

- 月次集計レポート: `accounting-reports:view`
- 締め履歴ドリルダウン: `cash-register-close:view`

一般スタッフには付与されない場合があります。
