# 月次集計レポートを出す

月単位の売上・指標を表示し、CSV・PDF で出力する操作です。

## 使う画面

サイドバー「**月次集計レポート**」をクリックします。

---

## 集計の前提

- **締めが済んでいる日** の会計だけが集計対象になります
- 締めていない日は集計から除外されます
- 取消された会計は売上から差し引かれます

> 締め未実行を確認したい場合：サイドバー「**レジ締め**」→「**履歴**」タブで、月内の各日が締め確定されているか確認できます。

---

## 期間を指定する

画面上部の **年・月プルダウン** または **期間切替タブ** で対象期間を選びます。

| 期間タイプ | 入力 |
|----------|------|
| 月 | 年・月 |
| 四半期 | 年・四半期 |
| 半期 | 年・半期 |
| 年 | 年 |
| カスタム | 開始日・終了日 |

選ぶと、即時にデータが読み込まれて表示されます。

---

## 表示される情報

| セクション | 内容 |
|----------|------|
| 売上推移 | 当月・前月・前年同月の比較 |
| 件数推移 | 会計件数・来院ペット数・新規飼主数 |
| 支払方法内訳 | 現金 / カード / 電子マネー / その他の構成比 |
| 診療カテゴリ別売上 | 診察 / 検査 / 物販 / トリミング / 入院 等 |
| 担当者別売上 | スタッフ別の実績 |
| 上位飼主（LTV） | 累計売上の上位飼主 |

---

## CSV で出力する

各テーブル右上の「**CSV**」ボタン、または画面上部の「**CSV出力**」ボタンをクリックします。

### 出力すると

- CSV ファイルがブラウザでダウンロードされます
- ファイル名に対象期間が含まれます（例: `report_2026-04.csv`）
- Excel で開いても文字化けしません（UTF-8 BOM 付き）

---

## PDF で印刷する

ブラウザの印刷機能（Cmd/Ctrl + P）を使います。

推奨設定：
- 用紙: A4 横向き
- 背景グラフィック: 有効化（グラフ色が反映されます）

「PDF として保存」を選ぶと PDF ファイルが保存できます。

---

## 表示されない時の確認点

| 症状 | 原因 |
|------|------|
| 「データの取得に失敗しました」 | サーバーエラー / ネットワーク切断 |
| 期間に集計値が出ない | その期間に締め済の会計が 0 件 |
| 担当者別売上に欠落 | 該当スタッフが無効化されている |
| 物販売上に欠落 | 物販マスタのカテゴリ紐付け未設定 |

---

## 必要な権限

月次集計レポートの閲覧権限が必要です。一般スタッフには制限される場合があります。
