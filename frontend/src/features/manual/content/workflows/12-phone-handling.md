# 電話・口頭での予約の入れ方

電話で受けた予約・予約変更・キャンセルを **予約管理画面** で登録する操作です。

## 使う画面

サイドバー「**予約管理**」が中心です。新規飼主の場合は「**飼主・ペット**」画面も使います。

---

## 新規予約を入れる（既存飼主）

1. サイドバー「**予約管理**」をクリックします。
2. 画面右上の「**新規予約登録**」ボタンをクリックします。
   - またはカレンダー上の空き枠を直接クリックしても OK です。
3. ペット選択画面で **飼主名・ペット名・電話番号** で検索します。
4. 候補リストから該当ペットをクリックします。
5. 予約情報を入力します：

   | 項目           | 必須 | 内容                                   |
   | -------------- | ---- | -------------------------------------- |
   | 開始日時       | ✅   | カレンダーから選択または直接入力       |
   | 終了日時       | ✅   | 予約区分のデフォルト所要時間で自動設定 |
   | 予約区分       | ✅   | 診察 / トリミング 等から選択           |
   | 担当医・担当者 | 任意 | スタッフから選択                       |
   | メモ           | 任意 | 飼主の要望など                         |

6. 「**登録**」ボタンをクリックします。

### 登録すると

- 予約がカレンダーに表示されます
- 当日の予約の場合、「**当日の受付**」画面の「受付予約」カラムにも自動で表示されます

### 警告が出る場合

同じ時間帯・同じ担当者で既存の予約がある時、警告ダイアログが表示されます（強行して登録することは可能です）。

---

## 新規予約を入れる（新規飼主）

1. サイドバー「**予約管理**」→ 「**新規予約登録**」をクリックします。
2. ペット選択モーダルが開きます。
3. 「**新規飼主登録**」リンクをクリックします。
4. 飼主情報を入力します：

   | 項目                      | 必須 | 内容         |
   | ------------------------- | ---- | ------------ |
   | 姓 / 名                   | ✅   |              |
   | 電話番号                  | ✅   | 重複時は警告 |
   | フリガナ・住所・メール 等 | 任意 |              |

5. ペット情報を入力します：

   | 項目     | 必須 |
   | -------- | ---- |
   | ペット名 | ✅   |
   | 動物種   | ✅   |
   | 品種     | ✅   |

6. 続けて予約情報を入力します。
7. 「**登録**」ボタンをクリックします。

### 登録すると

- 新しい飼主とペットが保存されます
- 飼主一覧（サイドバー「飼主・ペット」）でも確認できるようになります
- 予約がカレンダーに表示されます

---

## 予約の日時を変える

### 方法 A: カレンダー上でドラッグ&ドロップ

1. カレンダーの該当予約ブロックを掴みます。
2. 移動先の時刻にドラッグして離します。
3. 確認ダイアログで「変更する」を選びます。

### 方法 B: 編集画面から変更

1. 予約ブロックをダブルクリックします。
2. 編集画面で日時を変更します。
3. 「**保存**」をクリックします。

### 警告が出る場合

変更後の時間帯で既存予約と競合する場合、警告が表示されます。

---

## 予約をキャンセルする

1. カレンダーの該当予約ブロックをクリックします。
2. 編集画面の「**キャンセル**」ボタンをクリックします。
3. キャンセル理由（任意）を入力します。
4. 「**キャンセルする**」を選びます。

### キャンセルすると

- 予約のステータスが「**キャンセル**」になります
- カレンダー上で薄色 / 取消線表示になります
- 当日予約の場合、紐付く受付もキャンセル状態になります

> ⚠️ 削除ではなく **キャンセル状態の記録** になります。元のステータスに戻すには管理者権限が必要です。

---

## 予約のステータスを変える

予約には以下のステータスがあります：

| ステータス | 設定タイミング                          |
| ---------- | --------------------------------------- |
| 予約済     | 初期状態                                |
| 確認済     | 飼主への確認連絡が完了した時（手動）    |
| 来院済     | 当日の受付で「受付済」になると **自動** |
| キャンセル | キャンセル操作時                        |
| 無断不参加 | 当日来院がなく一定時間経過              |

### 設定方法

予約編集画面の「**ステータス**」プルダウンから選んで保存します。

---

## カレンダーの表示を絞り込む

画面上部のフィルタを使います：

| フィルタ   | 入力                       |
| ---------- | -------------------------- |
| 表示モード | 月 / 週 / 日 / リスト      |
| 予約区分   | 区分を選択                 |
| 担当医     | スタッフを選択             |
| 検索       | 飼主名・ペット名・電話番号 |

---

## LINE 経由の予約について

LINE 公式アカウントから受け付けた予約も **同じカレンダー** に表示されます（LINE バッジ付き）。

操作方法は通常の予約と同じです。

詳細は「**LINE予約管理**」画面のマニュアルを参照してください。
