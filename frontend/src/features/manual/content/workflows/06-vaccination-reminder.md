# ワクチン接種の登録とタグ自動付与

ワクチン接種を記録し、次回案内タグが自動で付与されるまでの流れです。

## 使う画面

| 画面          | 開き方                                   |
| ------------- | ---------------------------------------- |
| 予防接種      | サイドバー「予防接種」                   |
| Lステップ連携 | サイドバー「Lステップ連携」→「連携設定」 |

---

## Step 1: 接種記録を登録する

サイドバー「**予防接種**」をクリックします。

1. 画面右上の「**新規登録**」ボタンをクリックします。
2. ペットを検索・選択します。
3. 接種情報を入力します：

   | 項目           | 必須 | 内容                  |
   | -------------- | ---- | --------------------- |
   | ワクチン種別   | ✅   | マスタから選択        |
   | 接種日         | ✅   | 既定: 当日            |
   | ロット番号     | ✅   | 副反応追跡用          |
   | 有効期限       | ✅   | 自動算出 or 手動入力  |
   | 担当医         | ✅   | スタッフから選択      |
   | 接種部位       | 任意 | 左肩 / 右肩 / 背部 等 |
   | 副反応観察記録 | 任意 |                       |

4. 「**登録**」ボタンをクリックします。

### 登録すると

- 接種記録が保存されます
- **次回接種予定日が自動で算出されます**（接種日 + マスタの間隔）
- **該当ワクチンの在庫が自動で減算されます**

### 確認する場所

- 予防接種一覧に行が追加されます
- 在庫管理画面でワクチン在庫の減算を確認できます

---

## 次回接種予定日の自動算出

接種日 + マスタの接種間隔 = 次回予定日

例：

- 混合ワクチン犬5種 → 接種日 + 365 日
- 狂犬病 → 接種日 + 365 日（法定）

マスタ設定: サイドバー「**マスタ設定**」→「**診療項目マスタ**」→「**ワクチン**」タブで間隔を設定できます。

---

## 期限ステータスの自動表示

予防接種一覧では、各記録のステータスが自動表示されます：

| ステータス | 条件                    |
| ---------- | ----------------------- |
| 期限内     | 次回予定 - 今日 > 30 日 |
| 期限間近   | 30 日以内               |
| 期限切れ   | 次回予定を過ぎている    |

絞り込みでステータス別に表示できます。

---

## Lステップタグの自動付与

Lステップ連携が有効な場合、システムが自動で対応するタグを飼主に付与します（定期バッチで実行）。

- 期限間近の飼主 → `vaccine_期限間近_30日前` 等のタグ
- 期限切れの飼主 → `vaccine_期限切れ` 等のタグ

これらのタグに紐付くシナリオが Lステップ側で設定されていれば、自動で配信されます。

### 確認する場所

サイドバー「**Lステップ連携**」→「**タグ管理**」で各飼主のタグ付与状況を確認できます。

---

## 接種記録を編集する

1. 予防接種一覧で該当行をクリックします。
2. 編集モードで項目を変更します。
3. 「**保存**」をクリックします。

### 保存すると

- 接種記録が更新されます
- 変更履歴が記録されます
