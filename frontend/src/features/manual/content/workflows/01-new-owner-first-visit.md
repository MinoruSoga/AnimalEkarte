# 新規飼主の登録から初診会計まで

新規飼主が来院した時の **登録から会計までの全手順** です。

## 使う画面

| 順番 | 画面             | 開き方                       |
| ---- | ---------------- | ---------------------------- |
| 1    | 飼主・ペット     | サイドバー「飼主・ペット」   |
| 2    | 当日の受付       | サイドバー「当日の受付」     |
| 3    | カルテ           | 受付カードのペット名クリック |
| 4    | 会計             | 受付カードの「会計」ボタン   |
| 5    | 予約管理（任意） | サイドバー「予約管理」       |

---

## Step 1: 飼主とペットを登録する

サイドバー「**飼主・ペット**」をクリックします。

1. 画面右上の「**新規登録**」ボタンをクリックします。
2. 飼主情報を入力します：

   | 項目                    | 必須 | 内容       |
   | ----------------------- | ---- | ---------- |
   | 姓 / 名                 | ✅   |            |
   | フリガナ姓 / フリガナ名 | 推奨 | 検索性向上 |
   | 電話番号                | ✅   | 重複時警告 |
   | 郵便番号・住所          | 任意 |            |
   | メール                  | 任意 |            |
   | 性別・生年月日          | 任意 |            |

3. 「**ペット情報**」タブに切り替えます。
4. ペットを 1 頭以上登録します：

   | 項目                            | 必須 | 内容 |
   | ------------------------------- | ---- | ---- |
   | ペット名                        | ✅   |      |
   | 動物種                          | ✅   |      |
   | 品種                            | ✅   |      |
   | 性別・避妊去勢・生年月日        | 任意 |      |
   | 体重・毛色・MC 番号・アレルギー | 任意 |      |

5. 複数頭いる場合は「**ペット追加**」で追加します。
6. 「**登録**」ボタンをクリックします。

### 登録すると

- 飼主とペットが保存されます
- 飼主一覧と詳細画面で確認できるようになります
- 飼主 No・ペット番号が自動で採番されます

### 警告が出る場合

同じ電話番号で既に登録されている飼主がいる時、警告が出ます（同居家族など意図的な重複なら強行できます）。

---

## Step 2: 当日の受付に登録する

サイドバー「**当日の受付**」をクリックします。

1. 画面右上の「**新規予約登録**」ボタンをクリックします。
2. ペット選択画面で Step 1 で登録したペットを検索・選択します。
3. 受付情報を入力します：

   | 項目     | 必須 | 内容           |
   | -------- | ---- | -------------- |
   | 来院目的 | ✅   | 主訴・症状     |
   | 予約区分 | ✅   | 診察 / 初診 等 |
   | 担当医   | 任意 |                |
   | 予約日時 | ✅   | 既定: 現在時刻 |

4. 「**登録**」をクリックします。

### 登録すると

- 受付カードが「**受付予約**」カラムに追加されます
- 飼主の来院後、ステータスを「**受付済**」→「**診療中**」と順次進めます

---

## Step 3: カルテを作成して確定する

受付カードの **ペット名をクリック** すると、カルテ作成画面に直接遷移します。

カルテの各セクションを入力します：

| セクション | 入力内容                                 |
| ---------- | ---------------------------------------- |
| 基本情報   | 来院日時 / 診察医 / 看護師 / 体重 / 体温 |
| 主訴       | 飼主の相談内容（問診テンプレも選択可）   |
| 所見       | 視診・触診・聴診の結果                   |
| 診断       | 病名（マスタ選択 or 自由入力）           |
| 処置       | 治療項目（マスタから選択）               |
| 処方       | 薬剤・数量・用法                         |
| 検査       | 別画面の「検査管理」と連動               |
| 次回案内   | 次回来院予定日                           |

入力完了後、「**確定**」ボタンをクリックします。

### 確定すると

- カルテが編集不可（確定済）になります
- **会計が自動的に作られます**（カルテの明細が会計に自動で入ります）
- 受付ステータスが「**会計待ち**」に自動で変わります
- 処方薬剤の在庫減算が予約されます（確定は会計時）

---

## Step 4: 会計を確定する

受付カードの「**会計**」ボタンをクリックします。

会計詳細画面で：

1. カルテから自動で入った明細を確認します。
2. 必要なら物販を追加（「**明細追加**」ボタン）。
3. 割引率を確認します（飼主に登録された値が自動適用）。
4. 保険適用があれば「**保険適用**」タブで設定します。
5. 支払方法を選びます（現金 / カード / 電子マネー 等）。
6. 領収書宛名を確認します。
7. 「**確定して領収書発行**」ボタンをクリックします。

### 確定すると

- 会計が「**会計済**」になります
- **物販分の在庫が自動で減算** されます
- 領収書 PDF が生成されます
- 受付ステータスが「**会計済**」に自動で変わります

---

## Step 5: 次回予約を入れる（任意）

次回来院が必要な場合、サイドバー「**予約管理**」で予約を登録します。

1. 「**新規予約登録**」ボタンをクリックします。
2. 同じペットを選びます。
3. 次回来院日時と予約区分を入力します。
4. 「**登録**」をクリックします。

---

## 全体で記録される情報

| 記録   | 件数                         |
| ------ | ---------------------------- |
| 飼主   | 1                            |
| ペット | 1 以上                       |
| 予約   | 1（次回予約があれば 2 以上） |
| 受付   | 1                            |
| カルテ | 1                            |
| 検査   | 0 以上（検査の有無による）   |
| 会計   | 1                            |
| 領収書 | 1                            |

---

## エラーが起きる場合

| Step | 状況                                   |
| ---- | -------------------------------------- |
| 1    | 電話番号重複（警告のみ、強行可）       |
| 1    | 必須項目未入力                         |
| 3    | カルテ必須項目未入力                   |
| 4    | 物販在庫不足（警告。強行は権限による） |
