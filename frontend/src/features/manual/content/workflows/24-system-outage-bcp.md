# システム障害時の応急対応

システム全停止・部分障害が発生した時の **応急対応** と業務継続計画（BCP）です。

> ⚠️ 個別エラー対応は業務フロー「**エラー・トラブル対応**」参照。本ガイドは **システム全体が使えない時** の対応です。

---

## 障害レベルの判断

| レベル | 症状 | 対応 |
|------|------|------|
| **L1（軽微）** | 特定機能のみ動かない | 個別エラー対応で復旧 |
| **L2（中程度）** | 複数画面が動かない | 管理者がサポートに連絡。スタッフは手作業で業務継続 |
| **L3（重大）** | システム全停止・ログイン不能 | **手書きフォールバック** に切替 |

---

## L3 障害時の手作業フォールバック

システムが完全に使えない時、業務を止めずに継続する手順です。

### 事前準備（管理者）

| ✅ | 準備物 |
|---|------|
| ☐ | 紙のカルテテンプレート（印刷済） |
| ☐ | 紙の受付シート（印刷済） |
| ☐ | 手書き領収書（市販） |
| ☐ | 当日のシフト表（紙） |
| ☐ | 飼主連絡先リスト（直近の CSV エクスポート） |
| ☐ | 入院中ペットの情報（直近の CSV エクスポート） |

これらを **オフラインで保管** しておく。

---

### 障害発生時の即時対応

| ✅ | 担当 | 操作 |
|---|------|------|
| ☐ | 受付 | 紙の受付シートに来院ペット情報を記録 |
| ☐ | 医師 | 紙のカルテテンプレートに診察記録 |
| ☐ | 受付 | 手書き領収書で会計（控えを残す） |
| ☐ | 管理者 | サポート・ベンダーに連絡 |
| ☐ | 全員 | 復旧時間の見込みを確認 |

---

### 飼主への対応

- 状況を簡潔に説明（「システムトラブルで一時的に紙対応」）
- 後日のフォローを約束（領収書の電子化等）
- LINE 等での緊急連絡先を案内

---

## 復旧後のデータ入力

システム復旧後、紙で記録したデータをシステムに入力します。

### 優先順位

| 優先 | データ |
|-----|------|
| 1 | 当日の会計・領収書（売上計上のため） |
| 2 | 当日のカルテ（医療記録のため） |
| 3 | 入院中ペットの記録 |
| 4 | 予約情報 |

### 入力手順

1. 紙の記録を時系列に並べる
2. システムに 1 件ずつ入力
3. 「**作成日**」フィールドを手動で当日に設定（実装による）
4. 入力後、紙と照合してチェック
5. 全件入力完了後、紙の記録は **法定保存期間中** 保管

## 部分障害時の対応

### LINE / Lステップ連携停止

- 自動配信は止まる
- 受付・会計は通常通り動く
- 復旧後、未配信メッセージは自動で再送される（実装による）

### レジ締めができない

- 当日中に復旧しない場合、翌日に **遡って締め** を実行
- 締め時刻を実際の時刻に手動入力（実装による）
- 過去日の締めは管理者権限で可能

### ログインできないスタッフがいる

アカウント単位のロックや解除操作は **存在しません**。

- **1〜2 分待って再試行** してもらう（同一 IP は 5 回 / 1 分までのレート制限。時間経過で自動回復）
- 続く場合はパスワード再発行、または本人のパスワードリセット
- それでもダメならスタッフマスタでアカウントの **有効/無効** 状態を確認

詳細は画面マニュアル「**ログイン**」を参照。

---

## 連絡フロー

```
障害発見
   ↓
スタッフ → 管理者・院長に即時報告
   ↓
管理者 → ベンダー・サポートに連絡
   ↓
ベンダーが原因調査・復旧作業
   ↓
管理者 → 全スタッフに状況共有
   ↓
復旧 → 業務正常化 → データ入力
```

---

## サポート連絡先

| 項目 | 内容 |
|------|------|
| サポート電話 | （院ごとに記入） |
| サポートメール | （院ごとに記入） |
| 緊急時 SMS | （院ごとに記入） |
| 営業時間 | （院ごとに記入） |
| 夜間・休日 | （院ごとに記入） |

この情報を紙でも掲示しておく。

---

## 定期演習（推奨）

| 頻度 | 内容 |
|------|------|
| 半年 | フォールバック準備物のチェック |
| 年次 | 模擬障害訓練（30 分の手作業業務） |

訓練により、実障害時の混乱を最小化できる。

---

## 関連する画面・workflow

- 業務フロー「**エラー・トラブル対応**」: 個別エラーの対処
- 業務フロー「**法定保存期間とデータ保護**」: バックアップの考え方
- 業務フロー「**監査ログ・操作履歴の確認**」: 障害後の検証
- 画面マニュアル「**会計**」: 領収書の再発行
