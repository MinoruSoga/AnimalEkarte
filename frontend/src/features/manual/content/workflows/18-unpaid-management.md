# 未収金（売掛金）の管理

その場で支払いが完了せず、後日支払い予定になった会計（**未収金**）の管理・督促・回収業務の手順です。

## 使う画面

- サイドバー「**会計管理**」→「**未収者一覧**」タブ

## 未収金の発生

会計確定時、以下のいずれかの場合に未収金として登録されます：

- 支払方法を「**未収金**」で確定
- 一部だけ支払いを受けて残額が残った

---

## 未収金一覧を確認する

1. サイドバー「**会計管理**」をクリックします。
2. 「**未収者一覧**」タブを開きます。

### 表示される項目

- **飼主名・ペット名**
- **会計日**
- **金額**: 未収の残額
- **発生日からの経過日数**
- **支払予定日**（メモから取得）

### 絞り込み

- 経過日数（30 日以内 / 60 日以内 / 90 日以上）
- 飼主名
- 会計日範囲

---

## 督促リストを作成する

支払催促が必要な飼主を抽出します。

### 操作手順

1. 「**未収者一覧**」タブで経過日数 60 日以上などで絞り込み。
2. 抽出された飼主に対し、電話・メール・LINE で督促連絡。
3. 連絡記録を会計のメモ欄に追記（「2026/05/15 督促連絡 → 来週支払い予定」など）。

---

## 未収金の入金処理

支払いを受けた時の操作です。

### 操作手順

1. 「**未収者一覧**」タブで該当飼主の行をクリック。
2. 「**入金処理**」ボタンをクリック。
3. 入金情報を入力：

   | 項目     | 必須 | 内容             |
   | -------- | ---- | ---------------- |
   | 入金額   | ✅   | 整数             |
   | 支払方法 | ✅   | 現金 / カード 等 |
   | 入金日   | ✅   |                  |

4. 「**入金確定**」をクリック。

### 処理すると

- **全額受領の場合**:
  - 未収者一覧から該当行が消える
  - 会計の支払方法が実方法に更新される
  - 領収書を再発行可能（実際の支払方法が記載）

- **一部受領の場合**:
  - 残額が一覧に表示される
  - 複数回の分割入金に対応

---

## 分割支払いの記録

長期分割支払いを設定する場合：

1. 初回支払い時に **「入金処理」** で受領額を入力。
2. 残額が一覧に残る。
3. 次回支払い時にもう一度入金処理。
4. 全額完済まで繰り返し。

---

## 月次の未収金チェック

### 月初の業務

1. 「**未収者一覧**」タブで全件確認。
2. 経過日数の長い順にソート。
3. 90 日以上経過の飼主に督促連絡。
4. 30〜60 日経過の飼主に状況確認。

---

## 月次集計レポートへの影響

未収金は **売上として確定済み** のため、月次集計の売上にはカウントされています。

ただし「**実際の入金額** = **売上額 - 未収金残額**」になる点に注意。経理処理では未収金残額を別途管理してください。

---

## 督促時の文面例（参考）

> ○○様、いつもありがとうございます。
> △月△日のご来院分のお支払いが未だ確認できておりません。
> ご都合のよろしい時に当院までご一報いただけますと幸いです。

LINE 連携している場合は、Lステップで一括配信することも可能（管理者操作）。

---

## 未収金の貸倒れ処理（最終手段）

回収困難な未収金がある場合：

1. 管理者と相談の上、貸倒れとして処理。
2. 該当の会計を **「取消」** （取消理由：「貸倒れ」）。
3. 元の売上から控除される（月次集計に反映）。
4. 監査ログに記録される。

### 注意

- 安易な取消は禁止。経理・院長と相談のこと。
- 貸倒れの記録は税務上の根拠資料になります。
