# 未収金（売掛金）の管理

その場で支払いが完了せず、後日支払い予定になった会計（**未収金**）の管理・督促・回収業務の手順です。

## 使う画面

- サイドバー「**会計管理**」→「**未納者一覧**」タブ

## 未収金の発生

会計確定時、以下のいずれかの場合に未収金として登録されます：

- 支払方法を「**未収金**」で確定
- 一部だけ支払いを受けて残額が残った

---

## 未収金一覧を確認する

1. サイドバー「**会計管理**」をクリックします。
2. 「**未納者一覧**」タブを開きます。

### 表示の切り替え

3 つの表示モードがあります：

| モード         | 表示内容                                                          |
| -------------- | ----------------------------------------------------------------- |
| 飼主単位       | 飼主名 / 件数 / 未納額合計 / 最古未納日 / 最新未納日 / 経過日数     |
| 会計単位       | 飼主名 / ペット名 / 診療日 / 最新未納日 / 未納額 / 経過日数         |
| 月末未納者一覧 | 飼主名 / ペット名 / 最新未納日 / 期間前繰越 / 期間内未納 / 期末繰越 |

### 絞り込み

- 会計日の範囲（開始日・終了日）で絞り込めます

### 行をクリックすると

- **飼主単位**の行 → 飼主詳細画面に遷移します
- **会計単位**の行 → 会計精算画面に遷移します

---

## 督促リストを作成する

支払催促が必要な飼主を抽出します。

### 操作手順

1. 「**未納者一覧**」タブを開き、飼主単位表示で経過日数を確認します。
2. 経過日数の長い飼主から順に、電話・メール・LINE で督促連絡。
3. 連絡記録を会計のメモ欄に追記（「2026/05/15 督促連絡 → 来週支払い予定」など）。

---

## 未収金の入金処理

支払いを受けた時の操作です。

### 操作手順

1. 「**未納者一覧**」タブを会計単位表示にし、該当の会計の行をクリック → **会計精算画面**が開きます。
2. 支払い欄で、支払方法を実際に受領した方法（現金 / カード 等）に修正し、受領額を入力します。
3. 「**修正を保存する**」ボタンをクリックします。

### 処理すると

- **全額受領の場合**:
  - 未納者一覧から該当行が消える
  - 領収書（明細兼領収書）を再発行すると実際の支払方法が記載されます

- **一部受領の場合**:
  - 残額が一覧に表示される
  - 複数回の分割入金に対応

---

## 分割支払いの記録

分割支払いを受けた場合：

1. 初回支払い時に会計精算画面を開き、支払い欄で受領した分の支払いを入力して保存。
2. 残額が未納者一覧に残ります。
3. 次回支払い時にもう一度同じ会計を開いて支払いを追加・修正します。
4. 全額完済まで繰り返し。

---

## 月次の未収金チェック

### 月初の業務

1. 「**未納者一覧**」タブで全件確認。
2. 飼主単位表示に切り替え、経過日数の長い順に確認。
3. 長期間経過している飼主に督促連絡。
4. 「**月末未納者一覧**」モードで、期間前繰越・期間内未納・期末繰越を確認。

---

## 月次集計レポートへの影響

未収金は **売上として確定済み** のため、月次集計の売上にはカウントされています。

ただし「**実際の入金額** = **売上額 - 未収金残額**」になる点に注意。経理処理では未収金残額を別途管理してください。

---

## 督促時の文面例（参考）

> ○○様、いつもありがとうございます。
> △月△日のご来院分のお支払いが未だ確認できておりません。
> ご都合のよろしい時に当院までご一報いただけますと幸いです。

LINE 連携している場合は、Lステップで一括配信することも可能（管理者操作）。

---

## 未収金の貸倒れ処理（最終手段）

回収困難な未収金がある場合：

1. 管理者と相談の上、貸倒れとして処理。
2. 該当の会計を **「取消」** （取消理由：「貸倒れ」）。
3. 元の売上から控除される（月次集計に反映）。
4. 監査ログに記録される。

### 注意

- 安易な取消は禁止。経理・院長と相談のこと。
- 貸倒れの記録は税務上の根拠資料になります。
