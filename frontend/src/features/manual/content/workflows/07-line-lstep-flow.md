# Lステップ連携の設定とタグ運用

Lステップとの連携設定、タグ管理、健診対象者の抽出操作です。

## 使う画面

| 画面 | 開き方 |
|------|-------|
| 連携設定 | サイドバー「マスタ設定」→「Lステップ連携設定」、または「Lステップ連携」グループから |
| タグ管理 | サイドバー「Lステップ連携」→「タグ管理」 |
| 健診対象者抽出 | サイドバー「Lステップ連携」→「健診対象者抽出」 |
| 分析レポート | サイドバー「Lステップ連携」→「分析レポート」 |

---

## 連携設定の主な項目

サイドバー「**Lステップ連携**」→「**連携設定**」を開きます。

### 接続情報

| 項目 | 内容 |
|------|------|
| Lステップ APIキー | Lステップで発行された認証キー |
| LINE Channel Access Token | LINE Developers から取得 |
| LINE Channel Secret | 同上 |
| LIFF ID | LIFF アプリ識別子 |
| LステップベースURL | Lステップの接続先 URL |

### CPM 設定

| 項目 | 入力 | 効果 |
|------|------|------|
| CPMバージョン | V1 / V2 | 集計の方式を切り替え |

### CPM V2 来院数閾値

| 項目 | 既定 | 効果 |
|------|------|------|
| 出会い → 良好 | 2 | このセグメントに変わる来院数 |
| 良好 → ファミリー | 4 | 同上 |
| ファミリー → NOAH | 8 | 同上 |
| NOAH | 13 | NOAH 維持の年間来院数 |

### 休眠予防閾値

| 項目 | 既定 | 効果 |
|------|------|------|
| 180 日閾値 | 180 | この日数経過で「休眠予防 180日」タグ自動付与 |
| 210 日閾値 | 210 | 同 210日 |
| 240 日閾値 | 240 | 同 240日 |
| 365 日閾値 | 365 | 同 365日 |

### 同期 ON/OFF

「**同期を有効にする**」トグルで連携処理を ON/OFF できます。OFF にしても設定値は保持されます。

---

## 接続テストを行う

「**Lステップ接続テスト**」「**LINE接続テスト**」ボタンをそれぞれクリックします。

### ボタンを押すと

- 各 API へテスト送信されます
- 成否が画面に表示されます

設定は保存されません（テストのみ）。

---

## 設定を保存する

各セクション下部の「**保存**」ボタンをクリックします。

### 保存すると

- 設定が保存されます
- 変更履歴が記録されます

---

## 配信優先順位の設定

「**配信優先順位**」セクションで、各配信種別の優先度を数値で設定します（数値小さいほど優先）。

| 配信種別 | 既定 |
|---------|------|
| 休眠防止 365日 | 2 |
| 健診フォロー | 3 |
| ノミ・ダニアラート | 4 |
| フィラリアアラート | 4 |
| 休眠防止 240日 | 5 |
| 休眠防止 210日 | 6 |
| 休眠防止 180日 | 7 |
| ワクチン期限 30日前 | 8 |
| ワクチン期限 60日前 | 8 |
| フードリマインド | 10 |
| 次回来院リマインド | 11 |
| 誕生日メッセージ | 12 |
| 初診フォロー 3日後 | 13 |
| 初診フォロー 7日後 | 13 |
| 初診ウェルカム | 14 |

## 自動管理タグのプレフィックス

サイドバー「**Lステップ連携**」→「**タグ管理**」、または連携設定画面の同セクションで管理します。

以下のプレフィックスから始まるタグは **手動付与・削除ができない**（システムが自動管理）：

| プレフィックス | カテゴリ | 用途 |
|--------------|---------|------|
| canceled_visit | B | キャンセル予約タグ |
| no_show_ | B | 無断未来院タグ |
| reserved_ | B | 予約タグ |
| birth_year_ | C1 | 生年タグ |
| breed_ | C1 | 犬種・猫種タグ |
| intact | C1 | 未避妊去勢タグ |
| pet_birthday_ | C1 | 誕生日タグ |
| sex_ | C1 | 性別タグ |
| spay_neutered | C1 | 避妊去勢済みタグ |
| checkup_ | C2 | 健診タグ |
| chronic_ | C2 | 慢性疾患タグ |
| next_checkup_ | C2 | 次回健診タグ |
| next_visit_ | C2 | 次回来院タグ |
| refill_due_ | C2 | 処方箋補充期限タグ |
| vaccine_ | C2 | ワクチンタグ |
| cert_sent_ | C3 | 証明書送付タグ |
| pet_deceased_ | C3 | ペット死亡タグ |
| post_discharge_ | C3 | 退院フォロータグ |
| post_surgery_ | C3 | 術後フォロータグ |

### プレフィックスを追加・削除する

| 項目 | 必須 | 内容 |
|------|---|------|
| プレフィックス | ✅ | 例: `vaccine_` |
| カテゴリ | ✅ | B / C1 / C2 / C3 |

「**追加**」ボタンで保存。各行右の「**削除**」で削除します。

## 慢性疾患コードをタグに変換する

カルテに慢性疾患コードが記録されると、対応するタグが自動付与されます。

例：
- `ckd` → `chronic_ckd`
- `diabetes` → `chronic_diabetes`

### マッピングを追加する

連携設定画面の「**慢性疾患コード → タグマッピング**」セクションで：

| 項目 | 必須 | 内容 |
|------|---|------|
| 疾患コード | ✅ | 例: `dm` |
| タグ名 | ✅ | 例: `CHRON_DM` |

「**追加**」ボタンで保存します。

---

## 健診対象者を抽出する

サイドバー「**Lステップ連携**」→「**健診対象者抽出**」を開きます。

「**抽出実行**」ボタンをクリックします。

### 抽出すると

- 経過月数の条件で対象飼主が検索されます
- 該当飼主に健診タグが自動で付与されます
- Lステップにタグ追加リクエストが送信されます
- 画面に対象者一覧が表示されます

---

## 配信モニターを確認する

サイドバー「**Lステップ連携**」→「**配信モニター**」を開きます。

表示される内容：
- 配信日時
- 受信飼主
- 配信種別
- 配信結果（成功 / エラー）

配信エラーが連続する飼主には自動的に **EXCL タグ** が付与され、以後の配信から除外されます。

---

## 分析レポートを確認する

サイドバー「**Lステップ連携**」→「**分析レポート**」を開きます。

| セクション | 内容 |
|----------|------|
| タグ別来院数 | タグごとの来院ペット数 |
| タグ別売上 | タグごとの累計売上 |
| 配信実績 | 配信件数・開封率 |
| 休眠復帰率 | 休眠タグ付与後の来院率 |

期間切替プルダウンで対象期間を変更できます。
