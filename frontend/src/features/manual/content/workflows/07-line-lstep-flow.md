# Lステップ連携の設定とタグ運用

Lステップとの連携設定、タグ確認、健診対象者抽出、分析・配信モニターの操作です。

## 使う画面

| 画面                   | URL                            |
| ---------------------- | ------------------------------ |
| 連携設定               | `/settings/integrations/lstep` |
| タグ管理               | `/settings/lstep/tags`         |
| 健診対象者抽出         | `/lstep/checkup-sync`          |
| 分析レポート           | `/lstep/analytics`             |
| 配信モニター           | `/lstep/delivery-monitor`      |
| LINE予約管理（別機能） | `/line-reservation`            |

サイドバーでは「Lステップ連携」グループから開きます。配信モニターは URL 直接または分析系メニューから到達します。

---

## 連携設定の主な項目

`/settings/integrations/lstep` を開きます。

### 接続情報

| 項目                      | 内容                                             |
| ------------------------- | ------------------------------------------------ |
| 接続に必要なトークン・URL | 画面の入力欄に従う（Lステップベース URL 等）     |
| 接続テスト                | 画面のテストボタンで疎通確認（設定の保存とは別） |

表示されている項目だけを入力します。マニュアル上の架空フィールド名は使いません。

### CPM・休眠などの閾値

- **CPM バージョン**（V1 / V2）と、画面に並ぶ閾値フィールドを医院方針に合わせて設定します
- 数値の既定値はフォームの初期値であり、運用中の医院設定が正です

### 同期の ON/OFF

同期を無効にしても設定値は保持されます。無効時は外部への反映が止まります。

### Write API 一時停止について

環境によっては Lステップへのタグ書き込み API が **一時停止（noop）** になっていることがあります。その場合、内部のタグキャッシュや判定・監査は更新されても、Lステップ側の実タグは変わりません。運用状態は管理者・運用 Runbook を確認してください。

---

## 設定を保存する

各セクションの「**保存**」で反映します。変更は監査対象です。

---

## 配信優先順位

連携設定内の配信優先順位セクションで、配信トリガー種別ごとの優先度を設定できます（数値が小さいほど優先、など画面の説明に従う）。

画面に並んでいる種別だけが有効です。古い固定一覧を暗記する必要はありません。

---

## タグ管理

`/settings/lstep/tags` でタグ保有状況や飼主一覧を確認します。

- システムが自動管理するタグ（CPM・来院間隔・属性など）があります
- 自動管理タグの手動付与・削除は制限される場合があります
- 慢性疾患コード→タグのマッピングがある場合は、連携設定内の該当セクションで管理します

### 権限

- 連携設定・健診抽出など: `hospital-settings` が中心
- タグ一覧・分析・配信モニター: `lstep-analytics` が必要な画面があります

403 が出る場合は権限グループを確認してください。

---

## 健診対象者を抽出する

`/lstep/checkup-sync` を開きます。

1. 健診種別・動物種・最終来院・年齢・慢性疾患・CPM・累計診療費などを条件指定します（固定条件のワンクリックではありません）。
2. プレビューで対象を確認します。
3. 付与するタグ名を指定して一括付与を実行します。

Write API 停止中は外部反映がされない点に注意します。

---

## 配信モニターを確認する

`/lstep/delivery-monitor` を開きます。

- 期間・トリガー種別・結果で配信ログを確認できます
- サマリーカードとログテーブルで成功／失敗を把握します

---

## 分析レポートを確認する

`/lstep/analytics` でタグ別の来院・売上などの分析を確認します（`lstep-analytics` 権限）。

---

## LINE 予約との分担

| 目的                             | 画面                       |
| -------------------------------- | -------------------------- |
| 飼主からの予約受付条件・文言・枠 | `/line-reservation` 配下   |
| 配信・タグ・CRM                  | 本フローの Lステップ画面群 |
| 予約の院内運用                   | `/reservations` と `/`     |

---

## 失敗時の考え方（要約）

| 経路                               | 契約の目安                                   |
| ---------------------------------- | -------------------------------------------- |
| 会計完了などイベント直後のタグ更新 | 本処理は成功のまま。タグ失敗はログ（非致命） |
| 画面からの 1 飼主同期              | 失敗をエラーとして観測                       |
| 定時バッチ                         | 1 件失敗後も続行し、件数を監査               |

詳細は仕様書（Lステップ連携）と運用 Runbook を参照してください。
