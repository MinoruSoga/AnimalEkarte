# 新人スタッフ初日のセットアップ

新しく入職したスタッフが、システムを使い始めるまでの **初日に必要な手順** です。

## このシートの読み方

- 上から順番に実施してください
- ✅ チェック欄を埋めながら進めると確実

---

## 事前準備（前日までに管理者が実施）

| ✅  | 項目                                        | 担当   |
| --- | ------------------------------------------- | ------ |
| ☐   | スタッフマスタにアカウント作成              | 管理者 |
| ☐   | 職種・権限グループ設定                      | 管理者 |
| ☐   | 初期パスワード発行・メモ                    | 管理者 |
| ☐   | 業務 PC の用意                              | 管理者 |
| ☐   | 推奨ブラウザ（Chrome / Edge）のインストール | 管理者 |
| ☐   | 業務用メールアドレス開設                    | 管理者 |

詳細は業務フロー「**スタッフアカウント・権限の管理**」参照。

---

## Step 1: 初回ログイン

| ✅  | 操作                                         |
| --- | -------------------------------------------- |
| ☐   | 業務 PC で推奨ブラウザを開く                 |
| ☐   | システムの URL にアクセス                    |
| ☐   | メールアドレスを入力                         |
| ☐   | 初期パスワードを入力（管理者から事前に受領） |
| ☐   | 「ログイン」をクリック                       |

---

## Step 2: パスワード変更（必須）

初回ログイン直後、または最初の業務終了前に必ず実施。

| ✅  | 操作                                           |
| --- | ---------------------------------------------- |
| ☐   | サイドバー左下の **鍵アイコン** をクリック     |
| ☐   | 現パスワード（初期パスワード）を入力           |
| ☐   | 新パスワード（8 文字以上、英字数字混在）を入力 |
| ☐   | 新パスワード（確認）を再入力                   |
| ☐   | 「変更」ボタンをクリック                       |
| ☐   | 自動ログアウト後、新パスワードで再ログイン     |

> ⚠️ パスワードは他人に教えない。紙に書いて貼らない。

---

## Step 3: サイドバーの確認

業務 PC のサイドバー（左メニュー）で、自分の役職に必要な機能が表示されているか確認。

| 役職         | 表示されるべきメニュー                                    |
| ------------ | --------------------------------------------------------- |
| 受付スタッフ | 当日の受付・飼主・ペット・予約管理・会計管理・レジ締め 等 |
| 獣医師       | 当日の受付・カルテ・検査管理・予防接種 等                 |
| 看護師       | 当日の受付・カルテ・入院・ホテル・在庫管理 等             |
| トリマー     | 当日の受付・トリミング 等                                 |

→ 表示されないメニューがあれば、管理者に **権限グループの確認** を依頼。

---

## Step 4: マニュアルを開く

サイドバー左下「**取扱説明書**」をクリック。

| ✅  | 操作                                          |
| --- | --------------------------------------------- |
| ☐   | サイドバー「取扱説明書」をクリック            |
| ☐   | マニュアル目次が表示されることを確認          |
| ☐   | 「マニュアルの使い方」を開く                  |
| ☐   | 「役職別 必読リスト」で自分の役職の項目を確認 |

---

## Step 5: 役職別の必読マニュアルを読む

「マニュアルの使い方」→「**役職別 必読リスト**」から、自分の役職に該当する項目を順番に読む。

最低限読むべき項目（受付スタッフ例）：

| ✅  | マニュアル                 |
| --- | -------------------------- |
| ☐   | ログイン                   |
| ☐   | 共通の UI 機能・ダイアログ |
| ☐   | 当日の受付                 |
| ☐   | 飼主・ペット管理           |
| ☐   | 会計                       |
| ☐   | レジ締め                   |

---

## Step 6: 練習（テスト環境がある場合）

可能なら、テスト環境で以下の操作を練習：

| ✅  | 練習項目                    |
| --- | --------------------------- |
| ☐   | テスト飼主・ペットを登録    |
| ☐   | 受付を登録 → ステータス遷移 |
| ☐   | 試験会計を作成 → 確定       |
| ☐   | 領収書 PDF を発行           |
| ☐   | 取消の操作                  |

---

## Step 7: 共有端末利用のルール理解

複数スタッフが同じ PC を使う場合、業務フロー「**セキュリティと複数医院の運用**」を必ず読む。

要点：

- 業務終了時は必ず **ログアウト**
- 短時間離席は **PC をロック**
- 他人のアカウントで操作しない

---

## Day 2 〜 7（初週）

| 日       | やること                                 |
| -------- | ---------------------------------------- |
| 2 日目   | 実業務の受付登録・会計を OJT             |
| 3 日目   | レジ締めを OJT                           |
| 4 日目   | カルテ・検査・予防接種等の周辺画面を確認 |
| 5 日目   | エラー対応 workflow を一読               |
| 1 週目末 | 不明点・疑問点を OJT 担当に質問          |

---

## Day 8 〜 30（初月）

- 全画面マニュアルを一通り読む
- 業務フロー全件を一読
- 月末のレジ締め・月次集計を体験
- マスタ設定の概要を理解

---

## 困った時の連絡先

| 困りごと       | 連絡先         |
| -------------- | -------------- |
| パスワード忘れ | 院長・管理者   |
| 権限がない     | 院長・管理者   |
| 業務操作の質問 | OJT 担当者     |
| システム障害   | 院長・サポート |

---

## 関連する画面・workflow

- 画面マニュアル「**マニュアルの使い方**」: 役職別必読リスト
- 画面マニュアル「**ログイン**」: パスワード変更の詳細
- 業務フロー「**セキュリティと複数医院の運用**」: 共有端末ルール
- 業務フロー「**スタッフアカウント・権限の管理**」: 管理者向け
