# 在庫の登録・在庫数の更新

在庫アイテムの **登録・編集・在庫数の更新** の操作です。

## 使う画面

サイドバー「**在庫管理**」をクリックします。

---

## 新規アイテムを登録する

新しい在庫品目をシステムに登録する操作です。

1. サイドバー「**在庫管理**」を開きます。
2. 画面右上の「**新規登録**」ボタンをクリックします。
3. アイテム情報を入力します：

   | 項目       | 必須 | 内容                              |
   | ---------- | ---- | --------------------------------- |
   | 品名       | ✅   | 商品名                            |
   | カテゴリ   | ✅   | 医薬品 / 消耗品 / フード / その他 |
   | 単位       | ✅   | バイアル / 錠 / 個 / 袋 等        |
   | 在庫数     | ✅   | 現在の数量                        |
   | 最低在庫数 | ✅   | この数を下回ると「残少」表示      |
   | 保管場所   | 任意 | 例: 薬品棚A-1                     |
   | 有効期限   | 任意 |                                   |
   | 仕入先     | 任意 |                                   |
   | 最終入荷日 | 任意 |                                   |

4. 「**登録**」ボタンをクリックします。

### 登録すると

- アイテムが一覧に追加されます

---

## 入荷した時（在庫数を増やす）

商品が届いた時の操作です。

1. 在庫一覧から該当アイテムを開き、「**編集**」ボタンをクリックします。
2. 「**在庫数**」を入荷後の数量に変更します。
3. 「**最終入荷日**」を更新します（仕入先・有効期限の変更もここで更新できます）。
4. 保存します。

> ⚠️ 入荷ごとの履歴は記録されません。過去の入荷実績を遡って確認する機能はありません。

---

## 棚卸（実数補正）をする

定期的に物理的な実数を数えて、システム値と照合します。

1. サイドバー「**在庫管理**」を開きます。
2. 一覧と実数を照合し、差異があるアイテムを開きます。
3. 「**編集**」ボタンをクリックし、「**在庫数**」を実数に修正して保存します。

> ⚠️ 一括で実数を入力する棚卸モードや、差異・棚卸履歴の記録機能はありません。差異理由を残したい場合は別途記録してください。

---

## 廃棄した時（在庫数を減らす）

期限切れ・破損などで廃棄した場合の操作です。

1. 一覧で該当アイテムを開き、「**編集**」ボタンをクリックします。
2. 「**在庫数**」から廃棄分を差し引いた数量に修正して保存します。

> ⚠️ 廃棄理由・廃棄履歴を登録する機能はありません。廃棄の記録が必要な場合は別途管理してください。

---

## 在庫ステータスの自動表示

在庫一覧では各アイテムの状態が自動で表示されます：

| ステータス | 条件              |
| ---------- | ----------------- |
| 在庫切れ   | 在庫数 0          |
| 残少       | 在庫数 ≤ 最低在庫 |
| 十分       | 在庫数 > 最低在庫 |

絞り込みで「残少」「在庫切れ」のみ表示することもできます。

---

## 自動減算（出庫）の仕組み

カルテの処置登録で在庫アイテムを指定すると、登録数量ぶんの在庫が **自動的に** 減算されます。処置の登録フォームで対象の在庫アイテムを選択（紐付け）してください。紐付けがない処置では在庫は減算されません。

---

## 必要な権限

- 画面を見る → 閲覧権限
- 新規登録・編集・削除 → 編集権限
