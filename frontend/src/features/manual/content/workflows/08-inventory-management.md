# 在庫の入荷・棚卸・廃棄

在庫アイテムの **入荷登録・棚卸補正・廃棄処理** の操作です。

## 使う画面

サイドバー「**在庫管理**」をクリックします。

---

## 新規アイテムを登録する

新しい在庫品目をシステムに登録する操作です。

1. サイドバー「**在庫管理**」を開きます。
2. 画面右上の「**新規登録**」ボタンをクリックします。
3. アイテム情報を入力します：

   | 項目                 | 必須 | 内容                              |
   | -------------------- | ---- | --------------------------------- |
   | 品名                 | ✅   | 商品名                            |
   | 商品コード           | 任意 | 内部管理用                        |
   | カテゴリ             | ✅   | 医薬品 / 消耗品 / フード / その他 |
   | 単位                 | ✅   | バイアル / 錠 / 個 / 袋 等        |
   | 仕入価格             | 任意 |                                   |
   | 販売価格             | 任意 | 物販扱いの場合                    |
   | 最低在庫             | 任意 | この数を下回るとアラート          |
   | 保管場所             | 任意 |                                   |
   | 有効期限管理         | 任意 | ON 時はロット管理                 |
   | 紐付けマスタアイテム | 任意 | 薬剤 / 物販 / 検査消耗品から選択  |

4. 「**登録**」ボタンをクリックします。

### 登録すると

- アイテムが保存されます（初期在庫数 0）

---

## 入荷を登録する

商品が届いた時の操作です。

1. 在庫一覧から該当アイテムをクリック → 詳細画面が開きます。
2. 「**入荷**」ボタンをクリックします。
3. 入荷情報を入力します：

   | 項目       | 必須 | 内容           |
   | ---------- | ---- | -------------- |
   | 入荷数量   | ✅   |                |
   | ロット番号 | 任意 | 医薬品は推奨   |
   | 有効期限   | 任意 | 医薬品は推奨   |
   | 仕入価格   | 任意 | 変動がある場合 |
   | 仕入先     | 任意 |                |

4. 「**登録**」ボタンをクリックします。

### 登録すると

- 入荷記録が保存されます
- **在庫数が増加** します
- 有効期限管理が ON のアイテムは、ロット別在庫が記録されます

### 確認する場所

- 在庫一覧で在庫数の増加
- アイテム詳細「**履歴**」タブで入荷記録

---

## 自動減算（出庫）の仕組み

スタッフが手動で出庫操作をする必要はありません。以下の操作で **自動的に** 在庫が減算されます：

| 次の操作が行われた時   | 減算される在庫       |
| ---------------------- | -------------------- |
| カルテ確定（処方明細） | 薬剤に紐付く在庫     |
| 予防接種登録           | ワクチンに紐付く在庫 |
| トリミング完了         | オプション消耗品     |
| 会計確定（物販明細）   | 物販に紐付く在庫     |
| 入院中の投薬記録       | 薬剤に紐付く在庫     |

### 自動減算の前提

マスタ設定で、診療項目・薬剤・物販と在庫アイテムが紐付けされている必要があります。紐付けがない場合、自動減算は機能しません。

### 取消した場合

上記操作を取り消すと、**在庫が自動で戻されます**。

---

## 棚卸（実数補正）をする

定期的に物理的な実数を数えて、システム値と照合します。

1. サイドバー「**在庫管理**」を開きます。
2. 「**棚卸モード**」タブ または ボタンをクリックします。
3. 各アイテム行に表示される「**実数入力**」欄に、数えた実数を入力します。
4. システム値との **差異が即時表示** されます。
5. すべて入力後、「**棚卸確定**」ボタンをクリックします。
6. 必要なら差異理由を入力します。

### 棚卸を確定すると

- 差異がある場合、補正記録が保存されます
- **在庫数が入力した実数で上書き** されます
- 棚卸履歴に記録されます

### 確認する場所

アイテム詳細「**棚卸履歴**」タブで補正記録を確認できます。

---

## 廃棄処理をする

期限切れ・破損などで廃棄する場合の操作です。

1. アイテム詳細画面の「**廃棄**」ボタンをクリックします。
2. 廃棄情報を入力します：

   | 項目     | 必須 | 内容                            |
   | -------- | ---- | ------------------------------- |
   | 廃棄数量 | ✅   |                                 |
   | 廃棄理由 | ✅   | 期限切れ / 破損 / 紛失 / その他 |
   | メモ     | 任意 |                                 |

3. 「**廃棄登録**」ボタンをクリックします。

### 登録すると

- 廃棄記録が保存されます
- **在庫数が廃棄分だけ減算** されます
- 廃棄履歴に記録されます

---

## 在庫ステータスの自動表示

在庫一覧では各アイテムの状態が自動で表示されます：

| ステータス | 条件              |
| ---------- | ----------------- |
| 在庫切れ   | 在庫数 0          |
| 残少       | 在庫数 ≤ 最低在庫 |
| 十分       | 在庫数 > 最低在庫 |

絞り込みで「残少」「在庫切れ」のみ表示することもできます。

---

## ロット管理（有効期限 ON 時）

アイテム詳細画面の「**ロット**」タブで確認します：

- ロット番号別の在庫数
- 各ロットの有効期限
- 期限 30 日以内のロットはハイライト表示

### 自動減算のルール

古いロットから先に減算されます（先入れ先出し）。

---

## マスタとの紐付けについて

在庫の自動減算には、診療項目・薬剤・物販マスタとの紐付けが必要です。

| 設定する場所                                | 紐付け対象      |
| ------------------------------------------- | --------------- |
| サイドバー「マスタ設定」→「診療項目マスタ」 | 診療項目 → 在庫 |
| サイドバー「マスタ設定」→「薬剤マスタ」     | 薬剤 → 在庫     |
| サイドバー「マスタ設定」→「物販マスタ」     | 物販 → 在庫     |

紐付けがない場合、自動減算は機能しません。
