# スタッフアカウント・権限の管理

スタッフのシステムアカウントを作成・編集・無効化し、権限グループを管理する操作です（管理者向け）。

## 使う画面

| 画面         | 開き方                                          |
| ------------ | ----------------------------------------------- |
| スタッフ管理 | サイドバー「マスタ設定」→「スタッフマスタ」     |
| 職種マスタ   | サイドバー「マスタ設定」→「職種マスタ」         |
| 権限グループ | サイドバー「マスタ設定」→「権限グループマスタ」 |

---

## 職種マスタを登録する

新しい職種が必要な場合に追加します。

1. サイドバー「**マスタ設定**」→「**職種マスタ**」を開きます。
2. 「**新規追加**」ボタンをクリックします。
3. 名称を入力します（例：院長 / 獣医師 / 看護師 / トリマー / 受付）。
4. 「**保存**」をクリックします。

### 保存すると

- 職種が登録されます
- スタッフ登録時の職種プルダウンに表示されるようになります

---

## 権限グループを新規作成する

役職ごとに「どの機能を使えるか・どの操作ができるか」を細かく設定します。

1. サイドバー「**マスタ設定**」→「**権限グループマスタ**」を開きます。
2. 「**新規グループ**」ボタンをクリックします。
3. グループ情報を入力します：

   | 項目       | 必須 | 内容                        |
   | ---------- | ---- | --------------------------- |
   | グループ名 | ✅   | 例：トリマー / 受付スタッフ |
   | 説明       | 任意 | 用途のメモ                  |

4. **権限マトリクス** で機能ごとに操作を ON/OFF します：

   | 操作     | できること           |
   | -------- | -------------------- |
   | 閲覧     | 画面を見る           |
   | 新規作成 | データを新しく作る   |
   | 編集     | 既存データを変更する |
   | 削除     | データを削除する     |

5. 「**保存**」をクリックします。

### 保存すると

- 権限グループが保存されます
- スタッフ登録・編集時に選択肢として表示されるようになります

> 💡 権限は **最小限から始めて、必要に応じて追加** するのが安全です。

---

## スタッフを新規登録する

新入職員のアカウントを発行する操作です。

1. サイドバー「**マスタ設定**」→「**スタッフマスタ**」を開きます。
2. 「**新規スタッフ**」ボタンをクリックします。
3. スタッフ情報を入力します：

   | 項目           | 必須   | 内容                                           |
   | -------------- | ------ | ---------------------------------------------- |
   | 姓 / 名        | ✅     |                                                |
   | フリガナ       | 推奨   |                                                |
   | メールアドレス | 任意   | ログインする場合のみ。ログイン ID。重複不可    |
   | パスワード     | 任意   | ログインする場合のみ。管理者が入力。8 文字以上 |
   | 職種           | ✅     | 職種マスタから選択                             |
   | 権限グループ   | ✅     | 権限グループから選択                           |
   | 担当領域       | 任意   | 医師の専門・トリマー担当動物種 等              |
   | 所属医院       | ✅     | 複数選択可                                     |
   | 主医院         | 必要時 | 複数所属時のデフォルト                         |

4. 「**登録**」ボタンをクリックします。

### 登録すると

- スタッフが保存されます
- ログイン用パスワードを入力した場合、その値が暗号化されて保存されます
- システムが初期パスワードを自動生成して一度だけ表示する方式ではありません

### ⚠️ 重要

管理者が入力したパスワードを本人へ伝達してください。保存後はシステムから取得できません。アカウントなしのスタッフ（メール・パスワード空）も登録できます。

### エラーになる場合

- メールアドレスが既に登録されている
- 必須項目が未入力

---

## スタッフの権限を変更する

1. サイドバー「**マスタ設定**」→「**スタッフマスタ**」で該当スタッフをクリックします。
2. 「**権限グループ**」プルダウンを変更します。
3. 「**保存**」をクリックします。

### 保存すると

- スタッフの権限グループが更新されます
- 該当スタッフが **次回ログイン時から** 新しい権限が反映されます

> 既存のログインセッションには即時反映されません。再ログインが必要です。

---

## スタッフを無効化する（退職時）

1. サイドバー「**マスタ設定**」→「**スタッフマスタ**」で該当スタッフを開きます。
2. 「**ステータス**」プルダウンを「**無効**」に変更します。
3. 「**保存**」をクリックします。

### 無効化すると

- スタッフのステータスが「**無効**」になります
- 次回ログイン試行時に拒否されます

> ⚠️ 物理削除ではなく **無効化** を使ってください。過去カルテ・会計の担当者参照を維持するためです。

---

## パスワードを変更する（管理者操作）

スタッフがパスワードを忘れた場合の操作です。

1. サイドバー「**マスタ設定**」→「**スタッフマスタ**」で該当スタッフを開きます。
2. 「**パスワード**」欄に新しいパスワードを入力します（プレースホルダは「変更する場合のみ入力」）。
3. 「**保存**」をクリックします。

自動生成・一時パスワード再発行ボタン、初回ログイン時の強制変更はありません。

---

## スタッフ自身でパスワードをリセットする

ログイン画面の「**パスワードをお忘れですか？**」リンクから、本人が自分でリセットできます。

詳細は画面マニュアル「**ログイン**」を参照。

---

## ログインできないスタッフへの対応

アカウント単位のロックや解除操作は **存在しません**。

ログインは **同一 IP につき 5 回 / 1 分** までに制限されます。超過時は約 1 分待つと自動的に再試行可能になります。

それでもログインできない場合:

1. 1〜2 分待って再試行してもらう
2. 上記の管理者パスワード変更、または本人のパスワードリセット
3. スタッフマスタでアカウントの **有効/無効** 状態を確認する

詳細は画面マニュアル「**ログイン**」を参照。
