# 法定保存期間とデータ保護

動物病院が法律上 **保存する必要があるデータの期間** と、その保護手順です（管理者向け）。

> ⚠️ 法的要件は法改正で変わる可能性があります。最新情報は獣医師会・税理士・弁護士に確認してください。

---

## データ別の保存期間（参考）

### 診療関連

| データ                 | 保存期間     | 根拠                       |
| ---------------------- | ------------ | -------------------------- |
| カルテ（診療録）       | **3 年以上** | 獣医師法（推奨は 5〜7 年） |
| 処方箋                 | 3 年以上     | 同上                       |
| 検査結果               | 3 年以上     | 同上                       |
| 麻薬・向精神薬使用記録 | **2 年**     | 麻薬及び向精神薬取締法     |
| 狂犬病予防接種記録     | **3 年**     | 狂犬病予防法               |

### 会計関連

| データ           | 保存期間 | 根拠               |
| ---------------- | -------- | ------------------ |
| 領収書控え       | **5 年** | 所得税法・法人税法 |
| 月次集計レポート | **7 年** | 会社法・税法       |
| 売上帳簿         | **7 年** | 同上               |

### スタッフ関連

| データ             | 保存期間     | 根拠       |
| ------------------ | ------------ | ---------- |
| 勤怠記録（シフト） | **3 年**     | 労働基準法 |
| スタッフ操作履歴   | **3 年以上** | 推奨       |

## システム上の保存

Animal Ekarte では、以下のデータが **自動的に永続保存** されています：

| データ       | 取扱                       |
| ------------ | -------------------------- |
| カルテ       | 削除不可。確定後はロック   |
| 会計         | 取消可だが過去データは保持 |
| 飼主・ペット | アーカイブ後も削除不可     |
| 監査ログ     | 削除不可                   |

> 物理削除は **基本的に行いません**。「アーカイブ」「無効化」で論理削除し、データは保持されます。

## バックアップ（管理者向け）

### バックアップの仕組み

システムは自動的に日次バックアップを取得しています（インフラ側で実装）。

- 詳細は IT サポート・インフラ担当に確認
- 保管場所・保管期間は契約による

### 手動でのデータ取得

定期的に以下をエクスポート保存：

- 月次集計レポート（CSV / PDF）
- 監査ログ（CSV）
- 飼主・ペット一覧（CSV）

これは緊急時のオフラインバックアップとして有用。

---

## 個人情報保護

### 取り扱う個人情報

| 種類         | 内容                                                                      |
| ------------ | ------------------------------------------------------------------------- |
| 飼主情報     | 氏名・住所・電話番号・メール                                              |
| 支払情報     | クレジットカード番号は **システムに保存されない**（決済代行サービス経由） |
| スタッフ情報 | 氏名・連絡先・職種                                                        |

### 保護のルール

- パスワードは個人管理（他人に教えない）
- スクリーンショット撮影時は個人情報をマスキング
- スマートフォンでの画面撮影は **業務目的のみ**
- 退職時は業務 PC のキャッシュ・ブックマーク削除
- USB 等の外部メディアへの **データコピー禁止**（特例は管理者承認）

---

## 患者死亡後のデータ取扱

ペット死亡後も、法定保存期間中は **過去カルテ・会計を保持** します。

業務フロー「**ペット死亡時の処理**」参照。

---

## データ削除依頼への対応

飼主から「自分のデータを削除してほしい」と依頼された場合：

| 状況               | 対応                                             |
| ------------------ | ------------------------------------------------ |
| 法定保存期間内     | **削除不可**。飼主に説明（個人情報保護法の例外） |
| 法定保存期間経過後 | 院長判断で対応（実装によっては完全削除も可）     |

詳細は弁護士・税理士に相談。

---

## 監査・税務調査への対応

税務調査・労務監査等で当局からデータ提示要求があった場合：

1. 院長・税理士・弁護士に確認
2. 必要な期間・データを特定
3. CSV / PDF でエクスポート
4. 印刷物として提示

詳細は業務フロー「**監査ログ・操作履歴の確認**」参照。

---

## システム解約時のデータ移行

将来、システムを別のベンダーに変更する場合：

1. 全データの CSV エクスポート
2. PDF 形式でカルテ印刷
3. 法定保存期間中はアクセス可能な形式で保管
4. 新システムへのインポート（フォーマット要確認）
