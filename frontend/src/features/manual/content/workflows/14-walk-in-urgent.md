# 予約なし来院の受付登録

事前予約のないペット（飛び込み・急患）が来院した時の **システム上の受付登録** の操作です。

## 使う画面

サイドバー「**当日の受付**」が中心です。新規飼主の場合は「**飼主・ペット**」画面も使います。

---

## 既存ペットの場合

すでに登録されているペットの飛び込み受付です。

1. サイドバー「**当日の受付**」をクリックします。
2. 画面右上の「**新規予約登録**」ボタンをクリックします。
3. ペット選択画面で **飼主名・ペット名・電話番号** で検索します。
4. 候補リストから該当ペットをクリックします。
5. 受付情報を入力します：

   | 項目     | 必須 | 内容            |
   | -------- | ---- | --------------- |
   | 来院目的 | ✅   | 主訴・症状      |
   | 予約区分 | ✅   | 診察 等から選択 |
   | 予約日時 | ✅   | 既定: 現在時刻  |

6. 「**登録**」ボタンをクリックします。

### 登録すると

- 受付カードが「**受付予約**」カラムに追加されます
- そのまま「受付済」や「診療中」に直接変更することもできます

---

## 新規飼主の場合

未登録の飼主・ペットの飛び込み受付です。

1. 「**当日の受付**」→ 「**新規予約登録**」をクリックします。
2. ペット選択画面で「**新規飼主登録**」リンクをクリックします。
3. 飼主情報を入力します（最小限で OK）：

   | 項目     | 必須 |
   | -------- | ---- |
   | 姓 / 名  | ✅   |
   | 電話番号 | ✅   |

4. ペット情報を入力します（最小限で OK）：

   | 項目     | 必須 |
   | -------- | ---- |
   | ペット名 | ✅   |
   | 動物種   | ✅   |
   | 品種     | ✅   |

5. 続けて受付情報を入力します。
6. 「**登録**」をクリックします。

### 登録すると

- 飼主とペットが新規保存されます
- 受付カードが「受付予約」カラムに追加されます

### 追加情報の入力

住所・フリガナ・生年月日等は **後日でも追加できます**。サイドバー「**飼主・ペット**」→ 該当飼主の編集画面から追記します。

---

## 直接「診療中」にする

緊急対応で即座に診察室に入る場合、ステータスを途中の状態を飛ばして直接変更できます。

1. カードのステータスバッジをクリックします。
2. メニューから「**診療中**」を直接選びます。

### 変更すると

- ステータスが **「受付済」を飛ばして「診療中」** になります
- カードが「診療中」カラムに移動します

> 順序を飛ばしてもエラーにはなりません。

---

## 予約に割り込む場合

システムには順序の自動制御はありません。手動でステータスを進めます。

例：通常の予約患者が「受付済」で待機中、急患が来た場合

- 急患のカードを **「診療中」** に直接変更
- 予約患者のカードはそのまま「受付済」のまま待機
- 緊急対応終了後、予約患者のステータスを順次進める

---

## 予約区分について

「緊急」「急患」等のカスタム区分がマスタにない場合：

- 「**診察**」区分を選んで、メモ欄に「急患」と書いておく
- または管理者が「**マスタ設定**」→「**予約区分マスタ**」で新しい区分を追加します

---

## カルテ作成への遷移

受付登録後、カードのペット名をクリックすると、カルテ作成画面に直接遷移できます。
