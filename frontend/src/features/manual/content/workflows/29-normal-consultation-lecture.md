# 通常診療レクチャー（受付から会計・ホテルと入院）

受付 → 問診 → 診察 → 血液検査 → 所見入力 → 注射などの処置入力 → 薬処方の記録 → 会計を、一頭のペットで順に確認するための取説です。2026年10月13日のノア打合せ向けに、同日時点の main の画面・操作を基準にしています。

このページは **アプリの操作説明** です。検査の実施、診断、薬剤の選択・用量・投与方法は獣医師の判断と院内の指示に従ってください。練習は院内で許可された検証用の飼主・ペットを使い、実患者の記録や会計を練習で確定しないでください。

## 開き方と準備

サイドバー「取扱説明書」→「業務フロー」→「来院対応」→「通常診療レクチャー（受付から会計・ホテルと入院）」で開きます。検索欄では「通常診療」「レクチャー」「血液検査」「ホテル」でも探せます。

- 飼主・ペットが登録済みで、対象医院・飼主名・ペット名を確認できること。未登録なら先に「飼主・ペット管理」で登録します。
- 診療区分の予約、担当スタッフ、主訴・診断・診療項目・薬剤・検査項目など、使うマスタと価格が用意されていること。選択肢がない、価格未設定と表示される場合は設定担当者に確認します。
- 必要な権限は下表の目安を確認します。権限や記録の状態によってボタンが非表示・無効になります。死亡登録されたペットは、新規診療記録などの作成を進められません。

| 工程                                 | 権限の目安                                                          |
| ------------------------------------ | ------------------------------------------------------------------- |
| 受付を見る・予約登録・ステータス更新 | `reception:view`、`reservations:create` / `reservations:edit`       |
| カルテを見る・作る・保存する         | `medical-records:view` / `create` / `edit`                          |
| 治療明細を追加・更新する             | `medical-records:create` / `edit`                                   |
| 検査を見る・作る・結果入力・取り込む | `examinations:view` / `create` / `edit`（新規入力にも edit が必要） |
| 会計を見る・作る・精算する           | `accounting:view` / `create` / `edit`                               |
| 医師の「チェック完了」               | `medical-records:edit` に加え `accounting:view` / `edit`            |
| 入院・ホテルを見る・登録・更新する   | `hospitalization:view` / `create` / `edit`                          |

## 主編：通常診療

### 1. 受付する

**開始条件：** 登録済みのペットが来院し、「当日の受付」の日付が当日になっていること。

1. サイドバー「当日の受付」を開きます。
2. 予約がある場合は「受付予約」の対象カードを開き、飼主・ペット・予約内容を確認して「受付済にする」を押します。
3. 予約がない場合は「新規予約登録」で対象ペット、当日の日時、診療用の予約区分などを入力して保存します。当日のこの導線では受付済として登録されるので、「受付済」の対象カードを確認します。
4. 「受付済」の対象カードを開き、診療の「カルテ作成」を押します。

**確認する結果：** 受付が「受付済」、続いて「診療中」へ進み、対象ペットのカルテが開きます。新規カルテは下書きの作成完了を待ちます。エラー表示時は成功したとみなさず、受付の状態と既存カルテを確認してください。

**次の工程：** カルテの「問診」タブへ。既に診療中なら「カルテ入力」で対象カルテを再開します。

### 2. 問診を入力する

**開始条件：** 対象ペットの編集可能なカルテが開いていること。

1. 「問診」タブの「主訴区分」「主訴詳細」に聞き取った内容を入力します。
2. 「治療方針」に院内で確認した内容を入力します。過去の「カルテ履歴」も参照できます。
3. 「保存」を押します。下書き作成中で保存や子記録の追加が使えない場合は、作成完了を待ちます。

**確認する結果：** 保存が成功し、同じカルテを開き直して主訴・方針が残っていることを確認します。タブ移動だけを保存の代わりにしないでください。

> 過去問診のコピーは現在の主訴・方針を置き換え、治療明細も追加することがあります。今回の内容と単価・重複を確認してから使います。

**次の工程：** 「診察/治療プラン」へ。

### 3. 診察内容を記録する

**開始条件：** 問診を保存済みで、診察担当者が入力内容を確認できること。

1. 「診察/治療プラン」タブを開きます。
2. 「診察(PE)」に身体検査所見を入力します。「診断」の選択欄・詳細欄には確認した内容を入力します。
3. 体温・体重などは「バイタル記録」から実測値を記録します。下書き作成前や確定済みでは追加できません。
4. カルテの文章欄は「保存」で保存します。

**確認する結果：** 所見・診断とバイタル記録が対象ペットのカルテに残っていること。ここでの入力だけで受付を会計待ちにしたり、会計を作成したりするわけではありません。

**次の工程：** 血液検査が必要なら工程4へ。不要なら工程5へ。

### 4. 血液検査の結果を記録してカルテに取り込む

**開始条件：** 対象カルテが保存され、医院の検査種別・測定項目が設定されていること。実際の採血・測定は院内の手順に従います。

1. カルテの文章欄を保存してから、サイドバー「検査管理」→「新規検査登録」を開き、同じペットを選びます。
2. 検査フォームで「検査種別」「担当医」「検査日」「ステータス」を確認します。血液検査の種別名や測定項目は医院のマスタによって異なります。
3. 測定項目の「結果値」に実測結果を入力します。「備考・所見」には補足を入力できます。
4. テンプレートにない項目は「検査項目を追加」で項目名・結果値を入力します。手入力行に設定されていない単位・基準値を自動補完されたものとして扱わず、必要な補足は「備考・所見」に記録します。
5. まず「結果入力済み」などの編集可能な状態で「保存」し、対象・日付・結果を確認します。「完了」「確定」にすると結果の編集が制限されるため、取込前に安易に確定しないでください。
6. 同じカルテの「検査」タブへ戻り、「記録を追加」で「検査取り込み」を開きます。対象の検査を選び「○件取り込む」を押します。
7. 「検査結果一覧」に対象日の項目名・結果値が表示されることを確認します。結果を再編集する場合は、対象検査の「検歴を表示」から検査詳細へ進めます。

**確認する結果：** 検査が保存され、今回のカルテに紐付いた結果が表示されること。検査を保存・確定しただけでカルテへの取込が済むわけではありません。候補がない場合はペット、既存の紐付け、検査の状態を確認します。確定済みなど取込できない記録は候補から除外されます。

**次の工程：** 結果を参照して工程5へ。検査の完了・確定は院内の確認手順に従って行います。

#### 外部検査機器の連携について

機器からの受信には医院ごとの機器設定、項目マッピング、患者IDとペットの紐付けが必要です。サイドバー「検査受信」や設定の「検査機器マスタ」などを、権限のある担当者が確認します。このレクチャーは実機受信を検証していません。機器の値が自動で届くことを前提に進めないでください。

受信結果が無い場合は、上記の検査フォームで確認済みの測定値を手入力できます。既に受信・登録された結果がある場合は、同一検査を重複作成せず、対象と日付を照合して取込候補を確認します。基準値や判定は設定に依存するため、表示だけで医学的な判断をしないでください。

### 5. 検査後の所見・方針を入力する

**開始条件：** 診察内容と必要な検査結果を担当者が確認したこと。

1. 「診察/治療プラン」に戻り、「診察所見・診断・治療方針」の「身体検査所見」「診断詳細」「治療方針」を、確認した内容に更新します。この「治療方針」は問診タブの同名欄とは別の入力欄です。
2. 「保存」を押します。検査そのものに関する所見は、検査詳細の「備考・所見」にも記録できます。

**確認する結果：** 今回の所見・診断が保存されていること。「治療プラン」は予定の記録として扱い、次の「治療」で実施した明細を確認します。

**次の工程：** 注射など実施処置の入力へ。

### 6. 注射などの処置を入力する

**開始条件：** 保存済み・未確定のカルテで、実施内容が確認されていること。

1. 「治療」タブを開き、「マスタから追加」で今回実施した診療・処置を選びます。
2. マスタにない内容を記録する場合は「手入力で追加」→種別「処置」などを選び、「治療内容」を入力して「追加」を押します。
3. 明細の内容・単価・数量・メモを確認します。数量編集は画面の案内に従い Enter を2回押して確定できます。保存エラーや数量の警告を解消してから次へ進みます。

**確認する結果：** 実施明細が「治療」に表示され、再読込しても残ること。明細の追加・更新は個別に保存されます。カルテ本文の「保存」と分けて成功を確認します。

**次の工程：** 処方された薬の記録へ。注射薬を薬品明細として記録する場合も、次の工程の薬品入力を使います。処置料と薬品代の重複・漏れを確認してください。

### 7. 薬処方を薬品明細として記録する

**開始条件：** 獣医師が薬剤・数量・投与方法を決定していること。

1. 同じ「治療」タブの「マスタから追加」で薬剤を選びます。
2. 手入力の場合は「手入力で追加」→種別「薬品」を選び、「投与方法」「治療内容」を入力して「追加」を押します。
3. 数量・単価・メモを実際の指示と照合します。服薬の指示など必要な情報は、表示されるメモやカルテの方針欄に記録します。
4. 投与量の計算・警告が表示される場合は設定や記録済み体重などに依存します。表示値を処方判断の代わりにせず、担当者が確認します。エラーがある状態を保存済みとして扱わないでください。

**確認する結果：** 処方した薬が薬品明細として保存され、内容・数量・投与方法が院内指示と一致すること。この手順は薬品明細への記録を説明しています。独立した処方箋発行や、薬品記録だけでの自動調剤を保証するものではありません。

**次の工程：** 医師の明細確認と会計へ。

### 8. 医師確認・カルテ確定・会計精算を行う

**開始条件：** カルテ本文、検査・処置・薬品が保存され、請求対象が揃っていること。

1. 「会計(医師確認)」タブで診療・処置・薬品・検査などの内容、数量、価格、割引を確認します。
2. 「チェック完了」を押し、確認ダイアログでも「チェック完了」を押します。「確認済み」表示を確認します。明細がない・価格未設定などのエラーは先に解消します。
3. 必要な本文保存を終えてから、別のタブで「確定する」を押し、確認ダイアログで確定します。カルテは編集ロックされ、以後の文章修正は追記の経路になります。医師確認が未完了なら確定できません。
4. 「当日の受付」に戻り、「診療中」の対象カードで「診察を終了する」を押します。「会計待ち」へ移ったことを確認します。カルテの確定だけではこの移動や会計作成は済みません。
5. 「会計待ち」の対象カードの「会計へ進む」で会計画面を開きます。今回の対象ペット・日付と、取り込まれた未請求明細を確認します。
6. 未請求項目の警告がある場合は、対象の診療や他サービスの会計準備状態を確認します。取り残し・重複・価格未設定を解消し、最新明細を読み直してから進めます。
7. 保険・割引・支払方法・入金額などを確認して「会計を確定する」を押します。精算済みの会計を再び新規作成しないでください。

**確認する結果：** 会計が「精算済」となり、明細・支払いの結果を確認できること。「明細兼領収書」で内容を確認します。受付の状態も再確認してください。カルテの「保存」、医師の「チェック完了」、カルテの「確定する」、会計の「会計を確定する」はそれぞれ別の操作です。

**次の工程：** 会計後の院内対応へ。精算後の訂正や締め済み日の操作は別の権限・理由入力が必要なため、担当者に引き継ぎます。

## 補足編：ホテル・入院

ホテルと入院は「入院・ホテル」の同じ登録画面を使い、**「入院タイプ」だけを「ホテル」または「入院」に分けます**。通常診療のカルテ作成だけでは滞在は登録されません。

### A. 滞在を登録する

**開始条件：** 登録済みの対象ペット、滞在期間、担当者、必要なケージ・ケア内容を院内で確認したこと。

1. サイドバー「入院・ホテル」→「新規入院登録」でペットを選びます。
2. 「入院タイプ」で「ホテル」または「入院」を選び、「期間」の開始日・終了日、担当医、メモなどを入力します。
3. 「ケージ・個室」を選びます。「選択なし」で登録することもできます。空き状況・適合するケージは院内で確認し、競合エラーが出た場合は割当・期間を見直します。
4. 登録時の治療プランが必要なら、内容のある行を入力してから「保存」を押します。このプランは登録時のスナップショットで、日々のケアは詳細画面で管理します。

**確認する結果：** 対象の滞在が一覧に保存され、期間・タイプ・ケージ・状態が正しいこと。ケージを選ばなければボードの「ケージ未割当」を確認します。「予約」状態の記録は実際の受け入れ時に詳細の「チェックイン」を使い、「入院中」になったことを確認します。

**次の工程：** 対象記録の詳細を開き、日々のケアへ。

### B. 日々のケアを記録する

**開始条件：** 対象の入院中記録が開き、ケア・バイタルなどの操作権限があること。

1. 詳細の「デイリーカルテ」を確認します。画面幅によってプラン管理と並んで表示される場合があります。
2. 対象日を選び、バイタルやケアログを記録します。ケアログの「追加」では「時刻」「種別」「値 / 量」「メモ」を入力し「追加」で保存します。
3. 継続する投薬・給餌・処置などは「プラン管理・詳細」のケアプランに登録し、実施内容を記録します。予定と実施を混同しないでください。

**確認する結果：** 対象日の記録が表示され、再読込しても残ること。ホテルでは預かり中の食事・排泄・連絡事項、入院では指示された観察・実施内容を記録します。

**次の工程：** 期間・ケージを変える場合は「入院情報の編集」→「更新」。退院・お迎え時はCへ。

### C. 退院・お迎えと会計

**開始条件：** 記録・実施内容・料金を確認済みで、対象が「入院中」であること。ホテルでもボタン名は「退院処理」です。

1. 対象詳細の「退院処理」を押します。
2. ダイアログは退院日を本日にして「退院済」へ変更する内容です。取り消せないため対象を再確認します。
3. 同時に会計を作成して進む場合は「退院後、そのまま会計画面へ進む」にチェックします。
4. 「退院処理を実行」を押し、成功表示と「退院済」を確認します。チェックした場合は作成された会計へ進み、主編工程8と同様に明細・入金内容を確認して精算します。
5. チェックしなかった場合は退院だけを行います。後から会計する場合は既存会計の有無と請求対象を確認して会計担当者へ引き継ぎます。

**確認する結果：** 退院状態と実際の会計明細が一致すること。登録時プランやケア記録を入力しただけで、すべての料金が自動で請求済みになるとは限りません。滞在料金・処置・薬品の漏れと重複を実明細で照合します。

**次の工程：** お迎え・退院後の院内対応へ。

## レクチャーの確認チェック

- 同じ医院・飼主・ペットを各工程で確認できたか。
- 問診・診察所見・検査結果・処置・薬品が保存され、開き直して確認できたか。
- 検査の取込と医師確認、カルテ確定、受付の会計待ちへの移動を区別できたか。
- 会計明細に今回の対象が揃い、重複・未請求の警告を解消できたか。
- 補足編ではタイプ・期間・ケージ、日々の記録、退院時の会計作成有無を確認できたか。

実機連携の受信、院内のマスタ・権限・料金設定、実際の患者での診療・精算はこのページの作成時点では未確認です。打合せでは操作説明と院内設定・実機確認を分けて確認してください。
