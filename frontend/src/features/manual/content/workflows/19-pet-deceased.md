# ペット死亡時の処理

ペットが死亡した時の **システム上の処理手順** と、自動で起きる連動の解説です。

## 使う画面

| 画面              | 開き方                                   |
| ----------------- | ---------------------------------------- |
| 飼主・ペット      | サイドバー「飼主・ペット」               |
| Lステップタグ管理 | サイドバー「Lステップ連携」→「タグ管理」 |

---

## Step 1: ペットを「アーカイブ」する

サイドバー「**飼主・ペット**」をクリックします。

1. 該当飼主の詳細画面を開きます。
2. 「**ペット**」タブで該当ペットを選択します。
3. ペット編集モードで「**アーカイブ**」ボタンをクリックします。
4. 理由を入力します：

   | 項目   | 必須 | 入力           |
   | ------ | ---- | -------------- |
   | 理由   | ✅   | 「死亡」を選択 |
   | 死亡日 | ✅   | 日付を入力     |
   | メモ   | 任意 | 死因・備考等   |

5. 「**確定**」をクリックします。

### 確定すると

- ペットが **「死亡」状態** になります
- 一覧の「生死」列が「死亡」表示に変わります
- **過去のカルテ・会計・予防接種・健診・トリミング・入院 等の全データは保持** されます
- 新規受付・予約・カルテ作成からは選択できなくなります

---

## Step 2: 自動で起きるシステム処理

ペット死亡を登録すると、システムが以下を自動で実行します：

### A. 臨床アラートの表示

ペットの過去カルテを開くと、**患者情報カード** に **「死亡」バッジ** が表示されます。

→ 詳細は画面マニュアル「**共通の UI 機能・ダイアログ**」参照。

### B. Lステップタグの自動付与

Lステップ連携が有効な場合、該当飼主に以下のタグが自動付与されます：

- `pet_deceased_<ペット名>`: 死亡ペットの記録
- 既存の `vaccine_期限間近` 等のタグは **自動的に解除** されます（配信停止のため）

### C. 配信からの除外

Lステップ配信で、死亡ペット関連のリマインダー（ワクチン期限・健診案内 等）は **自動的に除外** されます。

→ 詳細は画面マニュアル「**Lステップ連携**」の配信モニター参照。

---

## Step 3: 飼主への対応

### お悔やみメッセージ

Lステップ連携でお悔やみメッセージのシナリオを設定している場合、`pet_deceased_` タグ付与をトリガーに自動配信されます（Lステップ側の設定）。

### 既存予約のキャンセル

該当ペットに未来の予約がある場合、サイドバー「**予約管理**」で該当予約を **キャンセル** します。

### 未確定カルテの処理

死亡前に作成途中のカルテがある場合：

- 内容を確認して **確定 or 削除** を判断
- 確定する場合: 通常通り「**確定**」ボタン
- 不要な場合: 管理者に削除を依頼

### 未収金がある場合

該当ペットの会計に未収金がある場合、業務フロー「**未収金（売掛金）の管理**」を参照。

> 死亡を理由とした未収金の貸倒れ処理は経理・院長判断のうえ実施します。

---

## Step 4: 多頭飼育の場合の注意

同じ飼主が複数ペットを飼っている場合：

- 死亡ペットのみアーカイブ → 他のペットは引き続き診察可能
- 飼主自体は **アーカイブしない**

飼主アカウントは存続させ、生存ペットの診察を継続します。

---

## 復活させたい場合（誤操作の場合）

誤って死亡登録した場合：

1. 飼主詳細画面でペットを開きます。
2. 「**アーカイブ解除**」ボタンをクリックします（管理者権限が必要）。

### 解除すると

- ペットが「生存」状態に戻ります
- 自動付与された Lステップタグは個別に削除する必要があります（管理者操作）

---

## 全体で起きる更新まとめ

| 項目                 | 状態変化                           |
| -------------------- | ---------------------------------- |
| ペット               | 「生存」→「死亡」、アーカイブ状態  |
| 飼主タグ             | `pet_deceased_<ペット名>` 自動付与 |
| ワクチン・健診タグ   | 自動解除（配信停止）               |
| 過去のカルテ・会計等 | 保持（参照可能）                   |
| 未来の予約           | スタッフが手動キャンセル           |

---

## 注意事項

- **削除ではなくアーカイブ** を使用すること。物理削除は禁止
- 過去カルテは医療記録として **法定保存期間** 中は維持される
- Lステップで誤って配信されないよう、**死亡登録は速やかに** 行うこと
- 飼主の心情に配慮し、システム上の処理と並行して **適切な連絡対応** を行うこと
