# components/shared — 共有プリミティブ

アプリ横断で再利用する低レベルコンポーネント置き場。feature 非依存・副作用最小に保つ。

## 印刷用グローバルスタイル注入（PrintPortal）

`@media print` でアプリ本体を隠す系のスタイルを `document.body` 直下へ注入する場合、
**除外セレクタは per-instance な id/testId ではなく、全ポータル共通の固定属性をキーにする**こと。

- ❌ `body > :not([data-testid="<instance>"]) { display:none }`
  → 同一ページに 2 つ以上同居すると、各ポータルの除外ルールが相手にマッチし
  specificity 競合で全印刷面が消え白紙化する（#187）。
- ✅ `body > :not([data-print-portal]) { display:none }`（固定キー）
  → ポータル同士は互いを隠さない。注入ルールが同一テキストになり打ち消し合わない。
- 同居時に印刷面を 1 件へ限定したい場合は `data-print-active` 等の**アクティブ属性でゲート**し、
  既定は「全ポータル表示（最低 1 面は必ず残る）」にして意図しない全消失を防ぐ。
  注意: 同居する全ポータルを非アクティブ化すると印刷面が 0 になり再び白紙化する。
  印刷時は最低 1 面を active に保つのは呼び出し側責務（保証は既定値に依存し構造的ではない）。

新しい印刷導線を追加する際は、上記の固定キー方式を踏襲し、`PrintPortal` を再利用する。
