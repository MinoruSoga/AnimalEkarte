# Gemini Code Assist Style Guide for Animal Ekarte

This file intentionally holds no independent rules. The style guide, coding conventions, and testing commands are maintained once, in `.claude/CLAUDE.md` (and the directory-level `CLAUDE.md` files it links to) — read those directly.

Do not add rules here that don't already exist in `.claude/CLAUDE.md`. If Gemini Code Assist needs a rule that isn't there, add it to `.claude/CLAUDE.md` first.

Full-repo commands (`go test ./...`, `golangci-lint run ./...`, `pnpm test:run`, `pnpm build`, etc.) must NOT be auto-executed — see `.claude/CLAUDE.md` → Auto-Execution Prohibited Commands.
