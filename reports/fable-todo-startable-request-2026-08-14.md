「着手可能」の定義（この依頼の正）:

## 4. 行ごとの行き先（この4つだけ）

各見出し・各 TASK・§8 の各行について、次のどれか1つ。

| 行き先 | 使うとき |
|--------|----------|
| `KEEP` | 次の一手が今できる。todo.md の open 実行リストに残す |
| `ARCHIVE` | 済んだ記録。§7.1 か git に閉じ、open リストから消す |
| `HOLD_PO` | まだ PO 裁定が要る。todo-po.md の確認待ちへ |
| `DEFER` | 今期外・gate 未充足。`phase2.html` か todo.md の「着手しない索引」ではなく **open リストの外**へ |

`KEEP` にする行は、必ず **今の次の一手** を1文で書く。前提が未充足なら KEEP にしない。

例外: 「#249 依頼を送る」は KEEP。「#249 の range 値を決める」「外部 import を実装する」は KEEP にしない。

§8.3 の「staging merge」「実 LINE」は、preflight / STG health が未完なら KEEP にしない（DEFER か、前提が揃うまでリストに載せない）。
