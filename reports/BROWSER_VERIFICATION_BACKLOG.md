## 完了時の bug.md 更新ルール

1. 本表で PASS を付けた BUG のみ、`bug.md` 個票の `原文シナリオ再検証` を PASS に更新してよい  
2. ブラウザ PASS かつ回帰なしのときだけ `VERIFIED_FIXED` を検討（人間判断）  
3. FAIL は個票を OPEN に戻すか、新規 BUG を切る  
4. 件数サマリは個票更新後に機械抽出し直す
