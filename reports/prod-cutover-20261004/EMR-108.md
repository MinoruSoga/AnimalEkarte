## Type A: 死亡日より後のカルテが存在（1,545 件）

検出 SQL:

```sql
SELECT p.id AS pet_id, p.owner_id, p.clinic_id,
       (p.deceased_at AT TIME ZONE 'Asia/Tokyo')::date AS deceased_date_jst,
       p.birth_date, m.last_mr_date, m.last_finalized_mr_date,
       m.post_death_mr_count,
       m.last_mr_date - (p.deceased_at AT TIME ZONE 'Asia/Tokyo')::date AS gap_days
FROM pets p
JOIN LATERAL (
  SELECT max(mr.date)                                        AS last_mr_date,
         max(mr.date) FILTER (WHERE mr.status='finalized')   AS last_finalized_mr_date,
         count(*) FILTER (
           WHERE mr.date > (p.deceased_at AT TIME ZONE 'Asia/Tokyo')::date
         )                                                   AS post_death_mr_count
  FROM medical_records mr
  WHERE mr.pet_id = p.id AND mr.deleted_at IS NULL
) m ON true
WHERE p.deleted_at IS NULL
  AND p.deceased_at IS NOT NULL
  AND m.last_mr_date > (p.deceased_at AT TIME ZONE 'Asia/Tokyo')::date;
```

観察:

- **全 1,545 件で post-death カルテに finalized が含まれる**（draft だけの誤検出なし）。
- 死亡日〜最終カルテ日のギャップ分布: 1–7日 859 / 8–30日 329 / 31–180日 160 / 181–365日 86 / 365日超 111。最大ギャップは約 18.5 年（死亡 2004-03-01 → 最終カルテ 2022-09-18 の 1 件）。
- 数日以内ギャップの一部は「死亡確定後の事務的カルテ記載」等の正当操作の可能性があるため、ギャップ日数でレビュー優先度を分けることを推奨（行データの `gap_days` 降順）。

## Type B: 死亡日より後の来院実績が存在（86 件）

検出 SQL（来院実績 = `status IN ('checked_in','in_consultation','accounting','completed')`、キャンセル/no_show は除外）:

```sql
SELECT p.id AS pet_id, ..., v.last_visit_date, v.post_death_visit_count, ... AS gap_days
FROM pets p
JOIN LATERAL (
  SELECT max((a.start_time AT TIME ZONE 'Asia/Tokyo')::date) AS last_visit_date,
         count(*) FILTER (
           WHERE (a.start_time AT TIME ZONE 'Asia/Tokyo')::date
               > (p.deceased_at AT TIME ZONE 'Asia/Tokyo')::date
         ) AS post_death_visit_count
  FROM appointments a
  WHERE a.pet_id = p.id AND a.deleted_at IS NULL
    AND a.status IN ('checked_in','in_consultation','accounting','completed')
) v ON true
WHERE p.deleted_at IS NULL AND p.deceased_at IS NOT NULL
  AND v.last_visit_date > (p.deceased_at AT TIME ZONE 'Asia/Tokyo')::date;
```

観察: 86 件全てが Type A に包含（来院すればカルテが残るため）。最悪例は 死亡 2021-03-09 ののち 45 回来院（最終 2026-08-11）の 1 件 — 死亡記録が明らかに誤り。
