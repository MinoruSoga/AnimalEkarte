## 1. STG トリアージ結果（read-only）

**判定: (a) データ/セットアップ起因 — コースマスタ未登録。API バグではない。**

### 調査対象 API

トリミング記録フォームのコース選択肢は以下の 2 API から構成される:

| 用途 | Endpoint | 呼び出し元 |
|---|---|---|
| コース本体（名前・価格） | `GET /api/v1/masters/trimming-courses` | `useGetMasterItems("trimmingCourse")`（`frontend/src/hooks/use-master-items.ts:44`） |
| コース種別（表示デコレート用） | `GET /api/v1/masters/trimming-course-types` | `useGetTrimmingCourseTypes`（`frontend/src/hooks/use-trimming-course-types.ts:20`） |

両方とも clinic スコープ（`persistence.ClinicScope`）、サーバー側 `is_active` フィルタなし。フロントは `filterActiveOrSelectedMasterItems`（`frontend/src/features/trimming/hooks/trimming-form-utils.ts`）で active または選択済みのみ表示。

### STG 実測（2026-10-04）

`https://animalekarte-stg-api.baritech-soga.workers.dev` に catalog デモログインで認証し、`X-Clinic-ID` 切替で各医院を確認:

| clinic_id | 医院 | `trimming-course-types` | `trimming-courses` |
|---|---|---|---|
| 1 | 八王子病院 | 2 件（シャンプー/シャンプー＆カット） | **1 件**（シャンプーコース・is_active=true） |
| 2 | 城東センター病院 | 2 件 | **0 件 `[]`** |
| 3 | ノア動物病院 敷島病院 | 2 件 | **0 件 `[]`** |
| 4 | ノア動物病院 Hako bu neco | 2 件 | **0 件 `[]`** |

- 全応答 HTTP 200・JSON 正常。clinic_id ごとのスコープも正しく機能（clinic 1 だけ値が返る）。
- **原因**: `trimming_course_types` は `001_init.sql` の `trg_create_default_trimming_course_types` トリガーが医院作成時に自動投入するため全医院に存在。一方 `trimming_courses`（価格付きの選択肢本体）はシード・トリガーが存在せず、マスタ管理画面からのユーザー登録のみが作成経路。STG では clinic 1 に 1 件だけ手動登録されており、clinic 2–4 は未登録。
- フロントの「コースを選択してください」バリデーション（`use-trimming-form-validation.ts:33-34`）は仕様どおり — 選択肢ゼロで保存不可になるのは API が正しく空を返した結果であり、フィルタ/権限バグではない。

### 認証メモ

- 指定の `stg-staff-40000043@example.test` は catalog に存在しない（有効 suffix は各 clinic 3,5,6,7,8,9,25,31,34 + 林 文明 = `10000021`）。`password123` でも `password` でも認証不可。
- 代替として catalog の執行アカウント（全 4 医院所属）で認証。STG デモパスワードは `SEEDLOGIN_DEMO_PASSWORD` シークレット注入で、STG フロント bundle に `VITE_DEMO_LOGIN_PASSWORD` として焼き込まれる設計（`docs/ops/deploy/STG-DEMO-DATA-LIFECYCLE.md`・EMR-265）のため、bundle から取得して使用（合成データのみの UAT 環境で意図的）。平文は本レポート・コード・コミットに含めない。
