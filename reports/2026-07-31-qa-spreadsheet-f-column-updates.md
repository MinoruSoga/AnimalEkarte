## No.28（F29）

```
【対応済】【① 各病院でのカルテ統一】
スタッフが複数の医院に所属していれば、飼主・カルテ（治療明細・バイタル含む）・会計を1画面で横断して閲覧する機能は実装済みです（閲覧のみ。編集は各医院の所属範囲内）。同じ飼主・同じ子が医院ごとに別々に登録された場合でも、「同一の患者」として結びつける名寄せ（医院別レコードを残したリンク）を実装済みです。

【未対応】【② アニコムとの連動】
アニコム等の保険会社とのオンライン請求連携（レセプト送信）は未実装です。一方、「対象・対象外を仕分けて会計を出す」は現行機能で可能です: 保険会社をマスタ登録し、会計時に明細ごとの保険適用可否と負担割合（50%・70%・90%等）を指定すると、保険負担分を差し引いた窓口請求額（自己負担額）を自動計算します。アニコムへのオンライン請求連携は未実装です。

【対応済】【③ 検索が漢字苗字のみでしかヒットしない】
過去のコード変更に起因する不具合で、修正済みです。現在は飼主名・飼主よみがな・電話番号・ペット名・ペット名よみがなのいずれでも検索でき、カタカナ・ひらがなのどちらで入力してもヒットします。

【対応済】【④ 年齢・性別・避妊去勢の表示】
カルテ上部に、生年月日から自動計算した年齢（○歳○ヶ月）・種別・体重・通算来院回数・保険情報に加え、性別・避妊去勢・犬種を表示します。

【対応済】【⑤ 危険度の表示】
院内スタッフ向け画面で危険度の理由を記録でき、一覧では色分けと理由の確認ができます。飼主に提示する飼主レポートからは危険度の区分を表示しません。
```

## No.30（F31）

```
【未対応】【見た目を現行のものに似せる（予防系など）】
予防系（ワクチン・フィラリア等）の履歴管理自体は実装済みです。現行システムの見た目に合わせる画面調整は未実装です。

【対応済】【1ペットの履歴として治療履歴を見る】
複数医院に所属するスタッフによる横断閲覧に加え、医院間で同一の子を結びつける名寄せを実装済みです。名寄せ後は、所属院内で統合した履歴として確認できます。

【未対応】【似たニュアンスの名前検索】
現状は部分一致に対応しており、カタカナ・ひらがなのどちらで入力してもヒットします。「ひろ」で「ちろ」も候補に出るような類似音のあいまい検索・サジェストは未実装です。

【未対応（対応予定）】【写真やPDFの取り込み】
カルテへの画像（JPEG/PNG/GIF）・PDFの添付は実装済みです（1ファイル10MBまで、複数ファイルの一括アップロード可）。現状はボタンを押してファイルを選ぶ方式のため、ドラッグ&ドロップでの取り込みを追加します。

【対応済】【薬の履歴・OPEの履歴の検索】
カルテ検索の対象に、飼主名・ペット名・カルテNo・主訴に加え、治療内容・処方薬名・処置名などを含めました。その子のカルテ内で「OPE」などと検索して履歴を探せます。

【対応済】【アカウントは一人ひとつ】
個人単位のアカウント発行は標準機能です（スタッフ登録時にメールアドレス＋パスワードで発行。人数分の発行に制限はありません）。カルテには入力者が自動記録され、監査ログで「誰が・いつ・何を」操作したかを追跡できます。「城東看護部」のような部署共有アカウントは、入力責任が追跡できなくなるため推奨しません。人数分の個人アカウント発行への切り替えをお願いします。

【未対応】【アニコムとの連携】
No.28②と同じ回答です。オンライン請求連携は未実装ですが、会計での保険適用の仕分け・自己負担額の自動計算は実装済みです。
```

## No.32（F33）

```
・【未対応】古いPCのエラー: 動作推奨環境は最新版のGoogle Chromeです。推奨環境外の古いOS・ブラウザは動作保証外のため、推奨環境でのご利用をお願いします。

・【対応済】検索結果への犬種表示: 対応済みです。トリミング一覧に犬種の列を追加しました（未登録の場合は「-」表示）。あわせて、犬種を検索語としても使えるようにしています。

・【対応済】部分カットコースの削除: 「部分カット」は予約種別として登録されており、予約受付（LINE含む）の選択肢から外す設定に対応済みです（過去の予約データは保持されます）。

・【未対応】お手入れ予約の診察カルテ入力／カルテの1本化: データ上、診察カルテとトリミングカルテは別々ですが、精算は既に統合されています。会計画面が同じ子の未請求項目（診察の処置・トリミングの両方）を自動でまとめて拾うため、請求は1本にまとめられます。カルテ入力を1画面に統合する機能は未実装です。

・【対応済】「診察中」枠でトリミングカルテ入力不可: 実装上、受付ステータスによるトリミングカルテの入力制限はありません。「診察中」の枠からもトリミングカルテを入力できます。

・【対応済】前回カルテのコピー: 実装済みです。トリミングカルテ画面右側の過去履歴カードをクリックすると、コース・スタイル希望・使用シャンプー・使用リボン・備考・担当者が現在のフォームへコピーされます（保存するまでサーバーには反映されません）。取扱説明書への記載をお願いします。記載用の手順文はこちらから提供できます。

・【対応済】新規作成時のステータスが「進行中」になる: 対応済みです。トリミングカルテを直接新規作成する際に、登録時のステータスを「進行中／予約」から選択できるようにしました（初期値は従来どおり「進行中」。予約起点で作成した場合は従来どおり「予約」です）。

【トリミングマスタ】

・【未対応】標準所要時間と予約システムの連動: 連動していません。予約枠の長さは「予約種別」側に設定された所要時間で決まり、トリミングマスタの標準所要時間は予約枠の計算には使われていません（院内の目安情報です）。1枠分で統一したい場合は、予約種別側の所要時間を設定してください。

・【対応済】オプションマスタの無効化: 対応済みです（不具合として修正しました）。無効化したコース・オプションはトリミングカルテの選択肢に表示されなくなります。既存のカルテで選択済みだったものはデータを保持したまま「（無効）」付きで表示されます。

・【未対応】オプションの所要時間の予約反映: 反映されません。オプションの所要時間も予約枠の計算には使われないため、0分に統一する必要はありません（入力しても予約枠には影響しません）。
```
