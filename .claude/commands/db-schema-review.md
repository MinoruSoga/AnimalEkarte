# /db-schema-review

データベーススキーマ設計をレビューし、改善提案を行います。

## レビュー項目

### 正規化
- [ ] 1NF（第一正規形）達成
- [ ] 2NF（第二正規形）達成
- [ ] 3NF（第三正規形）達成
- [ ] 過度な正規化がないか

### インデックス戦略
- [ ] PRIMARY KEY 設定
- [ ] FOREIGN KEY 設定
- [ ] 検索カラムのインデックス
- [ ] 複合インデックスの活用

### パフォーマンス
- [ ] N+1 クエリ対策
- [ ] 参照整合性
- [ ] 継承戦略（ST または JT）
- [ ] パーティショニング必要性

### セキュリティ
- [ ] 機密データ暗号化
- [ ] Row-level security
- [ ] 監査ログ

## 出力形式

```markdown
## スキーマ分析

### テーブル一覧
- table_1: XX columns
- table_2: XX columns
...

### 改善提案
1. [High] インデックス追加: ...
2. [Medium] 正規化: ...
3. [Low] パフォーマンス: ...

### ERD 更新
- Updated: docs/ERD.md
```

## 使用エージェント

`architect` (Opus) のレビュー実施
